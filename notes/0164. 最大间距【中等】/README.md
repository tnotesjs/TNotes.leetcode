## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/maximum-gap/)

给定一个无序的数组 `nums`，返回数组在排序之后，相邻元素之间最大的差值。如果数组元素个数小于 2，则返回 `0`。

您必须编写一个在「线性时间」内运行并使用「线性额外空间」的算法。

---

示例 1：

```txt
输入: nums = [3, 6, 9, 1]
输出: 3
```

解释: 排序后的数组是 `[1, 3, 6, 9]`，其中相邻元素 `(3, 6)` 和 `(6, 9)` 之间都存在最大差值 3。

---

示例 2：

```txt
输入: nums = [10]
输出: 0
```

解释: 数组元素个数小于 2，因此返回 0。

---

提示：

- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

- 时间复杂度：$O(n)$，其中 $n$ 是数组长度
- 空间复杂度：$O(n)$，桶数组的大小

算法思路：

- $gap_{max} \;\geq\; \frac{max - min}{n - 1}$：根据鸽巢原理，排序后相邻元素的最大间距至少是平均值
- $bucketSize = \max\!\left(1,\; \left\lfloor \frac{max - min}{n - 1} \right\rfloor\right)$：保证正确性
  - 桶内任意两数之差满足「桶内差 $< bucketSize \leq$ 平均间距 $\leq gap_{max}$」，故严格小于全局最大间距
  - 最大间距只可能出现在相邻非空桶之间（后一个桶的最小值 $-$ 前一个桶的最大值），因此每个桶只需记录最大值、最小值
- $\text{bucketCount} = \left\lfloor \frac{max-min}{\text{bucketSize}} \right\rfloor + 1$：保证覆盖性
  - 确保 `nums` 中的所有成员都能入桶

## 3. 【AI】这道题为什么要用“桶”？

核心目的就一条：**在 $O(n)$ 时间内求出排序后相邻元素的最大差，而不真的去排序。**

### 3.1. 约束逼出来的

题目要求线性时间 + 线性额外空间。普通排序是 $O(n\log n)$，过不了这个约束。

但答案的定义本身又依赖「排序后相邻」——所以需要一种办法：**不用完全排好序，也能找到那个最大相邻差。**

### 3.2. 桶在干什么

桶不是为了「排序」，而是为了做一次**粗粒度分组**：

1. 按数值范围把数丢进若干等宽桶
2. 每个桶只记 **min / max**（桶内细节直接丢掉）
3. 答案只可能出现在**相邻非空桶之间**：`后桶.min - 前桶.max`

之所以敢这么做，是因为桶宽选成了 $gap_{max}$ 的下界——**桶内差一定小于真正的最大间距**，所以桶内不用比。

### 3.3. 一句话

用桶 = **用 $O(n)$ 的「分桶 + 只比桶边界」代替 $O(n\log n)$ 的「全排序再扫相邻差」**。

## 4. 【AI】推导：`桶大小 = (max - min) / (n - 1)`

### 4.1. 从排序后出发

对 `nums` 排序后，得到有序序列：

$$a_0 \leq a_1 \leq a_2 \leq \cdots \leq a_{n-1}$$

定义相邻间距：

$$gap_i = a_i - a_{i-1}, \quad i = 1, 2, \ldots, n-1$$

共有 **(n - 1) 个间距**，把它们全部加起来：

$$\sum_{i=1}^{n-1} gap_i = a_{n-1} - a_0 = max - min$$

---

### 4.2. 鸽巢原理 — 至少有一个间距 ≥ 平均值

> **(n - 1) 个间距的总和 = (max - min)，那么至少有一个间距不会小于平均值。**

$$\max(gap_i) \;\geq\; \frac{max - min}{n - 1}$$

这就是最大间距的**下界**。记为：

$$\boxed{gap_{max} \;\geq\; \frac{max - min}{n - 1}}$$

---

### 4.3. 桶的大小选为这个下界

设桶大小：

$$B = \left\lfloor \frac{max - min}{n - 1} \right\rfloor$$

**关键性质：同一桶内，任意两个元素之差 < B**

因为桶 `i` 覆盖的范围是 $[min + i \cdot B,\; min + (i+1) \cdot B)$，区间长度为 `B`。

所以桶内任意两个元素的差：

$$a - b < B \leq \frac{max - min}{n-1} \leq gap_{max}$$

**结论：桶内的最大差值严格小于全局最大间距。**

$$\text{桶内最大差} < B \leq gap_{max}$$

---

### 4.4. 所以最大间距一定在桶与桶之间

既然：

- 桶内任何两个元素的差都 **< gap_max**
- 而 gap_max **≥ (max-min)/(n-1) ≥ B**

那么 **gap_max 不可能在同一个桶内**，只可能出现在：

$$\text{某个桶的 min} - \text{前一个非空桶的 max}$$

---

### 4.5. 用具体例子感受

```
nums = [1, 3, 6, 9]
排序后: [1, 3, 6, 9]    n = 4

间距:   2,  3,  3       共 n-1 = 3 个间距
总和:   8 = max(9) - min(1)

平均间距 = 8 / 3 ≈ 2.67
最大间距 = 3  ≥  2.67  ✓  （鸽巢原理成立）
```

选 `B = ⌊8/3⌋ = 2`，把 4 个数放入 5 个桶：

```
桶0: [1,3) → {1}       → 不看桶内，看桶间
桶1: [3,5) → {3}
桶2: [5,7) → {6}
桶3: [7,9) → { }
桶4: [9,11)→ {9}

桶间差:
  桶0→桶1:  3 - 1 = 2
  桶1→桶2:  6 - 3 = 3  ← 最大间距！
  桶2→桶4:  9 - 6 = 3  ← 最大间距！
```

**桶内没有两个元素挨着比较，所有比较都是跨桶的。**

---

### 4.6. 总结

```
                    n-1个间距
              ┌──────────────────┐
              │  gap₁ gap₂ ... gapₙ₋₁ │
              └──────────────────┘
                      │
                      ▼
           总和 = max - min
                      │
                      ▼
        平均值 = (max-min) / (n-1)
                      │
                      ▼
      至少有一个 gap ≥ 平均值（鸽巢原理）
                      │
                      ▼
        桶大小选为这个平均值 → 桶内差 < gap_max
                      │
                      ▼
         最大间距必在相邻桶之间 → O(n) 解法
```
