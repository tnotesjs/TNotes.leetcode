## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/number-of-dice-rolls-with-target-sum/)

这里有 `n` 个一样的骰子，每个骰子上都有 `k` 个面，分别标号为 `1` 到 `k`。

给定三个整数 `n`、`k` 和 `target`，请返回投掷骰子的所有可能得到的结果（共有 `k^n` 种方式），使得骰子面朝上的数字总和等于 `target`。

由于答案可能很大，你需要对 `10^9 + 7` 取模。

---

示例 1：

```txt
输入：n = 1, k = 6, target = 3
输出：1
解释：你掷了一个有 6 个面的骰子。
得到总和为 3 的结果的方式只有一种。
```

示例 2：

```txt
输入：n = 2, k = 6, target = 7
输出：6
解释：你掷了两个骰子，每个骰子有 6 个面。
有 6 种方式得到总和为 7 的结果: 1+6, 2+5, 3+4, 4+3, 5+2, 6+1。
```

示例 3：

```txt
输入：n = 30, k = 30, target = 500
输出：222616187
解释：返回的结果必须对 109 + 7 取模。
```

---

提示：

- `1 <= n, k <= 30`
- `1 <= target <= 1000`

## 2. 🎯 s.1 - 动态规划

::: code-group

```js [js]
/**
 * @param {number} n
 * @param {number} k
 * @param {number} target
 * @return {number}
 */
var numRollsToTarget = function (n, k, target) {
  const MOD = 1e9 + 7
  const dp = Array.from({ length: n + 1 }, () => new Array(target + 1).fill(0))
  dp[0][0] = 1
  for (let i = 1; i <= n; i++) {
    for (let j = i; j <= target; j++) {
      for (let f = 1; f <= k && f <= j; f++) {
        dp[i][j] = (dp[i][j] + dp[i - 1][j - f]) % MOD
      }
    }
  }
  return dp[n][target]
}
```

```c [c]
int numRollsToTarget(int n, int k, int target) {
    long long MOD = 1000000007;
    long long dp[n + 1][target + 1];
    memset(dp, 0, sizeof(dp));
    dp[0][0] = 1;
    for (int i = 1; i <= n; i++) {
        for (int j = i; j <= target; j++) {
            for (int f = 1; f <= k && f <= j; f++) {
                dp[i][j] = (dp[i][j] + dp[i - 1][j - f]) % MOD;
            }
        }
    }
    return (int)dp[n][target];
}
```

```py [py]
class Solution:
    def numRollsToTarget(self, n: int, k: int, target: int) -> int:
        MOD = 10 ** 9 + 7
        dp = [[0] * (target + 1) for _ in range(n + 1)]
        dp[0][0] = 1
        for i in range(1, n + 1):
            for j in range(i, target + 1):
                for f in range(1, k + 1):
                    if f > j:
                        break
                    dp[i][j] = (dp[i][j] + dp[i - 1][j - f]) % MOD
        return dp[n][target]
```

:::

- 时间复杂度：$O(n \times target \times k)$，三层循环遍历
- 空间复杂度：$O(n \times target)$，DP 表的大小

算法思路：

- 定义 `dp[i][j]` 表示投掷 `i` 个骰子得到总和为 `j` 的方法数
- 初始化 `dp[0][0] = 1`，0 个骰子得到总和 0 有 1 种方式
- 转移：对于每个骰子面值 `f`（`1` 到 `k`），`dp[i][j] += dp[i-1][j-f]`
- 结果对 $10^9 + 7$ 取模
