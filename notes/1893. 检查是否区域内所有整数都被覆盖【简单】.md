## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/check-if-all-the-integers-in-a-range-are-covered/)

给你一个二维整数数组 `ranges` 和两个整数 `left` 和 `right`。每个 `ranges[i] = [starti, endi]` 表示一个从 `starti` 到 `endi` 的闭区间。

如果闭区间 `[left, right]` 内每个整数都被 `ranges` 中至少一个区间覆盖，那么请你返回 `true`，否则返回 `false`。

已知区间 `ranges[i] = [starti, endi]`，如果整数 `x` 满足 `starti <= x <= endi`，那么我们称整数 `x` 被覆盖了。

---

示例 1：

```txt
输入：ranges = [[1,2],[3,4],[5,6]], left = 2, right = 5
输出：true

解释：
2 到 5 的每个整数都被覆盖了：
- 2 被第一个区间覆盖。
- 3 和 4 被第二个区间覆盖。
- 5 被第三个区间覆盖。
```

---

示例 2：

```txt
输入：ranges = [[1,10],[10,20]], left = 21, right = 21
输出：false

解释：
21 没有被任何一个区间覆盖。
```

---

提示：

- `1 <= ranges.length <= 50`
- `1 <= starti <= endi <= 50`
- `1 <= left <= right <= 50`

## 2. 🎯 s.1 - 差分数组

::: code-group

```js [js]
/**
 * @param {number[][]} ranges
 * @param {number} left
 * @param {number} right
 * @return {boolean}
 */
var isCovered = function (ranges, left, right) {
  // 索引到 51，处理 r+1
  const diff = new Array(52).fill(0)

  for (const [l, r] of ranges) {
    // 区间开始位置+1
    diff[l] += 1
    // 区间结束的下一个位置-1
    diff[r + 1] -= 1
  }

  let cover = 0
  for (let i = 1; i <= 50; i += 1) {
    // 计算前缀和，得到当前位置被覆盖次数
    cover += diff[i]
    // 检查目标范围内是否未被覆盖
    if (i >= left && i <= right && cover === 0) return false
  }
  return true
}
```

:::

- 时间复杂度：$O(M)$，$M=50$ 常数范围内线性扫描
- 空间复杂度：$O(M)$，常数大小差分数组

算法思路：

- 创建长度为 52 的差分数组 diff，用于标记区间覆盖情况
- 遍历 ranges，对每个区间 `[l, r]` 执行差分操作：`diff[l]++`，`diff[r+1]--`
- 通过前缀和还原覆盖次数：从 1 到 50 累加 `diff[i]`，得到每个位置的实际覆盖次数
- 检查 `[left, right]` 范围内是否所有位置的覆盖次数都大于 0
