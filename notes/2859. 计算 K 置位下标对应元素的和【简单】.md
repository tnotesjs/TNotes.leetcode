## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/sum-of-values-at-indices-with-k-set-bits/)

给你一个下标从 0 开始的整数数组 `nums` 和一个整数 `k`。

请你用整数形式返回 `nums` 中的特定元素之和，这些特定元素满足：其对应下标的二进制表示中恰存在 `k` 个置位。

整数的二进制表示中的 1 就是这个整数的置位。

例如，`21` 的二进制表示为 `10101`，其中有 `3` 个置位。

---

示例 1：

```txt
输入：nums = [5,10,1,5,2], k = 1
输出：13

解释：
下标的二进制表示是：
0 = 0002
1 = 0012
2 = 0102
3 = 0112
4 = 1002
下标 1、2 和 4 在其二进制表示中都存在 k = 1 个置位。
因此，答案为 nums[1] + nums[2] + nums[4] = 13。
```

---

示例 2：

```txt
输入：nums = [4,3,2,1], k = 2
输出：1

解释：
下标的二进制表示是：
0 = 002
1 = 012
2 = 102
3 = 112
只有下标 3 的二进制表示中存在 k = 2 个置位。
因此，答案为 nums[3] = 1。
```

---

提示：

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^5`
- `0 <= k <= 10`

## 2. 🎯 s.1 - 位运算

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var sumIndicesWithKSetBits = function (nums, k) {
  // 计算一个数字的二进制表示中 1 的个数
  const countSetBits = (num) => {
    let count = 0
    while (num > 0) {
      count += num & 1
      num >>= 1
    }
    return count
  }

  let sum = 0
  for (let i = 0; i < nums.length; i++) {
    if (countSetBits(i) === k) {
      sum += nums[i]
    }
  }

  return sum
}
```

:::

- 时间复杂度：$O(n \log n)$,n 是数组 nums 的长度,计算每个下标的置位数需要 $O(\log n)$ 时间
- 空间复杂度：$O(1)$,只使用常数额外空间

算法思路：

- 定义辅助函数 countSetBits 计算一个数字的二进制表示中 1 的个数
- 遍历数组的每个下标 i
- 如果下标 i 的二进制表示中恰好有 k 个置位,则累加 nums[i]
- 返回累加和
