## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/license-key-formatting/)

给定一个许可密钥字符串 `s`，仅由字母、数字字符和破折号组成。字符串由 `n` 个破折号分成 `n + 1` 组。你也会得到一个整数 `k`。

我们想要重新格式化字符串 `s`，使每一组包含 `k` 个字符，除了第一组，它可以比 `k` 短，但仍然必须包含至少一个字符。此外，两组之间必须插入破折号，并且应该将所有小写字母转换为大写字母。

返回 **重新格式化的许可密钥**。

---

示例 1：

```txt
输入：S = "5F3Z-2e-9-w", k = 4
输出："5F3Z-2E9W"

解释：
字符串 S 被分成了两个部分，每部分 4 个字符；
注意，两个额外的破折号需要删掉。
```

---

示例 2：

```txt
输入：S = "2-5g-3-J", k = 2
输出："2-5G-3J"

解释：
字符串 S 被分成了 3 个部分，按照前面的规则描述，
第一部分的字符可以少于给定的数量，其余部分皆为 2 个字符。
```

---

提示：

- `1 <= s.length <= 10^5`
- `s` 只包含字母、数字和破折号 `'-'`.
- `1 <= k <= 10^4`

## 2. s.1 - 从右往左分组

::: code-group

```c [c]
char* licenseKeyFormatting(char* s, int k) {
    int n = strlen(s);
    int cnt = 0;
    for (int i = 0; i < n; ++i) {
        if (s[i] != '-') {
            ++cnt;
        }
    }

    if (cnt == 0) {
        char* ans = malloc(1);
        ans[0] = '\0';
        return ans;
    }

    int len = cnt + (cnt - 1) / k;
    char* ans = malloc(len + 1);
    ans[len] = '\0';

    int p = len - 1;
    int group = 0;
    for (int i = n - 1; i >= 0; --i) {
        if (s[i] == '-') {
            continue;
        }
        if (group == k) {
            ans[p--] = '-';
            group = 0;
        }
        ans[p--] = toupper((unsigned char)s[i]);
        ++group;
    }

    return ans;
}
```

```js [js]
/**
 * @param {string} s
 * @param {number} k
 * @return {string}
 */
var licenseKeyFormatting = function (s, k) {
  const chars = []
  let group = 0

  for (let i = s.length - 1; i >= 0; i--) {
    if (s[i] === '-') continue
    if (group === k) {
      chars.push('-')
      group = 0
    }
    chars.push(s[i].toUpperCase())
    group++
  }

  return chars.reverse().join('')
}
```

```py [py]
class Solution:
    def licenseKeyFormatting(self, s: str, k: int) -> str:
        chars = []
        group = 0

        for i in range(len(s) - 1, -1, -1):
            if s[i] == '-':
                continue
            if group == k:
                chars.append('-')
                group = 0
            chars.append(s[i].upper())
            group += 1

        chars.reverse()
        return ''.join(chars)
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 为字符串 $s$ 的长度，需要遍历一遍原串并生成结果
- 空间复杂度：$O(n)$，用于存放格式化后的结果

算法思路：

- 设 $s$ 的长度为 $n$。重新分组后，只有最左边一组的长度可以小于 $k$，其余每组恰好 $k$ 个字符，因此从右边开始分组更直接
- 从右往左扫描 $s$，跳过原有破折号，将其余字符转为大写后依次放入结果；每放满 $k$ 个字符就插入一个破折号
- 由于字符是从右往左收集的，最后再调整为从左到右的顺序，即为格式化后的密钥
