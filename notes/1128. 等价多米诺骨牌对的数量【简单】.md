## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/number-of-equivalent-domino-pairs/)

给你一组多米诺骨牌 `dominoes`。

形式上，`dominoes[i] = [a, b]` 与 `dominoes[j] = [c, d]` 等价当且仅当 (`a == c` 且 `b == d`) 或者 (`a == d` 且 `b == c`)。即一张骨牌可以通过旋转 `0` 度或 `180` 度得到另一张多米诺骨牌。

在 `0 <= i < j < dominoes.length` 的前提下，找出满足 `dominoes[i]` 和 `dominoes[j]` 等价的骨牌对 `(i, j)` 的数量。

---

示例 1：

```txt
输入：dominoes = [[1,2],[2,1],[3,4],[5,6]]
输出：1
```

---

示例 2：

```txt
输入：dominoes = [[1,2],[1,2],[1,1],[1,2],[2,2]]
输出：3
```

---

提示：

- `1 <= dominoes.length <= 4 * 10^4`
- `dominoes[i].length == 2`
- `1 <= dominoes[i][j] <= 9`

## 2. 🎯 s.1 - 字符串键

::: code-group

```js [js]
/**
 * @param {number[][]} dominoes
 * @return {number}
 */
var numEquivDominoPairs = function (dominoes) {
  const count = new Map()
  let result = 0

  for (const [a, b] of dominoes) {
    // 标准化多米诺骨牌表示（较小的数字在前）
    const key = a <= b ? `${a},${b}` : `${b},${a}`

    // 计算当前等价类的对数
    const currentCount = count.get(key) || 0
    result += currentCount // 每新增一个，能与之前的所有组成对
    count.set(key, currentCount + 1)
  }

  return result
}
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 为多米诺骨牌数量，遍历一次数组
- 空间复杂度：$O(n)$，最坏情况下哈希表需存储所有骨牌的计数

算法思路：

- 遍历骨牌数组，将每张骨牌规范化为“小值,大值”格式的字符串键
- 使用哈希表记录每个键出现的次数
- 遍历过程中，当前骨牌能与之前已记录的同类骨牌组成 `currentCount` 对，累加到结果中

## 3. 🎯 s.2 - 数字编码

::: code-group

```js [js]
/**
 * @param {number[][]} dominoes
 * @return {number}
 */
var numEquivDominoPairs = function (dominoes) {
  const map = new Map()
  for (let [a, b] of dominoes) {
    if (a > b) [a, b] = [b, a]
    const key = a * 10 + b // 1..9，安全编码到两位数
    map.set(key, (map.get(key) || 0) + 1)
  }
  let ans = 0
  for (let c of map.values()) {
    ans += (c * (c - 1)) / 2
  }
  return ans
}
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 为多米诺骨牌数量，需遍历数组统计并对哈希表求和
- 空间复杂度：$O(1)$，因骨牌数字范围有限，编码后的键空间大小固定

算法思路：

- 将骨牌规范化（小值在前），通过 `a * 10 + b` 编码为唯一整数键
- 使用哈希表统计各编码出现的频次
- 遍历频次 $c$，利用组合公式 $c(c-1)/2$ 累加等价对数量
