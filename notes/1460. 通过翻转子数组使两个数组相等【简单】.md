## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/make-two-arrays-equal-by-reversing-subarrays/)

给你两个长度相同的整数数组 `target` 和 `arr`。每一步中，你可以选择 `arr` 的任意非空子数组并将它翻转。你可以执行此过程任意次。

如果你能让 `arr` 变得与 `target` 相同，返回 True；否则，返回 False。

---

示例 1：

```txt
输入：target = [1,2,3,4], arr = [2,4,1,3]
输出：true

解释：
你可以按照如下步骤使 arr 变成 target：
  1. 翻转子数组 [2,4,1]，arr 变成 [1,4,2,3]
  2. 翻转子数组 [4,2]，arr 变成 [1,2,4,3]
  3. 翻转子数组 [4,3]，arr 变成 [1,2,3,4]
上述方法并不是唯一的，还存在多种将 arr 变成 target 的方法。
```

示例 2：

```txt
输入：target = [7], arr = [7]
输出：true

解释：
arr 不需要做任何翻转已经与 target 相等。
```

示例 3：

```txt
输入：target = [3,7,9], arr = [3,7,11]
输出：false

解释：
arr 没有数字 9，所以无论如何也无法变成 target。
```

---

提示：

- `target.length == arr.length`
- `1 <= target.length <= 1000`
- `1 <= target[i] <= 1000`
- `1 <= arr[i] <= 1000`

## 2. 🎯 s.1 - 暴力解法

::: code-group

```js [js]
/**
 * @param {number[]} target
 * @param {number[]} arr
 * @return {boolean}
 */
var canBeEqual = function (target, arr) {
  return (
    target.sort((a, b) => a - b).join('') === arr.sort((a, b) => a - b).join('')
  )
}
```

:::

- 时间复杂度：$O(n \log n)$，排序两数组
- 空间复杂度：$O(1)$，就地排序（或 $O(n)$ 取决于排序实现）

算法思路：

- 反转子数组等价于数组可自由重排，因此只要元素频次一致即可相等
- 将 `target` 与 `arr` 排序后逐项比较，相等则可通过若干反转得到；否则不可

## 3. 🎯 s.2 - 计数（哈希表）

::: code-group

```js [js]
/**
 * @param {number[]} target
 * @param {number[]} arr
 * @return {boolean}
 */
var canBeEqual = function (target, arr) {
  if (target.length !== arr.length) return false
  const count = new Map()
  for (const x of target) {
    count.set(x, (count.get(x) || 0) + 1)
  }
  for (const x of arr) {
    if (!count.has(x)) return false
    const c = count.get(x) - 1
    if (c === 0) count.delete(x)
    else count.set(x, c)
  }
  return count.size === 0
}
```

:::

- 时间复杂度：$O(n)$，单次遍历计数和匹配
- 空间复杂度：$O(n)$，哈希表存储频次

算法思路：

- 反转等价于重排，只需验证两数组元素频次是否一致
- 用哈希表统计 `target` 中每个值的出现次数，再遍历 `arr` 抵消计数
- 若过程中出现负数/缺失或最终计数不为空，则不可；全部抵消则可相等
