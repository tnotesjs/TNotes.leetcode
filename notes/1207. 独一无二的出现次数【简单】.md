## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/unique-number-of-occurrences/)

给你一个整数数组 `arr`，如果每个数的出现次数都是独一无二的，就返回 `true`；否则返回 `false`。

---

示例 1：

```txt
输入：arr = [1,2,2,1,1,3]
输出：true
```

解释：

- 在该数组中，1 出现了 3 次，2 出现了 2 次，3 只出现了 1 次。
- 没有两个数的出现次数相同。

---

示例 2：

```txt
输入：arr = [1,2]
输出：false
```

---

示例 3：

```txt
输入：arr = [-3,0,1,-3,1,1,1,-3,10,0]
输出：true
```

---

提示：

- `1 <= arr.length <= 1000`
- `-1000 <= arr[i] <= 1000`

## 2. 🎯 s.1 - 计数校验

::: code-group

```js [js]
/**
 * @param {number[]} arr
 * @return {boolean}
 */
var uniqueOccurrences = function (arr) {
  // 统计每个数的出现次数
  const freq = new Map()
  for (const num of arr) {
    freq.set(num, (freq.get(num) || 0) + 1)
  }

  // 检查出现次数是否都唯一
  const seen = new Set()
  for (const count of freq.values()) {
    if (seen.has(count)) return false
    seen.add(count)
  }

  return true
}
```

:::

- 时间复杂度：$O(N)$，两次线性遍历完成计数与校验
- 空间复杂度：$O(N)$，哈希与集合存储频次

算法思路：

- 先用哈希表统计每个数字的出现次数
- 再用集合收集次数，判断是否有重复
