## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/reverse-degree-of-a-string/)

给你一个字符串 `s`，计算其反转度。

反转度的计算方法如下：

1. 对于每个字符，将其在反转字母表中的位置（`'a'` = 26, `'b'` = 25, ..., `'z'` = 1）与其在字符串中的位置（下标从 1 开始）相乘。
2. 将这些乘积加起来，得到字符串中所有字符的和。

返回反转度。

---

示例 1：

```txt
输入：s = "abc"
输出：148
```

解释：

| 字母 | 反转字母表中的位置 | 字符串中的位置 | 乘积 |
| ---- | ------------------ | -------------- | ---- |
| 'a'  | 26                 | 1              | 26   |
| 'b'  | 25                 | 2              | 50   |
| 'c'  | 24                 | 3              | 72   |

反转度是 `26 + 50 + 72 = 148`。

---

示例 2：

```txt
输入：s = "zaza"
输出：160
```

解释：

| 字母 | 反转字母表中的位置 | 字符串中的位置 | 乘积 |
| ---- | ------------------ | -------------- | ---- |
| 'z'  | 1                  | 1              | 1    |
| 'a'  | 26                 | 2              | 52   |
| 'z'  | 1                  | 3              | 3    |
| 'a'  | 26                 | 4              | 104  |

反转度是 `1 + 52 + 3 + 104 = 160`。

---

提示：

- `1 <= s.length <= 1000`
- `s` 仅包含小写字母。

## 2. 🎯 s.1 - 模拟

::: code-group

```js [js]
/**
 * @param {string} s
 * @return {number}
 */
var reverseDegree = function (s) {
  let result = 0

  for (let i = 0; i < s.length; i++) {
    // 反转字母表位置：'a' = 26, 'b' = 25, ..., 'z' = 1
    const reversePos = 26 - (s.charCodeAt(i) - 97)
    // 字符串位置从 1 开始
    const pos = i + 1
    result += reversePos * pos
  }

  return result
}
```

:::

- 时间复杂度：$O(n)$，其中 n 是字符串长度，需要遍历一次字符串
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：

- 按题意模拟，遍历字符串中的每个字符
- 对于每个字符，计算其在反转字母表中的位置：`26 - (charCode - 97)`，即 `'a'` 对应 26，`'z'` 对应 1
- 将反转位置与字符串位置（下标 + 1）相乘，累加到结果中
