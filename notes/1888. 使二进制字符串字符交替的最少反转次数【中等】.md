## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/minimum-number-of-flips-to-make-the-binary-string-alternating/)

给你一个二进制字符串 `s`。你可以按任意顺序执行以下两种操作任意次：

- 类型 1 ：删除 字符串 `s` 的第一个字符并将它 添加 到字符串结尾。
- 类型 2 ：选择 字符串 `s` 中任意一个字符并将该字符 反转，也就是如果值为 `'0'`，则反转得到 `'1'`，反之亦然。

请你返回使 `s` 变成 交替 字符串的前提下， 类型 2 的 最少 操作次数。

我们称一个字符串是 交替 的，需要满足任意相邻字符都不同。

- 比方说，字符串 `"010"` 和 `"1010"` 都是交替的，但是字符串 `"0100"` 不是。

---

示例 1：

```txt
输入：s = "111000"
输出：2
解释：执行第一种操作两次，得到 s = "100011"。
然后对第三个和第六个字符执行第二种操作，得到 s = "101010"。
```

示例 2：

```txt
输入：s = "010"
输出：0
解释：字符串已经是交替的。
```

示例 3：

```txt
输入：s = "1110"
输出：1
解释：对第二个字符执行第二种操作，得到 s = "1010"。
```

---

提示：

- `1 <= s.length <= 10^5`
- `s[i]` 要么是 `'0'`，要么是 `'1'`。

## 2. 🎯 s.1 - 滑动窗口

::: code-group

```js [js]
/**
 * @param {string} s
 * @return {number}
 */
var minFlips = function (s) {
  const n = s.length
  const ss = s + s
  let diff0 = 0,
    diff1 = 0 // 与“01...”和“10...”的不匹配数
  for (let i = 0; i < n; i++) {
    if (ss[i] !== String(i % 2)) diff0++
    if (ss[i] !== String(1 - (i % 2))) diff1++
  }
  let ans = Math.min(diff0, diff1)
  for (let i = n; i < 2 * n; i++) {
    // 加入 i，移除 i-n
    if (ss[i] !== String(i % 2)) diff0++
    if (ss[i] !== String(1 - (i % 2))) diff1++
    if (ss[i - n] !== String((i - n) % 2)) diff0--
    if (ss[i - n] !== String(1 - ((i - n) % 2))) diff1--
    ans = Math.min(ans, diff0, diff1)
  }
  return ans
}
```

```c [c]
#include <string.h>

int minFlips(char* s) {
  int n = strlen(s);
  int diff0 = 0, diff1 = 0;
  for (int i = 0; i < n; i++) {
    int c = s[i] - '0';
    if (c != i % 2) diff0++;
    if (c != 1 - i % 2) diff1++;
  }
  int ans = diff0 < diff1 ? diff0 : diff1;
  for (int i = 0; i < n; i++) {
    int c = s[i] - '0';
    // 加入新元素 s[i] 在位置 n+i
    if (c != (n + i) % 2) diff0++;
    if (c != 1 - (n + i) % 2) diff1++;
    // 移除旧元素 s[i] 在位置 i
    if (c != i % 2) diff0--;
    if (c != 1 - i % 2) diff1--;
    int m = diff0 < diff1 ? diff0 : diff1;
    if (m < ans) ans = m;
  }
  return ans;
}
```

```py [py]
class Solution:
    def minFlips(self, s: str) -> int:
        n = len(s)
        ss = s + s
        diff0 = diff1 = 0
        for i in range(n):
            if int(ss[i]) != i % 2:
                diff0 += 1
            if int(ss[i]) != 1 - i % 2:
                diff1 += 1
        ans = min(diff0, diff1)
        for i in range(n, 2 * n):
            c = int(ss[i])
            if c != i % 2:
                diff0 += 1
            if c != 1 - i % 2:
                diff1 += 1
            oc = int(ss[i - n])
            if oc != (i - n) % 2:
                diff0 -= 1
            if oc != 1 - (i - n) % 2:
                diff1 -= 1
            ans = min(ans, diff0, diff1)
        return ans
```

:::

- 时间复杂度：$O(n)$，其中 n 是字符串长度
- 空间复杂度：$O(n)$，存储拼接字符串

算法思路：

- 将字符串拼接一次自身，模拟所有循环旋转
- 维护窗口内与目标交替串不同的位置数
- 滑动窗口取所有旋转中的最少反转次数
