## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/find-the-sum-of-encrypted-integers/)

给你一个整数数组 `nums`，数组中的元素都是 正 整数。定义一个加密函数 `encrypt`，`encrypt(x)` 将一个整数 `x` 中 每一个 数位都用 `x` 中的 最大 数位替换。比方说 `encrypt(523) = 555` 且 `encrypt(213) = 333`。

请你返回数组中所有元素加密后的 和。

---

示例 1：

```txt
输入：nums = [1,2,3]
输出：6
```

解释：

- 加密后的元素位 `[1,2,3]`。
- 加密元素的和为 `1 + 2 + 3 == 6`。

---

示例 2：

```txt
输入：nums = [10,21,31]
输出：66
```

解释：

- 加密后的元素为 `[11,22,33]`。
- 加密元素的和为 `11 + 22 + 33 == 66`。

---

提示：

- `1 <= nums.length <= 50`
- `1 <= nums[i] <= 1000`

## 2. 🎯 s.1 - 模拟

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var sumOfEncryptedInt = function (nums) {
  const encrypt = (x) => {
    const s = String(x)
    // 找到最大数位
    let maxDigit = '0'
    for (const c of s) {
      if (c > maxDigit) {
        maxDigit = c
      }
    }
    // 所有数位替换为最大数位
    return parseInt(maxDigit.repeat(s.length))
  }

  let sum = 0
  for (const num of nums) {
    sum += encrypt(num)
  }
  return sum
}
```

:::

- 时间复杂度：$O(n \times L)$，其中 n 是数组长度，L 是数字的平均位数
- 空间复杂度：$O(L)$，存储数字的字符串表示

算法思路：

- 对每个数字进行加密：
  - 将数字转换为字符串，找到其中最大的数位
  - 用最大数位替换所有数位，形成新数字
- 将所有加密后的数字累加求和
