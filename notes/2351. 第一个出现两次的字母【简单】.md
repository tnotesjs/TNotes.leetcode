## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/first-letter-to-appear-twice/)

给你一个由小写英文字母组成的字符串 `s`，请你找出并返回第一个出现两次的字母。

注意：

- 如果 `a` 的第二次出现比 `b` 的第二次出现在字符串中的位置更靠前，则认为字母 `a` 在字母 `b` 之前出现两次。
- `s` 包含至少一个出现两次的字母。

---

示例 1：

```txt
输入：s = "abccbaacz"
输出："c"
解释：
字母 'a' 在下标 0 、5 和 6 处出现。
字母 'b' 在下标 1 和 4 处出现。
字母 'c' 在下标 2 、3 和 7 处出现。
字母 'z' 在下标 8 处出现。
字母 'c' 是第一个出现两次的字母，因为在所有字母中，'c' 第二次出现的下标是最小的。
```

---

示例 2：

```txt
输入：s = "abcdd"
输出："d"
解释：
只有字母 'd' 出现两次，所以返回 'd'。
```

---

提示：

- `2 <= s.length <= 100`
- `s` 由小写英文字母组成
- `s` 包含至少一个重复字母

## 2. 🎯 s.1 - 哈希集合

::: code-group

```js [js]
/**
 * @param {string} s
 * @return {character}
 */
var repeatedCharacter = function (s) {
  const seen = new Set()

  for (const char of s) {
    if (seen.has(char)) {
      return char
    }
    seen.add(char)
  }
}
```

:::

- 时间复杂度：$O(N)$，其中 N 是字符串 s 的长度，最多遍历一次字符串
- 空间复杂度：$O(1)$，哈希集合最多存储 26 个小写字母

算法思路：

- 使用哈希集合记录已经出现过的字符
- 遍历字符串，如果当前字符已在集合中，说明这是第一个出现两次的字母，直接返回
- 否则将字符加入集合继续遍历
