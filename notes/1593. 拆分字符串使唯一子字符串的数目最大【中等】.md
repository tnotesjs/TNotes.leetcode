## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/split-a-string-into-the-max-number-of-unique-substrings/)

给你一个字符串 `s`，请你拆分该字符串，并返回拆分后唯一子字符串的最大数目。

字符串 `s` 拆分后可以得到若干 非空子字符串，这些子字符串连接后应当能够还原为原字符串。但是拆分出来的每个子字符串都必须是 唯一的。

注意：子字符串 是字符串中的一个连续字符序列。

---

示例 1：

```txt
输入：s = "ababccc"
输出：5

解释：
一种最大拆分方法为 ['a', 'b', 'ab', 'c', 'cc']。
像 ['a', 'b', 'a', 'b', 'c', 'cc'] 这样拆分不满足题目要求，因为其中的 'a' 和 'b' 都出现了不止一次。
```

示例 2：

```txt
输入：s = "aba"
输出：2

解释：
一种最大拆分方法为 ['a', 'ba']。
```

示例 3：

```txt
输入：s = "aa"
输出：1

解释：
无法进一步拆分字符串。
```

---

提示：

- `1 <= s.length <= 16`
- `s` 仅包含小写英文字母

## 2. 🎯 s.1 - 回溯

::: code-group

```js [js]
/**
 * @param {string} s
 * @return {number}
 */
var maxUniqueSplit = function (s) {
  let res = 0
  const backtrack = (idx, used) => {
    if (idx === s.length) {
      res = Math.max(res, used.size)
      return
    }
    for (let i = idx + 1; i <= s.length; i++) {
      const sub = s.slice(idx, i)
      if (!used.has(sub)) {
        used.add(sub)
        backtrack(i, used)
        used.delete(sub)
      }
    }
  }
  backtrack(0, new Set())
  return res
}
```

```py [py]
class Solution:
    def maxUniqueSplit(self, s: str) -> int:
        self.res = 0

        def backtrack(idx: int, used: set[str]) -> None:
            if idx == len(s):
                self.res = max(self.res, len(used))
                return
            for i in range(idx + 1, len(s) + 1):
                sub = s[idx:i]
                if sub not in used:
                    used.add(sub)
                    backtrack(i, used)
                    used.discard(sub)

        backtrack(0, set())
        return self.res
```

:::

- 时间复杂度：$O(2^n)$，其中 $n$ 是字符串长度，最多 16
- 空间复杂度：$O(n)$，递归栈和已使用子串集合

算法思路：

- 回溯枚举所有可能的分割方式
- 在每个位置尝试不同长度的子串，若该子串未被使用则加入集合并递归
- 递归到末尾时更新最大唯一子串数
