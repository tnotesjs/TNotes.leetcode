## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/maximum-number-of-vowels-in-a-substring-of-given-length)

给你字符串 `s` 和整数 `k`。

请返回字符串 `s` 中长度为 `k` 的单个子字符串中可能包含的最大元音字母数。

英文中的 元音字母 为（`a`, `e`, `i`, `o`, `u`）。

示例 1：

```txt
输入：s = "abciiidef", k = 3
输出：3
解释：子字符串 "iii" 包含 3 个元音字母。
```

示例 2：

```txt
输入：s = "aeiou", k = 2
输出：2
解释：任意长度为 2 的子字符串都包含 2 个元音字母。
```

示例 3：

```txt
输入：s = "leetcode", k = 3
输出：2
解释："lee"、"eet" 和 "ode" 都包含 2 个元音字母。
```

示例 4：

```txt
输入：s = "rhythms", k = 4
输出：0
解释：字符串 s 中不含任何元音字母。
```

示例 5：

```txt
输入：s = "tryhard", k = 4
输出：1
```

提示：

- `1 <= s.length <= 10^5`
- `s` 由小写英文字母组成
- `1 <= k <= s.length`

## 2. 🎯 s.1 - 滑动窗口

::: code-group

```js [js]
/**
 * @param {string} s
 * @param {number} k
 * @return {number}
 */
var maxVowels = function (s, k) {
  const vowels = new Set('aeiou')
  let count = 0
  for (let i = 0; i < k; i++) if (vowels.has(s[i])) count++
  let maxCount = count
  for (let i = k; i < s.length; i++) {
    if (vowels.has(s[i])) count++
    if (vowels.has(s[i - k])) count--
    maxCount = Math.max(maxCount, count)
  }
  return maxCount
}
```

```c [c]
int isVowel(char c) {
    return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
}

int maxVowels(char* s, int k) {
    int n = strlen(s), count = 0;
    for (int i = 0; i < k; i++) if (isVowel(s[i])) count++;
    int maxCount = count;
    for (int i = k; i < n; i++) {
        if (isVowel(s[i])) count++;
        if (isVowel(s[i - k])) count--;
        if (count > maxCount) maxCount = count;
    }
    return maxCount;
}
```

```py [py]
class Solution:
    def maxVowels(self, s: str, k: int) -> int:
        vowels = set('aeiou')
        count = sum(1 for c in s[:k] if c in vowels)
        max_count = count
        for i in range(k, len(s)):
            count += (s[i] in vowels) - (s[i - k] in vowels)
            max_count = max(max_count, count)
        return max_count
```

:::

- 时间复杂度：$O(n)$，其中 n 是字符串长度
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 使用固定大小为 k 的滑动窗口
- 先统计前 k 个字符中的元音数
- 窗口每右移一位，加入新字符、移除旧字符，更新元音计数并维护最大值
