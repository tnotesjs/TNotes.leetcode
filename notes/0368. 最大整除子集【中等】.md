## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/largest-divisible-subset/)

给你一个由无重复正整数组成的集合 `nums`，请你找出并返回其中最大的整除子集 `answer`，子集中每一元素对 `(answer[i], answer[j])` 都应当满足：

- `answer[i] % answer[j] == 0`，或
- `answer[j] % answer[i] == 0`

如果存在多个有效解子集，返回其中任何一个均可。

---

示例 1：

```txt
输入：nums = [1, 2, 3]
输出：[1, 2]
解释：[1, 3] 也会被视为正确答案。
```


---

示例 2：

```txt
输入：nums = [1, 2, 4, 8]
输出：[1, 2, 4, 8]
```

---

提示：

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 2 * 10^9`
- `nums` 中的所有整数互不相同

## 2. s.1 - 动态规划

::: code-group

```c [c]
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int cmp(const void* a, const void* b) { return *(int*)a - *(int*)b; }

int* largestDivisibleSubset(int* nums, int numsSize, int* returnSize) {
    qsort(nums, numsSize, sizeof(int), cmp);
    int* dp = (int*)malloc(sizeof(int) * numsSize);
    int* parent = (int*)malloc(sizeof(int) * numsSize);
    for (int i = 0; i < numsSize; i++) { dp[i] = 1; parent[i] = -1; }
    int maxIdx = 0;
    for (int i = 1; i < numsSize; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[i] % nums[j] == 0 && dp[j] + 1 > dp[i]) {
                dp[i] = dp[j] + 1;
                parent[i] = j;
            }
        }
        if (dp[i] > dp[maxIdx]) maxIdx = i;
    }
    *returnSize = dp[maxIdx];
    int* res = (int*)malloc(sizeof(int) * (*returnSize));
    int idx = *returnSize - 1;
    for (int i = maxIdx; i != -1; i = parent[i]) res[idx--] = nums[i];
    free(dp); free(parent);
    return res;
}
```

```js [js]
/**
 * @param {number[]} nums
 * @return {number[]}
 */
var largestDivisibleSubset = function (nums) {
  nums.sort((a, b) => a - b)
  const n = nums.length
  const dp = new Array(n).fill(1)
  const parent = new Array(n).fill(-1)
  let maxIdx = 0
  for (let i = 1; i < n; i++) {
    for (let j = 0; j < i; j++) {
      if (nums[i] % nums[j] === 0 && dp[j] + 1 > dp[i]) {
        dp[i] = dp[j] + 1
        parent[i] = j
      }
    }
    if (dp[i] > dp[maxIdx]) maxIdx = i
  }
  const res = []
  for (let i = maxIdx; i !== -1; i = parent[i]) res.push(nums[i])
  return res.reverse()
}
```

```py [py]
class Solution:
    def largestDivisibleSubset(self, nums: List[int]) -> List[int]:
        nums.sort()
        n = len(nums)
        dp = [1] * n
        parent = [-1] * n
        max_idx = 0
        for i in range(1, n):
            for j in range(i):
                if nums[i] % nums[j] == 0 and dp[j] + 1 > dp[i]:
                    dp[i] = dp[j] + 1
                    parent[i] = j
            if dp[i] > dp[max_idx]:
                max_idx = i
        res = []
        i = max_idx
        while i != -1:
            res.append(nums[i])
            i = parent[i]
        return res[::-1]
```

:::

- 时间复杂度：$O(n^2)$，其中 $n$ 是数组长度
- 空间复杂度：$O(n)$

算法思路：

- 排序后，$dp[i]$ 表示以 $nums[i]$ 结尾的最大整除子集长度
- 若 $nums[i] \% nums[j] = 0$ 且 $dp[j] + 1 > dp[i]$，则转移
- 用 `parent` 数组回溯路径构造结果

## 3. 【AI】s.1 动态规划解法详解

### 3.1. 核心思想

这道题的关键洞察是：**排序后，整除关系具有传递性**。

排序后，如果 `nums[i] % nums[j] == 0` 且 `j < i`（即 `nums[j] ≤ nums[i]`），那么 `nums[i]` 可以接在 `nums[j]` 所在的整除子集后面，形成更长的整除子集。

为什么排序能保证正确性？因为题目要求子集中**任意两个元素**都满足整除关系（大的能被小的整除）。排序后，只要保证 **相邻（或链式）** 的整除关系成立，整个子集就都满足——因为整除具有传递性：若 `a | b` 且 `b | c`，则 `a | c`。

---

### 3.2. 算法步骤拆解

#### 第一步：排序

```py
nums.sort()
```

排序后，整除关系只可能是「后面的数除以前面的数」，方向单一，方便 DP。

---

#### 第二步：定义状态

- `dp[i]`：以 `nums[i]` **结尾**的最大整除子集的长度
- `parent[i]`：记录 `dp[i]` 是由哪个 `j` 转移来的（用于回溯构造答案）

初始化：每个元素自己构成一个长度 1 的子集。

```py
dp = [1] * n
parent = [-1] * n
```

---

#### 第三步：状态转移

对每个 `i`，遍历所有 `j < i`：

```py
if nums[i] % nums[j] == 0 and dp[j] + 1 > dp[i]:
    dp[i] = dp[j] + 1
    parent[i] = j
```

含义：如果 `nums[i]` 能被 `nums[j]` 整除，且把 `nums[i]` 接到以 `nums[j]` 结尾的子集后面能得到更长的子集，就更新。

同时记录全局最大值的位置 `maxIdx`：

```py
if dp[i] > dp[max_idx]:
    max_idx = i
```

---

#### 第四步：回溯构造答案

从 `maxIdx` 出发，沿着 `parent` 链一路向前，把元素收集起来，最后**逆序**输出。

```py
res = []
i = max_idx
while i != -1:
    res.append(nums[i])
    i = parent[i]
return res[::-1]
```

回溯得到的是**从大到小**的顺序（因为 `parent` 指向更小的下标），而题目要求子集顺序通常按从小到大，所以需要 `reverse` / `[::-1]` 反转。C 版本则是从后往前填充，天然得到正序。

---

### 3.3. 举例演示

以 `nums = [1, 2, 3]` 为例：

排序后 `nums = [1, 2, 3]`

| i | nums[i] | j | nums[i]%nums[j] | dp[j]+1 | dp[i] | parent[i] |
|---|---------|---|-----------------|---------|-------|-----------|
| 0 | 1       | - | -               | -       | 1     | -1        |
| 1 | 2       | 0 | 2%1==0 ✓        | 1+1=2   | 2     | 0         |
| 2 | 3       | 0 | 3%1==0 ✓        | 1+1=2   | 2     | 0         |
| 2 | 3       | 1 | 3%2==1 ✗        | -       | 2     | 0         |

- `dp = [1, 2, 2]`，`parent = [-1, 0, 0]`
- `maxIdx = 1`（`dp[1]=2`）

回溯：`i=1 → parent=0 → i=0 → parent=-1` 结束，收集 `[2, 1]`，反转得 `[1, 2]`。

以 `nums = [1, 2, 4, 8]` 为例：

- `dp[0]=1`, `dp[1]=2`（接 1）, `dp[2]=3`（接 2）, `dp[3]=4`（接 4）
- 回溯得 `[8,4,2,1]`，反转得 `[1,2,4,8]` ✓

---

### 3.4. 复杂度分析

- **时间复杂度**：$O(n^2)$，双重循环。排序为 $O(n \log n)$，被 $O(n^2)$ 主导。
- **空间复杂度**：$O(n)$，`dp`、`parent`、结果数组各占 $O(n)$。

---

### 3.5. 关键点总结

1. **排序是前提**：让整除关系单向化，避免处理双向比较。
2. **DP 定义**：以某元素结尾的最长链，这是「最长递增子序列」类问题的典型套路。
3. **parent 数组**：不仅要求长度，还要输出具体方案，所以必须记录转移来源。
4. **回溯 + 反转**：构造路径的通用技巧。
