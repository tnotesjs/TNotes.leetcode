## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/check-if-the-sentence-is-pangram/)

全字母句指包含英语字母表中每个字母至少一次的句子。

给你一个仅由小写英文字母组成的字符串 `sentence`，请你判断 `sentence` 是否为全字母句。

如果是，返回 `true`；否则，返回 `false`。

---

示例 1：

```txt
输入：sentence = "thequickbrownfoxjumpsoverthelazydog"
输出：true

解释：
sentence 包含英语字母表中每个字母至少一次。
```

---

示例 2：

```txt
输入：sentence = "leetcode"
输出：false
```

---

提示：

- `1 <= sentence.length <= 1000`
- `sentence` 由小写英语字母组成

## 2. 🎯 s.1 - 掩码

::: code-group

```js [js]
/**
 * @param {string} sentence
 * @return {boolean}
 */
var checkIfPangram = function (sentence) {
  // 使用位掩码记录26个字母的出现情况，每一位代表一个字母
  let mask = 0

  for (let i = 0; i < sentence.length; i += 1) {
    const bit = sentence.charCodeAt(i) - 97 // 'a'
    mask |= 1 << bit

    // 遍历过程中如果 mask 已达到目标值，直接返回 true
    if (mask === 0x3ffffff) return true
  }

  // mask 前 26 位都是 1，对应的十六进制是 0x3ffffff
  return mask === 0x3ffffff
}
```

:::

- 时间复杂度：$O(N)$，其中 N 是字符串 sentence 的长度，需要遍历一次字符串
- 空间复杂度：$O(1)$，只使用一个整数变量作为位掩码

算法思路：

- 使用整数 mask 作为 26 位位掩码，每一位代表一个字母是否出现
- 遍历字符串，对每个字符计算其对应的位 bit = charCode - 97（'a' -> 0, 'b' -> 1, ...）
- 通过或运算 `mask |= (1 << bit)` 将对应位设为 1
- 检查 mask 是否等于 `0x3ffffff`（即二进制 `11111111111111111111111111`，表示 26 个字母全部出现）
- 优化：遍历过程中如果 mask 已达到目标值，可提前返回 true
