## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/maximum-strength-of-a-group/)

给你一个下标从 0 开始的整数数组 `nums`，它表示一个班级中所有学生在一次考试中的成绩。老师想选出一部分同学组成一个 非空 小组，且这个小组的 实力值 最大，如果这个小组里的学生下标为 `i0`, `i1`, `i2`, ... , `ik`，那么这个小组的实力值定义为 `nums[i0] * nums[i1] * nums[i2] * ... * nums[ik​]`。

请你返回老师创建的小组能得到的最大实力值为多少。

---

示例 1：

```txt
输入：nums = [3,-1,-5,2,5,-9]
输出：1350
解释：一种构成最大实力值小组的方案是选择下标为 [0,2,3,4,5] 的学生。实力值为 3 * (-5) * 2 * 5 * (-9) = 1350，这是可以得到的最大实力值。
```

示例 2：

```txt
输入：nums = [-4,-5,-4]
输出：20
解释：选择下标为 [0, 1] 的学生。得到的实力值为 20。我们没法得到更大的实力值。
```

---

提示：

- `1 <= nums.length <= 13`
- `-9 <= nums[i] <= 9`

## 2. 🎯 s.1 - 贪心

::: code-group

```js [js]
var maxStrength = function (nums) {
  const n = nums.length
  if (n === 1) return nums[0]
  const neg = nums.filter((x) => x < 0).sort((a, b) => a - b)
  const pos = nums.filter((x) => x > 0)
  const zeros = nums.filter((x) => x === 0).length
  if (pos.length === 0 && neg.length <= 1) {
    return neg.length === 1 && zeros === 0 ? neg[0] : 0
  }
  let result = 1
  for (const x of pos) result *= x
  for (let i = 0; i + 1 < neg.length; i += 2) {
    result *= neg[i] * neg[i + 1]
  }
  return result
}
```

```c [c]
int cmp(const void* a, const void* b) {
    return *(int*)a - *(int*)b;
}

long long maxStrength(int* nums, int numsSize) {
    if (numsSize == 1) return nums[0];
    int neg[13], pos[13], negCnt = 0, posCnt = 0, zeroCnt = 0;
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] < 0) neg[negCnt++] = nums[i];
        else if (nums[i] > 0) pos[posCnt++] = nums[i];
        else zeroCnt++;
    }
    if (posCnt == 0 && negCnt <= 1) {
        return (negCnt == 1 && zeroCnt == 0) ? neg[0] : 0;
    }
    qsort(neg, negCnt, sizeof(int), cmp);
    long long result = 1;
    for (int i = 0; i < posCnt; i++) result *= pos[i];
    for (int i = 0; i + 1 < negCnt; i += 2) result *= (long long)neg[i] * neg[i + 1];
    return result;
}
```

```py [py]
class Solution:
    def maxStrength(self, nums: list[int]) -> int:
        if len(nums) == 1:
            return nums[0]
        neg = sorted(x for x in nums if x < 0)
        pos = [x for x in nums if x > 0]
        zeros = sum(1 for x in nums if x == 0)
        if not pos and len(neg) <= 1:
            return neg[0] if neg and zeros == 0 else 0
        result = 1
        for x in pos:
            result *= x
        for i in range(0, len(neg) - 1, 2):
            result *= neg[i] * neg[i + 1]
        return result
```

:::

- 时间复杂度：$O(N \log N)$，其中 N 是数组长度
- 空间复杂度：$O(N)$

算法思路：

- 将数组中的正数、负数、零分开统计
- 所有正数都应选入乘积
- 负数按绝对值从大到小排序，成对相乘（两个负数之积为正）
- 若无正数且负数不足两个，结果为 0（有零时）或唯一负数本身
