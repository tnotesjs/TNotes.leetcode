## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-search-tree/)

给定一个二叉搜索树, 找到该树中两个指定节点的最近公共祖先。

[百度百科][1] 中最近公共祖先的定义为：“对于有根树 T 的两个结点 p、q，最近公共祖先表示为一个结点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。”

例如，给定如下二叉搜索树: `root = [6, 2, 8, 0, 4, 7, 9, null, null, 3, 5]`

![](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-09-10-21-50-30.png)

---

示例 1：

```txt
输入: root = [6, 2, 8, 0, 4, 7, 9, null, null, 3, 5], p = 2, q = 8
输出: 6
```

解释：节点 2 和节点 8 的最近公共祖先是 6。

---

示例 2：

```txt
输入: root = [6, 2, 8, 0, 4, 7, 9, null, null, 3, 5], p = 2, q = 4
输出: 2
```

解释：节点 2 和节点 4 的最近公共祖先是 2，因为根据定义最近公共祖先节点可以为节点本身。

---

说明:

- 所有节点的值都是唯一的。
- p、q 为不同节点且均存在于给定的二叉搜索树中。

## 2. s.1 - BST 性质

::: code-group

```c [c]
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     struct TreeNode *left;
 *     struct TreeNode *right;
 * };
 */

struct TreeNode* lowestCommonAncestor(struct TreeNode* root, struct TreeNode* p, struct TreeNode* q) {
    struct TreeNode* node = root;
    while (node) {
        if (p->val < node->val && q->val < node->val) node = node->left;
        else if (p->val > node->val && q->val > node->val) node = node->right;
        else return node;
    }
    return NULL;
}
```

```js [js]
/**
 * Definition for a binary tree node.
 * function TreeNode(val) {
 *     this.val = val;
 *     this.left = this.right = null;
 * }
 */

/**
 * @param {TreeNode} root
 * @param {TreeNode} p
 * @param {TreeNode} q
 * @return {TreeNode}
 */
var lowestCommonAncestor = function (root, p, q) {
  let node = root
  while (node) {
    if (p.val < node.val && q.val < node.val) node = node.left
    else if (p.val > node.val && q.val > node.val) node = node.right
    else return node
  }
}
```

```py [py]
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        node = root
        while node:
            if p.val < node.val and q.val < node.val:
                node = node.left
            elif p.val > node.val and q.val > node.val:
                node = node.right
            else:
                return node
```

:::

- 时间复杂度：$O(H)$，其中 $H$ 是树的高度
- 空间复杂度：$O(1)$，迭代实现

算法思路：

- 利用 BST 性质：若 p、q 都小于当前节点则往左走，都大于则往右走
- 否则当前节点即为分叉点，也就是 LCA
    - LCA：Lowest Common Ancestor，表示最近公共祖先，也叫“最低公共祖先”

## 3. 【AI】s.1 解释

这段代码解决的是 **LeetCode 235. 二叉搜索树的最近公共祖先（LCA）**。它利用二叉搜索树（BST）的有序性，从根节点开始一路向下查找，不需要递归回溯。

### 3.1. 核心思路

BST 的性质：
- 左子树所有节点值 **<** 根节点值
- 右子树所有节点值 **>** 根节点值

对于任意节点 `node`，判断 `p` 和 `q` 相对于 `node.val` 的位置：

| 情况 | 说明 | 下一步 |
|---|---|---|
| `p.val < node.val` 且 `q.val < node.val` | p、q 都在左子树 | LCA 一定在左子树 → `node = node.left` |
| `p.val > node.val` 且 `q.val > node.val` | p、q 都在右子树 | LCA 一定在右子树 → `node = node.right` |
| 其他情况 | p、q 分别在两侧，或其中一个就是 `node` | **当前 `node` 就是 LCA** |

### 3.2. 为什么第三种情况就是答案？

当不满足“同时小于”也不满足“同时大于”时，只有两种可能：

1. **一个在左、一个在右**  
   例如 `p.val < node.val < q.val`。  
   此时从 `node` 往下走，无论去左还是去右，都会丢掉其中一个节点。  
   所以 `node` 是它们能同时到达的最后一个公共节点，即最近公共祖先。

2. **其中一个等于 `node.val`**  
   例如 `p.val === node.val`。  
   那么 `p` 本身就是 `node`，它当然是 `q` 的祖先（或就是同一个节点），所以 `node` 就是 LCA。

因此 `else` 分支直接 `return node`。

### 3.3. 代码逐行解释

```js
var lowestCommonAncestor = function (root, p, q) {
  let node = root          // 从根节点开始
  while (node) {           // 一直向下找，直到找到答案
    if (p.val < node.val && q.val < node.val) {
      node = node.left     // 两个都在左边，去左子树找
    } else if (p.val > node.val && q.val > node.val) {
      node = node.right    // 两个都在右边，去右子树找
    } else {
      return node          // 分叉点 / 其中一个就是当前节点，找到 LCA
    }
  }
}
```

### 3.4. 举例说明

假设 BST 如下：

```
        6
       / \
      2   8
     / \ / \
    0  4 7  9
      / \
     3   5
```

- `p = 2, q = 8`  
  根节点 6：`2 < 6`，`8 > 6`，一左一右 → 返回 6。  
  LCA 是 6 ✅

- `p = 2, q = 4`  
  根 6：都小于 6 → 去左子树，`node = 2`  
  节点 2：`2` 等于 p，`4 > 2` → 落入 else → 返回 2。  
  LCA 是 2 ✅

- `p = 3, q = 5`  
  6 → 都小于，去左  
  2 → 都大于，去右  
  4 → `3 < 4`，`5 > 4` → 一左一右 → 返回 4。  
  LCA 是 4 ✅

### 3.5. 复杂度

- **时间复杂度：O(h)**  
  `h` 是树的高度。最坏情况退化成链表，`h = n`；平衡树 `h = log n`。  
  每次只往一个方向走，不会重复访问。
- **空间复杂度：O(1)**  
  只用了一个指针 `node`，没有递归栈。

### 3.6. 与递归写法对比

递归写法：
```js
if (p.val < root.val && q.val < root.val) return lowestCommonAncestor(root.left, p, q)
if (p.val > root.val && q.val > root.val) return lowestCommonAncestor(root.right, p, q)
return root
```
迭代版本只是把递归改成了 `while` 循环，逻辑完全一致，但省去了递归调用栈。

### 3.7. 注意点

- 题目保证 `p`、`q` 都存在于 BST 中，所以 `while` 一定会通过 `return` 结束，不会走到 `node` 为 `null`。
- 如果 `p` 和 `q` 可能不存在，则需要在循环外处理 `return null`，但本题不需要。
