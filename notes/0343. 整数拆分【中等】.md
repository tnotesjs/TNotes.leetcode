## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/integer-break/)

给定一个正整数 `n`，将其拆分为 `k` 个正整数的和（ `k >= 2` ），并使这些整数的乘积最大化。

返回你可以获得的最大乘积。

---

示例 1：

```txt
输入: n = 2
输出: 1
解释：2 = 1 + 1, 1 × 1 = 1。
```

---

示例 2：

```txt
输入: n = 10
输出: 36
解释：10 = 3 + 3 + 4, 3 × 3 × 4 = 36。
```

---

提示：

- `2 <= n <= 58`

## 2. s.1 - 数学贪心

::: code-group

```c [c]
int integerBreak(int n) {
    if (n <= 3) return n - 1;
    int q = n / 3, r = n % 3;
    if (r == 0) return (int)pow(3, q);
    if (r == 1) return (int)pow(3, q - 1) * 4;
    return (int)pow(3, q) * 2;
}
```

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var integerBreak = function (n) {
  if (n <= 3) return n - 1
  const q = Math.floor(n / 3),
    r = n % 3
  if (r === 0) return 3 ** q
  if (r === 1) return 3 ** (q - 1) * 4
  return 3 ** q * 2
}
```

```py [py]
class Solution:
    def integerBreak(self, n: int) -> int:
        if n <= 3:
            return n - 1
        q, r = divmod(n, 3)
        if r == 0:
            return 3 ** q
        if r == 1:
            return 3 ** (q - 1) * 4
        return 3 ** q * 2
```

:::

- 时间复杂度：$O(1)$
- 空间复杂度：$O(1)$

算法思路：

- 尽可能拆成 3，因为 $3 \times 3 > 2 \times 2 \times 2$
- 余数为 0 直接返回 $3^q$，余 1 则拆一个 3 出来凑成 $4$，余 2 则乘 $2$

## 3. 【AI】s.1 - 数学推导

核心思路是：**先证明“均分最优”，再找到那个最优的“均分因子”**。

### 3.1. 第一步：为什么“均分”时乘积最大？

假设我们将一个正整数 $n$ 拆分成 $k$ 个正整数之和，即 $n = n_1 + n_2 + \cdots + n_k$。

根据**算术-几何均值不等式（AM-GM Inequality）**，当这些正整数相等时，它们的乘积最大。

**算术平均值 ≥ 几何平均值**

$$
\frac{n_1 + n_2 + \cdots + n_k}{k} \geq \sqrt[k]{n_1 n_2 \cdots n_k}
$$

当且仅当 $n_1 = n_2 = \cdots = n_k$ 时，等号成立，乘积达到最大值。

所以，我们的目标可以简化为：**找到一个最优的因子 $x$，把 $n$ 尽可能多地拆成若干个 $x$**。

### 3.2. 第二步：寻找最优因子 $x$

现在问题变成了：将 $n$ 拆成 $k$ 个相等的部分，每部分大小为 $x = n / k$，如何选择 $x$ 来最大化乘积 $x^k$？

利用微积分可以找到答案。令 $y = x^{n/x}$，通过求导寻找极值点：

1. 对等式两边取对数：$\ln y = \frac{n}{x} \ln x$
2. 对 $x$ 求导并令导数为0：$\frac{d(\ln y)}{dx} = n \cdot \frac{1 - \ln x}{x^2} = 0$
3. 解得驻点：$1 - \ln x = 0 \Rightarrow \ln x = 1 \Rightarrow x = e \approx 2.718$

这个结果表明，**当每个拆分因子都接近自然常数 $e$ 时，乘积最大**。

### 3.3. 第三步：为什么是3，而不是2？

由于我们必须拆分出整数，所以需要在 $e$ 附近的整数中选择。$e \approx 2.718$ 最近的整数就是 **3** 和 **2**，而 3 离 $e$ 更近，因此直觉上更优。

我们可以通过简单的比较来验证：

| 比较场景 | 乘积 |
| :--- | :--- |
| 拆出 **两个 2**：$2 + 2$ | $2 \times 2 = 4$ |
| 拆出 **一个 3**：$3$ | $3$ |
| - | - |
| 拆出 **三个 2**：$2+2+2$ | $2 \times 2 \times 2 = 8$ |
| 拆出 **两个 3**：$3+3$ | $3 \times 3 = 9$ ✅ |

可以看出，**三个2的乘积（8）不如两个3的乘积（9）大**。因此，我们的贪心策略应**尽可能多地使用3，同时避免出现三个2**。

### 3.4. 第四步：排除其他候选因子

在确定使用3之前，我们还可以先排除掉一些明显不优的因子：

*   **因子1**：乘以1不会增加乘积，所以拆分出1是浪费。
*   **因子 ≥ 5**：任何大于等于5的因子，都可以拆分成一个3和一个$(n-3)$，因为 $3 \times (n-3) > n$（当 $n \geq 5$ 时），乘积会更大。

因此，最终的候选因子只剩下2和3，而3已被证明是更优的选择。

### 3.5. 总结：完整的贪心策略

基于以上推导，我们可以得到完整的贪心策略：

1.  **优先拆3**：尽可能多地从 $n$ 中拆分出因子3。
2.  **处理余数**：
    *   若余数为 **0**，直接返回 $3^k$。
    *   若余数为 **1**，说明剩下一个1，这很浪费。应从已有的3中拿出一个，将 “3+1” 组合成 “2+2”，因为 $2 \times 2 = 4 > 3 \times 1 = 3$。所以返回 $3^{k-1} \times 4$。
    *   若余数为 **2**，直接乘以2即可，返回 $3^k \times 2$。

这套策略之所以成立，是因为它始终在**避免出现效率低下的因子**（如1和大于等于5的数），并确保了在2和3之间，**3的“性价比”更高**。
