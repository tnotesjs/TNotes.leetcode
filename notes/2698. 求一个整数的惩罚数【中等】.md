## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/find-the-punishment-number-of-an-integer/)

给你一个正整数 `n`，请你返回 `n` 的 惩罚数。

`n` 的 惩罚数 定义为所有满足以下条件 `i` 的数的平方和：

- `1 <= i <= n`
- `i * i` 的十进制表示的字符串可以分割成若干连续子字符串，且这些子字符串对应的整数值之和等于 `i`。

---

示例 1：

```txt
输入：n = 10
输出：182
解释：总共有 3 个范围在 [1, 10] 的整数 i 满足要求：
- 1，因为 1 * 1 = 1
- 9，因为 9 * 9 = 81，且 81 可以分割成 8 + 1。
- 10，因为 10 * 10 = 100，且 100 可以分割成 10 + 0。
因此，10 的惩罚数为 1 + 81 + 100 = 182
```

示例 2：

```txt
输入：n = 37
输出：1478
解释：总共有 4 个范围在 [1, 37] 的整数 i 满足要求：
- 1，因为 1 * 1 = 1
- 9，因为 9 * 9 = 81，且 81 可以分割成 8 + 1。
- 10，因为 10 * 10 = 100，且 100 可以分割成 10 + 0。
- 36，因为 36 * 36 = 1296，且 1296 可以分割成 1 + 29 + 6。
因此，37 的惩罚数为 1 + 81 + 100 + 1296 = 1478
```

---

提示：

- `1 <= n <= 1000`

## 2. 🎯 s.1 - 回溯

::: code-group

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var punishmentNumber = function (n) {
  function canPartition(s, idx, target) {
    if (idx === s.length) return target === 0
    let num = 0
    for (let i = idx; i < s.length; i++) {
      num = num * 10 + Number(s[i])
      if (num > target) break
      if (canPartition(s, i + 1, target - num)) return true
    }
    return false
  }

  let ans = 0
  for (let i = 1; i <= n; i++) {
    if (canPartition(String(i * i), 0, i)) {
      ans += i * i
    }
  }
  return ans
}
```

```py [py]
class Solution:
    def punishmentNumber(self, n: int) -> int:
        def can_partition(s: str, idx: int, target: int) -> bool:
            if idx == len(s):
                return target == 0
            num = 0
            for i in range(idx, len(s)):
                num = num * 10 + int(s[i])
                if num > target:
                    break
                if can_partition(s, i + 1, target - num):
                    return True
            return False

        ans = 0
        for i in range(1, n + 1):
            if can_partition(str(i * i), 0, i):
                ans += i * i
        return ans
```

:::

- 时间复杂度：$O(N \times 2^{\log_{10}(N^2)})$，对每个 i 回溯其平方数的所有分割
- 空间复杂度：$O(\log N)$，回溯递归栈深度

算法思路：

- 枚举 1 到 n 的每个整数 i，检查 i² 是否可以分割为若干子串使得子串对应的整数之和等于 i
- 用回溯法枚举所有可能的分割方式
- 满足条件的 i² 累加到答案中
