## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/132-pattern/)

给你一个整数数组 `nums`，数组中共有 `n` 个整数。132 模式的子序列由三个整数 `nums[i]`、`nums[j]` 和 `nums[k]` 组成，并同时满足：`i < j < k` 和 `nums[i] < nums[k] < nums[j]`。

如果 `nums` 中存在 132 模式的子序列，返回 `true`；否则，返回 `false`。

---

示例 1：

```txt
输入：nums = [1, 2, 3, 4]
输出：false
解释：序列中不存在 132 模式的子序列。
```

---

示例 2：

```txt
输入：nums = [3, 1, 4, 2]
输出：true
解释：序列中有 1 个 132 模式的子序列：[1, 4, 2]。
```

---

示例 3：

```txt
输入：nums = [-1, 3, 2, 0]
输出：true
解释：序列中有 3 个 132 模式的的子序列：[-1, 3, 2]、[-1, 3, 0] 和 [-1, 2, 0]。
```

---

提示：

- `n == nums.length`
- `1 <= n <= 2 * 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 2. s.1 - 单调栈

::: code-group

```c [c]
bool find132pattern(int* nums, int numsSize) {
    int* stack = (int*)malloc(sizeof(int) * numsSize);
    int top = 0;
    int third = INT_MIN;
    for (int i = numsSize - 1; i >= 0; i--) {
        if (nums[i] < third) { free(stack); return true; }
        while (top > 0 && stack[top - 1] < nums[i])
            third = stack[--top];
        stack[top++] = nums[i];
    }
    free(stack);
    return false;
}
```

```js [js]
/**
 * @param {number[]} nums
 * @return {boolean}
 */
var find132pattern = function (nums) {
  const n = nums.length
  const stack = []
  let third = -Infinity // nums_k ("2" in 132)
  for (let i = n - 1; i >= 0; i--) {
    if (nums[i] < third) return true
    while (stack.length && stack[stack.length - 1] < nums[i]) {
      third = stack.pop()
    }
    stack.push(nums[i])
  }
  return false
}
```

```py [py]
class Solution:
    def find132pattern(self, nums: List[int]) -> bool:
        stack = []
        third = float('-inf')
        for i in range(len(nums) - 1, -1, -1):
            if nums[i] < third:
                return True
            while stack and stack[-1] < nums[i]:
                third = stack.pop()
            stack.append(nums[i])
        return False
```

:::

- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$

算法思路：

- 从右往左遍历，维护单调递减栈
- `third` 记录被弹出的最大值（即 132 中的 "2"）
- 若当前元素 < `third`，则找到了 132 模式

s.1 从右往左扫，维护一个从栈底到栈顶单调递减的栈，同时用 `third` 记下到目前为止「能当 2」的最大值：栈里是右边还没确定角色的候选；遇到更大的数就把栈里比它小的弹出，弹出的值在它右边、又比它小，可以当 2，当前这个数就是对应的 3。之后如果再在左边碰到比 `third` 还小的数，它就是 1，三者位置和大小都对上了。`third` 取被弹出的最大值，是为了让左边更容易找到 1。每个数最多进栈出栈一次，时间和空间都是 $O(n)$。

每一轮里 `nums[i]` 的处理顺序：

1. 先拿它当 1，跟已有的 `third` 比；
2. 没中的话再拿它当 3，把栈里比它小的弹出，用来更新 `third`；
    1. 栈单调递减
    2. 栈成员均位于 i 的右侧
    3. **最后弹出的是 i 右侧小于 `nums[i]` 的最大值**
3. 最后它自己入栈，继续当候选的 3；

用「示例 2」中的 `[3, 1, 4, 2]` 走一遍：

1. 先压入 2；遇到 4 时弹出 2，`third = 2`，再压入 4；
2. 轮到 1 时，`1 < 2`，找到 `[1, 4, 2]`，返回 true；

「示例 1」是递增序列，栈里不会弹出，`third` 一直是负无穷，结果是 false。
