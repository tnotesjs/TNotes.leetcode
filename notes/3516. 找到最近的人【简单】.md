## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/find-closest-person/)

给你三个整数 `x`、`y` 和 `z`，表示数轴上三个人的位置：

- `x` 是第 1 个人的位置。
- `y` 是第 2 个人的位置。
- `z` 是第 3 个人的位置，第 3 个人 不会移动。

第 1 个人和第 2 个人以 相同 的速度向第 3 个人移动。

判断谁会 先 到达第 3 个人的位置：

- 如果第 1 个人先到达，返回 1。
- 如果第 2 个人先到达，返回 2。
- 如果两个人同时到达，返回 0。

根据上述规则返回结果。

---

示例 1：

输入：x = 2, y = 7, z = 4

输出：1

解释：

- 第 1 个人在位置 2，到达第 3 个人（位置 4）需要 2 步。
- 第 2 个人在位置 7，到达第 3 个人需要 3 步。

由于第 1 个人先到达，所以输出为 1。

---

示例 2：

输入：x = 2, y = 5, z = 6

输出：2

解释：

- 第 1 个人在位置 2，到达第 3 个人（位置 6）需要 4 步。
- 第 2 个人在位置 5，到达第 3 个人需要 1 步。

由于第 2 个人先到达，所以输出为 2。

---

示例 3：

输入：x = 1, y = 5, z = 3

输出：0

解释：

- 第 1 个人在位置 1，到达第 3 个人（位置 3）需要 2 步。
- 第 2 个人在位置 5，到达第 3 个人需要 2 步。

由于两个人同时到达，所以输出为 0。

---

提示：

- `1 <= x, y, z <= 100`

## 2. 🎯 s.1 - 比较距离

::: code-group

```js [js]
/**
 * @param {number} x
 * @param {number} y
 * @param {number} z
 * @return {number}
 */
var findClosest = function (x, y, z) {
  // 计算两人到第 3 个人的距离
  const dist1 = Math.abs(x - z)
  const dist2 = Math.abs(y - z)

  if (dist1 < dist2) return 1
  if (dist2 < dist1) return 2
  return 0
}
```

:::

- 时间复杂度：$O(1)$，只需常数次运算
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：

- 由于两人速度相同，谁先到达取决于谁离第 3 个人更近
- 分别计算第 1 个人和第 2 个人到第 3 个人的距离（绝对值）
- 比较两个距离：距离小的先到达，距离相等则同时到达
