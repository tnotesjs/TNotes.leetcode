## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/count-integers-with-even-digit-sum/)

给你一个正整数 `num`，请你统计并返回 小于或等于 `num` 且各位数字之和为 偶数 的正整数的数目。

正整数的 各位数字之和 是其所有位上的对应数字相加的结果。

---

示例 1：

```txt
输入：num = 4
输出：2
解释：
只有 2 和 4 满足小于等于 4 且各位数字之和为偶数。
```

示例 2：

```txt
输入：num = 30
输出：14
解释：
只有 14 个整数满足小于等于 30 且各位数字之和为偶数，分别是：
2、4、6、8、11、13、15、17、19、20、22、24、26 和 28。
```

---

提示：

- `1 <= num <= 1000`

## 2. 🎯 s.1 - 枚举求和

::: code-group

```js [js]
/**
 * @param {number} num
 * @return {number}
 */
var countEven = function (num) {
  let ans = 0

  for (let x = 1; x <= num; x += 1) {
    let s = 0
    let t = x
    while (t > 0) {
      s += t % 10
      t = Math.trunc(t / 10)
    }
    if (s % 2 === 0) ans += 1
  }

  return ans
}
```

:::

- 时间复杂度：$O(N)$，遍历 1..num 逐个求数位和判偶
- 空间复杂度：$O(1)$，仅使用计数与临时求和变量

算法思路：

- 遍历 1 到 `num`，对每个数求数位和判断偶数则计数；范围仅到 1000，直接枚举即可通过。
