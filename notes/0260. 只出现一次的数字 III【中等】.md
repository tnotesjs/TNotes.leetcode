## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/single-number-iii/)

给你一个整数数组 `nums`，其中恰好有两个元素只出现一次，其余所有元素均出现两次。找出只出现一次的那两个元素。你可以按任意顺序返回答案。

你必须设计并实现线性时间复杂度的算法且仅使用常量额外空间来解决此问题。

---

示例 1：

```txt
输入：nums = [1, 2, 1, 3, 2, 5]
输出：[3, 5]
```

解释：`[5, 3]` 也是有效的答案。

---

示例 2：

```txt
输入：nums = [-1, 0]
输出：[-1, 0]
```

---

示例 3：

```txt
输入：nums = [0, 1]
输出：[1, 0]
```

---

提示：

- `2 <= nums.length <= 3 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- 除两个只出现一次的整数外，`nums` 中的其他数字都出现两次

## 2. s.1 - 异或运算

::: code-group

```c [c]
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int* singleNumber(int* nums, int numsSize, int* returnSize) {
    int xor = 0;

    // 全部异或，得到两个只出现一次的数的异或值
    for (int i = 0; i < numsSize; i++) {
        xor ^= nums[i];
    }

    // 找到最低位为 1 的掩码。按无符号计算，避免 x 为 INT_MIN 时溢出
    unsigned int ux = (unsigned int)xor;
    unsigned int rightmostBit = ux & ~(ux - 1);

    int num1 = 0;
    int num2 = 0;

    // 根据最低位 1 分组
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] & rightmostBit) {
            num1 ^= nums[i];
        } else {
            num2 ^= nums[i];
        }
    }

    int* result = (int*)malloc(sizeof(int) * 2);
    result[0] = num1;
    result[1] = num2;
    *returnSize = 2;
    return result;
}
```

```js [js]
/**
 * @param {number[]} nums
 * @return {number[]}
 */
var singleNumber = function (nums) {
  let xor = 0

  // 全部异或，得到两个只出现一次的数的异或值
  for (const num of nums) {
    xor ^= num
  }

  // 找到最低位为 1 的掩码
  const rightmostBit = xor & ~(xor - 1)

  let num1 = 0
  let num2 = 0

  // 根据最低位 1 分组
  for (const num of nums) {
    if (num & rightmostBit) {
      num1 ^= num
    } else {
      num2 ^= num
    }
  }

  return [num1, num2]
}
```

```py [py]
class Solution:
    def singleNumber(self, nums: list[int]) -> list[int]:
        xor = 0

        # 全部异或，得到两个只出现一次的数的异或值
        for num in nums:
            xor ^= num

        # 找到最低位为 1 的掩码
        rightmost_bit = xor & ~(xor - 1)

        num1 = 0
        num2 = 0

        # 根据最低位 1 分组
        for num in nums:
            if num & rightmost_bit:
                num1 ^= num
            else:
                num2 ^= num

        return [num1, num2]
```

:::

- 时间复杂度：$O(n)$，遍历数组两次，$n$ 为数组长度
- 空间复杂度：$O(1)$，只使用常数个额外变量

算法思路：

- 相同的数异或为 0，任何数与 0 异或不变，且异或满足交换律和结合律
- 把数组全部异或，成对的数互相抵消，剩下两个只出现一次的数的异或值 $a \oplus b$。二者不同，所以结果至少有一位是 1
- 用 $x \& \sim(x - 1)$ 取出这个异或值最低的 1，作为分组掩码。$a$ 和 $b$ 在这一位上不同，会被分到两组；每个成对出现的数都落在同一组
- 两组分别再异或，组内成对的数抵消，每组剩下的就是一个只出现一次的数

## 3. 【AI】s.1 解释


```ts
var singleNumber = function (nums) {

```

这段代码解决的是 **LeetCode 260. Single Number III**：数组中只有两个数字出现一次，其余数字都出现两次，找出这两个只出现一次的数字。

结合示例 `nums = [1, 2, 1, 3, 2, 5]`，输出 `[3, 5]`，下面逐步解释。

---

### 3.1. 整体思路

核心是 **异或运算** 的性质：

- 任何数和自己异或结果为 $0$：$a \oplus a = 0$
- 任何数和 $0$ 异或结果为自己：$a \oplus 0 = a$
- 异或满足交换律和结合律

因此，如果把数组中所有数字全部异或，出现两次的数字会两两抵消为 $0$，最终剩下的就是那两个只出现一次的数字的异或值：

$$
\text{xor} = a \oplus b
$$

但此时我们只知道 $a \oplus b$，不知道 $a$ 和 $b$ 分别是多少。接下来需要利用 $a \oplus b$ 的二进制特征把它们分开。

---

### 3.2. 对示例逐步计算

数组：

$$
[1,\ 2,\ 1,\ 3,\ 2,\ 5]
$$

#### 第一步：全部异或

```js
let xor = 0
for (const num of nums) {
  xor ^= num
}
```

计算过程：

$$
1 \oplus 2 \oplus 1 \oplus 3 \oplus 2 \oplus 5
$$

利用交换律和结合律：

$$
(1 \oplus 1) \oplus (2 \oplus 2) \oplus 3 \oplus 5
= 0 \oplus 0 \oplus 3 \oplus 5
= 3 \oplus 5
$$

$3$ 的二进制是 `011`，$5$ 的二进制是 `101`：

$$
3 \oplus 5 = 011 \oplus 101 = 110 = 6
$$

所以：

$$
\text{xor} = 6
$$

---

#### 第二步：找到最低位的 $1$

```js
const rightmostBit = xor & ~(xor - 1)
```

这个表达式的目的是取出 `xor` 二进制中 **最低位的 $1$** 所对应的值。

这里 `xor = 6`，二进制为 `110`。

- `xor - 1 = 5`，二进制 `101`
- `~(xor - 1)` 在 JavaScript 中按位取反，但我们可以用更直观的等价写法：`xor & -xor`
- `-6` 在补码中相当于 `~6 + 1`，即 `...11111010`，与 `6` 做 `&` 运算：

$$
6 \& (-6) = 110 \& ...010 = 010 = 2
$$

所以：

$$
\text{rightmostBit} = 2
$$

这个 $2$ 的二进制是 `010`，表示 $3$ 和 $5$ 在 **从右往左第 $2$ 位**（权值为 $2$）上不同：$3$ 的该位是 $1$，$5$ 的该位是 $0$。

---

#### 第三步：根据 `rightmostBit` 分组异或

```js
let num1 = 0
let num2 = 0

for (const num of nums) {
  if (num & rightmostBit) {
    num1 ^= num
  } else {
    num2 ^= num
  }
}
```

用 `rightmostBit = 2`（二进制 `010`）检查每个数字：

| 数字 | 二进制 | 与 `010` 做 `&` | 分组 |
|------|--------|----------------|------|
| 1    | 001    | 0              | 组2  |
| 2    | 010    | 2              | 组1  |
| 1    | 001    | 0              | 组2  |
| 3    | 011    | 2              | 组1  |
| 2    | 010    | 2              | 组1  |
| 5    | 101    | 0              | 组2  |

- **组1**（该位为 $1$）：$2,\ 3,\ 2$
- **组2**（该位为 $0$）：$1,\ 1,\ 5$

然后分别对两组内部异或：

**组1**：

$$
2 \oplus 3 \oplus 2 = (2 \oplus 2) \oplus 3 = 0 \oplus 3 = 3
$$

所以 `num1 = 3`

**组2**：

$$
1 \oplus 1 \oplus 5 = (1 \oplus 1) \oplus 5 = 0 \oplus 5 = 5
$$

所以 `num2 = 5`

最终返回：

$$
[3,\ 5]
$$

---

### 3.3. 为什么这样分组有效？

因为 $a \oplus b$ 中为 $1$ 的位，表示 $a$ 和 $b$ 在该位上不同。我们取出最低位的 $1$ 作为掩码 `rightmostBit`，那么 $a$ 和 $b$ 中必然有一个在该位上为 $1$，另一个为 $0$。

因此，用这个掩码把数组分成两组：

- 一组包含 $a$ 以及若干成对出现的数字；
- 另一组包含 $b$ 以及若干成对出现的数字。

每组内部，成对出现的数字依然会两两抵消为 $0$，最后剩下的就是 $a$ 或 $b$。

---

### 3.4. 关键位运算技巧

```js
const rightmostBit = xor & ~(xor - 1)
```

等价于：

```js
const rightmostBit = xor & -xor
```

它的作用是：**只保留一个整数二进制表示中最右边的那个 $1$**。

例如：

- $6$ 的二进制 `110`，最低位的 $1$ 是 `010`，即 $2$。
- $12$ 的二进制 `1100`，最低位的 $1$ 是 `0100`，即 $4$。

---

### 3.5. 总结

对于示例 `[1, 2, 1, 3, 2, 5]`：

1. 全部异或得到 $3 \oplus 5 = 6$；
2. 取最低位 $1$ 得到掩码 $2$；
3. 按掩码分组：
   - 组1：$2, 3, 2$ → 异或得 $3$
   - 组2：$1, 1, 5$ → 异或得 $5$
4. 返回 $[3, 5]$。

这种方法时间复杂度 $O(n)$，空间复杂度 $O(1)$，是本题的最优解。
