## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/first-unique-character-in-a-string/)

给定一个字符串 `s`，找到它的第一个不重复的字符，并返回它的索引。如果不存在，则返回 `-1`。

---

示例 1：

```txt
输入: s = "leetcode"
输出: 0
```

---

示例 2：

```txt
输入: s = "loveleetcode"
输出: 2
```

---

示例 3：

```txt
输入: s = "aabb"
输出: -1
```

---

提示：

- `1 <= s.length <= 10^5`
- `s` 只包含小写字母

## 2. s.1 - 数组解法

::: code-group

```c [c]
int firstUniqChar(char* s) {
    // 第一次遍历：统计每个字符的出现次数
    int charCount[26] = {0};

    for (int i = 0; s[i]; i++) {
        charCount[s[i] - 'a']++;
    }

    // 第二次遍历：找到第一个出现次数为 1 的字符
    for (int i = 0; s[i]; i++) {
        if (charCount[s[i] - 'a'] == 1) {
            return i;
        }
    }

    return -1;
}
```

```js [js]
/**
 * @param {string} s
 * @return {number}
 */
var firstUniqChar = function (s) {
  // 第一次遍历：统计每个字符的出现次数
  const charCount = new Array(26).fill(0)

  for (const char of s) {
    charCount[char.charCodeAt(0) - 97]++
  }

  // 第二次遍历：找到第一个出现次数为 1 的字符
  for (let i = 0; i < s.length; i++) {
    if (charCount[s[i].charCodeAt(0) - 97] === 1) {
      return i
    }
  }

  return -1
}
```

```py [py]
class Solution:
    def firstUniqChar(self, s: str) -> int:
        # 第一次遍历：统计每个字符的出现次数
        char_count = [0] * 26

        for ch in s:
            char_count[ord(ch) - ord('a')] += 1

        # 第二次遍历：找到第一个出现次数为 1 的字符
        for i, ch in enumerate(s):
            if char_count[ord(ch) - ord('a')] == 1:
                return i

        return -1
```

:::

- 时间复杂度：$O(n)$，需要遍历字符串两次
- 空间复杂度：$O(1)$，使用了固定大小的数组（26 个字母）

算法思路：

- 使用数组来统计字符出现的次数
- 从 s 的第一个字符开始逐字符往后检查每个字符的出现次数，直到找到首个出现次数为 1 的字符

## 3. s.2 - 哈希表统计索引

::: code-group

```c [c]
int firstUniqChar(char* s) {
    // 存储每个字符的索引，-2 表示未出现，重复字符标记为 -1
    int index[26];
    for (int c = 0; c < 26; c++) {
        index[c] = -2;
    }

    int n = 0;
    for (; s[n]; n++) {
        int c = s[n] - 'a';
        if (index[c] == -2) {
            index[c] = n; // 存储索引
        } else {
            index[c] = -1; // 标记为重复
        }
    }

    // 找到最小的有效索引
    int minIndex = n;
    for (int c = 0; c < 26; c++) {
        if (index[c] >= 0 && index[c] < minIndex) {
            minIndex = index[c];
        }
    }

    return minIndex == n ? -1 : minIndex;
}
```

```js [js]
/**
 * @param {string} s
 * @return {number}
 */
var firstUniqChar = function (s) {
  const map = new Map()

  // 存储每个字符的索引，重复字符标记为-1
  for (let i = 0; i < s.length; i++) {
    const char = s[i]
    if (map.has(char)) {
      map.set(char, -1) // 标记为重复
    } else {
      map.set(char, i) // 存储索引
    }
  }

  // 找到最小的非-1索引
  let minIndex = s.length
  for (const [char, index] of map) {
    if (index !== -1 && index < minIndex) {
      minIndex = index
    }
  }

  return minIndex === s.length ? -1 : minIndex
}
```

```py [py]
class Solution:
    def firstUniqChar(self, s: str) -> int:
        index_map = {}

        # 存储每个字符的索引，重复字符标记为 -1
        for i, ch in enumerate(s):
            if ch in index_map:
                index_map[ch] = -1  # 标记为重复
            else:
                index_map[ch] = i  # 存储索引

        # 找到最小的非 -1 索引
        min_index = len(s)
        for idx in index_map.values():
            if idx != -1 and idx < min_index:
                min_index = idx

        return -1 if min_index == len(s) else min_index
```

:::

- 时间复杂度：$O(n + k) = O(n)$，遍历字符串一次 $O(n)$ + 遍历哈希表一次 $O(k)$，其中 k 是不同字符的个数
- 空间复杂度：$O(k)$，其中 k 是字符串中不同字符的个数，需要存储所有不同字符及其索引

算法思路：

- 用哈希表存储每个字符的索引
- 遍历一次字符串：记录字符首次出现的索引，若重复出现则标记为 -1
- 遍历哈希表：找到最小的有效索引


## 对比 s.1 和 s.2

  - s.1 两次遍历字符串，若字符串较长，循环次数将明显高于 26
  - s.2 只需一次字符串遍历，第二次只遍历哈希表（循环次数固定 <= 26）
  - s.2 实现逻辑稍复杂，不如 s.1 直观
