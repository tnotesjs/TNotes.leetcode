## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/count-of-smaller-numbers-after-self/)

给你一个整数数组 `nums`，按要求返回一个新数组 `counts`。数组 `counts` 有该性质：`counts[i]` 的值是 `nums[i]` 右侧小于 `nums[i]` 的元素的数量。

---

示例 1：

```txt
输入：nums = [5, 2, 6, 1]
输出：[2, 1, 1, 0]
```

解释：

- 5 的右侧有 2 个更小的元素 (2 和 1)
- 2 的右侧仅有 1 个更小的元素 (1)
- 6 的右侧有 1 个更小的元素 (1)
- 1 的右侧有 0 个更小的元素

---

示例 2：

```txt
输入：nums = [-1]
输出：[0]
```

---

示例 3：

```txt
输入：nums = [-1, -1]
输出：[0, 0]
```

---

提示：

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 2. s.1 - 离散化 + 树状数组

::: code-group

```c [c]
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int cmp(const void* a, const void* b) {
    return *(int*)a - *(int*)b;
}

int* countSmaller(int* nums, int numsSize, int* returnSize) {
    int* sorted = (int*)malloc(numsSize * sizeof(int));
    memcpy(sorted, nums, numsSize * sizeof(int));
    qsort(sorted, numsSize, sizeof(int), cmp);

    // 去重
    int m = 0;
    for (int i = 0; i < numsSize; i++) {
        if (i == 0 || sorted[i] != sorted[i - 1])
            sorted[m++] = sorted[i];
    }

    int* tree = (int*)calloc(m + 1, sizeof(int));
    int* res = (int*)malloc(numsSize * sizeof(int));

    for (int i = numsSize - 1; i >= 0; i--) {
        int val = nums[i];
        // 二分查找排名（1-based）
        int l = 0, r = m - 1, rank = 0;
        while (l <= r) {
            int mid = l + (r - l) / 2;
            if (sorted[mid] == val) { rank = mid + 1; break; }
            else if (sorted[mid] < val) l = mid + 1;
            else r = mid - 1;
        }

        // query(rank - 1)
        int sum = 0;
        for (int j = rank - 1; j > 0; j -= j & -j) sum += tree[j];
        res[i] = sum;

        // update(rank, 1)
        for (int j = rank; j <= m; j += j & -j) tree[j] += 1;
    }

    free(sorted);
    free(tree);
    *returnSize = numsSize;
    return res;
}
```

```js [js]
/**
 * @param {number[]} nums
 * @return {number[]}
 */
var countSmaller = function(nums) {
    const n = nums.length;
    // 1. 离散化：将数值映射为排名（1-based）
    const sorted = [...new Set(nums)].sort((a, b) => a - b);
    const rankMap = new Map();
    sorted.forEach((v, i) => rankMap.set(v, i + 1));

    const tree = new Array(sorted.length + 1).fill(0);
    const res = new Array(n).fill(0);

    // 树状数组单点更新
    const update = (i, delta) => {
        for (; i < tree.length; i += i & -i) tree[i] += delta;
    };
    // 树状数组前缀和查询
    const query = (i) => {
        let s = 0;
        for (; i > 0; i -= i & -i) s += tree[i];
        return s;
    };

    // 2. 从右往左遍历，查询已插入元素中比当前值小的个数
    for (let i = n - 1; i >= 0; i--) {
        const rank = rankMap.get(nums[i]);
        res[i] = query(rank - 1); // 查询排名小于当前值的元素个数
        update(rank, 1);          // 将当前值插入树状数组
    }
    return res;
};
```

```py [py]
class Solution:
    def countSmaller(self, nums: List[int]) -> List[int]:
        sorted_nums = sorted(set(nums))
        rank = {v: i + 1 for i, v in enumerate(sorted_nums)}
        m = len(sorted_nums)
        tree = [0] * (m + 1)
        res = [0] * len(nums)

        def update(i, delta):
            while i <= m:
                tree[i] += delta
                i += i & -i

        def query(i):
            s = 0
            while i > 0:
                s += tree[i]
                i -= i & -i
            return s

        for i in range(len(nums) - 1, -1, -1):
            r = rank[nums[i]]
            res[i] = query(r - 1)
            update(r, 1)

        return res
```

:::

- 时间复杂度：$O(n log n)$，排序离散化 $O(n log n)$，每次查询和更新各 $O(log n)$，共 $n$ 次。
- 空间复杂度：$O(n)$，树状数组和结果数组各 $O(n)$。

算法思路：

- 离散化：将可能很大或为负的数值，按其相对大小映射为 `1 ~ k` 的排名，以便树状数组使用紧凑的下标
- 从右向左遍历：保证树状数组中只包含当前元素右侧已遍历过的元素
- `tree` 是一个按离散化排名维护的频次树状数组，记录已经遍历过的元素中，每个排名出现了多少次
- `tree[i]` 管理排名区间 `[i - lowbit(i), i - 1]` 内元素出现的总次数
- 查询 + 更新：对每个元素，先 `query(rank - 1)` 得到右侧比它小的元素个数，再 `update(rank, 1)` 把它加入树状数组
    - `update(rank, 1)`：把当前元素的排名频次加 1
    - `query(rank - 1)`：查询排名小于当前元素的已出现元素总数，即右侧比它小的个数
