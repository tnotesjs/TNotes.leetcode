## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/day-of-the-week/)

给你一个日期，请你设计一个算法来判断它是对应一周中的哪一天。

输入为三个整数：`day`、`month` 和 `year`，分别表示日、月、年。

您返回的结果必须是这几个值中的一个 `{"Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"}`。

---

示例 1：

```txt
输入：day = 31, month = 8, year = 2019
输出："Saturday"
```

示例 2：

```txt
输入：day = 18, month = 7, year = 1999
输出："Sunday"
```

示例 3：

```txt
输入：day = 15, month = 8, year = 1993
输出："Sunday"
```

---

提示：

- 给出的日期一定是在 `1971` 到 `2100` 年之间的有效日期。

## 2. 🎯 s.1 - 暴力解法

::: code-group

```js [js]
/**
 * @param {number} day
 * @param {number} month
 * @param {number} year
 * @return {string}
 */
var dayOfTheWeek = function (day, month, year) {
  // 定义星期几的名称数组
  const daysOfWeek = [
    'Sunday',
    'Monday',
    'Tuesday',
    'Wednesday',
    'Thursday',
    'Friday',
    'Saturday',
  ]

  // 创建日期对象，注意月份是从0开始的，所以month需要减1
  const date = new Date(year, month - 1, day)

  // 获取星期几（0表示周日，1表示周一...6表示周六）
  const dayIndex = date.getDay()

  // 返回对应的星期名称
  return daysOfWeek[dayIndex]
}
```

:::

- 时间复杂度：$O(1)$，创建日期对象和获取星期几都是常数时间操作
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：

- 直接使用内置的 `Date` 对象计算日期对应的星期几
- 创建 `Date` 对象时，月份参数从 0 开始，需要将输入的月份减 1
- 调用 `getDay()` 方法获取星期索引，返回值为 0（周日）到 6（周六）
- 通过预定义的星期名称数组映射索引到对应的字符串

## 3. 🎯 s.2 - Sakamoto 算法

::: code-group

```js [js]
/**
 * @param {number} day
 * @param {number} month
 * @param {number} year
 * @return {string}
 */
var dayOfTheWeek = function (day, month, year) {
  const names = [
    'Sunday',
    'Monday',
    'Tuesday',
    'Wednesday',
    'Thursday',
    'Friday',
    'Saturday',
  ]
  const t = [0, 3, 2, 5, 0, 3, 5, 1, 4, 6, 2, 4]
  if (month < 3) year -= 1
  const w =
    (year +
      Math.floor(year / 4) -
      Math.floor(year / 100) +
      Math.floor(year / 400) +
      t[month - 1] +
      day) %
    7
  return names[w]
}
```

:::

- 时间复杂度：$O(1)$，只进行常数次的算术运算
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：

- 使用 Sakamoto 算法计算给定日期是星期几
- 核心公式：$w = (year + \lfloor year/4 \rfloor - \lfloor year/100 \rfloor + \lfloor year/400 \rfloor + t[month-1] + day) \bmod 7$
- 如果月份是 1 或 2 月，将年份减 1，简化闰年处理
- 数组 `t` 存储每个月的偏移量，用于修正月份对星期的影响
- 计算结果 `w` 对应 0（周日）到 6（周六），映射到星期名称返回
