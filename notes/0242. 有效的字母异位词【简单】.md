## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/valid-anagram/)

给定两个字符串 `s` 和 `t`，编写一个函数来判断 `t` 是否是 `s` 的字母异位词。

> 字母异位词
>
> 字母异位词是通过重新排列不同单词或短语的字母而形成的单词或短语，并使用所有原字母一次。

---

示例 1：

```txt
输入: s = "anagram", t = "nagaram"
输出: true
```

---

示例 2：

```txt
输入: s = "rat", t = "car"
输出: false
```

---

提示：

- `1 <= s.length, t.length <= 5 * 10^4`
- `s` 和 `t` 仅包含小写字母

---

进阶：如果输入字符串包含 unicode 字符怎么办？你能否调整你的解法来应对这种情况？

## 2. s.1 - 哈希计数

::: code-group

```c [c]
typedef struct {
    int key;
    int val;
    UT_hash_handle hh;
} Entry;

// 读出一个 UTF-8 码点；到结尾返回 -1
static int nextCodePoint(const unsigned char** pp) {
    const unsigned char* s = *pp;
    unsigned char c = *s;
    if (c == 0) return -1;

    unsigned int cp;
    int n;
    if (c < 0x80) {
        cp = c;
        n = 1;
    } else if ((c & 0xE0) == 0xC0 && (s[1] & 0xC0) == 0x80) {
        cp = ((unsigned int)(c & 0x1F) << 6) | (s[1] & 0x3F);
        n = 2;
    } else if ((c & 0xF0) == 0xE0 && (s[1] & 0xC0) == 0x80 && (s[2] & 0xC0) == 0x80) {
        cp = ((unsigned int)(c & 0x0F) << 12) | ((unsigned int)(s[1] & 0x3F) << 6) | (s[2] & 0x3F);
        n = 3;
    } else if ((c & 0xF8) == 0xF0 && (s[1] & 0xC0) == 0x80 && (s[2] & 0xC0) == 0x80 && (s[3] & 0xC0) == 0x80) {
        cp = ((unsigned int)(c & 0x07) << 18) | ((unsigned int)(s[1] & 0x3F) << 12) | ((unsigned int)(s[2] & 0x3F) << 6) | (s[3] & 0x3F);
        n = 4;
    } else {
        cp = c;
        n = 1;
    }
    *pp = s + n;
    return (int)cp;
}

static void bump(Entry** map, int key, int delta) {
    Entry* e = NULL;
    HASH_FIND_INT(*map, &key, e);
    if (!e) {
        e = (Entry*)calloc(1, sizeof(Entry));
        e->key = key;
        HASH_ADD_INT(*map, key, e);
    }
    e->val += delta;
}

bool isAnagram(char* s, char* t) {
    // 码点多重集相同则 UTF-8 字节数相同
    if (strlen(s) != strlen(t)) return false;

    Entry* map = NULL;
    const unsigned char* p = (const unsigned char*)s;
    int cp;
    while ((cp = nextCodePoint(&p)) >= 0) bump(&map, cp, 1);

    p = (const unsigned char*)t;
    while ((cp = nextCodePoint(&p)) >= 0) bump(&map, cp, -1);

    bool ok = true;
    Entry *cur, *tmp;
    HASH_ITER(hh, map, cur, tmp) {
        if (cur->val != 0) ok = false;
        HASH_DEL(map, cur);
        free(cur);
    }
    return ok;
}
```

```js [js]
/**
 * @param {string} s
 * @param {string} t
 * @return {boolean}
 */
var isAnagram = function (s, t) {
  if (s.length !== t.length) return false

  const count = new Map()
  // for...of 按 Unicode 码点遍历，不把代理对拆开
  for (const ch of s) count.set(ch, (count.get(ch) || 0) + 1)
  for (const ch of t) count.set(ch, (count.get(ch) || 0) - 1)

  for (const v of count.values()) {
    if (v !== 0) return false
  }
  return true
}
```

```py [py]
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False

        count = {}
        for ch in s:
            count[ch] = count.get(ch, 0) + 1
        for ch in t:
            count[ch] = count.get(ch, 0) - 1

        for v in count.values():
            if v != 0:
                return False
        return True
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是字符数。每个字符做一次哈希更新。
- 空间复杂度：$O(k)$，其中 $k$ 是不同字符的个数，最坏为 $O(n)$。

算法思路：

- 字母异位词要求两个字符串长度相同，且每个字符出现次数相同。
- 用哈希表计数，键是字符，值是出现次数，从而覆盖任意 Unicode 字符。
- 长度不同直接返回 `false`。扫描 `s` 时对应字符加 1，扫描 `t` 时减 1，结束后每个计数都是 0 即成立。
