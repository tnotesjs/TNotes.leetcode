## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/longest-square-streak-in-an-array/)

给你一个整数数组 `nums`。如果 `nums` 的子序列满足下述条件，则认为该子序列是一个 方波 ：

- 子序列的长度至少为 `2`，并且
- 将子序列从小到大排序 之后，除第一个元素外，每个元素都是前一个元素的 平方。

返回 `nums` 中 最长方波 的长度，如果不存在 方波 则返回 `-1`。

子序列 也是一个数组，可以由另一个数组删除一些或不删除元素且不改变剩余元素的顺序得到。

---

示例 1 ：

```txt
输入：nums = [4,3,6,16,8,2]
输出：3
解释：选出子序列 [4,16,2]。排序后，得到 [2,4,16]。
- 4 = 2 * 2.
- 16 = 4 * 4.
因此，[4,16,2] 是一个方波.
可以证明长度为 4 的子序列都不是方波。
```

---

示例 2 ：

```txt
输入：nums = [2,3,5,6,7]
输出：-1
解释：nums 不存在方波，所以返回 -1。
```

---

提示：

- `2 <= nums.length <= 10^5`
- `2 <= nums[i] <= 10^5`

## 2. 🎯 s.1 - 哈希集合

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var longestSquareStreak = function (nums) {
  const set = new Set(nums)
  let ans = -1
  for (const num of set) {
    let x = num,
      len = 0
    while (set.has(x)) {
      len++
      x = x * x
      if (x > 1e5) break
    }
    if (len >= 2) ans = Math.max(ans, len)
  }
  return ans
}
```

```c [c]
int longestSquareStreak(int* nums, int numsSize) {
    int visited[100001] = {0};
    for (int i = 0; i < numsSize; i++) visited[nums[i]] = 1;
    int ans = -1;
    for (int i = 0; i < numsSize; i++) {
        long long x = nums[i];
        int len = 0;
        while (x <= 100000 && visited[x]) {
            len++;
            x = x * x;
        }
        if (len >= 2 && len > ans) ans = len;
    }
    return ans;
}
```

```py [py]
class Solution:
    def longestSquareStreak(self, nums: list[int]) -> int:
        s = set(nums)
        ans = -1
        for num in s:
            x, length = num, 0
            while x in s:
                length += 1
                x = x * x
                if x > 10**5:
                    break
            if length >= 2:
                ans = max(ans, length)
        return ans
```

:::

- 时间复杂度：$O(n \log \log M)$，其中 $n$ 是数组长度，$M$ 是数组最大值，方波链长度不超过 $O(\log \log M)$
- 空间复杂度：$O(n)$，哈希集合存储所有元素

算法思路：

- 将所有元素加入哈希集合
- 遍历集合中每个元素 $x$，沿 $x \to x^2 \to x^4 \to \dots$ 方向在集合中查找，统计链长度
- 取所有长度 $\geq 2$ 的链的最大值，若不存在则返回 $-1$
