## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/power-of-four/)

给定一个整数，写一个函数来判断它是否是 4 的幂次方。如果是，返回 `true`；否则，返回 `false`。

整数 `n` 是 4 的幂次方需满足：存在整数 `x` 使得 `n == 4^x`

---

示例 1：

```txt
输入：n = 16
输出：true
```

---

示例 2：

```txt
输入：n = 5
输出：false
```

---

示例 3：

```txt
输入：n = 1
输出：true
```

---

提示：

- `-2^31 <= n <= 2^31 - 1`

---

进阶：你能不使用循环或者递归来完成本题吗？

## 2. s.1 - 位运算

::: code-group

```c [c]
bool isPowerOfFour(int n) {
    // 4 的幂必须是正整数
    if (n <= 0) return false;

    // 必须是 2 的幂（二进制中只有一个 1）
    if ((n & (n - 1)) != 0) return false;

    // 4 的幂在二进制中，1 只出现在奇数位置
    // 0x55555555 的二进制是 01010101010101010101010101010101
    // 这个掩码的奇数位都是 1，偶数位都是 0
    return (n & 0x55555555) != 0;
}
```

```js [js]
/**
 * @param {number} n
 * @return {boolean}
 */
var isPowerOfFour = function (n) {
  // 4 的幂必须是正整数
  if (n <= 0) return false

  // 必须是 2 的幂（二进制中只有一个 1）
  if ((n & (n - 1)) !== 0) return false

  // 4 的幂在二进制中，1 只出现在奇数位置
  // 0x55555555 的二进制是 01010101010101010101010101010101
  // 这个掩码的奇数位都是 1，偶数位都是 0
  return (n & 0x55555555) !== 0
}
```

```py [py]
class Solution:
    def isPowerOfFour(self, n: int) -> bool:
        # 4 的幂必须是正整数
        if n <= 0:
            return False

        # 必须是 2 的幂（二进制中只有一个 1）
        if (n & (n - 1)) != 0:
            return False

        # 4 的幂在二进制中，1 只出现在奇数位置
        # 0x55555555 的二进制是 01010101010101010101010101010101
        # 这个掩码的奇数位都是 1，偶数位都是 0
        return (n & 0x55555555) != 0
```

:::

- 时间复杂度：$O(1)$
- 空间复杂度：$O(1)$

算法思路：

  - n 如果是 4 的幂，那么一定也是 2 的幂
  - n 是 2 的幂的前提下，又满足 4 的幂具有的特性（二进制的 1 在奇数位上），那么 n 就是 4 的幂

:::

- 空间复杂度：$O(1)$

算法思路：

  - n 如果是 4 的幂，那么一定也是 2 的幂
  - n 是 2 的幂的前提下，又满足 4 的幂具有的特性 `(n - 1) % 3 === 0`，那么 n 就是 4 的幂

### 3.1. 公式说明：$(n \& (n - 1)) = 0$

该公式用于判断一个正整数 $n$ 是否为 $2$ 的幂。

- 若 $n$ 是 $2$ 的幂，则其二进制表示中**有且仅有一个 $1$**，其余位均为 $0$。
- $n - 1$ 会将该唯一的 $1$ 变为 $0$，并将其右侧的所有 $0$ 变为 $1$。
- 因此 $n$ 与 $n - 1$ 在任何一个二进制位上都不会同时为 $1$，所以按位与的结果为 $0$。
- 反之，若 $n$ 不是 $2$ 的幂（且 $n > 0$），则其二进制中至少有两个 $1$，$n - 1$ 只会影响最低位的 $1$ 及其右侧，无法消除所有 $1$，因此 $n \& (n - 1)$ 的结果必然不为 $0$。
- 注意：$n$ 必须为正整数，负数和 $0$ 不满足条件。

**结论**：$(n \& (n - 1)) = 0$ 是 $n$ 为 $2$ 的幂的充要条件（在 $n > 0$ 的前提下）。

### 3.2. 公式说明：$(n - 1) \bmod 3 = 0$

该公式用于在已知 $n$ 是 $2$ 的幂的基础上，进一步判断它是否为 $4$ 的幂。

- 设 $n = 2^k$（因为 $n$ 是 $2$ 的幂）。
- 若 $k$ 为偶数，即 $k = 2m$，则 $n = 2^{2m} = (2^2)^m = 4^m$，此时 $n$ 是 $4$ 的幂。
- 若 $k$ 为奇数，即 $k = 2m + 1$，则 $n = 2^{2m+1} = 2 \cdot 4^m$，此时 $n$ 不是 $4$ 的幂。
- 考察 $2^k$ 对 $3$ 取模的规律：
  - $2^1 = 2 \equiv -1 \pmod 3$
  - $2^2 = 4 \equiv 1 \pmod 3$
  - $2^3 = 8 \equiv 2 \pmod 3$
  - $2^4 = 16 \equiv 1 \pmod 3$
  - 可见：当 $k$ 为偶数时，$2^k \equiv 1 \pmod 3$；当 $k$ 为奇数时，$2^k \equiv 2 \pmod 3$。
- 因此：
  - 若 $n$ 是 $4$ 的幂，则 $k$ 为偶数，$n \equiv 1 \pmod 3$，所以 $n - 1 \equiv 0 \pmod 3$，即 $(n - 1) \bmod 3 = 0$。
  - 若 $n$ 是 $2$ 的幂但不是 $4$ 的幂，则 $k$ 为奇数，$n \equiv 2 \pmod 3$，所以 $n - 1 \equiv 1 \pmod 3$，即 $(n - 1) \bmod 3 \neq 0$。

**结论**：在 $n$ 已经是 $2$ 的幂的前提下，$(n - 1) \bmod 3 = 0$ 是 $n$ 为 $4$ 的幂的充要条件。单独使用该条件不能判断 $4$ 的幂（例如 $n = 7$ 时 $(7 - 1) \bmod 3 = 0$，但 $7$ 不是 $2$ 的幂），必须与 $(n \& (n - 1)) = 0$ 联合使用。
