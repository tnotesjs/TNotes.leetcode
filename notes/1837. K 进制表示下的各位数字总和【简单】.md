## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/sum-of-digits-in-base-k/)

给你一个整数 `n`（`10` 进制）和一个基数 `k`，请你将 `n` 从 `10` 进制表示转换为 `k` 进制表示，计算并返回转换后各位数字的总和。

转换后，各位数字应当视作是 `10` 进制数字，且它们的总和也应当按 `10` 进制表示返回。

---

示例 1：

```txt
输入：n = 34, k = 6
输出：9

解释：
34 (10 进制) 在 6 进制下表示为 54。5 + 4 = 9。
```

---

示例 2：

```txt
输入：n = 10, k = 10
输出：1

解释：
n 本身就是 10 进制。 1 + 0 = 1。
```

---

提示：

- `1 <= n <= 100`
- `2 <= k <= 10`

## 2. 🎯 s.1 - 取模累加

::: code-group

```js [js]
/**
 * @param {number} n
 * @param {number} k
 * @return {number}
 */
var sumBase = function (n, k) {
  let ans = 0

  while (n > 0) {
    ans += n % k // 取 k 进制下的最后一位数字加入总和
    n = Math.floor(n / k) // 去掉 k 进制下的最后一位数字
  }

  return ans
}
```

:::

- 时间复杂度：$O(\log_k N)$，其中 N 是输入数字 n，需要循环 $\log_k N$ 次将 n 转换为 k 进制
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 初始化结果变量 ans 为 0
- 循环处理直到 n 为 0：提取最低位 n % k 累加到 ans，然后 n 整除 k 去掉最低位
- 重复上述过程直到 n 变为 0，此时 ans 即为 k 进制下各位数字之和，最终返回 ans 即可
