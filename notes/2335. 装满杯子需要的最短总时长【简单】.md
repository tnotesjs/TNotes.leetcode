## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/minimum-amount-of-time-to-fill-cups/)

现有一台饮水机，可以制备冷水、温水和热水。每秒钟，可以装满 `2` 杯不同类型的水或者 `1` 杯任意类型的水。

给你一个下标从 0 开始、长度为 `3` 的整数数组 `amount`，其中 `amount[0]`、`amount[1]` 和 `amount[2]` 分别表示需要装满冷水、温水和热水的杯子数量。返回装满所有杯子所需的最少秒数。

---

示例 1：

```txt
输入：amount = [1,4,2]
输出：4

解释：
下面给出一种方案：
第 1 秒：装满一杯冷水和一杯温水。
第 2 秒：装满一杯温水和一杯热水。
第 3 秒：装满一杯温水和一杯热水。
第 4 秒：装满一杯温水。
可以证明最少需要 4 秒才能装满所有杯子。
```

---

示例 2：

```txt
输入：amount = [5,4,4]
输出：7

解释：
下面给出一种方案：
第 1 秒：装满一杯冷水和一杯热水。
第 2 秒：装满一杯冷水和一杯温水。
第 3 秒：装满一杯冷水和一杯温水。
第 4 秒：装满一杯温水和一杯热水。
第 5 秒：装满一杯冷水和一杯热水。
第 6 秒：装满一杯冷水和一杯温水。
第 7 秒：装满一杯热水。
```

---

示例 3：

```txt
输入：amount = [5,0,0]
输出：5

解释：
每秒装满一杯冷水。
```

---

提示：

- `amount.length == 3`
- `0 <= amount[i] <= 100`

## 2. 🎯 s.1 - 数学公式

::: code-group

```js [js]
/**
 * @param {number[]} amount
 * @return {number}
 */
var fillCups = function (amount) {
  amount.sort((a, b) => a - b)
  const [a, b, c] = amount

  // 如果最大值大于等于另外两个之和,则需要 c 秒(一次装一杯)
  // 否则每次尽量装两杯不同的,需要 ceil((a+b+c)/2) 秒
  if (c >= a + b) {
    return c
  }
  return Math.ceil((a + b + c) / 2)
}
```

:::

- 时间复杂度:$O(1)$,只需要排序 3 个元素和简单计算
- 空间复杂度:$O(1)$,只使用常数额外空间

算法思路:

- 对三个杯子数量排序,设为 a ≤ b ≤ c
- 如果最大值 c ≥ a + b,说明在装完 a 和 b 的过程中可以同时消耗部分 c,剩余的 c 只能单独装,总时间为 c
- 否则每次尽量同时装两种杯子,总时间为 $\lceil(a + b + c) / 2\rceil$
