## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/append-characters-to-string-to-make-subsequence/)

给你两个仅由小写英文字母组成的字符串 `s` 和 `t`。

现在需要通过向 `s` 末尾追加字符的方式使 `t` 变成 `s` 的一个 子序列，返回需要追加的最少字符数。

子序列是一个可以由其他字符串删除部分（或不删除）字符但不改变剩下字符顺序得到的字符串。

---

示例 1：

```txt
输入：s = "coaching", t = "coding"
输出：4
解释：向 s 末尾追加字符串 "ding"，s = "coachingding"。
现在，t 是 s ("coachingding") 的一个子序列。
可以证明向 s 末尾追加任何 3 个字符都无法使 t 成为 s 的一个子序列。
```

---

示例 2：

```txt
输入：s = "abcde", t = "a"
输出：0
解释：t 已经是 s ("abcde") 的一个子序列。
```

---

示例 3：

```txt
输入：s = "z", t = "abcde"
输出：5
解释：向 s 末尾追加字符串 "abcde"，s = "zabcde"。
现在，t 是 s ("zabcde") 的一个子序列。
可以证明向 s 末尾追加任何 4 个字符都无法使 t 成为 s 的一个子序列。
```

---

提示：

- `1 <= s.length, t.length <= 10^5`
- `s` 和 `t` 仅由小写英文字母组成

## 2. 🎯 s.1 - 双指针

::: code-group

```js [js]
/**
 * @param {string} s
 * @param {string} t
 * @return {number}
 */
var appendCharacters = function (s, t) {
  let j = 0
  for (let i = 0; i < s.length && j < t.length; i++) {
    if (s[i] === t[j]) j++
  }
  return t.length - j
}
```

```c [c]
int appendCharacters(char* s, char* t) {
    int j = 0, tLen = strlen(t);
    for (int i = 0; s[i] && j < tLen; i++) {
        if (s[i] == t[j]) j++;
    }
    return tLen - j;
}
```

```py [py]
class Solution:
    def appendCharacters(self, s: str, t: str) -> int:
        j = 0
        for c in s:
            if j < len(t) and c == t[j]:
                j += 1
        return len(t) - j
```

:::

- 时间复杂度：$O(n + m)$，其中 n 和 m 分别是两个字符串的长度
- 空间复杂度：$O(1)$

算法思路：

- 双指针分别遍历 s 和 t
- 尽可能匹配 t 中的字符，未匹配的剩余部分即为需追加的字符数
