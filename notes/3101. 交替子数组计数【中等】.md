## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/count-alternating-subarrays/)

给你一个二进制数组 `nums`。

> 二进制数组是只包含 0 和 1 的数组。

如果一个子数组中 不存在 两个 相邻 元素的值 相同 的情况，我们称这样的子数组为 交替子数组。

> 子数组 是数组中连续的 非空 元素序列。

返回数组 `nums` 中交替子数组的数量。

---

示例 1：

- 输入：nums = [0,1,1,1]
- 输出：5
- 解释：以下子数组是交替子数组：`[0]` 、`[1]` 、`[1]` 、`[1]` 以及 `[0,1]`。

---

示例 2：

- 输入：nums = [1,0,1,0]
- 输出：10
- 解释：数组的每个子数组都是交替子数组。可以统计在内的子数组共有 10 个。

---

提示：

- `1 <= nums.length <= 10^5`
- `nums[i]` 不是 `0` 就是 `1`。

## 2. 🎯 s.1 - 一次遍历

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var countAlternatingSubarrays = function(nums) {
  const n = nums.length
  let count = 0
  let len = 1
  count = 1
  for (let i = 1; i < n; i++) {
    if (nums[i] !== nums[i - 1]) {
      len++
    } else {
      len = 1
    }
    count += len
  }
  return count
}
```

:::

- 时间复杂度：$O(n)$，遍历数组一次
- 空间复杂度：$O(1)$，只用常数额外空间

算法思路：

- 维护当前交替子数组的长度 len
- 如果当前元素与前一个不同，len++；否则 len 重置为 1
- 以每个位置结尾的交替子数组数量等于 len，累加即可
