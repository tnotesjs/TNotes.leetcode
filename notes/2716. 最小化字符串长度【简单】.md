## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/minimize-string-length/)

给你一个下标从 0 开始的字符串 `s`，重复执行下述操作任意次：

- 在字符串中选出一个下标 `i`，并使 `c` 为字符串下标 `i` 处的字符。并在 `i` 左侧（如果有）和右侧（如果有）各删除一个距离 `i` 最近的字符 `c`。

请你通过执行上述操作任意次，使 `s` 的长度最小化。

返回一个表示最小化字符串的长度的整数。

---

示例 1：

```txt
输入：s = "aaabc"
输出：3

解释：
在这个示例中，s 等于 "aaabc"。
我们可以选择位于下标 1 处的字符 'a' 开始。
接着删除下标 1 左侧最近的那个 'a'（位于下标 0）以及下标 1 右侧最近的那个 'a'（位于下标 2）。
执行操作后，字符串变为 "abc"。
继续对字符串执行任何操作都不会改变其长度。
因此，最小化字符串的长度是 3。
```

---

示例 2：

```txt
输入：s = "cbbd"
输出：3

解释：
我们可以选择位于下标 1 处的字符 'b' 开始。
下标 1 左侧不存在字符 'b'，但右侧存在一个字符 'b'（位于下标 2），所以会删除位于下标 2 的字符 'b'。
执行操作后，字符串变为 "cbd"。
继续对字符串执行任何操作都不会改变其长度。
因此，最小化字符串的长度是 3。
```

---

示例 3：

```txt
输入：s = "dddaaa"
输出：2

解释：
我们可以选择位于下标 1 处的字符 'd' 开始。
接着删除下标 1 左侧最近的那个 'd'（位于下标 0）以及下标 1 右侧最近的那个 'd'（位于下标 2）。
执行操作后，字符串变为 "daaa"。
继续对新字符串执行操作，可以选择位于下标 2 的字符 'a'。
接着删除下标 2 左侧最近的那个 'a'（位于下标 1）以及下标 2 右侧最近的那个 'a'（位于下标 3）。
执行操作后，字符串变为 "da"。
继续对字符串执行任何操作都不会改变其长度。
因此，最小化字符串的长度是 2。
```

---

提示：

- `1 <= s.length <= 100`
- `s` 仅由小写英文字母组成

## 2. 🎯 s.1 - 哈希集合

::: code-group

```js [js]
/**
 * @param {string} s
 * @return {number}
 */
var minimizedStringLength = function (s) {
  return new Set(s).size
}
```

:::

- 时间复杂度：$O(n)$，n 是字符串 s 的长度
- 空间复杂度：$O(n)$，哈希集合最多存储 n 个不同字符

算法思路：

- 观察操作规则：选择某个字符，删除其左右两侧最近的相同字符
- 关键发现：通过重复操作，每种字符最终都可以只保留一个
- 因此最小化后的字符串长度等于不同字符的数量
- 使用哈希集合统计字符串中不同字符的个数即可
