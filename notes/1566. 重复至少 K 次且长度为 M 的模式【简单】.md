## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/detect-pattern-of-length-m-repeated-k-or-more-times/)

给你一个正整数数组 `arr`，请你找出一个长度为 `m` 且在数组中至少重复 `k` 次的模式。

模式是由一个或多个值组成的子数组（连续的子序列），连续重复多次但不重叠。模式由其长度和重复次数定义。

如果数组中存在至少重复 `k` 次且长度为 `m` 的模式，则返回 `true`，否则返回 `false`。

---

示例 1：

```txt
输入：arr = [1,2,4,4,4,4], m = 1, k = 3
输出：true

解释：
模式 (4) 的长度为 1，且连续重复 4 次。
注意，模式可以重复 k 次或更多次，但不能少于 k 次。
```

---

示例 2：

```txt
输入：arr = [1,2,1,2,1,1,1,3], m = 2, k = 2
输出：true

解释：
模式 (1,2) 长度为 2，且连续重复 2 次。
另一个符合题意的模式是 (2,1)，同样重复 2 次。
```

---

示例 3：

```txt
输入：arr = [1,2,1,2,1,3], m = 2, k = 3
输出：false

解释：
模式 (1,2) 长度为 2，但是只连续重复 2 次。
不存在长度为 2 且至少重复 3 次的模式。
```

---

示例 4：

```txt
输入：arr = [1,2,3,1,2], m = 2, k = 2
输出：false

解释：
模式 (1,2) 出现 2 次但并不连续，所以不能算作连续重复 2 次。
```

---

示例 5：

```txt
输入：arr = [2,2,2,2], m = 2, k = 3
输出：false

解释：
长度为 2 的模式只有 (2,2)，但是只连续重复 2 次。
注意，不能计算重叠的重复次数。
```

---

提示：

- `2 <= arr.length <= 100`
- `1 <= arr[i] <= 100`
- `1 <= m <= 100`
- `2 <= k <= 100`

## 2. 🎯 s.1 - 三重循环

::: code-group

```js [js]
/**
 * @param {number[]} arr
 * @param {number} m
 * @param {number} k
 * @return {boolean}
 */
var containsPattern = function (arr, m, k) {
  const n = arr.length
  const need = m * k

  // 遍历所有可能的起始位置 i
  for (let i = 0; i + need <= n; i++) {
    let ok = true
    // 检查模式的每个位置 offset（0 到 m-1）
    for (let offset = 0; offset < m; offset++) {
      // 检查重复的 k 次
      for (let rep = 1; rep < k; rep++) {
        if (arr[i + offset] !== arr[i + rep * m + offset]) {
          ok = false
          break
        }
      }
      if (!ok) break
    }
    if (ok) return true
  }

  return false
}
```

:::

- 时间复杂度：$O(N \cdot M \cdot K)$，外层枚举起点 $O(N)$，内层两重循环分别遍历模式长度 $O(M)$ 和重复次数 $O(K)$
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 枚举所有可能的起始位置 `i`（需满足 `i + m * k <= n`）
- 对于每个起始位置，检查模式的每个位置 `offset`（从 0 到 m-1）在 k 次重复中是否都相等
- 通过三重循环验证：起点循环、模式位置循环、重复次数循环
- 若某个位置不匹配则立即剪枝，所有位置都匹配则返回 `true`

## 3. 🎯 s.2 - 一重循环

::: code-group

```js [js]
/**
 * @param {number[]} arr
 * @param {number} m
 * @param {number} k
 * @return {boolean}
 */
var containsPattern = function (arr, m, k) {
  let count = 0
  for (let i = 0; i < arr.length - m; i++) {
    // 比较当前元素与 m 个位置后的元素
    if (arr[i] === arr[i + m]) {
      count++
      // 如果连续匹配了 m*(k-1) 次，说明找到了模式
      if (count >= m * (k - 1)) {
        return true
      }
    } else {
      // 若 arr[i] === arr[i+m] 不成立，则 arr[i] 不可能出现在任何有效的模式串中
      // 此时 0-i 都已经扫描过了，继续向后检查即可
      count = 0 // 重置计数器
    }
  }
  return false
}
```

:::

- 时间复杂度：$O(N)$，只需遍历数组一次
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 核心观察：如果存在长度为 m、重复 k 次的模式，那么 `arr[i] == arr[i+m]` 必须连续成立 $m \times (k-1)$ 次
- 遍历数组，比较当前元素与距离 m 的元素是否相等，相等则计数器加 1，不等则重置为 0
- 当计数器达到 $m \times (k-1)$ 时，说明找到了符合条件的模式
