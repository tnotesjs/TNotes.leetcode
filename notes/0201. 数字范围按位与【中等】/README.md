## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/bitwise-and-of-numbers-range/)

给你两个整数 `left` 和 `right`，表示区间 `[left, right]`，返回此区间内所有数字按位与的结果（包含 `left`、`right` 端点）。

---

示例 1：

```txt
输入：left = 5, right = 7
输出：4
```

---

示例 2：

```txt
输入：left = 0, right = 0
输出：0
```

---

示例 3：

```txt
输入：left = 1, right = 2147483647
输出：0
```

---

提示：

- `0 <= left <= right <= 2^31 - 1`

算法思路：

- 范围内所有数字按位与的结果就是 `left` 和 `right` 的二进制公共前缀
- 同时右移 `left` 和 `right` 直到它们相等，记录移动次数，最后左移回去

## 3. 【AI】为什么 s.1 求的最长公共前缀就是本题的解？

这句是在说：**区间里所有数做按位与，结果等于两端 `left`、`right` 二进制的公共前缀（后面补 0）。**

### 3.1. 为什么？

按位与里，某一位最终是 1，当且仅当区间里**每一个数**这一位都是 1。  
只要区间里有人这一位是 0，这一位结果就是 0。

从 `left` 连续加到 `right`，二进制会不断进位。进位意味着：

- **公共前缀之后的那些低位**，在区间里一定会既出现 0 也出现 1（甚至会整体翻一遍）
- 所以这些低位在「全体按位与」里必然变成 0
- **只有两边都没变过的高位前缀**才能留下来

因此：

$$
left\ \&\ (left+1)\ \&\ \cdots\ \&\ right
$$

等于 `left` 与 `right` 的二进制公共前缀（其后补 0），不必真的把中间每个数都与一遍。

### 3.2. 用示例 `left = 5, right = 7`

```text
5 = 101
6 = 110
7 = 111
────────
AND = 100 = 4
```

`5` 和 `7` 的公共前缀是高位的 `1`，后面两位不同 → 补 0 得 `100`。

代码做法：两边一起右移，直到相等（公共前缀对齐），再左移同样次数补回 0：

```text
5 >> 1 → 2,  7 >> 1 → 3
2 >> 1 → 1,  3 >> 1 → 1   ← 相等，前缀是 1
1 << 2 → 4
```

### 3.3. 直觉一句话

区间越宽，低位翻得越狠，留下来的公共前缀越短；若跨过了更高位的进位（比如 `1` 到 `2^31-1`），前缀为空，结果就是 `0`。
