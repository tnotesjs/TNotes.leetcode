## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/contains-duplicate-ii/)

给你一个整数数组 `nums` 和一个整数 `k`，判断数组中是否存在两个不同的索引 `i` 和 `j`，满足 `nums[i] == nums[j]` 且 `abs(i - j) <= k`。

- 如果存在，返回 `true`
- 否则，返回 `false`

---

示例 1：

```txt
输入：nums = [1, 2, 3, 1], k = 3
输出：true
```

---

示例 2：

```txt
输入：nums = [1, 0, 1, 1], k = 1
输出：true
```

---

示例 3：

```txt
输入：nums = [1, 2, 3, 1, 2, 3], k = 2
输出：false

```

---

提示：

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `0 <= k <= 10^5`

## 2. s.1 - 滑动窗口 + 哈希集合

```c [c]
static unsigned int hashInt(int x) {
    unsigned int h = (unsigned int)x;
    h ^= h >> 16;
    h *= 0x7feb352du;
    h ^= h >> 15;
    h *= 0x846ca68bu;
    h ^= h >> 16;
    return h;
}

// 删除不能只打标记，要把探测链上能前移的元素搬过来补洞
static void eraseAt(size_t i, int *keys, unsigned char *used, size_t cap) {
    size_t j = i;
    for (;;) {
        j = (j + 1) & (cap - 1);
        if (!used[j]) break;

        size_t home = hashInt(keys[j]) & (cap - 1);
        // home 落在 (i, j] 这段环形区间内，说明 keys[j] 不能前移
        if (i <= j ? (home > i && home <= j) : (home > i || home <= j)) continue;

        keys[i] = keys[j];
        used[i] = 1;
        i = j;
    }
    used[i] = 0;
}

bool containsNearbyDuplicate(int* nums, int numsSize, int k) {
    // 窗口最多同时存在 min(n, k + 1) 个元素，容量按它取，保证负载因子不超过 0.5
    size_t maxWin = (size_t)((k + 1 < numsSize) ? k + 1 : numsSize);
    size_t cap = 1;
    while (cap < maxWin * 2) {
        cap <<= 1;
    }

    int *keys = (int *)malloc(cap * sizeof(int));
    unsigned char *used = (unsigned char *)calloc(cap, sizeof(unsigned char));

    if (!keys || !used) {
        free(keys);
        free(used);
        return false;
    }

    for (int i = 0; i < numsSize; i++) {
        int x = nums[i];

        // 开放寻址线性探测
        size_t pos = hashInt(x) & (cap - 1);
        while (used[pos]) {
            if (keys[pos] == x) {
                free(keys);
                free(used);
                return true;
            }
            pos = (pos + 1) & (cap - 1);
        }

        used[pos] = 1;
        keys[pos] = x;

        // 下标 i - k 滑出窗口
        if (i >= k) {
            int old = nums[i - k];
            size_t hole = hashInt(old) & (cap - 1);
            while (!used[hole] || keys[hole] != old) {
                hole = (hole + 1) & (cap - 1);
            }
            eraseAt(hole, keys, used, cap);
        }
    }

    free(keys);
    free(used);
    return false;
}
```

```js [js]
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {boolean}
 */
var containsNearbyDuplicate = function (nums, k) {
  const seen = new Set();

  for (let i = 0; i < nums.length; i++) {
    // 窗口里出现过，说明它上一次出现的下标与 i 的距离不超过 k
    if (seen.has(nums[i])) {
      return true;
    }

    seen.add(nums[i]);

    // 下标 i - k 滑出窗口
    if (i >= k) {
      seen.delete(nums[i - k]);
    }
  }

  return false;
};
```

```py [py]
class Solution:
    def containsNearbyDuplicate(self, nums: List[int], k: int) -> bool:
        seen = set()

        for i, num in enumerate(nums):
            # 窗口里出现过，说明它上一次出现的下标与 i 的距离不超过 k
            if num in seen:
                return True

            seen.add(num)

            # 下标 i - k 滑出窗口
            if i >= k:
                seen.remove(nums[i - k])

        return False
```

:::

- 时间复杂度：$O(n)$，其中 n 是数组长度；每个元素最多进、出窗口各一次，哈希集合的查找、插入、删除都是期望 $O(1)$
- 空间复杂度：$O(\min(n, k))$，哈希集合只保存当前窗口内的元素，最多 $k + 1$ 个，不随 n 无限增长

算法思路：

- 关键洞察是「只需要回看最近 `k` 个元素」：更早出现过的下标距离当前一定超过 `k`，没有再比较的价值，滑出窗口的元素可以放心丢掉
- 窗口里保存的是「最近访问过的元素」，最多同时存在 `k + 1` 个
- 遍历数组，如果当前元素已在窗口里，说明它上一次出现的下标与当前下标的距离不超过 `k`，直接返回 `true`
- 否则把当前元素加入窗口
- 当 `i >= k` 时，下标 `i - k` 已经不可能再和后面的元素凑成合法的一对，把它从窗口里移出，窗口大小因而只和 `k` 有关
- 遍历结束仍未命中，返回 `false`
