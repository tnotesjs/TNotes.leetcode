## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/count-primes/)

给定整数 `n`，返回所有小于非负整数 `n` 的质数的数量。

---

示例 1：

```txt
输入：n = 10
输出：4
```

解释：小于 10 的质数一共有 4 个，它们是 2、3、5、7。

---

示例 2：

```txt
输入：n = 0
输出：0
```

---

示例 3：

```txt
输入：n = 1
输出：0
```

---

提示：

- `0 <= n <= 5 * 10^6`

算法思路：

- 初始化布尔数组，所有数默认为质数
- 从 2 开始，将每个质数的倍数标记为非质数，从 $i^2$ 开始标记以避免重复

## 3. 【AI】请简单介绍一下“埃氏筛”算法

埃氏筛全称 **埃拉托斯特尼筛法**（Sieve of Eratosthenes），用来高效找出不超过某个上限的所有质数。核心想法：

**从小到大枚举数；每遇到一个质数，就把它的倍数全部划掉——剩下没被划掉的就是质数。**

### 3.1. 为什么这样对？

- 合数 $m$ 一定有因子 $d$，且 $1 < d \le \sqrt{m}$
- 所以当枚举到质数 $p$ 时，所有 $p$ 的倍数 $2p, 3p, \ldots$ 都不可能是质数，可以一次性标记掉
- $0$、$1$ 不是质数，一开始就排除

### 3.2. 流程（求 $< n$ 的质数个数）

1. 开长度为 $n$ 的布尔数组，默认都是质数候选；把 `0`、`1` 标为否  
2. 从 $i = 2$ 枚举到 $\sqrt{n}$：若 $i$ 仍是质数，则从 $i^2$ 起，按步长 $i$ 把倍数标成非质数  
3. 统计数组里仍为质数的个数  

从 $i^2$ 开始标，是因为更小的倍数 $2i, 3i, \ldots, (i-1)i$ 早已被更小的质因子标过了。

### 3.3. 小例子（$n = 10$，求 $< 10$ 的质数）

初始候选：`2 3 4 5 6 7 8 9`

- $i=2$ 是质数 → 划掉 $4,6,8$（从 $2^2=4$ 起）  
- $i=3$ 是质数 → 划掉 $9$（从 $3^2=9$ 起）  
- $i=4$ 已被划掉，跳过  

剩下：`2 3 5 7`，共 4 个。

### 3.4. 复杂度

- 时间约 $O(n \log \log n)$，比「每个数试除到 $\sqrt{x}$」的 $O(n\sqrt{n})$ 好得多  
- 空间 $O(n)$，要存整张标记表  

本题数据到 $5\times 10^6$，埃氏筛是标准解；若上限极大、只要判单个数是否质数，则不必筛整张表。
