## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/happy-number/)

编写一个算法来判断一个数 `n` 是不是快乐数。

「快乐数」定义为：

- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和。
- 然后重复这个过程直到这个数变为 1，也可能是无限循环但始终变不到 1。
- 如果这个过程结果为 1，那么这个数就是快乐数。

如果 `n` 是快乐数就返回 `true`；不是，则返回 `false`。

---

示例 1：

```txt
输入：n = 19
输出：true
```

解释：

- $1^2 + 9^2 = 82$
- $8^2 + 2^2 = 68$
- $6^2 + 8^2 = 100$
- $1^2 + 0^2 + 0^2 = 1$

---

示例 2：

```txt
输入：n = 2
输出：false
```

---

提示：

- `1 <= n <= 2^31 - 1`

- 时间复杂度：$O(\log n)$，每次各位平方和会使数值快速变小
- 空间复杂度：$O(\log n)$，哈希表记录出现过的中间结果（实际很快落入很小范围）

算法思路：

- 反复将当前数替换为各位数字的平方和
- 用哈希集合记录已出现过的数：若再次出现，说明进入非 1 的循环，返回 `false`
- 若某次结果为 1，则是快乐数，返回 `true`

- 时间复杂度：$O(\log n)$，与哈希判环同量级，每次平方和会使数值快速变小
- 空间复杂度：$O(1)$，只用快慢两个指针，无需记录历史

算法思路：

- 将「各位平方和」看作链表上的 `next`，快乐数过程要么到 1，要么进环
- 慢指针每次走 1 步，快指针每次走 2 步
- 若快指针先到 1，则是快乐数；若两者相遇，则进入非 1 的环，返回 `false`
