## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/reverse-bits/)

颠倒给定的 32 位无符号整数的二进制位。

---

示例 1：

```txt
输入：n = 43261596
输出：964176192
```

解释：

| 整数      | 二进制                           |
| --------- | -------------------------------- |
| 43261596  | 00000010100101000001111010011100 |
| 964176192 | 00111001011110000010100101000000 |

---

示例 2：

```txt
输入：n = 2147483644
输出：1073741822
```

解释：

| 整数       | 二进制                           |
| ---------- | -------------------------------- |
| 2147483644 | 01111111111111111111111111111100 |
| 1073741822 | 00111111111111111111111111111110 |

---

提示：

- `0 <= n <= 2^31 - 2`
- `n` 为偶数

---

进阶：如果多次调用这个函数，你将如何优化你的算法？

## 2. s.1 - 逐位反转

::: code-group

```c [c]
uint32_t reverseBits(uint32_t n) {
    uint32_t result = 0;
    for (int i = 0; i < 32; i++) {
        // result 左移腾出最低位；取 n 的最低位拼进去；n 右移处理下一位
        result = (result << 1) | (n & 1);
        n >>= 1;
    }
    return result;
}
```

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var reverseBits = function (n) {
  let result = 0
  for (let i = 0; i < 32; i++) {
    // result 左移腾出最低位；取 n 的最低位拼进去；n 右移处理下一位
    result = (result << 1) | (n & 1)
    n >>= 1
  }
  return result
}
```

```py [py]
class Solution:
    def reverseBits(self, n: int) -> int:
        result = 0
        for _ in range(32):
            # result 左移腾出最低位；取 n 的最低位拼进去；n 右移处理下一位
            result = (result << 1) | (n & 1)
            n >>= 1
        return result
```

:::

- 时间复杂度：$O(1)$，固定循环 32 次，与输入数值大小无关
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 从低到高处理 `n` 的每一位：取出最低位，拼到 `result` 的最低位
- 每处理一位：`result` 左移一位腾位置，`n` 右移一位准备下一位
- 循环恰好 32 次后，`result` 即为颠倒后的 32 位结果（JS 需再 `>>> 0` 转成无符号）

## 3. s.2 - 分治位运算

::: code-group

```c [c]
uint32_t reverseBits(uint32_t n) {
    // 先交换左右 16 位，再 8、4、2、1，成块完成位反转
    n = (n >> 16) | (n << 16);
    n = ((n & 0x00ff00ffu) << 8) | ((n & 0xff00ff00u) >> 8);
    n = ((n & 0x0f0f0f0fu) << 4) | ((n & 0xf0f0f0f0u) >> 4);
    n = ((n & 0x33333333u) << 2) | ((n & 0xccccccccu) >> 2);
    n = ((n & 0x55555555u) << 1) | ((n & 0xaaaaaaaau) >> 1);
    return n;
}
```

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var reverseBits = function (n) {
  // 先交换左右 16 位，再 8、4、2、1，成块完成位反转
  n = ((n >>> 16) | (n << 16)) >>> 0
  n = (((n & 0x00ff00ff) << 8) | ((n & 0xff00ff00) >>> 8)) >>> 0
  n = (((n & 0x0f0f0f0f) << 4) | ((n & 0xf0f0f0f0) >>> 4)) >>> 0
  n = (((n & 0x33333333) << 2) | ((n & 0xcccccccc) >>> 2)) >>> 0
  n = (((n & 0x55555555) << 1) | ((n & 0xaaaaaaaa) >>> 1)) >>> 0
  return n
}
```

```py [py]
class Solution:
    def reverseBits(self, n: int) -> int:
        # 先交换左右 16 位，再 8、4、2、1，成块完成位反转
        n = ((n >> 16) | (n << 16)) & 0xFFFFFFFF
        n = (((n & 0x00FF00FF) << 8) | ((n & 0xFF00FF00) >> 8)) & 0xFFFFFFFF
        n = (((n & 0x0F0F0F0F) << 4) | ((n & 0xF0F0F0F0) >> 4)) & 0xFFFFFFFF
        n = (((n & 0x33333333) << 2) | ((n & 0xCCCCCCCC) >> 2)) & 0xFFFFFFFF
        n = (((n & 0x55555555) << 1) | ((n & 0xAAAAAAAA) >> 1)) & 0xFFFFFFFF
        return n
```

:::

- 时间复杂度：$O(1)$，固定若干次整字位运算，与输入数值大小无关
- 空间复杂度：$O(1)$，原地修改，只使用常数额外空间

算法思路：

- 类似归并：先把左右 16 位对调，再对调每组内的 8 位，依次到 4、2、1
- 每一步用掩码取出奇数段/偶数段，分别左移、右移后合并
- 与 s.1 同为 $O(1)/O(1)$，但循环轮次更少，常数通常更小；可读性不如逐位法
