## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/wiggle-sort-ii/)

给你一个整数数组 `nums`，将它重新排列成 `nums[0] < nums[1] > nums[2] < nums[3]...` 的顺序。

你可以假设所有输入数组都可以得到满足题目要求的结果。

---

示例 1：

```txt
输入：nums = [1, 5, 1, 1, 6, 4]
输出：[1, 6, 1, 5, 1, 4]
```

解释：`[1, 4, 1, 5, 1, 6]` 同样是符合题目要求的结果，可以被判题程序接受。

---

示例 2：

```txt
输入：nums = [1, 3, 2, 2, 3, 1]
输出：[2, 3, 1, 3, 1, 2]
```

---

提示：

- `1 <= nums.length <= 5 * 10^4`
- `0 <= nums[i] <= 5000`
- 题目数据保证，对于给定的输入 `nums`，总能产生满足题目要求的结果

---

进阶：你能用 $O(n)$ 时间复杂度和 / 或原地 $O(1)$ 额外空间来实现吗？

## 2. s.1 - 快速选择 + 三路划分

::: code-group

```c [c]
void swap(int* a, int* b) { int t = *a; *a = *b; *b = t; }

int mapIndex(int i, int n) { return (1 + 2 * i) % (n | 1); }

int findMedian(int* nums, int n) {
    int target = n / 2, lo = 0, hi = n - 1;
    while (lo <= hi) {
        int pivot = nums[lo + rand() % (hi - lo + 1)];
        int lt = lo, i = lo, gt = hi;
        while (i <= gt) {
            if (nums[i] < pivot) swap(&nums[lt++], &nums[i++]);
            else if (nums[i] > pivot) swap(&nums[i], &nums[gt--]);
            else i++;
        }
        if (target < lt) hi = lt - 1;
        else if (target > gt) lo = gt + 1;
        else return pivot;
    }
    return nums[target];
}

void wiggleSort(int* nums, int numsSize) {
    int median = findMedian(nums, numsSize);
    int lt = 0, i = 0, gt = numsSize - 1;
    while (i <= gt) {
        int vi = mapIndex(i, numsSize);
        if (nums[vi] > median) {
            swap(&nums[mapIndex(lt, numsSize)], &nums[vi]);
            lt++;
            i++;
        } else if (nums[vi] < median) {
            swap(&nums[vi], &nums[mapIndex(gt, numsSize)]);
            gt--;
        } else {
            i++;
        }
    }
}
```

/**
 * @param {number[]} nums
 * @return {void} Do not return anything, modify nums in-place instead.

var wiggleSort = function (nums) {
  const n = nums.length

  function findMedian(target) {
    let lo = 0,
      hi = n - 1
    while (lo <= hi) {
      const pivot = nums[lo + Math.floor(Math.random() * (hi - lo + 1))]
      let lt = lo,
        i = lo,
        gt = hi
      while (i <= gt) {
        if (nums[i] < pivot) {
          [nums[lt], nums[i]] = [nums[i], nums[lt]]
          lt++
          i++
        } else if (nums[i] > pivot) {
          [nums[i], nums[gt]] = [nums[gt], nums[i]]
          gt--
        } else {
          i++
        }
      }
      if (target < lt) hi = lt - 1
      else if (target > gt) lo = gt + 1
      else return pivot
    }
    return nums[target]
  }

  const median = findMedian(Math.floor(n / 2))
  const map = (i) => (1 + 2 * i) % (n | 1)
  let lt = 0,
    i = 0,
    gt = n - 1
  while (i <= gt) {
    const vi = map(i)
    if (nums[vi] > median) {
      const j = map(lt)
      ;[nums[j], nums[vi]] = [nums[vi], nums[j]]
      lt++
      i++
    } else if (nums[vi] < median) {
      const j = map(gt)
      ;[nums[vi], nums[j]] = [nums[j], nums[vi]]
      gt--
    } else {
      i++
    }
  }
}

```py [py]
import random

class Solution:
    def wiggleSort(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        n = len(nums)

        def find_median(target):
            lo, hi = 0, n - 1
            while lo <= hi:
                pivot = nums[random.randint(lo, hi)]
                lt, i, gt = lo, lo, hi
                while i <= gt:
                    if nums[i] < pivot:
                        nums[lt], nums[i] = nums[i], nums[lt]
                        lt += 1
                        i += 1
                    elif nums[i] > pivot:
                        nums[i], nums[gt] = nums[gt], nums[i]
                        gt -= 1
                    else:
                        i += 1
                if target < lt:
                    hi = lt - 1
                elif target > gt:
                    lo = gt + 1
                else:
                    return pivot
            return nums[target]

        median = find_median(n // 2)

        def mapped(i):
            return (1 + 2 * i) % (n | 1)

        lt, i, gt = 0, 0, n - 1
        while i <= gt:
            vi = mapped(i)
            if nums[vi] > median:
                j = mapped(lt)
                nums[j], nums[vi] = nums[vi], nums[j]
                lt += 1
                i += 1
            elif nums[vi] < median:
                j = mapped(gt)
                nums[vi], nums[j] = nums[j], nums[vi]
                gt -= 1
            else:
                i += 1
```

:::

- 时间复杂度：平均 $O(n)$，快速选择期望线性，三路划分再扫一遍
- 空间复杂度：$O(1)$，原地完成，只用常数额外变量

算法思路：

- 随机选取划分点做快速选择，得到升序下标 $\lfloor n / 2 \rfloor$ 处的中位数
- 下标 $i$ 映射为 `(1 + 2i) % (n | 1)` 后，前半段是奇数位，后半段是偶数位
- 沿该映射做三路划分：大于中位数的放前面，小于中位数的放后面，相等的留在中间，相邻位就不会相等

### 2.1. `findMedian(target)`：快速选择找中位数

它的作用是找到 **排序后** 下标为 `target` 的元素。这里：

```js
const median = findMedian(Math.floor(n / 2));
```

即找中位数。如果 `n` 是偶数，取的是偏右的那个中位数。

这里用了 **三路划分**，把当前区间分成：

```text
[lo, lt-1]   小于 pivot
[lt, gt]     等于 pivot
[gt+1, hi]   大于 pivot
```

然后看目标下标 `target` 落在哪一段：

- `target < lt`：目标在左边，继续在左半段找；
- `target > gt`：目标在右边，继续在右半段找；
- 否则目标就在等于 `pivot` 的区间里，直接返回 `pivot`。

随机选 pivot 是为了让平均时间复杂度达到 `O(n)`。

### 2.2. `map(i)`：虚拟索引映射

```js
const map = (i) => (1 + 2 * i) % (n | 1);
```

这是这个算法最巧妙的地方。

它生成一个“虚拟访问顺序”，例如 `n = 6` 时：

```text
i:     0  1  2  3  4  5
map:   1  3  5  0  2  4
 ```

也就是说，虚拟顺序是：

```text
奇数下标：1, 3, 5, ...
偶数下标：0, 2, 4, ...
```

为什么这样映射？

因为 wiggle 序列要求：

```text
偶数位 < 奇数位 > 偶数位 < 奇数位 ...
```

所以我们希望：

- 大于中位数的数尽量放在奇数位；
- 小于中位数的数尽量放在偶数位；
- 等于中位数的数放中间。

而虚拟顺序中，前一段对应实际奇数位，后一段对应实际偶数位。

这样对虚拟顺序做三路划分，就能自然地把大数放到奇数位，小数放到偶数位。

### 2.3. 主循环：在虚拟索引上做三路划分

```js
let lt = 0, i = 0, gt = n - 1;
while (i <= gt) {
  const vi = map(i);
  if (nums[vi] > median) {
    const j = map(lt);
    [nums[j], nums[vi]] = [nums[vi], nums[j]];
    lt++;
    i++;
  } else if (nums[vi] < median) {
    const j = map(gt);
    [nums[vi], nums[j]] = [nums[j], nums[vi]];
    gt--;
  } else {
    i++;
  }
}
```

这里是在虚拟索引空间上按 `median` 做三路划分：

- `nums[vi] > median`：放到虚拟序列前部，也就是实际奇数位；
- `nums[vi] < median`：放到虚拟序列后部，也就是实际偶数位；
- `nums[vi] === median`：留在中间，不急着移动。

交换时：

- `map(lt)` 是虚拟前部当前位置对应的实际索引；
- `map(gt)` 是虚拟后部当前位置对应的实际索引。

这样最终数组会变成：

```text
奇数位：大于或等于中位数的数
偶数位：小于或等于中位数的数
```

并且由于中位数本身的性质和虚拟索引的错位映射，相邻位置不会出现相等，从而满足严格 wiggle：

```text
nums[0] < nums[1] > nums[2] < nums[3] ...
```

### 2.4. 为什么这样能得到 wiggle 序列？

因为中位数把数组分成两部分：

- 小于中位数的数；
- 大于中位数的数；
- 等于中位数的数。

把大于中位数的数放到奇数位，把小于中位数的数放到偶数位，那么任意相邻的：

```text
偶数位 < 奇数位
奇数位 > 下一个偶数位
```

就能成立。

等于中位数的数被放在中间，避免它们破坏相邻的大小关系。

```{4}
i:     0  1  2  3  4  5
map:   1  3  5  0  2  4
假设： 大 大 中 中 小 小
中位数对应的真实索引是数组的两端，并且题目数据保证给的数据一定有解，因此不会出现中中相邻的情况。
```

在真实索引中，中位数会被“挤”到数组的两端和交界处，而相邻位置总是“一大一小”或“一大一中”或“一中一小”的组合，不会出现“中中”相邻。

### 2.5. 复杂度

- 时间复杂度：平均 `O(n)`，最坏 `O(n^2)`，但随机 pivot 使最坏情况概率极低。
- 空间复杂度：`O(1)`，原地修改数组。

总结一句话：这段代码先用快速选择找到中位数，再通过 `map` 虚拟索引把数组按中位数三路划分，最终让奇数位放大数、偶数位放小数，从而原地构造出 wiggle 序列。
