## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/bulb-switcher/)

初始时有 `n` 个灯泡处于关闭状态。第一轮，你将会打开所有灯泡。接下来的第二轮，你将会每两个灯泡关闭第二个。

第三轮，你每三个灯泡就切换第三个灯泡的开关（即，打开变关闭，关闭变打开）。第 `i` 轮，你每 `i` 个灯泡就切换第 `i` 个灯泡的开关。直到第 `n` 轮，你只需要切换最后一个灯泡的开关。

找出并返回 `n` 轮后有多少个亮着的灯泡。

---

示例 1：

![](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-09-11-11-59-29.png) {w=262px}

```txt
输入：n = 3
输出：1
```

解释：

- 初始时, 灯泡状态 `[关闭, 关闭, 关闭]`.
- 第一轮后, 灯泡状态 `[开启, 开启, 开启]`.
- 第二轮后, 灯泡状态 `[开启, 关闭, 开启]`.
- 第三轮后, 灯泡状态 `[开启, 关闭, 关闭]`.

你应该返回 1，因为只有一个灯泡还亮着。

---

示例 2：

```txt
输入：n = 0
输出：0
```

---

示例 3：

```txt
输入：n = 1
输出：1
```

---

提示：

- `0 <= n <= 10^9`

## 2. s.1 - 数学

::: code-group

```c [c]
int bulbSwitch(int n) {
    return (int)sqrt((double)n);
}
```

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var bulbSwitch = function (n) {
  return Math.floor(Math.sqrt(n))
}
```

```py [py]
class Solution:
    def bulbSwitch(self, n: int) -> int:
        return int(n ** 0.5)
```

:::

- 时间复杂度：$O(1)$
- 空间复杂度：$O(1)$

算法思路：

- 第 $k$ 个灯泡被切换的次数等于 $k$ 的约数个数
- 只有完全平方数有奇数个约数，因此答案即 $\lfloor\sqrt{n}\rfloor$

## 3. 【AI】详细解释 `s.1`

### 3.1. 题目规则

有 `n` 个灯泡，初始全部**关闭**。

进行 `n` 轮操作：

- 第 1 轮：**打开所有灯泡**（即切换所有灯泡，因为初始全关，切换后全开）。
- 第 2 轮：每 2 个灯泡切换一次（第 2、4、6… 个）。
- 第 3 轮：每 3 个灯泡切换一次（第 3、6、9… 个）。
- ……
- 第 `i` 轮：每 `i` 个灯泡切换一次（编号为 `i` 的倍数的灯泡）。
- 第 `n` 轮：只切换第 `n` 个灯泡。

问：`n` 轮之后，有多少个灯泡是**亮**的？

> 注意：第 1 轮虽然是“打开”，但可以统一理解为“切换”，因为初始全关，切换后就是全开。

---

### 3.2. 关键观察：每个灯泡被切换几次？

编号为 `k` 的灯泡，会在哪些轮被切换？

第 `d` 轮会切换所有编号是 `d` 的倍数的灯泡。

所以编号 `k` 的灯泡在第 `d` 轮被切换，当且仅当 `d` 能整除 `k`，也就是 `d` 是 `k` 的约数。

因此：

> **灯泡 `k` 被切换的次数 = `k` 的约数个数。**

---

### 3.3. 约数是什么？

约数（因数）就是能整除某个数的正整数。

例如 12 的约数：1, 2, 3, 4, 6, 12 —— 共 6 个。

灯泡 12 会在第 1、2、3、4、6、12 轮被切换，共 6 次。

---

### 3.4. 切换次数与亮灭的关系

初始是关闭的。

- 切换奇数次 → 亮
- 切换偶数次 → 关

所以问题变成：

> 哪些编号的约数个数是奇数？

---

### 3.5. 哪些数的约数个数是奇数？

先看约数是怎么配对的。

以 12 为例：

- 1 × 12 = 12
- 2 × 6 = 12
- 3 × 4 = 12

每一对乘积都是 12，所以约数总是**成对出现**，总数是偶数。

但有一种特殊情况：**完全平方数**。

以 9 为例，约数有：1, 3, 9。 

配对：

- 1 × 9 = 9
- 3 × 3 = 9

中间的 3 和自己配对，只算一个约数。所以 9 的约数个数是 3 个，奇数。

结论：

- **非完全平方数**：约数成对出现，个数是偶数 → 灯泡最终关。
- **完全平方数**：中间有一个约数和自己配对，个数是奇数 → 灯泡最终亮。

---

### 3.6. 答案

最终亮着的灯泡就是 1 到 `n` 中的完全平方数：

`1, 4, 9, 16, 25, 36, ...`

数量就是 `1` 到 `n` 中完全平方数的个数，也就是：

```text
⌊√n⌋
```

例如：

- `n = 3`：完全平方数有 1，共 1 个 → `⌊√3⌋ = 1`
- `n = 4`：有 1, 4，共 2 个 → `⌊√4⌋ = 2`
- `n = 10`：有 1, 4, 9，共 3 个 → `⌊√10⌋ = 3`
- `n = 16`：有 1, 4, 9, 16，共 4 个 → `⌊√16⌋ = 4`

---

### 3.7. 代码

```js
/**
 * @param {number} n
 * @return {number}
 */
var bulbSwitch = function(n) {
    return Math.floor(Math.sqrt(n));
};
```

时间 O(1)，空间 O(1)。

---

### 3.8. 一句话总结

每个灯泡被切换的次数等于其编号的约数个数；只有完全平方数的约数个数为奇数，所以最终亮着的灯泡就是完全平方数，个数为 `⌊√n⌋`。
