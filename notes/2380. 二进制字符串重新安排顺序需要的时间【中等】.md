## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/time-needed-to-rearrange-a-binary-string/)

给你一个二进制字符串 `s`。在一秒之中，所有 子字符串 `"01"` 同时 被替换成 `"10"`。这个过程持续进行到没有 `"01"` 存在。

请你返回完成这个过程所需要的秒数。

---

示例 1：

```txt
输入：s = "0110101"
输出：4
解释：
一秒后，s 变成 "1011010"。
再过 1 秒后，s 变成 "1101100"。
第三秒过后，s 变成 "1110100"。
第四秒后，s 变成 "1111000"。
此时没有 "01" 存在，整个过程花费 4 秒。
所以我们返回 4。
```

示例 2：

```txt
输入：s = "11100"
输出：0
解释：
s 中没有 "01" 存在，整个过程花费 0 秒。
所以我们返回 0。
```

---

提示：

- `1 <= s.length <= 1000`
- `s[i]` 要么是 `'0'`，要么是 `'1'`。

进阶：

你能以 O(n) 的时间复杂度解决这个问题吗？

## 2. 🎯 s.1 - 贪心计数

::: code-group

```js [js]
/**
 * @param {string} s
 * @return {number}
 */
var secondsToRemoveOccurrences = function (s) {
  let seconds = 0,
    zeros = 0
  for (const c of s) {
    if (c === '0') {
      zeros++
    } else if (zeros > 0) {
      seconds = Math.max(seconds + 1, zeros)
    }
  }
  return seconds
}
```

```c [c]
int secondsToRemoveOccurrences(char* s) {
    int seconds = 0, zeros = 0;
    for (int i = 0; s[i]; i++) {
        if (s[i] == '0') {
            zeros++;
        } else if (zeros > 0) {
            seconds = seconds + 1 > zeros ? seconds + 1 : zeros;
        }
    }
    return seconds;
}
```

```py [py]
class Solution:
    def secondsToRemoveOccurrences(self, s: str) -> int:
        seconds = zeros = 0
        for c in s:
            if c == '0':
                zeros += 1
            elif zeros > 0:
                seconds = max(seconds + 1, zeros)
        return seconds
```

:::

- 时间复杂度：$O(n)$，其中 n 是字符串长度
- 空间复杂度：$O(1)$

算法思路：

- 从左到右遍历，统计当前位置左侧的 0 的个数
- 遇到 1 且左侧有 0 时，seconds = max(seconds + 1, zeros)
- 这样考虑了并行移动和等待依赖的情况
