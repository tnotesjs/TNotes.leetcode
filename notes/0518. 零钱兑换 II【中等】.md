## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/coin-change-ii/)

给你一个整数数组 `coins` 表示不同面额的硬币，另给一个整数 `amount` 表示总金额。

请你计算并返回可以凑成总金额的硬币 **组合数**。如果任何硬币组合都无法凑出总金额，返回 `0`。

假设每一种面额的硬币有无限个。

题目数据保证结果符合 32 位带符号整数。

---

示例 1：

```txt
输入：amount = 5, coins = [1, 2, 5]
输出：4
解释：有四种方式可以凑成总金额：
5=5
5=2+2+1
5=2+1+1+1
5=1+1+1+1+1
```

---

示例 2：

```txt
输入：amount = 3, coins = [2]
输出：0
解释：只用面额 2 的硬币不能凑成总金额 3。
```

---

示例 3：

```txt
输入：amount = 10, coins = [10]
输出：1
```

---

提示：

- `1 <= coins.length <= 300`
- `1 <= coins[i] <= 5000`
- `coins` 中的所有值 **互不相同**
- `0 <= amount <= 5000`

## 2. s.1 - 完全背包

::: code-group

```c [c]
int change(int amount, int* coins, int coinsSize) {
    // 中间状态可能超过 32 位，最终答案保证符合 int
    unsigned long long* dp = (unsigned long long*)calloc(amount + 1, sizeof(unsigned long long));
    dp[0] = 1;
    for (int k = 0; k < coinsSize; k++)
        for (int i = coins[k]; i <= amount; i++)
            dp[i] += dp[i - coins[k]];
    int res = (int)dp[amount];
    free(dp);
    return res;
}
```

```js [js]
/**
 * @param {number} amount
 * @param {number[]} coins
 * @return {number}
 */
var change = function (amount, coins) {
  const dp = new Array(amount + 1).fill(0)
  dp[0] = 1
  for (const coin of coins) {
    for (let i = coin; i <= amount; i++) {
      dp[i] += dp[i - coin]
    }
  }
  return dp[amount]
}
```

```py [py]
class Solution:
    def change(self, amount: int, coins: List[int]) -> int:
        dp = [0] * (amount + 1)
        dp[0] = 1
        for coin in coins:
            for i in range(coin, amount + 1):
                dp[i] += dp[i - coin]
        return dp[amount]
```

:::

- 时间复杂度：$O(n \times \text{amount})$，其中 $n$ 是硬币种类数
- 空间复杂度：$O(\text{amount})$

算法思路：

- `dp[i]` 表示凑成金额 $i$ 的组合数
- 外层遍历硬币，内层正序遍历金额，保证组合不重复

---

正序：

正序是为了同一枚面额可以再用：算 $i$ 时，$dp[i - coin]$ 里已经包含用过当前硬币的方案。

---

先硬币后金额：

外层先遍历硬币，是为了只计组合、不计排列：先处理完 `1` 再处理 `2`，`1+2` 和 `2+1` 只会记一次。若把两层循环对调，这两种就会被算成两种。

外层先枚举硬币时，每种面额只在一轮里被考虑，组合只能按「先 1、后 2」这种固定顺序累加，所以 `1+2` 和 `2+1` 是同一次转移。两层对调后，每凑一个金额都可以再接任意一种硬币，不同顺序会各记一次。

可以用 `amount = 3`、`coins = [1, 2]` 走一遍。

外层硬币、内层金额正序，初始 `dp = [1, 0, 0, 0]`：

- 处理 `1` 后：`[1, 1, 1, 1]`，每种金额都只有全是 1 这一种
- 再处理 `2`：`dp[2] += dp[0]` 得到 2，`dp[3] += dp[1]` 得到 2，结果是 `[1, 1, 2, 2]`

这里 `dp[3] += dp[1]` 的含义是：**在已经用 1 凑好的 1 后面再放一枚 2**。**不会再出现「先放 2 再放 1」这条独立路径，所以只有 `1+1+1` 和 `2+1` 两种组合**。

如果改成外层金额、内层硬币：

- 凑 1：只能加 1，`dp[1] = 1`
- 凑 2：加 1 得到 `1+1`，加 2 得到 `2`，`dp[2] = 2`
- 凑 3：在 `dp[2]` 后面加 1，得到 `1+1+1` 和 `2+1`；在 `dp[1]` 后面加 2，得到 `1+2`。于是 `dp[3] = 3`

`2+1` 和 `1+2` 被当成两种方案。这就是循环对调后会多算排列的原因。

外层金额、内层硬币（Python 版）：

```py {5-6}
class Solution:
    def change(self, amount: int, coins: List[int]) -> int:
        dp = [0] * (amount + 1)
        dp[0] = 1
        for i in range(1, amount + 1):
            for coin in coins:
                if i >= coin:
                    dp[i] += dp[i - coin]
        return dp[amount]
```
