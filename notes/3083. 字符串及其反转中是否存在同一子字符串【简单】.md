## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/existence-of-a-substring-in-a-string-and-its-reverse/)

给你一个字符串 `s`，请你判断字符串 `s` 是否存在一个长度为 `2` 的子字符串，在 `s` 反转后的字符串中也出现。

如果存在这样的子字符串，返回 `true`；如果不存在，返回 `false`。

---

示例 1：

- 输入：s = "leetcode"
- 输出：true
- 解释：子字符串 `"ee"` 的长度为 `2`，它也出现在 `reverse(s) == "edocteel"` 中。

---

示例 2：

- 输入：s = "abcba"
- 输出：true
- 解释：所有长度为 `2` 的子字符串 `"ab"`、`"bc"`、`"cb"`、`"ba"` 也都出现在 `reverse(s) == "abcba"` 中。

---

示例 3：

- 输入：s = "abcd"
- 输出：false
- 解释：字符串 `s` 中不存在满足「在其反转后的字符串中也出现」且长度为 `2` 的子字符串。

---

提示：

- `1 <= s.length <= 100`
- 字符串 `s` 仅由小写英文字母组成。

## 2. 🎯 s.1 - 哈希表

::: code-group

```js [js]
/**
 * @param {string} s
 * @return {boolean}
 */
var isSubstringPresent = function (s) {
  // 将所有长度为 2 的子串存入哈希表
  const set = new Set()
  for (let i = 0; i + 1 < s.length; i++) {
    set.add(s[i] + s[i + 1])
  }
  // 检查反转后的子串是否存在
  for (let i = 0; i + 1 < s.length; i++) {
    // s[i] + s[i+1] 的反转是 s[i+1] + s[i]
    if (set.has(s[i + 1] + s[i])) {
      return true
    }
  }
  return false
}
```

:::

- 时间复杂度：$O(n)$，其中 n 是字符串长度
- 空间复杂度：$O(n)$，哈希表存储所有长度为 2 的子串

算法思路：

- 将字符串 s 中所有长度为 2 的子串存入哈希表
- 再次遍历，检查每个子串的反转是否在哈希表中
- 子串 `s[i] + s[i+1]` 的反转是 `s[i+1] + s[i]`
- 如果找到则返回 true
