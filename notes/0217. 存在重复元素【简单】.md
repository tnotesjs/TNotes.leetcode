## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/contains-duplicate/)

给你一个整数数组 `nums`。

- 如果任一值在数组中出现至少两次，返回 `true`
- 如果数组中每个元素互不相同，返回 `false`

---

示例 1：

```txt
输入：nums = [1, 2, 3, 1]
输出：true
```

解释：

元素 1 在下标 0 和 3 出现。

---

示例 2：

```txt
输入：nums = [1, 2, 3, 4]
输出：false
```

解释：

所有元素都不同。

---

示例 3：

```txt
输入：nums = [1,1,1,3,3,4,3,2,4,2]
输出：true
```

---

提示：

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 2. s.1 - 哈希表记录

::: code-group

```c [c]
bool containsDuplicate(int* nums, int numsSize) {
    if (numsSize <= 1) return false;

    // 哈希表容量取大于 2*n 的 2 的幂，降低冲突
    size_t cap = 1;
    while (cap < (size_t)numsSize * 2) {
        cap <<= 1;
    }

    int *keys = (int *)malloc(cap * sizeof(int));
    unsigned char *used = (unsigned char *)calloc(cap, sizeof(unsigned char));

    if (!keys || !used) {
        free(keys);
        free(used);
        return false;
    }

    for (int i = 0; i < numsSize; i++) {
        int x = nums[i];

        // 哈希函数：混合 int，兼容负数
        unsigned int h = (unsigned int)x;
        h ^= h >> 16;
        h *= 0x7feb352du;
        h ^= h >> 15;
        h *= 0x846ca68bu;
        h ^= h >> 16;

        size_t pos = h & (cap - 1);

        // 开放寻址线性探测
        while (used[pos]) {
            if (keys[pos] == x) {
                free(keys);
                free(used);
                return true;
            }
            pos = (pos + 1) & (cap - 1);
        }

        used[pos] = 1;
        keys[pos] = x;
    }

    free(keys);
    free(used);
    return false;
}

// C 没有内置哈希集合，只能手写；冲突严重时线性探测退化为逐个扫描，最坏 O(n^2)
```

```js [js]
/**
 * @param {number[]} nums
 * @return {boolean}
 */
var containsDuplicate = function (nums) {
  const seen = new Set();
  for (const num of nums) {
    if (seen.has(num)) return true; // 命中立刻退出
    seen.add(num);
  }
  return false;
};
```

```py [py]
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        seen = set()
        for num in nums:
            if num in seen:
                return True  # 命中立刻退出
            seen.add(num)
        return False
```

:::

- 时间复杂度：期望 $O(n)$，其中 n 是数组长度。找到重复就提前返回；答案是 `false`（无重复）时需要遍历完整个数组
- 空间复杂度：$O(n)$，最坏情况下需要额外的哈希空间存下所有元素

算法思路：

- 使用哈希表记录已经出现过的元素
- 遍历数组时，如果发现当前元素已在哈希表中，则存在重复

## 3. s.2 - 先排序再比较

::: code-group

```c [c]
static int cmp(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);
}

bool containsDuplicate(int* nums, int numsSize) {
    qsort(nums, numsSize, sizeof(int), cmp);

    for (int i = 1; i < numsSize; i++) {
        if (nums[i] == nums[i - 1]) {
            return true;
        }
    }

    return false;
}

// qsort 的辅助空间由实现决定：glibc 内存充足时走归并 O(n)，否则原地快排 O(log n)
// cmp 写成 (x > y) - (x < y) 而不是 x - y，避免 int 溢出
```

```js [js]
/**
 * @param {number[]} nums
 * @return {boolean}
 */
var containsDuplicate = function (nums) {
  // 先排序
  nums.sort((a, b) => a - b);

  // 相邻元素比较
  for (let i = 1; i < nums.length; i++) {
    if (nums[i] === nums[i - 1]) {
      return true;
    }
  }

  return false;
};

// 必须传比较函数，默认会把元素转成字符串排序：[10, 9, 1].sort() => [1, 10, 9]
// V8 的 sort 是 TimSort，需要 O(n) 辅助空间
```

```py [py]
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        # 先排序（原地修改 nums）
        nums.sort()

        # 相邻元素比较
        for i in range(1, len(nums)):
            if nums[i] == nums[i - 1]:
                return True

        return False

        # list.sort() 是 Timsort，需要 O(n) 辅助空间；想保留原数组用 sorted(nums)
```

:::

- 时间复杂度：$O(n \log n)$，其中 n 是数组长度，主要消耗在排序上
- 空间复杂度：$O(n)$，排序需要的辅助空间（各语言实现不同，见代码注释）

算法思路：

- 先对数组进行排序，使相同元素相邻
- 然后遍历数组比较相邻元素，如果相等则存在重复
