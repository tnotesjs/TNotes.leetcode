## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/smallest-value-of-the-rearranged-number/)

给你一个整数 `num`。重排 `num` 中的各位数字，使其值 最小化 且不含 任何 前导零。

返回不含前导零且值最小的重排数字。

注意，重排各位数字后，`num` 的符号不会改变。

---

示例 1：

```txt
输入：num = 310
输出：103
解释：310 中各位数字的可行排列有：013、031、103、130、301、310。
不含任何前导零且值最小的重排数字是 103。
```

示例 2：

```txt
输入：num = -7605
输出：-7650
解释：-7605 中各位数字的部分可行排列为：-7650、-6705、-5076、-0567。
不含任何前导零且值最小的重排数字是 -7650。
```

---

提示：

- `-10^15 <= num <= 10^15`

## 2. 🎯 s.1 - 排序 + 贪心

::: code-group

```js [js]
/**
 * @param {number} num
 * @return {number}
 */
var smallestNumber = function (num) {
  if (num === 0) return 0
  const neg = num < 0
  const digits = Math.abs(num).toString().split('').map(Number)
  if (neg) {
    // 最大值，降序排列
    digits.sort((a, b) => b - a)
    return -Number(digits.join(''))
  } else {
    // 最小值，升序排列，首位不能为 0
    digits.sort((a, b) => a - b)
    // 找第一个非零数字放到首位
    const idx = digits.findIndex((d) => d !== 0)
    ;[digits[0], digits[idx]] = [digits[idx], digits[0]]
    return Number(digits.join(''))
  }
}
```

```c [c]
int cmp2165asc(const void* a, const void* b) { return *(int*)a - *(int*)b; }
int cmp2165desc(const void* a, const void* b) { return *(int*)b - *(int*)a; }

long long smallestNumber(long long num) {
    if (num == 0) return 0;
    int neg = num < 0;
    long long val = neg ? -num : num;
    int digits[20], len = 0;
    while (val > 0) { digits[len++] = val % 10; val /= 10; }
    if (neg) {
        qsort(digits, len, sizeof(int), cmp2165desc);
        long long res = 0;
        for (int i = 0; i < len; i++) res = res * 10 + digits[i];
        return -res;
    } else {
        qsort(digits, len, sizeof(int), cmp2165asc);
        // 找第一个非零放首位
        for (int i = 0; i < len; i++) {
            if (digits[i] != 0) {
                int tmp = digits[i]; digits[i] = digits[0]; digits[0] = tmp;
                break;
            }
        }
        long long res = 0;
        for (int i = 0; i < len; i++) res = res * 10 + digits[i];
        return res;
    }
}
```

```py [py]
class Solution:
    def smallestNumber(self, num: int) -> int:
        if num == 0:
            return 0
        if num < 0:
            digits = sorted(str(-num), reverse=True)
            return -int(''.join(digits))
        else:
            digits = sorted(str(num))
            # 找第一个非零放首位
            for i, d in enumerate(digits):
                if d != '0':
                    digits[0], digits[i] = digits[i], digits[0]
                    break
            return int(''.join(digits))
```

:::

- 时间复杂度：$O(d \log d)$，其中 $d$ 是数字的位数
- 空间复杂度：$O(d)$，存储各位数字

算法思路：

- 正数：将各位数字升序排列得到最小值，若首位为 0 则与第一个非零数字交换
- 负数：将各位数字降序排列（绝对值最大）再取负，即为最小值
