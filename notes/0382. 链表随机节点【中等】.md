## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/linked-list-random-node/)

给你一个单链表，随机选择链表的一个节点，并返回相应的节点值。每个节点被选中的概率一样。

实现 `Solution` 类：

- `Solution(ListNode head)` 使用整数数组初始化对象。
- `int getRandom()` 从链表中随机选择一个节点并返回该节点的值。链表中所有节点被选中的概率相等。

---

示例：

```txt
输入
["Solution", "getRandom", "getRandom", "getRandom", "getRandom", "getRandom"]

输出

解释
Solution solution = new Solution([1, 2, 3]);
solution.getRandom(); // 返回 1
solution.getRandom(); // 返回 3
solution.getRandom(); // 返回 2
solution.getRandom(); // 返回 2
solution.getRandom(); // 返回 3
// getRandom() 方法应随机返回 1、2、3中的一个，每个元素被返回的概率相等。
```

---

提示：

- 链表中的节点数在范围 `[1, 10^4]` 内
- `-10^4 <= Node.val <= 10^4`
- 至多调用 `getRandom` 方法 `10^4` 次

## 2. s.1 - 蓄水池抽样

::: code-group

```c [c]
typedef struct {
    struct ListNode* head;
} Solution;

Solution* solutionCreate(struct ListNode* head) {
    Solution* obj = (Solution*)malloc(sizeof(Solution));
    obj->head = head;
    return obj;
}

int solutionGetRandom(Solution* obj) {
    int res = 0, i = 1;
    struct ListNode* node = obj->head;
    while (node) {
        if (rand() % i == 0) res = node->val;
        node = node->next;
        i++;
    }
    return res;
}

void solutionFree(Solution* obj) { free(obj); }
```

```js [js]
/**
 * @param {ListNode} head
 */
var Solution = function (head) {
  this.head = head
}

/**
 * @return {number}
 */
Solution.prototype.getRandom = function () {
  let res = 0,
    i = 1,
    node = this.head
  while (node) {
    // 蓄水池抽样：以 1/i 的概率选中当前节点
    if (Math.random() < 1 / i) res = node.val
    node = node.next
    i++
  }
  return res
}
```

```py [py]
class Solution:
    def __init__(self, head: Optional[ListNode]):
        self.head = head

    def getRandom(self) -> int:
        res, i, node = 0, 1, self.head
        while node:
            if random.randint(1, i) == 1:
                res = node.val
            node = node.next
            i += 1
        return res
```

:::

- 时间复杂度：初始化 $O(1)$，`getRandom` $O(n)$
- 空间复杂度：$O(1)$

算法思路：

- 蓄水池抽样：遍历链表时，第 $i$ 个节点以 $\frac{1}{i}$ 的概率被选中
- 保证每个节点被选中的概率均为 $\frac{1}{n}$

### 2.1. 如何保证每个节点的概率都是 `1/n`？

计算过程中的任意一个节点 `node_k` 设置为 `k`，表示它是第 `k` 个节点。

- 走到 `k` 时遇到 `node_k` 节点：以 `1 / k` 被选进 `res`
- 走到 `k + 1` 时遇到 `node_k_1`：k + 1 节点被选中的概率是 `1 / k + 1`，为了确保上一步被选进 `res` 的 `node_k` 不被替换，那么这一步的 `node_k_1` 不能被选中，不被选中的概率是 `1 - 1 / k + 1 = k / k + 1`
- 后面还有 `k + 2 ... n` 个节点，为了确保 `node_k` 不会被替换，后续每个节点都不能被选中

所以最终仍是它的概率：

$$
\frac{1}{k}\times\frac{k}{k+1}\times\frac{k+1}{k+2}\times\cdots\times\frac{n-1}{n}=\frac{1}{n}
$$

中间项全消掉，只剩 `1/n`。

综上，对于链表上的任意节点都一样，最终留下的概率都是 `1/n`。

## 3. 【AI】回答「进阶」描述中的两个问题

---

进阶里问了两句：

1. 如果链表非常大且长度未知，该怎么处理？
2. 你能否在不使用额外空间的情况下解决此问题？

---

### 3.1. 问题 1：链表很大、长度未知

先把「常见但这里不合适」的做法排除掉：

- **先遍历数长度再 `rand % n` 取第几个**：要两遍扫描；长度未知时第一遍还能做，但超长流式输入（只能读一次、或读完就丢）就挂了，也多一次完整遍历。
- **建数组 / 拷贝所有节点值再随机下标**：空间 $O(n)$，链表「非常大」时直接爆。

进阶要的就是：**只扫一遍、不依赖预先知道的 $n$**。做法就是 s.1 的蓄水池抽样（池大小为 1）：

- 边走边维护计数 $i$ 和当前结果 `res`
- 第 $i$ 个节点以 $\frac{1}{i}$ 的概率替换 `res`
- 扫完后，在「到目前为止见过的全部节点」上仍是均匀的；长度多大、事先知不知道，都不影响正确性

所以「很大且长度未知」不是另起一套算法，而是点明：**必须用蓄水池，而不是先 `len` 再取模**。

### 3.2. 问题 2：能否不使用额外空间？

能。s.1 已经是额外空间 $O(1)$ 的解：

- 构造时只存一个 `head` 指针（题面要求持有链表，不算「为了随机再开的大数组」）
- `getRandom` 里只有几个标量：`res`、`i`、游标 `node`
- 不把链表拷进数组，也不为每个节点另建索引结构

若把「额外空间」理解成相对输入而言的辅助空间，答案就是：**蓄水池抽样可以，且本题推荐写法就是这样。**

对照一下空间更大的替代：初始化时把所有 `val` 读进数组，之后 `getRandom` $O(1)$——时间换空间，能过小数据，但直接违背进阶第二问和「非常大」的设定。

### 3.3. 小结

| 进阶问题 | 答案 |
| --- | --- |
| 很大且长度未知 | 一遍蓄水池；$\frac{1}{i}$ 更新，不预知 $n$ |
| 不使用额外空间 | 可以；只保留 `head` + 常数变量，不要 $O(n)$ 数组 |
