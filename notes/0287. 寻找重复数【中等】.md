## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/find-the-duplicate-number/)

给定一个包含 `n + 1` 个整数的数组 `nums`，其数字都在 `[1, n]` 范围内（包括 `1` 和 `n`），可知至少存在一个重复的整数。

假设 `nums` 只有一个重复的整数，返回这个重复的数。

你设计的解决方案必须不修改数组 `nums` 且只用常量级 `O(1)` 的额外空间。

---

示例 1：

```txt
输入：nums = [1, 3, 4, 2, 2]
输出：2
```

---

示例 2：

```txt
输入：nums = [3, 1, 3, 4, 2]
输出：3
```

---

示例 3 :

```txt
输入：nums = [3, 3, 3, 3, 3]
输出：3
```

---

提示：

- `1 <= n <= 10^5`
- `nums.length == n + 1`
- `1 <= nums[i] <= n`
- `nums` 中只有一个整数出现两次或多次，其余整数均只出现一次

---

进阶：

- 如何证明 `nums` 中至少存在一个重复的数字?
- 你可以设计一个线性级时间复杂度 `O(n)` 的解决方案吗？

## 2. 题目解读

要求线性时间复杂度 `O(n)`，基本就告别“先排序”策略了。排序至少是 `O(n log n)`，原地排序会修改数组，复制后排序又需要 `O(n)` 额外空间，都不符合题目约束。

题目对数字范围的约束，其实是在暗示往链表方向思考。关键是这几个条件共同构成了映射 `i -> nums[i]`：

- `nums.length == n + 1`，下标范围是 `0..n`；
- `1 <= nums[i] <= n`，每个值都是合法下标；
- 值域不含 `0`，所以从下标 `0` 出发，一步之后就进入 `1..n`，并一直留在这 `n` 个点中。

因此，每个点只有一条出边，且出边一定不会越界。有限个点、每个点只有一条出边，从 `0` 出发的路径一定会成环，形状必然是“一条尾巴 + 一个环”。

关键是要理解为什么环入口就是重复数。设重复数字为 `x`，则至少有两个不同下标 `i`、`j` 使得 `nums[i] = nums[j] = x`，在图里就是 `i -> x`、`j -> x`，所以点 `x` 的入度至少为 2。题目保证只有一个数字重复，其余数字只出现一次，因此 `x` 是唯一入度大于 1 的点。而从 `0` 出发的路径中，环入口既被尾巴上的前驱指向，又被环上的前驱指向，所以它的入度也至少为 2。于是唯一入度大于 1 的点就是环入口，也就是重复数 `x`。

这样问题就转化为在函数图 `i -> nums[i]` 中找环入口。s.1 的 Floyd 快慢指针正是做这件事：先让快慢指针在环内相遇，再让一个指针回到起点，两个指针同速前进，再次相遇的位置就是环入口，也就是重复数。

## 3. s.1 - 快慢指针

::: code-group

```c [c]
int findDuplicate(int* nums, int numsSize) {
    int slow = nums[0], fast = nums[nums[0]];
    while (slow != fast) {
        slow = nums[slow];
        fast = nums[nums[fast]];
    }
    slow = 0;
    while (slow != fast) {
        slow = nums[slow];
        fast = nums[fast];
    }
    return slow;
}
```

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var findDuplicate = function (nums) {
  let slow = nums[0],
    fast = nums[nums[0]]
  while (slow !== fast) {
    slow = nums[slow]
    fast = nums[nums[fast]]
  }
  slow = 0
  while (slow !== fast) {
    slow = nums[slow]
    fast = nums[fast]
  }
  return slow
}
```

```py [py]
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        slow, fast = nums[0], nums[nums[0]]
        while slow != fast:
            slow = nums[slow]
            fast = nums[nums[fast]]
        slow = 0
        while slow != fast:
            slow = nums[slow]
            fast = nums[fast]
        return slow
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是数组长度
- 空间复杂度：$O(1)$

算法思路：

- 将数组视为链表（索引 $\to$ 值的映射），重复数即环的入口
- Floyd 快慢指针：先找到环内相遇点，再从起点和相遇点同时出发找环入口
- 有关 Floyd 算法的更多说明见：[TNotes.algorithms - 0019. Floyd 判圈算法][1]
