## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/largest-substring-between-two-equal-characters/)

给你一个字符串 `s`，请你返回两个相同字符之间的最长子字符串的长度，计算长度时不含这两个字符。如果不存在这样的子字符串，返回 `-1`。

子字符串是字符串中的一个连续字符序列。

---

示例 1：

```txt
输入：s = "aa"
输出：0
```

解释：最优的子字符串是两个 'a' 之间的空子字符串。

---

示例 2：

```txt
输入：s = "abca"
输出：2
```

解释：最优的子字符串是 "bc"。

---

示例 3：

```txt
输入：s = "cbzxy"
输出：-1
```

解释：s 中不存在出现出现两次的字符，所以返回 -1。

---

示例 4：

```txt
输入：s = "cabbac"
输出：4
```

解释：最优的子字符串是 "abba"，其他的非最优解包括 "bb" 和 ""。

---

提示：

- `1 <= s.length <= 300`
- `s` 只含小写英文字母

## 2. 🎯 s.1 - 首尾索引差

::: code-group

```c [c]
int maxLengthBetweenEqualCharacters(char* s) {
    int first[26];
    for (int i = 0; i < 26; i++) {
        first[i] = -1;
    }
    
    int ans = -1;
    
    for (int i = 0; s[i] != '\0'; i++) {
        int idx = s[i] - 'a';
        if (first[idx] == -1) {
            first[idx] = i;
        } else {
            int len = i - first[idx] - 1;
            if (len > ans) {
                ans = len;
            }
        }
    }
    
    return ans;
}
```

```js [js]
/**
 * @param {string} s
 * @return {number}
 */
var maxLengthBetweenEqualCharacters = function (s) {
  const first = new Array(26).fill(-1)
  let ans = -1

  for (let i = 0; i < s.length; i++) {
    const idx = s.charCodeAt(i) - 97
    if (first[idx] === -1) first[idx] = i
    else ans = Math.max(ans, i - first[idx] - 1)
  }

  return ans
}
```

```py [py]
class Solution:
    def maxLengthBetweenEqualCharacters(self, s: str) -> int:
        first = [-1] * 26
        ans = -1

        for i, ch in enumerate(s):
            idx = ord(ch) - ord("a")
            if first[idx] == -1:
                first[idx] = i
            else:
                ans = max(ans, i - first[idx] - 1)

        return ans
```

:::

- 时间复杂度：$O(N)$，其中 N 是字符串 s 的长度
- 空间复杂度：$O(1)$，使用固定大小为 26 的数组

算法思路：

- 创建长度为 26 的数组 `first`，初始化为 -1，用于记录每个字母首次出现的位置
- 初始化最大长度 `ans` 为 -1（因为若无重复字符需要返回 -1）
- 遍历字符串 s，对于每个字符：
  - 计算字符对应的索引：`idx = s.charCodeAt(i) - 97`（'a' 的 ASCII 码为 97）
  - 如果该字符首次出现（`first[idx] === -1`），记录其位置 `first[idx] = i`
  - 否则说明该字符重复出现，计算两个相同字符之间的子字符串长度：`i - first[idx] - 1`
  - 更新最大长度 `ans`
- 返回最大长度 `ans`
