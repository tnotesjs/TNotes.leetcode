## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/intersection-of-multiple-arrays/)

给你一个二维整数数组 `nums`，其中 `nums[i]` 是由不同正整数组成的一个非空数组，按升序排列返回一个数组，数组中的每个元素在 `nums` 所有数组中都出现过。

---

示例 1：

```txt
输入：nums = [[3,1,2,4,5],[1,2,3,4],[3,4,5,6]]
输出：[3,4]

解释：
nums[0] = [3,1,2,4,5]，nums[1] = [1,2,3,4]，nums[2] = [3,4,5,6]，
在 nums 中每个数组中都出现的数字是 3 和 4，所以返回 [3,4]。
```

---

示例 2：

```txt
输入：nums = [[1,2,3],[4,5,6]]
输出：[]
解释：
不存在同时出现在 nums[0] 和 nums[1] 的整数，所以返回一个空列表 []。
```

---

提示：

- `1 <= nums.length <= 1000`
- `1 <= sum(nums[i].length) <= 1000`
- `1 <= nums[i][j] <= 1000`
- `nums[i]` 中的所有值 互不相同

## 2. 🎯 s.1 - 计数求交

::: code-group

```js [js]
/**
 * @param {number[][]} nums
 * @return {number[]}
 */
var intersection = function (nums) {
  const cnt = Array(1001).fill(0)
  for (const arr of nums) {
    for (const v of arr) cnt[v] += 1
  }

  const res = []
  const need = nums.length
  for (let v = 1; v <= 1000; v += 1) {
    if (cnt[v] === need) res.push(v)
  }
  return res
}
```

:::

- 时间复杂度：$O(T)$，遍历总元素数 `T` 累计频次
- 空间复杂度：$O(U)$，值域 1e3 的计数数组

算法思路：

- 使用长度 1001 的计数数组统计每个值出现的次数，最终收集计数等于数组个数的值并升序返回。
