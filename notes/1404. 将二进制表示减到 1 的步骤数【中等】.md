## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/number-of-steps-to-reduce-a-number-in-binary-representation-to-one/)

给你一个以二进制形式表示的数字 `s`。请你返回按下述规则将其减少到 1 所需要的步骤数：

- 如果当前数字为偶数，则将其除以 `2`。
- 如果当前数字为奇数，则将其加上 `1`。

题目保证你总是可以按上述规则将测试用例变为 1。

---

示例 1：

```txt
输入：s = "1101"
输出：6
解释："1101" 表示十进制数 13。
Step 1) 13 是奇数，加 1 得到 14
Step 2) 14 是偶数，除 2 得到 7
Step 3) 7  是奇数，加 1 得到 8
Step 4) 8  是偶数，除 2 得到 4
Step 5) 4  是偶数，除 2 得到 2
Step 6) 2  是偶数，除 2 得到 1
```

示例 2：

```txt
输入：s = "10"
输出：1
解释："10" 表示十进制数 2。
Step 1) 2 是偶数，除 2 得到 1
```

示例 3：

```txt
输入：s = "1"
输出：0
```

---

提示：

- `1 <= s.length <= 500`
- `s` 由字符 `'0'` 或 `'1'` 组成。
- `s[0] == '1'`

## 2. 🎯 s.1 - 模拟二进制运算

::: code-group

```js [js]
/**
 * @param {string} s
 * @return {number}
 */
var numSteps = function (s) {
  let steps = 0,
    carry = 0
  for (let i = s.length - 1; i > 0; i--) {
    const bit = s[i] - '0' + carry
    if (bit % 2 === 1) {
      // 奇数：加 1 变偶数，再除 2
      steps += 2
      carry = 1
    } else {
      // 偶数：直接除 2
      steps += 1
    }
  }
  return steps + carry
}
```

```c [c]
int numSteps(char* s) {
    int n = strlen(s), steps = 0, carry = 0;
    for (int i = n - 1; i > 0; i--) {
        int bit = (s[i] - '0') + carry;
        if (bit % 2 == 1) {
            steps += 2;
            carry = 1;
        } else {
            steps += 1;
        }
    }
    return steps + carry;
}
```

```py [py]
class Solution:
    def numSteps(self, s: str) -> int:
        steps = 0
        carry = 0
        for i in range(len(s) - 1, 0, -1):
            bit = int(s[i]) + carry
            if bit % 2 == 1:
                steps += 2
                carry = 1
            else:
                steps += 1
        return steps + carry
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是二进制字符串的长度
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：

- 从二进制串末尾向前遍历，维护进位 carry
- 当前位为奇数时需 2 步（加 1 + 除 2），产生进位
- 当前位为偶数时需 1 步（除 2）
- 最终加上 carry 处理最高位
