## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/longest-nice-subarray/)

给你一个由 正 整数组成的数组 `nums`。

如果 `nums` 的子数组中位于 不同 位置的每对元素按位 与（AND）运算的结果等于 `0`，则称该子数组为 优雅 子数组。

返回 最长 的优雅子数组的长度。

子数组 是数组中的一个 连续 部分。

---

注意：长度为 `1` 的子数组始终视作优雅子数组。

---

示例 1：

```txt
输入：nums = [1,3,8,48,10]
输出：3
解释：最长的优雅子数组是 [3,8,48]。子数组满足题目条件：
- 3 AND 8 = 0
- 3 AND 48 = 0
- 8 AND 48 = 0
可以证明不存在更长的优雅子数组，所以返回 3。
```

示例 2：

```txt
输入：nums = [3,1,5,11,13]
输出：1
解释：最长的优雅子数组长度为 1，任何长度为 1 的子数组都满足题目条件。
```

---

提示：

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

## 2. 🎯 s.1 - 滑动窗口 + 位运算

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var longestNiceSubarray = function (nums) {
  let used = 0,
    left = 0,
    ans = 0
  for (let right = 0; right < nums.length; right++) {
    while (used & nums[right]) {
      used ^= nums[left++]
    }
    used |= nums[right]
    ans = Math.max(ans, right - left + 1)
  }
  return ans
}
```

```c [c]
int longestNiceSubarray(int* nums, int numsSize) {
    int used = 0, left = 0, ans = 0;
    for (int right = 0; right < numsSize; right++) {
        while (used & nums[right]) {
            used ^= nums[left++];
        }
        used |= nums[right];
        int len = right - left + 1;
        if (len > ans) ans = len;
    }
    return ans;
}
```

```py [py]
class Solution:
    def longestNiceSubarray(self, nums: list[int]) -> int:
        used = left = ans = 0
        for right, num in enumerate(nums):
            while used & num:
                used ^= nums[left]
                left += 1
            used |= num
            ans = max(ans, right - left + 1)
        return ans
```

:::

- 时间复杂度：$O(n)$，其中 n 是数组长度
- 空间复杂度：$O(1)$

算法思路：

- 维护 used 记录当前窗口内所有元素的按位或
- 右指针扩展时，若新元素与 used 有共同位（AND 不为 0），则收缩左指针
- 更新最大窗口长度
