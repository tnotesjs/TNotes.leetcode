## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/distance-between-bus-stops/)

环形公交路线上有 `n` 个站，按次序从 `0` 到 `n - 1` 进行编号。我们已知每一对相邻公交站之间的距离，`distance[i]` 表示编号为 `i` 的车站和编号为 `(i + 1) % n` 的车站之间的距离。

环线上的公交车都可以按顺时针和逆时针的方向行驶。

返回乘客从出发点 `start` 到目的地 `destination` 之间的最短距离。

提示：

- `1 <= n <= 10^4`
- `distance.length == n`
- `0 <= start, destination < n`
- `0 <= distance[i] <= 10^4`

## 2. 🎯 s.1 - 暴力解法

::: code-group

```js [js]
/**
 * @param {number[]} distance
 * @param {number} start
 * @param {number} destination
 * @return {number}
 */
var distanceBetweenBusStops = function (distance, start, destination) {
  if (start > destination) [start, destination] = [destination, start]
  let total = 0
  let path = 0
  for (let i = 0; i < distance.length; i++) {
    total += distance[i]
    if (i >= start && i < destination) path += distance[i]
  }
  return Math.min(path, total - path)
}
```

:::

- 时间复杂度：$O(n)$，其中 n 是公交站的数量，需要遍历一次数组计算总距离和路径距离
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：

- 环形路线有两条路径：顺时针和逆时针，求两者中的最小距离
  - 只有两种走法，哪个小选哪个
- 先确保 `start < destination`，简化后续计算
- 遍历数组，计算总距离 `total` 和从 `start` 到 `destination` 的顺时针距离 `path`
- 逆时针距离为 `total - path`
- 返回顺时针和逆时针距离的最小值
