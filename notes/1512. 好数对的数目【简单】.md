## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/number-of-good-pairs/)

给你一个整数数组 `nums`。

如果一组数字 `(i,j)` 满足 `nums[i] == nums[j]` 且 `i < j`，就可以认为这是一组好数对。

返回好数对的数目。

---

示例 1：

```txt
输入：nums = [1,2,3,1,1,3]
输出：4

解释：
有 4 组好数对，分别是 (0,3), (0,4), (3,4), (2,5)，下标从 0 开始
```

---

示例 2：

```txt
输入：nums = [1,1,1,1]
输出：6

解释：
数组中的每组数字都是好数对
```

---

示例 3：

```txt
输入：nums = [1,2,3]
输出：0
```

---

提示：

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 2. 🎯 s.1 - 统计组合

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var numIdenticalPairs = function (nums) {
  const cnt = new Array(101).fill(0)
  let res = 0

  // 统计每个值出现次数 cnt
  for (const x of nums) cnt[x] += 1

  // 统计组合数
  for (const c of cnt) {
    if (c > 1) res += (c * (c - 1)) / 2
  }

  return res
}
```

:::

- 时间复杂度：$O(N)$，单次计数
- 空间复杂度：$O(1)$，数值范围固定 100

算法思路：

- 统计每个值出现次数 `cnt`，好数对数为每个值的组合数 `cnt * (cnt - 1) / 2`
- 数值范围固定，可用长度 101 的数组计数，累加得到答案
