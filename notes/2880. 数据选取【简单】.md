```txt
DataFrame students

| Column Name | Type   |

| student_id  | int    |
| name        | object |
| age         | int    |
+-------------+--------+
```

示例 1：

```txt
输入：

| 128        | Henry   | 6   |
| 3          | Henry   | 11  |

输出：
+---------+-----+
| name    | age |
+---------+-----+
| Ulysses | 13  |
+---------+-----+
解释：
```
