## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/maximum-xor-of-two-numbers-in-an-array/)

给你一个整数数组 `nums`，返回 `nums[i] XOR nums[j]` 的最大运算结果，其中 `0 ≤ i ≤ j < n`。

---

示例 1：

```txt
输入：nums = [3, 10, 5, 25, 2, 8]
输出：28
解释：最大运算结果是 5 XOR 25 = 28.
```

---

示例 2：

```txt
输入：nums = [14, 70, 53, 83, 49, 91, 36, 80, 92, 51, 66, 70]
输出：127
```

---

提示：

- `1 <= nums.length <= 2 * 10^5`
- `0 <= nums[i] <= 2^31 - 1`

## 2. s.1 - 贪心 + 哈希表

::: code-group

```c [c]
#define HASH_SIZE 100003
typedef struct Node { int val; struct Node* next; } Node;

void hashInsert(Node** table, int val) {
    int idx = ((unsigned)val) % HASH_SIZE;
    Node* n = (Node*)malloc(sizeof(Node));
    n->val = val; n->next = table[idx]; table[idx] = n;
}

bool hashContains(Node** table, int val) {
    int idx = ((unsigned)val) % HASH_SIZE;
    for (Node* n = table[idx]; n; n = n->next) if (n->val == val) return true;
    return false;
}

void hashFree(Node** table) {
    for (int i = 0; i < HASH_SIZE; i++) { Node* n = table[i]; while (n) { Node* t = n; n = n->next; free(t); } table[i] = NULL; }
}

int findMaximumXOR(int* nums, int numsSize) {
    int max = 0, mask = 0;
    Node** table = (Node**)calloc(HASH_SIZE, sizeof(Node*));
    for (int i = 31; i >= 0; i--) {
        mask |= (1U << i);
        hashFree(table);
        for (int j = 0; j < numsSize; j++) {
            int prefix = nums[j] & mask;
            if (!hashContains(table, prefix)) hashInsert(table, prefix);
        }
        int candidate = max | (1U << i);
        for (int j = 0; j < numsSize; j++) {
            if (hashContains(table, (nums[j] & mask) ^ candidate)) { max = candidate; break; }
        }
    }
    free(table);
    return max;
}
```

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var findMaximumXOR = function (nums) {
  let max = 0,
    mask = 0
  for (let i = 31; i >= 0; i--) {
    mask |= 1 << i
    const set = new Set()
    for (const num of nums) set.add(num & mask)
    const candidate = max | (1 << i)
    for (const prefix of set) {
      if (set.has(prefix ^ candidate)) {
        max = candidate
        break
      }
    }
  }
  return max
}
```

```py [py]
class Solution:
    def findMaximumXOR(self, nums: List[int]) -> int:
        max_xor, mask = 0, 0
        for i in range(31, -1, -1):
            mask |= (1 << i)
            prefixes = {num & mask for num in nums}
            candidate = max_xor | (1 << i)
            if any(prefix ^ candidate in prefixes for prefix in prefixes):
                max_xor = candidate
        return max_xor
```

:::

- 时间复杂度：$O(32n)$，即 $O(n)$
- 空间复杂度：$O(n)$

算法思路：

- 从最高位到最低位贪心地确定每一位是否可以为 1
- 利用 $a \oplus b = c \Leftrightarrow a \oplus c = b$ 的性质，用哈希表判断候选值是否可达

### 2.1. 异或运算的可逆性

「异或的可逆性」也叫两边同时异或同一个数。因为 $a \oplus a = 0$，且 $0 \oplus x = x$，所以：

$a \oplus b = c \iff a \oplus b \oplus a = c \oplus a \iff b = a \oplus c$

两边同时异或 $a$，左边变成 $b$，右边变成 $a \oplus c$。

### 2.2. 详细说明

这道题的核心是：**从最高位往最低位，逐位尝试让答案变成 `1`；只有数组中确实存在两个数能做到，才保留这个 `1`。**

下面以 `[3, 10, 5, 25, 2, 8]` 为例来对 s.1 的解法进行详细说明。

#### 为什么从高位开始？

把这些数写成五位二进制：

```text
   3 = 00011
  10 = 01010
   5 = 00101
  25 = 11001
   2 = 00010
   8 = 01000
```

异或的规则是：相同为 `0`，不同为 `1`。

**我们要让异或结果尽可能大，就应该优先让高位为 `1`**。因为一个高位的 `1`，比它右边所有位的 `1` 加起来还大。例如 `10000` 大于 `01111`。

#### 每轮只看已经考虑到的前缀

第一轮只看最左边一位，第二轮看最左边两位，以此类推。后面还没考虑的位先忽略。

每轮先假设：**在保留之前结果的基础上，当前位也能取 `1`**。然后检查数组中是否存在两个前缀，它们异或后正好等于这个假设结果。

存在，就保留；不存在，就让当前位为 `0`。

#### 用示例逐轮走

为了容易观察，下面只展示最低五位。

::: tip
代码实现上是从第 31 位开始，但是示例的第 31～5 位都会尝试失败，因为所有数在这些位上都是 `0`，因此这里我们直接从首个有效位（第 4 位是 1 的底五位 `10000`）开始观察。
:::

---

**考虑第 4 位，尝试得到 `10000`。**

只保留每个数的第 4 位，其余位置先补 `0`：

```text {1-6}
   3 → 00000
  10 → 00000
   5 → 00000
  25 → 10000
   2 → 00000
   8 → 00000
```

存在 `00000 XOR 10000 = 10000`，所以这一位可以取 `1`。

目前答案：10000

---

**继续考虑第 3 位，尝试得到 `11000`。**

现在保留第 4～3 位：

```text {1,3-6}
   3 → 00000
  10 → 01000
   5 → 00000
  25 → 11000
   2 → 00000
   8 → 01000
```

存在 `00000 XOR 11000 = 11000`，所以这一位也可以取 `1`。

目前答案：11000

---

**继续考虑第 2 位，尝试得到 `11100`。**

现在保留第 4～2 位：

```text {3-4}
   3 → 00000
  10 → 01000
   5 → 00100
  25 → 11000
   2 → 00000
   8 → 01000
```

存在 `00100 XOR 11000 = 11100`，对应原数组中的 `5` 和 `25`，所以保留。

目前答案：11100

---

**继续考虑第 1 位，尝试得到 `11110`。**

现在保留第 4～1 位：

```text {3-4}
   3 → 00010
  10 → 01010
   5 → 00100
  25 → 11000
   2 → 00010
   8 → 01000
```

找不到两个前缀异或得到 `11110`，所以这一位只能取 `0`。

目前答案：11100

---

**继续考虑第 0 位，尝试得到 `11101`。**

现在看完整数字。找不到两个数异或得到 `11101`，所以最低位也取 `0`。

最终答案：11100 = 28

::: warning 注意
**每一轮并不是固定选中某两个数，而是在确认“是否存在一对数，能实现目前想要的答案前缀”**。随着考虑的位越来越多，条件越来越严格，直到最后得到完整的最大异或值。

虽然通过上述的分析，我们最终能确定留下来的是：5、25 两个数，$5 \oplus 25 = 28$。

但 s.1 算法并不知道最终是 5、25 异或得到了最终的最大异或结果 `28`，s.1 只知道可达的最大异或结果是 `28`。

每一轮循环只是算本轮的最大收益是否可达，只判断本轮的最值是否能组合出来，但不限定具体是谁跟谁组合。最终也不会知道是谁和谁组合得到的最终结果，只是从贪心的角度来思考，从收益最大的最高位开始判断本轮的最优解是否能组出来，最后返回能组出的最大结果。
:::

#### 哈希表是怎么检查的？

以尝试 `11100` 的那一轮为例，前缀集合是：`{00000, 01000, 00100, 11000}`

对于前缀 `00100`，如果希望异或结果是 `11100`，那么另一个前缀必须是：`00100 XOR 11100 = 11000`

集合里恰好有 `11000`，因此尝试成功。

这就是异或可逆性的用途：**知道目标结果和其中一个前缀，就能算出需要的另一个前缀，再去集合里查它存不存在。** 不必把所有数两两配对。

#### `mask` 只是用来提取前缀

`num & mask` 的作用是：保留本轮已经考虑的高位，清除还没考虑的低位。

例如考虑第 3 位时，代码中的完整 `mask` 是：`11111111 11111111 11111111 11111000`

它本身不是 `24`。**只看本例会用到的最低五位，才是 `11000`，也就是 `24`。** 更高位虽然也为 `1`，但原数组中的数字在那些位置都是 `0`，所以不会影响提取结果。
