## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/smallest-value-after-replacing-with-sum-of-prime-factors/)

给你一个正整数 `n`。

请你将 `n` 的值替换为 `n` 的 质因数 之和，重复这一过程。

- 注意，如果 `n` 能够被某个质因数多次整除，则在求和时，应当包含这个质因数同样次数。

返回 `n` 可以取到的最小值。

---

示例 1：

```txt
输入：n = 15
输出：5
解释：最开始，n = 15。
15 = 3 * 5，所以 n 替换为 3 + 5 = 8。
8 = 2 * 2 * 2，所以 n 替换为 2 + 2 + 2 = 6。
6 = 2 * 3，所以 n 替换为 2 + 3 = 5。
5 是 n 可以取到的最小值。
```

示例 2：

```txt
输入：n = 3
输出：3
解释：最开始，n = 3。
3 是 n 可以取到的最小值。
```

---

提示：

- `2 <= n <= 10^5`

## 2. 🎯 s.1 - 模拟 + 质因数分解

::: code-group

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var smallestValue = function (n) {
  while (true) {
    let sum = 0,
      x = n
    for (let i = 2; i * i <= x; i++) {
      while (x % i === 0) {
        sum += i
        x = Math.floor(x / i)
      }
    }
    if (x > 1) sum += x
    if (sum === n) return n
    n = sum
  }
}
```

```c [c]
int smallestValue(int n) {
    while (1) {
        int sum = 0, x = n;
        for (int i = 2; i * i <= x; i++) {
            while (x % i == 0) {
                sum += i;
                x /= i;
            }
        }
        if (x > 1) sum += x;
        if (sum == n) return n;
        n = sum;
    }
}
```

```py [py]
class Solution:
    def smallestValue(self, n: int) -> int:
        while True:
            s, x = 0, n
            i = 2
            while i * i <= x:
                while x % i == 0:
                    s += i
                    x //= i
                i += 1
            if x > 1:
                s += x
            if s == n:
                return n
            n = s
```

:::

- 时间复杂度：$O(\sqrt{n} \cdot \log n)$，每次分解 $O(\sqrt{n})$，最多迭代 $O(\log n)$ 次
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 对 $n$ 进行质因数分解，求所有质因数之和 $sum$
- 用 $sum$ 替换 $n$，重复上述过程
- 当 $sum = n$ 时（$n$ 本身是质数或不再变化），返回 $n$
