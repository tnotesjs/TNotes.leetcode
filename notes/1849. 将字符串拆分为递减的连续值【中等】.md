## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/splitting-a-string-into-descending-consecutive-values/)

给你一个仅由数字组成的字符串 `s`。

请你判断能否将 `s` 拆分成两个或者多个 非空子字符串，使子字符串的 数值 按 降序 排列，且每两个 相邻子字符串 的数值之 差 等于 `1`。

- 例如，字符串 `s = "0090089"` 可以拆分成 `["0090", "089"]`，数值为 `[90,89]`。这些数值满足按降序排列，且相邻值相差 `1`，这种拆分方法可行。
- 另一个例子中，字符串 `s = "001"` 可以拆分成 `["0", "01"]`、`["00", "1"]` 或 `["0", "0", "1"]`。然而，所有这些拆分方法都不可行，因为对应数值分别是 `[0,1]`、`[0,1]` 和 `[0,0,1]`，都不满足按降序排列的要求。

如果可以按要求拆分 `s`，返回 `true` ；否则，返回 `false`。

子字符串 是字符串中的一个连续字符序列。

---

示例 1：

```txt
输入：s = "1234"
输出：false
解释：不存在拆分 s 的可行方法。
```

示例 2：

```txt
输入：s = "050043"
输出：true
解释：s 可以拆分为 ["05", "004", "3"]，对应数值为 [5,4,3]。
满足按降序排列，且相邻值相差 1。
```

示例 3：

```txt
输入：s = "9080701"
输出：false
解释：不存在拆分 s 的可行方法。
```

示例 4：

```txt
输入：s = "10009998"
输出：true
解释：s 可以拆分为 ["100", "099", "98"]，对应数值为 [100,99,98]。
满足按降序排列，且相邻值相差 1。
```

---

提示：

- `1 <= s.length <= 20`
- `s` 仅由数字组成

## 2. 🎯 s.1 - 回溯

::: code-group

```js [js]
/**
 * @param {string} s
 * @return {boolean}
 */
var splitString = function (s) {
  function dfs(idx, prev, count) {
    if (idx === s.length) return count >= 2
    let num = 0n
    for (let i = idx; i < s.length; i++) {
      num = num * 10n + BigInt(s[i])
      if (num >= 10n ** 18n) break // 防止溢出
      if (prev === -1n || num === prev - 1n) {
        if (dfs(i + 1, num, count + 1)) return true
      }
    }
    return false
  }
  return dfs(0, -1n, 0)
}
```

```c [c]
#include <stdbool.h>
#include <string.h>

static bool dfs1849(char* s, int n, int idx, long long prev, int count) {
  if (idx == n) return count >= 2;
  long long num = 0;
  for (int i = idx; i < n; i++) {
    num = num * 10 + (s[i] - '0');
    if (num > 1e17) break;
    if (prev == -1 || num == prev - 1) {
      if (dfs1849(s, n, i + 1, num, count + 1)) return true;
    }
  }
  return false;
}

bool splitString(char* s) {
  return dfs1849(s, strlen(s), 0, -1, 0);
}
```

```py [py]
class Solution:
    def splitString(self, s: str) -> bool:
        def dfs(idx, prev, count):
            if idx == len(s):
                return count >= 2
            num = 0
            for i in range(idx, len(s)):
                num = num * 10 + int(s[i])
                if num > 10 ** 18:
                    break
                if prev == -1 or num == prev - 1:
                    if dfs(i + 1, num, count + 1):
                        return True
            return False
        return dfs(0, -1, 0)
```

:::

- 时间复杂度：$O(n \times 10^n)$，最坏情况下枚举所有分割方案
- 空间复杂度：$O(n)$，递归栈的深度

算法思路：

- 回溯尝试每个分割点，将字符串拆分为多个数字
- 每个数字必须严格递减，且差值为 1
- 注意处理前导零和大数溢出的情况
