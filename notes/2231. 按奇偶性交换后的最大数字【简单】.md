## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/largest-number-after-digit-swaps-by-parity/)

给你一个正整数 `num`。你可以交换 `num` 中奇偶性相同的任意两位数字（即，都是奇数或者偶数）。

返回交换任意次之后 `num` 的最大可能值。

---

示例 1：

```txt
输入：num = 1234
输出：3412

解释：
交换数字 3 和数字 1，结果得到 3214。
交换数字 2 和数字 4，结果得到 3412。
注意，可能存在其他交换序列，但是可以证明 3412 是最大可能值。
注意，不能交换数字 4 和数字 1，因为它们奇偶性不同。
```

---

示例 2：

```txt
输入：num = 65875
输出：87655

解释：
交换数字 8 和数字 6，结果得到 85675。
交换数字 5 和数字 7，结果得到 87655。
注意，可能存在其他交换序列，但是可以证明 87655 是最大可能值。
```

---

提示：

- `1 <= num <= 10^9`

## 2. 🎯 s.1 - 奇偶分段重排

::: code-group

```js [js]
/**
 * @param {number} num
 * @return {number}
 */
var largestInteger = function (num) {
  const digits = num.toString().split('').map(Number)

  const odds = []
  const evens = []
  for (const d of digits) {
    if (d % 2 === 0) evens.push(d)
    else odds.push(d)
  }

  odds.sort((a, b) => b - a)
  evens.sort((a, b) => b - a)

  let oi = 0
  let ei = 0
  const res = []
  for (const d of digits) {
    if (d % 2 === 0) res.push(evens[ei++])
    else res.push(odds[oi++])
  }

  return Number(res.join(''))
}
```

:::

- 时间复杂度：$O(L \log L)$，奇偶各自排序（L 为位数，常数上界）
- 空间复杂度：$O(L)$，存放拆分后的数字

算法思路：

- 将数字按奇偶性拆成两组，分别降序排序，再按原位奇偶取出对应组的最大剩余数字，重建结果即为可得的最大值。
