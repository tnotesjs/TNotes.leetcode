## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/number-of-1-bits/)

给定一个正整数 `n`，编写一个函数，获取一个正整数的二进制形式并返回其二进制表达式中设置位的个数（也被称为[汉明重量][1]）。

---

示例 1：

```txt
输入：n = 11
输出：3
```

解释：输入的二进制串 1011 中，共有 3 个设置位。

---

示例 2：

```txt
输入：n = 128
输出：1
```

解释：输入的二进制串 10000000 中，共有 1 个设置位。

---

示例 3：

```txt
输入：n = 2147483645
输出：30
```

解释：输入的二进制串 1111111111111111111111111111101 中，共有 30 个设置位。

---

提示：

- `1 <= n <= 2^31 - 1`

---

进阶：如果多次调用这个函数，你将如何优化你的算法？

<<< ./solutions/2/1.py [py]

- 时间复杂度：$O(k)$，其中 $k$ 是二进制中 1 的个数，最坏不超过 32
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 利用 `n & (n-1)` 的特性：这个操作会清除 n 中最右边的 1
- 每次操作都会减少一个 1，直到 n 变为 0
- 操作的次数就是 1 的个数
  - 示例：`n = 1101`
  - `n = 1101, n-1 = 1100, n&(n-1) = 1100, count=1`
  - `n = 1100, n-1 = 1011, n&(n-1) = 1000, count=2`
  - `n = 1000, n-1 = 0111, n&(n-1) = 0000, count=3`
  - `n = 0000`，结束循环

## 4. 【AI】请简单介绍一下 Brian Kernighan 算法

Brian Kernighan 是 C 语言与 Unix 领域的著名计算机科学家。这里说的「Brian Kernighan 算法」特指他提出的一种**统计二进制中 1 的个数**的技巧，核心就一句：

$$
n \;\&\; (n - 1)
$$

会清掉 $n$ 二进制表示里**最右边的那个 1**，其余位不变。

### 4.1. 为什么成立？

$n-1$ 的效果：从最低位借位，会把最右边的 1 变成 0，并把该位右边的所有 0 变成 1。再和原 $n$ 做与运算，那一位 1 被清掉，更高位保持原样。

例如 $n = 12$（`1100`）：

$$
\begin{align*}
n &= 1100 \\
n-1 &= 1011 \\
n \& (n-1) &= 1000
\end{align*}
$$

最右边的 1（原倒数第 3 位）消失了。

### 4.2. 怎么用来数 1？

反复执行 `n = n & (n - 1)`，每做一次就少一个 1，直到 $n = 0$。循环次数恰好等于汉明重量（1 的个数）。

### 4.3. 和逐位检查比呢？

| | 逐位检查（s.1） | Brian Kernighan（s.2） |
|--|----------------|------------------------|
| 循环次数 | 固定 32 | 等于 1 的个数 $k$ |
| 时间 | $O(1)$ | $O(k)$，稀疏时更快 |
| 空间 | $O(1)$ | $O(1)$ |

所以它不是渐进意义上「另一个量级」，而是**跳过所有 0 位**，只在 1 上花时间，更高效。
