## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/convert-a-number-to-hexadecimal/)

给定一个整数，编写一个算法将这个数转换为十六进制数。对于负整数，我们通常使用 [补码运算][1] 方法。

答案字符串中的所有字母都应该是小写字符，并且除了 0 本身之外，答案中不应该有任何前置零。

注意：不允许使用任何由库提供的将数字直接转换或格式化为十六进制的方法来解决这个问题。

---

示例 1：

```txt
输入：num = 26
输出："1a"
```

---

示例 2：

```txt
输入：num = -1
输出："ffffffff"
```

---

提示：

- `-2^31 <= num <= 2^31 - 1`

## 2. s.1 - 位运算

::: code-group

```c [c]
char* toHex(int num) {
    if (num == 0) {
        char* res = malloc(2);
        res[0] = '0';
        res[1] = '\0';
        return res;
    }

    const char* hex = "0123456789abcdef";
    unsigned int n = (unsigned int)num;
    char buf[9];
    int i = 8;
    buf[i] = '\0';

    while (n) {
        buf[--i] = hex[n & 15];
        n >>= 4;
    }

    char* res = malloc(9 - i);
    strcpy(res, buf + i);
    return res;
}
```

```js [js]
/**
 * @param {number} num
 * @return {string}
 */
var toHex = function (num) {
  if (num === 0) return '0'

  const hexChars = '0123456789abcdef'
  let result = ''
  // 无符号右移 0 位：按 32 位补码解释为无符号整数
  let n = num >>> 0

  while (n > 0) {
    result = hexChars[n & 15] + result
    n >>>= 4
  }

  return result
}
```

```py [py]
class Solution:
    def toHex(self, num: int) -> str:
        if num == 0:
            return "0"

        hex_chars = "0123456789abcdef"
        n = num & 0xFFFFFFFF  # 截成 32 位无符号
        res: list[str] = []

        while n:
            res.append(hex_chars[n & 15])
            n >>= 4

        return "".join(reversed(res))
```

:::

- 时间复杂度：$O(1)$，32 位整数最多循环 8 次
- 空间复杂度：$O(1)$，结果串长度至多 8，额外空间常数级

算法思路：

- 把 `num` 按 32 位补码看成无符号整数（负数高位自然全 1）
- 每次取最低 4 位映射到 `0-9a-f`，再无符号右移 4 位；最多 8 次
- `num == 0` 特判返回 `"0"`；循环到 0 即停，不会写出前置零

### 2.1. 解释：JS 实现中的 `let n = num >>> 0`

- `>>>` 是无符号右移运算符（Zero-fill right shift）
- 它会把数字当作 32 位无符号整数来处理
- 右移 0 位 → 数值不变，但类型语义变了

举个例子：

```js
console.log(-1 >>> 0) // 输出：4294967295
```

- `-1` 的 32 位补码是：`11111111 11111111 11111111 11111111`
- 当你用 `>>> 0`，JS 把它解释为无符号整数
- 二进制 `11111111 11111111 11111111 11111111` = 2³² - 1 = 4294967295

执行过程示例：

- 示例 1
    1. 26 & 15 = 10，对应字符 'a'
    2. 26 >>> 4 = 1
    3. 1 & 15 = 1，对应字符 '1'
    4. 1 >>> 4 = 0，循环结束
    5. 结果为 '1a'
- 示例 2
    1. -1 >>> 0 = 4294967295 (32 位无符号整数)
    2. 4294967295 & 15 = 15，对应字符 'f'
    3. 继续右移 4 位，总共 8 次得到 'ffffffff'
