## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/minimum-numbers-of-function-calls-to-make-target-array/)

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-09-22-14-58-08.png)

给你一个与 `nums` 大小相同且初始值全为 0 的数组 `arr`，请你调用以上函数得到整数数组 `nums`。

请你返回将 `arr` 变成 `nums` 的最少函数调用次数。

答案保证在 32 位有符号整数以内。

---

示例 1：

```txt
输入：nums = [1,5]
输出：5
解释：给第二个数加 1 ：[0, 0] 变成 [0, 1] （1 次操作）。
将所有数字乘以 2 ：[0, 1] -> [0, 2] -> [0, 4] （2 次操作）。
给两个数字都加 1 ：[0, 4] -> [1, 4] -> [1, 5] （2 次操作）。
总操作次数为：1 + 2 + 2 = 5。
```

示例 2：

```txt
输入：nums = [2,2]
输出：3
解释：给两个数字都加 1 ：[0, 0] -> [0, 1] -> [1, 1] （2 次操作）。
将所有数字乘以 2 ：[1, 1] -> [2, 2] （1 次操作）。
总操作次数为：2 + 1 = 3。
```

示例 3：

```txt
输入：nums = [4,2,5]
输出：6
解释：（初始）[0,0,0] -> [1,0,0] -> [1,0,1] -> [2,0,2] -> [2,1,2] -> [4,2,4] -> [4,2,5] （nums 数组）。
```

示例 4：

```txt
输入：nums = [3,2,2,4]
输出：7
```

示例 5：

```txt
输入：nums = [2,4,8,16]
输出：8
```

---

提示：

- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

## 2. 🎯 s.1 - 位运算分析

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var minOperations = function (nums) {
  let ops = 0,
    maxBits = 0
  for (const x of nums) {
    let bits = 0,
      v = x
    while (v > 0) {
      if (v & 1) ops++ // 每个 1 位需要一次 +1 操作
      bits++
      v >>= 1
    }
    maxBits = Math.max(maxBits, bits)
  }
  // 还需要 maxBits - 1 次 x2 操作（共享）
  if (maxBits > 0) ops += maxBits - 1
  return ops
}
```

```c [c]
int minOperations(int* nums, int numsSize) {
    int ops = 0, maxBits = 0;
    for (int i = 0; i < numsSize; i++) {
        int v = nums[i], bits = 0;
        while (v > 0) {
            if (v & 1) ops++;
            bits++;
            v >>= 1;
        }
        if (bits > maxBits) maxBits = bits;
    }
    if (maxBits > 0) ops += maxBits - 1;
    return ops;
}
```

```py [py]
class Solution:
    def minOperations(self, nums: list[int]) -> int:
        ops = max_bits = 0
        for x in nums:
            bits = 0
            v = x
            while v > 0:
                if v & 1:
                    ops += 1
                bits += 1
                v >>= 1
            max_bits = max(max_bits, bits)
        if max_bits > 0:
            ops += max_bits - 1
        return ops
```

:::

- 时间复杂度：$O(n \log M)$，其中 $M$ 是数组中的最大值
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：

- 将问题反向看：从目标数组减到全 0
- 「乘 2」操作对所有元素同时生效（二进制右移一位），「加 1」操作只影响单个元素
- 每个数的二进制中 `1` 的个数对应需要的「加 1」次数
- 全局需要的「乘 2」次数取决于最大值的二进制位数
- 总操作次数 = 所有数的 `1` 位个数之和 + 最大值的最高位数
