## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/different-ways-to-add-parentheses/)

给你一个由数字和运算符组成的字符串 `expression`，按不同优先级组合数字和运算符，计算并返回所有可能组合的结果。你可以按任意顺序返回答案。

生成的测试用例满足其对应输出值符合 32 位整数范围，不同结果的数量不超过 `10^4`。

---

示例 1：

```txt
输入：expression = "2-1-1"
输出：[0, 2]
```

解释：

- `((2 - 1) - 1) = 0`
- `(2 - (1 - 1)) = 2`

---

示例 2：

```txt
输入：expression = "2*3-4*5"
输出：[-34, -14, -10, -10, 10]
```

解释：

- `(2*(3-(4*5))) = -34`
- `((2*3)-(4*5)) = -14`
- `((2*(3-4))*5) = -10`
- `(2*((3-4)*5)) = -10`
- `(((2*3)-4)*5) = 10`

---

提示：

- `1 <= expression.length <= 20`
- `expression` 由数字和算符 `'+'`、`'-'` 和 `'*'` 组成。
- 输入表达式中的所有整数值在范围 `[0, 99]`
- 输入表达式中的所有整数都没有前导 `'-'` 或 `'+'` 表示符号。

## 2. s.1 - 分治 + 递归 + 记忆化搜索

```c [c]
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
static int* dfs(char* expression, int l, int r, int* returnSize, int* memo[][21], int memoSize[][21]) {
    if (memoSize[l][r] != -1) {
        *returnSize = memoSize[l][r];
        return memo[l][r];
    }

    int* res = NULL;
    int size = 0, cap = 0;

    for (int i = l; i < r; i++) {
        char ch = expression[i];
        if (ch == '+' || ch == '-' || ch == '*') {
            int leftSize, rightSize;
            int* left = dfs(expression, l, i, &leftSize, memo, memoSize);
            int* right = dfs(expression, i + 1, r, &rightSize, memo, memoSize);
            for (int a = 0; a < leftSize; a++) {
                for (int b = 0; b < rightSize; b++) {
                    int val;
                    if (ch == '+') val = left[a] + right[b];
                    else if (ch == '-') val = left[a] - right[b];
                    else val = left[a] * right[b];
                    if (size == cap) {
                        cap = cap == 0 ? 4 : cap * 2;
                        res = (int*)realloc(res, sizeof(int) * cap);
                    }
                    res[size++] = val;
                }
            }
        }
    }

    if (size == 0) {
        int num = 0;
        for (int i = l; i < r; i++) num = num * 10 + (expression[i] - '0');
        res = (int*)malloc(sizeof(int));
        res[size++] = num;
    }

    memo[l][r] = res;
    memoSize[l][r] = size;
    *returnSize = size;
    return res;
}

int* diffWaysToCompute(char* expression, int* returnSize) {
    int n = strlen(expression);
    int* memo[21][21] = {0};
    int memoSize[21][21];
    for (int i = 0; i <= n; i++) {
        for (int j = 0; j <= n; j++) memoSize[i][j] = -1;
    }

    int* res = dfs(expression, 0, n, returnSize, memo, memoSize);
    for (int i = 0; i <= n; i++) {
        for (int j = 0; j <= n; j++) {
            if (memo[i][j] != res) free(memo[i][j]);
        }
    }
    return res;
}
```

```js [js]
/**
 * @param {string} expression
 * @return {number[]}
 */
var diffWaysToCompute = function (expression) {
  const memo = new Map()

  function dfs(expr) {
    if (memo.has(expr)) return memo.get(expr)

    const res = []
    for (let i = 0; i < expr.length; i++) {
      const ch = expr[i]
      if (ch === '+' || ch === '-' || ch === '*') {
        const left = dfs(expr.slice(0, i))
        const right = dfs(expr.slice(i + 1))
        for (const l of left) {
          for (const r of right) {
            if (ch === '+') res.push(l + r)
            else if (ch === '-') res.push(l - r)
            else res.push(l * r)
          }
        }
      }
    }

    if (res.length === 0) res.push(Number(expr))
    memo.set(expr, res)
    return res
  }

  return dfs(expression)
}
```

```py [py]
class Solution:
    def diffWaysToCompute(self, expression: str) -> List[int]:
        memo = {}

        def dfs(expr: str) -> List[int]:
            if expr in memo:
                return memo[expr]

            res = []
            for i, ch in enumerate(expr):
                if ch in '+-*':
                    left = dfs(expr[:i])
                    right = dfs(expr[i + 1:])
                    for l in left:
                        for r in right:
                            if ch == '+':
                                res.append(l + r)
                            elif ch == '-':
                                res.append(l - r)
                            else:
                                res.append(l * r)
            if not res:
                res.append(int(expr))
            memo[expr] = res
            return res

        return dfs(expression)
```

- 时间复杂度：$O(C_n)$（卡特兰数），其中 $n$ 是运算符个数
- 空间复杂度：$O(C_n)$，存储所有可能的结果

算法思路：

- 以每个运算符为分割点，递归计算左右两侧所有可能的结果
- 将左右结果两两组合计算，基本情况为纯数字
- 核心代码逻辑就是：$\text{所有结果} = \bigcup_{\text{每个运算符}} \{\, \text{左结果} \ op \ \text{右结果} \,\}$
    - 其中左右结果又通过递归得到

### 2.1. 核心思想：分治

任何一个加括号的表达式，最终都可以看作**最后一次运算**把整个表达式分成左右两部分。

例如：

$$
2-1-1
$$

如果最后一次运算是第一个减号，那么表达式被分成：

- 左边：`2`
- 右边：`1-1`
- 运算：`2 - (1-1)`

如果最后一次运算是第二个减号，那么表达式被分成：

- 左边：`2-1`
- 右边：`1`
- 运算：`(2-1) - 1`

因此，我们只需要**枚举每一个运算符作为最后一次运算**，分别递归计算左右两边所有可能的结果，然后根据当前运算符组合左右结果。

这就是分治法：把大问题拆成左右两个子问题，分别求解，再合并。

### 2.2. 为什么这样能覆盖所有加括号方式？

任何加括号的表达式，本质上都是选择某个运算符作为**根运算**，把表达式分成左右两部分。左边和右边又可以继续递归地加括号。

所以，枚举每一个运算符作为最后一次运算，就等价于枚举了所有可能的括号结构。

例如：

$$
(2-1)-1
$$

最后一次运算是第二个减号。

$$
2-(1-1)
$$
最后一次运算是第一个减号。

因此，代码通过枚举所有运算符，就能得到所有可能结果。

### 2.3. 与卡特兰数的关系

如果表达式中有 $n$ 个运算符，那么就有 $n+1$ 个数字。所有可能的完全加括号方式数量是第 $n$ 个卡特兰数：

$$
C_n = \frac{1}{n+1}\binom{2n}{n}
$$

例如：

- `"2-1-1"` 有 2 个运算符，$C_2 = 2$，两种括号方式。
- `"2*3-4*5"` 有 3 个运算符，$C_3 = 5$，五种括号方式。
