## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/random-flip-matrix/)

给你一个 `m x n` 的二元矩阵 `matrix`，且所有值被初始化为 `0`。请你设计一个算法，随机选取一个满足 `matrix[i][j] == 0` 的下标 `(i, j)`，并将它的值变为 `1`。所有满足 `matrix[i][j] == 0` 的下标 `(i, j)` 被选取的概率应当均等。

尽量最少调用内置的随机函数，并且优化时间和空间复杂度。

实现 `Solution` 类：

- `Solution(int m, int n)` 使用二元矩阵的大小 `m` 和 `n` 初始化该对象
- `int[] flip()` 返回一个满足 `matrix[i][j] == 0` 的随机下标 `[i, j]`，并将其对应格子中的值变为 `1`
- `void reset()` 将矩阵中所有的值重置为 `0`

---

示例：

```txt
输入
["Solution", "flip", "flip", "flip", "reset", "flip"]
[[3, 1], [], [], [], [], []]
输出
[null, [1, 0], [2, 0], [0, 0], null, [2, 0]]

解释
Solution solution = new Solution(3, 1);
solution.flip();  // 返回 [1, 0]，此时返回 [0, 0]、[1, 0] 和 [2, 0] 的概率应当相同
solution.flip();  // 返回 [2, 0]，因为 [1, 0] 已经返回过了，此时返回 [2, 0] 和 [0, 0] 的概率应当相同
solution.flip();  // 返回 [0, 0]，根据前面已经返回过的下标，此时只能返回 [0, 0]
solution.reset(); // 所有值都重置为 0，并可以再次选择下标返回
solution.flip();  // 返回 [2, 0]，此时返回 [0, 0]、[1, 0] 和 [2, 0] 的概率应当相同
```

---

提示：

- `1 <= m, n <= 10^4`
- 每次调用`flip` 时，矩阵中至少存在一个值为 0 的格子。
- 最多调用 `1000` 次 `flip` 和 `reset` 方法。

## 2. s.1 - Fisher-Yates 洗牌 + 哈希表

::: code-group

```c [c]
#define HASH_SIZE 10007
typedef struct Entry { int key; int val; struct Entry* next; } Entry;

typedef struct {
    int m, n, total;
    Entry* table[HASH_SIZE];
} Solution;

int getOrDefault(Solution* obj, int key) {
    int idx = ((unsigned int)key) % HASH_SIZE;
    for (Entry* e = obj->table[idx]; e; e = e->next)
        if (e->key == key) return e->val;
    return key;
}

void putVal(Solution* obj, int key, int val) {
    int idx = ((unsigned int)key) % HASH_SIZE;
    for (Entry* e = obj->table[idx]; e; e = e->next)
        if (e->key == key) { e->val = val; return; }
    Entry* e = (Entry*)malloc(sizeof(Entry));
    e->key = key; e->val = val; e->next = obj->table[idx]; obj->table[idx] = e;
}

void clearTable(Solution* obj) {
    for (int i = 0; i < HASH_SIZE; i++) {
        Entry* e = obj->table[i];
        while (e) { Entry* t = e; e = e->next; free(t); }
        obj->table[i] = NULL;
    }
}

Solution* solutionCreate(int m, int n) {
    Solution* obj = (Solution*)calloc(1, sizeof(Solution));
    obj->m = m; obj->n = n; obj->total = m * n;
    return obj;
}

int* solutionFlip(Solution* obj, int* retSize) {
    *retSize = 2;
    int* res = (int*)malloc(sizeof(int) * 2);
    int r = rand() % obj->total;
    obj->total--;
    int val = getOrDefault(obj, r);
    putVal(obj, r, getOrDefault(obj, obj->total));
    res[0] = val / obj->n;
    res[1] = val % obj->n;
    return res;
}

void solutionReset(Solution* obj) {
    obj->total = obj->m * obj->n;
    clearTable(obj);
}

void solutionFree(Solution* obj) {
    clearTable(obj);
    free(obj);
}

 * int* param_1 = solutionFlip(obj, retSize);

 * solutionFree(obj);
```

```js [js]
/**
 * @param {number} m
 * @param {number} n
 */
var Solution = function (m, n) {
  this.m = m
  this.n = n
  this.total = m * n
  this.map = new Map()
}

/**
 * @return {number[]}
 */
Solution.prototype.flip = function () {
  const rand = Math.floor(Math.random() * this.total)
  this.total--
  const val = this.map.get(rand) ?? rand
  this.map.set(rand, this.map.get(this.total) ?? this.total)
  return [Math.floor(val / this.n), val % this.n]
}

Solution.prototype.reset = function () {
  this.total = this.m * this.n
  this.map.clear()
}
```

```py [py]
class Solution:
    def __init__(self, m: int, n: int):
        self.m = m
        self.n = n
        self.total = m * n
        self.map = {}

    def flip(self) -> List[int]:
        r = random.randint(0, self.total - 1)
        self.total -= 1
        val = self.map.get(r, r)
        self.map[r] = self.map.get(self.total, self.total)
        return [val // self.n, val % self.n]

    def reset(self) -> None:
        self.total = self.m * self.n
        self.map.clear()
```

:::

- 时间复杂度：`flip` $O(1)$，`reset` $O(F)$，$F$ 为已翻转次数
- 空间复杂度：$O(F)$

算法思路：

- 将矩阵展平为一维，用哈希表实现虚拟交换
- 每次随机选一个位置，与末尾交换，缩小范围

---

题目解读：

题目要求在一个初始全 0 的 `m × n` 矩阵里，每次 `flip` 要等概率挑一个还是 0 的格子变成 1 并返回坐标，`reset` 再全部恢复成 0。

根据提示 `1 <= m, n <= 10^4` 可知矩阵最大有 $10^8$ 个格子，但 `flip` / `reset` 最多各 1000 次，因此不能真的开整张矩阵。

---

s.1 详细说明：

s.1 把矩阵看成长度为 $total = m \times n$ 的一维数组，用 Fisher-Yates 抽样：在 $[0, total)$ 里随机一个位置 `r`，取出它当前对应的格子，再和「当前最后一个未用位置」交换，然后把 $total$ 减 1，这样抽过的格子就不会再被抽到。真正的数组太长，只用哈希表记下被交换过的位置；没记过的位置默认就是下标自己。取出的一维编号 `val` 再还原成坐标 $[\lfloor val / n \rfloor, val \bmod n]$。`reset` 时恢复 $total$ 并清空哈希表。

---

哈希表在这里的作用：

哈希表记的是一维虚拟数组里「某个位置现在实际放的是哪个格子」。

矩阵被展平成下标 $0..mn-1$。一开始位置 $i$ 上就是格子 $i$，不必记。每次 `flip` 在 $[0, total)$ 里随机一个位置 `r`，取出它现在对应的格子，再把「当前最后一个未用位置」上的格子写到 `r` 上，然后缩小 $total$。被换过来的这个对应关系才写进哈希表：键是虚拟数组的位置，值是这个位置上的一维格子编号。没出现在表里的位置，默认还是下标自己。

比如 $3 \times 1$，第一次抽到位置 `1`（格子 `[1, 0]`）后，$total$ 变成 2，表里会记下「位置 1 现在放的是原来的末尾格子 2」。下次再抽到位置 1，拿到的就是格子 2，也就是 `[2, 0]`，不会重复抽到已经翻过的 `[1, 0]`。

需要注意 `total--` 之后，`total` 只是「最后一个未用位置」的下标，这个位置上放的不一定还是它自己。如果它先前被换过，真正的格子在 `map.get(total)` 里，否则真正的格子就是 `total` 自身。

比如在长度为 4 的一维数组中，先抽位置 `2`，表里记下「位置 2 现在是格子 3」，剩下 `[0, 1, 3]`。再抽位置 `0` 时，最后一个未用位置是 2，上面已经是格子 3。
