## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/maximum-number-of-consecutive-values-you-can-make/)

给你一个长度为 `n` 的整数数组 `coins`，它代表你拥有的 `n` 个硬币。第 `i` 个硬币的值为 `coins[i]`。如果你从这些硬币中选出一部分硬币，它们的和为 `x`，那么称，你可以 构造 出 `x`。

请返回从 `0` 开始（包括 `0` ），你最多能 构造 出多少个连续整数。

你可能有多个相同值的硬币。

---

示例 1：

```txt
输入：coins = [1,3]
输出：2
解释：你可以得到以下这些值：
- 0：什么都不取 []
- 1：取 [1]
从 0 开始，你可以构造出 2 个连续整数。
```

示例 2：

```txt
输入：coins = [1,1,1,4]
输出：8
解释：你可以得到以下这些值：
- 0：什么都不取 []
- 1：取 [1]
- 2：取 [1,1]
- 3：取 [1,1,1]
- 4：取 [4]
- 5：取 [4,1]
- 6：取 [4,1,1]
- 7：取 [4,1,1,1]
从 0 开始，你可以构造出 8 个连续整数。
```

示例 3：

```txt
输入：nums = [1,4,10,3,1]
输出：20
```

---

提示：

- `coins.length == n`
- `1 <= n <= 4 * 10^4`
- `1 <= coins[i] <= 4 * 10^4`

## 2. 🎯 s.1 - 排序 + 贪心

::: code-group

```js [js]
/**
 * @param {number[]} coins
 * @return {number}
 */
var getMaximumConsecutive = function (coins) {
  coins.sort((a, b) => a - b)
  let reach = 0 // 当前可构造 [0, reach]
  for (const c of coins) {
    if (c > reach + 1) break
    reach += c
  }
  return reach + 1
}
```

```c [c]
#include <stdlib.h>

int cmp1798(const void* a, const void* b) {
  return *(int*)a - *(int*)b;
}

int getMaximumConsecutive(int* coins, int coinsSize) {
  qsort(coins, coinsSize, sizeof(int), cmp1798);
  long long reach = 0;
  for (int i = 0; i < coinsSize; i++) {
    if (coins[i] > reach + 1) break;
    reach += coins[i];
  }
  return (int)(reach + 1);
}
```

```py [py]
class Solution:
    def getMaximumConsecutive(self, coins: list[int]) -> int:
        coins.sort()
        reach = 0
        for c in coins:
            if c > reach + 1:
                break
            reach += c
        return reach + 1
```

:::

- 时间复杂度：$O(n \log n)$，其中 n 是硬币数量
- 空间复杂度：$O(1)$，原地排序

算法思路：

- 将硬币排序，从小到大遍历
- 如果当前硬币 <= 已能构造的最大值 + 1，则可以扩展范围
- 否则无法继续扩展，返回当前可构造的最大值 + 1
