## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/maximum-total-importance-of-roads/)

给你一个整数 `n`，表示一个国家里的城市数目。城市编号为 `0` 到 `n - 1`。

给你一个二维整数数组 `roads`，其中 `roads[i] = [ai, bi]` 表示城市 `ai` 和 `bi` 之间有一条 双向 道路。

你需要给每个城市安排一个从 `1` 到 `n` 之间的整数值，且每个值只能被使用 一次。道路的 重要性 定义为这条道路连接的两座城市数值 之和。

请你返回在最优安排下，所有道路重要性 之和 最大 为多少。

---

提示：

- `2 <= n <= 5 * 10^4`
- `1 <= roads.length <= 5 * 10^4`
- `roads[i].length == 2`
- `0 <= ai, bi <= n - 1`
- `ai != bi`
- 没有重复道路。

## 2. 🎯 s.1 - 贪心 + 排序

::: code-group

```js [js]
/**
 * @param {number} n
 * @param {number[][]} roads
 * @return {number}
 */
var maximumImportance = function (n, roads) {
  const degree = new Array(n).fill(0)
  for (const [a, b] of roads) {
    degree[a]++
    degree[b]++
  }
  degree.sort((a, b) => a - b)
  let res = 0
  for (let i = 0; i < n; i++) {
    res += (i + 1) * degree[i]
  }
  return res
}
```

```c [c]
int cmp2285(const void* a, const void* b) {
    return *(int*)a - *(int*)b;
}

long long maximumImportance(int n, int** roads, int roadsSize, int* roadsColSize) {
    int* degree = (int*)calloc(n, sizeof(int));
    for (int i = 0; i < roadsSize; i++) {
        degree[roads[i][0]]++;
        degree[roads[i][1]]++;
    }
    qsort(degree, n, sizeof(int), cmp2285);
    long long res = 0;
    for (int i = 0; i < n; i++) {
        res += (long long)(i + 1) * degree[i];
    }
    free(degree);
    return res;
}
```

```py [py]
class Solution:
    def maximumImportance(self, n: int, roads: list[list[int]]) -> int:
        degree = [0] * n
        for a, b in roads:
            degree[a] += 1
            degree[b] += 1
        degree.sort()
        return sum((i + 1) * d for i, d in enumerate(degree))
```

:::

- 时间复杂度：$O(n \log n + m)$，其中 n 是城市数量，m 是道路数量
- 空间复杂度：$O(n)$，存储每个城市的度数

算法思路：

- 统计每个城市的度数（连接道路数）
- 将度数排序，度数越大的城市分配越大的值（贪心）
- 累加每个城市的 (排名 + 1) × 度数 即为最大总重要性
