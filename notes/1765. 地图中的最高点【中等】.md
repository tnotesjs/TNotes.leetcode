## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/map-of-highest-peak/)

给你一个大小为 `m x n` 的整数矩阵 `isWater`，它代表了一个由 陆地 和 水域 单元格组成的地图。

- 如果 `isWater[i][j] == 0`，格子 `(i, j)` 是一个 陆地 格子。
- 如果 `isWater[i][j] == 1`，格子 `(i, j)` 是一个 水域 格子。

你需要按照如下规则给每个单元格安排高度：

- 每个格子的高度都必须是非负的。
- 如果一个格子是 水域，那么它的高度必须为 `0`。
- 任意相邻的格子高度差 至多 为 `1`。当两个格子在正东、南、西、北方向上相互紧挨着，就称它们为相邻的格子。（也就是说它们有一条公共边）

找到一种安排高度的方案，使得矩阵中的最高高度值 最大。

请你返回一个大小为 `m x n` 的整数矩阵 `height`，其中 `height[i][j]` 是格子 `(i, j)` 的高度。如果有多种解法，请返回 任意一个。

- `n == isWater[i].length`

- 至少有 1 个水域格子。

## 2. 🎯 s.1 - 多源 BFS

```js [js]
/**
 * @param {number[][]} isWater
 * @return {number[][]}
 */
var highestPeak = function (isWater) {
  const m = isWater.length,
    n = isWater[0].length
  const height = Array.from({ length: m }, () => new Array(n).fill(-1))
  const queue = []
  for (let i = 0; i < m; i++) {
    for (let j = 0; j < n; j++) {
      if (isWater[i][j] === 1) {
        height[i][j] = 0
        queue.push([i, j])
      }
    }
  }
  const dirs = [
    [0, 1],
    [0, -1],
    [1, 0],
    [-1, 0],
  ]
  let head = 0
  while (head < queue.length) {
    const [x, y] = queue[head++]
    for (const [dx, dy] of dirs) {
      const nx = x + dx,
        ny = y + dy
      if (nx >= 0 && nx < m && ny >= 0 && ny < n && height[nx][ny] === -1) {
        height[nx][ny] = height[x][y] + 1
        queue.push([nx, ny])
      }
    }
  }
  return height
}
```

```c [c]
#include <stdlib.h>
#include <string.h>

int** highestPeak(int** isWater, int isWaterSize, int* isWaterColSize, int* returnSize, int** returnColumnSizes) {
  int m = isWaterSize, n = isWaterColSize[0];
  int** height = (int**)malloc(m * sizeof(int*));
  for (int i = 0; i < m; i++) {
    height[i] = (int*)malloc(n * sizeof(int));
    memset(height[i], -1, n * sizeof(int));
  }
  int* qx = (int*)malloc(m * n * sizeof(int));
  int* qy = (int*)malloc(m * n * sizeof(int));
  int head = 0, tail = 0;
  for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
      if (isWater[i][j] == 1) {
        height[i][j] = 0;
        qx[tail] = i;
        qy[tail] = j;
        tail++;
      }
    }
  }
  int dx[] = {0, 0, 1, -1}, dy[] = {1, -1, 0, 0};
  while (head < tail) {
    int x = qx[head], y = qy[head];
    head++;
    for (int d = 0; d < 4; d++) {
      int nx = x + dx[d], ny = y + dy[d];
      if (nx >= 0 && nx < m && ny >= 0 && ny < n && height[nx][ny] == -1) {
        height[nx][ny] = height[x][y] + 1;
        qx[tail] = nx;
        qy[tail] = ny;
        tail++;
      }
    }
  }
  free(qx);
  free(qy);
  *returnSize = m;
  *returnColumnSizes = (int*)malloc(m * sizeof(int));
  for (int i = 0; i < m; i++) (*returnColumnSizes)[i] = n;
  return height;
}
```

```py [py]
from collections import deque

class Solution:
    def highestPeak(self, isWater: list[list[int]]) -> list[list[int]]:
        m, n = len(isWater), len(isWater[0])
        height = [[-1] * n for _ in range(m)]
        q = deque()
        for i in range(m):
            for j in range(n):
                if isWater[i][j] == 1:
                    height[i][j] = 0
                    q.append((i, j))
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        while q:
            x, y = q.popleft()
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < m and 0 <= ny < n and height[nx][ny] == -1:
                    height[nx][ny] = height[x][y] + 1
                    q.append((nx, ny))
        return height
```

:::

- 时间复杂度：$O(mn)$，其中 m 和 n 分别是矩阵的行数和列数
- 空间复杂度：$O(mn)$，队列和结果矩阵的空间

算法思路：

- 以所有水域为起点进行多源 BFS
- 水域高度为 0，每向外扩展一层高度加 1
- 保证相邻格子高度差不超过 1
