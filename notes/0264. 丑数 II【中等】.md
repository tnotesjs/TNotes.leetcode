## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/ugly-number-ii/)

给你一个整数 `n`，请你找出并返回第 `n` 个丑数。

丑数就是质因子只包含 `2`、`3` 和 `5` 的正整数。

---

示例 1：

```txt
输入：n = 10
输出：12
```

解释：`[1, 2, 3, 4, 5, 6, 8, 9, 10, 12]` 是由前 10 个丑数组成的序列。

---

示例 2：

```txt
输入：n = 1
输出：1
```

解释：1 通常被视为丑数。

---

提示：

- `1 <= n <= 1690`

## 2. s.1 - 动态规划 + 三指针

::: code-group

```c [c]
int nthUglyNumber(int n) {
    int* dp = (int*)malloc(sizeof(int) * n);
    dp[0] = 1;
    int p2 = 0, p3 = 0, p5 = 0;
    for (int i = 1; i < n; i++) {
        long a = (long)dp[p2] * 2, b = (long)dp[p3] * 3, c = (long)dp[p5] * 5;
        long mn = a < b ? a : b;
        mn = mn < c ? mn : c;
        dp[i] = (int)mn;
        if (dp[i] == a) p2++;
        if (dp[i] == b) p3++;
        if (dp[i] == c) p5++;
    }
    int res = dp[n - 1];
    free(dp);
    return res;
}
```

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var nthUglyNumber = function (n) {
  const dp = new Array(n)
  dp[0] = 1
  let p2 = 0,
    p3 = 0,
    p5 = 0
  for (let i = 1; i < n; i++) {
    const a = dp[p2] * 2,
      b = dp[p3] * 3,
      c = dp[p5] * 5
    dp[i] = Math.min(a, b, c)
    if (dp[i] === a) p2++
    if (dp[i] === b) p3++
    if (dp[i] === c) p5++
  }
  return dp[n - 1]
}
```

```py [py]
class Solution:
    def nthUglyNumber(self, n: int) -> int:
        dp = [0] * n
        dp[0] = 1
        p2 = p3 = p5 = 0
        for i in range(1, n):
            a, b, c = dp[p2] * 2, dp[p3] * 3, dp[p5] * 5
            dp[i] = min(a, b, c)
            if dp[i] == a: p2 += 1
            if dp[i] == b: p3 += 1
            if dp[i] == c: p5 += 1
        return dp[-1]
```

:::

- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$，`dp` 数组

算法思路：

- 维护三个指针 p2、p3、p5，分别表示下一个要乘 2/3/5 的丑数位置
- 每次取三者乘积的最小值作为下一个丑数，同时推进等于该值的指针

### 2.1. 整体思路

每个丑数都可以由某个更小的丑数乘以 $2$、$3$ 或 $5$ 得到。例如：

- $2 = 1 \times 2$
- $3 = 1 \times 3$
- $4 = 2 \times 2$
- $5 = 1 \times 5$
- $6 = 2 \times 3 = 3 \times 2$

因此，我们可以从小到大依次生成丑数。维护三个指针 $p2$、$p3$、$p5$，分别表示下一个要乘以 $2$、$3$、$5$ 的丑数在数组中的位置。

每次从三个候选值中取最小值作为下一个丑数，然后将对应的指针向后移动一位，表示该丑数已经被使用过。

### 2.3. 为什么三个指针有效？

所有丑数都可以表示为：

$$
2^i \times 3^j \times 5^k
$$

其中 $i,j,k \ge 0$。如果我们按顺序生成丑数，那么每个新丑数必然是之前某个丑数乘以 $2$、$3$ 或 $5$ 得到的。

三个指针分别维护了“下一个应该乘以 $2$、$3$、$5$ 的丑数位置”。因为数组 `dp` 是递增的，所以 $dp[p2] \times 2$、$dp[p3] \times 3$、$dp[p5] \times 5$ 也是递增的候选值。每次取最小值，就能保证按顺序生成所有丑数。

### 2.4. 为什么用三个 `if` 而不是 `else if`？

考虑 $dp[i] = 6$ 时：

- $a = dp[p2] \times 2 = 3 \times 2 = 6$
- $b = dp[p3] \times 3 = 2 \times 3 = 6$

如果使用 `else if`，只会移动一个指针，另一个指针仍然指向产生 $6$ 的位置。下一次循环又会生成 $6$，导致重复。使用三个独立的 `if`，可以同时移动两个指针，跳过所有产生相同值的候选，避免重复。


### 2.5. 总结

这段代码是求解第 $n$ 个丑数的经典最优解法：

1. 用 `dp` 数组按顺序存储丑数；
2. 用三个指针分别跟踪乘以 $2$、$3$、$5$ 的候选位置；
3. 每次取三个候选值的最小值作为下一个丑数；
4. 使用三个独立的 `if` 避免重复；
5. 时间复杂度 $O(n)$，空间复杂度 $O(n)$。

核心思想：**每个丑数都是由更小的丑数乘以 $2$、$3$ 或 $5$ 得到的，通过多指针归并可以有序生成。**
