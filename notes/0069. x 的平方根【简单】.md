## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/sqrtx)

---

- 给你一个非负整数 `x`，计算并返回 `x` 的 算术平方根。
- 由于返回类型是整数，结果只保留 整数部分，小数部分将被 舍去。
- 注意：不允许使用任何内置指数函数和算符，例如 `pow(x, 0.5)` 或者 `x 0.5`。

---

示例 1：

```txt
输入：x = 4
输出：2
```

---

示例 2：

```txt
输入：x = 8
输出：2
```

解释：8 的算术平方根是 2.82842..., 由于返回类型是整数，小数部分将被舍去。

---

提示：

- `0 <= x <= 2^31 - 1`

## 2. s.1 - 二分查找法

::: code-group

```c [c]
int mySqrt(int x) {
    if (x == 0)
        return 0;

    long long left = 1, right = x, result = 0;
    while (left <= right) {
        long long mid = (left + right) / 2;
        if (mid <= x / mid) {
            result = mid;
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return (int)result;
}
```

```js [js]
/**
 * @param {number} x
 * @return {number}
 */
var mySqrt = function (x) {
  if (x === 0) return 0

  let left = 1
  let right = x
  let result = 0

  while (left <= right) {
    let mid = Math.floor((left + right) / 2)

    if (mid <= x / mid) {
      result = mid
      left = mid + 1
    } else {
      right = mid - 1
    }
  }

  return result
}
```

```py [py]
class Solution:
    def mySqrt(self, x: int) -> int:
        if x == 0:
            return 0

        left, right, result = 1, x, 0
        while left <= right:
            mid = (left + right) // 2
            if mid <= x // mid:
                result = mid
                left = mid + 1
            else:
                right = mid - 1
        return result
```

:::

- 时间复杂度：$O(\log x)$，每次将搜索区间缩小一半
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：

- 在 $[1, x]$ 范围内二分查找，判断条件为 `mid * mid <= x`（用除法 `mid <= x / mid` 避免溢出）
- 若 `mid` 满足条件，记录答案并收缩左边界；否则收缩右边界
- 循环结束后，最后一次满足条件的 `mid` 即为结果

## 3. s.2 - 牛顿求根法

::: code-group

```c [c]
int mySqrt(int x) {
    if (x == 0)
        return 0;

    long long r = x;
    while (r > x / r) {
        r = (r + x / r) / 2;
    }
    return (int)r;
}
```

```js [js]
/**
 * @param {number} x
 * @return {number}
 */
var mySqrt = function (x) {
  if (x === 0) return 0

  let r = x
  while (r > x / r) {
    r = Math.floor((r + x / r) / 2)
  }

  return r
}
```

```py [py]
class Solution:
    def mySqrt(self, x: int) -> int:
        if x == 0:
            return 0

        r = x
        while r > x // r:
            r = (r + x // r) // 2
        return r
```

:::

- 时间复杂度：$O(\log x)$，牛顿法具有二次收敛性，迭代次数近似 $\log x$
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：

- 求 $\sqrt{x}$ 等价于求方程 $r^2 - x = 0$ 的正根
- 牛顿求根公式：$r_{n+1} = \frac{r_n + x / r_n}{2}$，即取当前猜测值与“被当前猜测值除”的平均值作为新的猜测
- 初始猜测 $r_0 = x$，不断迭代直到 $r \le x / r$，此时 $r$ 即为 $\lfloor\sqrt{x}\rfloor$
