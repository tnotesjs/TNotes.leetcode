## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/power-of-three/)

给定一个整数，写一个函数来判断它是否是 3 的幂次方。如果是，返回 `true`；否则，返回 `false`。

整数 `n` 是 3 的幂次方需满足：存在整数 `x` 使得 `n == 3^x`

---

示例 1：

```txt
输入：n = 27
输出：true
```

---

示例 2：

```txt
输入：n = 0
输出：false
```

---

示例 3：

```txt
输入：n = 9
输出：true
```

---

示例 4：

```txt
输入：n = 45
输出：false
```

---

提示：

- `-2^31 <= n <= 2^31 - 1`

---

进阶：你能不使用循环或者递归来完成本题吗？

## 2. s.1 - 最大幂取余法

::: code-group

```c [c]
bool isPowerOfThree(int n) {
    // 3 的幂必须是正整数
    if (n <= 0) return false;

    // 在 32 位整数范围内，最大的 3 的幂是 3^19 = 1162261467
    // 如果 n 是 3 的幂，那么 1162261467 能被 n 整除
    return 1162261467 % n == 0;
}
```

```js [js]
/**
 * @param {number} n
 * @return {boolean}
 */
var isPowerOfThree = function (n) {
  // 3 的幂必须是正整数
  if (n <= 0) return false

  // 在 32 位整数范围内，最大的 3 的幂是 3^19 = 1162261467
  // 如果 n 是 3 的幂，那么 1162261467 能被 n 整除
  return 1162261467 % n === 0
}
```

```py [py]
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        # 3 的幂必须是正整数
        if n <= 0:
            return False

        # 在 32 位整数范围内，最大的 3 的幂是 3^19 = 1162261467
        # 如果 n 是 3 的幂，那么 1162261467 能被 n 整除
        return 1162261467 % n == 0
```

:::

- 时间复杂度：$O(1)$
- 空间复杂度：$O(1)$

算法思路：

- 3 本身是一个质数，可以直接在边界值做取余
- 对于 2、3、5、7、11、13……只要是质数，都可以用这个方法！

## 3. s.2 - 对数换底公式

::: code-group

```c [c]
bool isPowerOfThree(int n) {
    // 3 的幂必须是正整数
    if (n <= 0) return false;

    // log3(n) = log10(n) / log10(3)，结果为整数则 n 是 3 的幂
    double logResult = log10(n) / log10(3);
    return logResult == floor(logResult);
}
```

```js [js]
/**
 * @param {number} n
 * @return {boolean}
 */
var isPowerOfThree = function (n) {
  // 3 的幂必须是正整数
  if (n <= 0) return false

  const logResult = Math.log10(n) / Math.log10(3)
  return Number.isInteger(logResult)
}
```

```py [py]
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        # 3 的幂必须是正整数
        if n <= 0:
            return False

        # log3(n) = log10(n) / log10(3)，结果为整数则 n 是 3 的幂
        log_result = log10(n) / log10(3)
        return log_result.is_integer()
```

:::

- 时间复杂度：$O(1)$
- 空间复杂度：$O(1)$

算法思路：

- 使用换底公式：`log3(n) = log10(n) / log10(3)`
- 如果结果是整数，则 n 是 3 的幂
