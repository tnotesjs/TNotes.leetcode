## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/number-of-subarrays-with-lcm-equal-to-k/)

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回 `nums` 的 子数组 中满足 _元素最小公倍数为 `k`_ 的子数组数目。

子数组 是数组中一个连续非空的元素序列。

数组的最小公倍数 是可被所有数组元素整除的最小正整数。

示例 1 ：

```txt
输入：nums = [3,6,2,7,1], k = 6
输出：4
解释：以 6 为最小公倍数的子数组是：
- [3,6,2,7,1]
- [3,6,2,7,1]
- [3,6,2,7,1]
- [3,6,2,7,1]
```

示例 2 ：

```txt
输入：nums = [3], k = 2
输出：0
解释：不存在以 2 为最小公倍数的子数组。
```

---

提示：

- `1 <= nums.length <= 1000`
- `1 <= nums[i], k <= 1000`

## 2. 🎯 s.1 - 枚举子数组

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var subarrayLCM = function (nums, k) {
  const gcd = (a, b) => b === 0 ? a : gcd(b, a % b)
  const lcm = (a, b) => a / gcd(a, b) * b
  let count = 0
  for (let i = 0; i < nums.length; i++) {
    let l = 1
    for (let j = i; j < nums.length; j++) {
      l = lcm(l, nums[j])
      if (l === k) count++
      if (l > k) break
    }
  }
  return count
}
```

```py [py]
from math import gcd

class Solution:
    def subarrayLCM(self, nums: list[int], k: int) -> int:
        count = 0
        for i in range(len(nums)):
            l = 1
            for j in range(i, len(nums)):
                l = l * nums[j] // gcd(l, nums[j])
                if l == k:
                    count += 1
                if l > k:
                    break
        return count
```

:::

- 时间复杂度：$O(n^2)$，其中 n 是数组长度
- 空间复杂度：$O(1)$

算法思路：

- 枚举所有子数组，维护滚动 LCM
- 若 LCM 等于 k 则计数，若 LCM 超过 k 则提前终止当前子数组
