## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-cooldown/)

给定一个整数数组`prices`，其中第 `prices[i]` 表示第 `i` 天的股票价格。​

设计一个算法计算出最大利润。在满足以下约束条件下，你可以尽可能地完成更多的交易（多次买卖一支股票）:

- 卖出股票后，你无法在第二天买入股票（即冷冻期为 1 天）。

---

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

---

示例 1：

```txt
输入: prices = [1, 2, 3, 0, 2]
输出: 3
```

解释：对应的交易状态为：`[买入, 卖出, 冷冻期, 买入, 卖出]`

---

示例 2：

```txt
输入: prices = [1]
输出: 0
```

---

提示：

- `1 <= prices.length <= 5000`
- `0 <= prices[i] <= 1000`

## 2. s.1 - 状态机 DP

::: code-group

```c [c]
int maxProfit(int* prices, int pricesSize) {
    if (pricesSize == 0) return 0;
    int hold = -prices[0], sold = 0, rest = 0;
    for (int i = 1; i < pricesSize; i++) {
        int prevSold = sold;
        sold = hold + prices[i];
        hold = hold > rest - prices[i] ? hold : rest - prices[i];
        rest = rest > prevSold ? rest : prevSold;
    }
    return sold > rest ? sold : rest;
}
```

```js [js]
/**
 * @param {number[]} prices
 * @return {number}
 */
var maxProfit = function (prices) {
  const n = prices.length
  if (n === 0) return 0
  let hold = -prices[0],
    sold = 0,
    rest = 0
  for (let i = 1; i < n; i++) {
    const prevSold = sold
    sold = hold + prices[i]
    hold = Math.max(hold, rest - prices[i])
    rest = Math.max(rest, prevSold)
  }
  return Math.max(sold, rest)
}
```

```py [py]
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        if not prices:
            return 0
        hold, sold, rest = -prices[0], 0, 0
        for i in range(1, len(prices)):
            prev_sold = sold
            sold = hold + prices[i]
            hold = max(hold, rest - prices[i])
            rest = max(rest, prev_sold)
        return max(sold, rest)
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是价格数组长度
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 记录每天结束后可能的所有状态下的局部最优解，以此推导出第 n 天的最大收益。
- 每天结束后只有 3 种状态：
    - hold：今天结束后持有股票
    - sold：今天卖出了股票（明天是冷冻期）
    - rest：今天结束后不持有，且明天可以买入
    - sold 只能由 hold 转移，hold 只能由 hold 或 rest 转移，rest 只能由 rest 或 sold 转移
- 初始化：
    - `hold = -prices[0]` 第 0 天买入
    - `sold = 0` 第 0 天不可能卖出，设为 0 不影响
    - `rest = 0` 第 0 天不操作
- `sold = hold + price`
    - 今天变成 sold
    - `hold + price` 必须昨天持有，今天卖出
- `hold = max(hold, rest - price)`
    - 今天变成 hold
    - `hold` 昨天就持有，今天继续持有
    - `rest - price` 昨天是 rest（不持有且可买），今天买入，卖出后下一天必须冷冻，所以只能从 rest 状态买入
- `rest = max(rest, prevSold)`
    - 今天变成 rest
    - `rest` 昨天就是 rest，今天继续休息
    - `prevSold` 昨天是 sold（今天冷冻期，不能买），自然进入 rest
- 最终返回 `max(sold, rest)`，不需要考虑 `hold`，因为最后一天若还持股，一定不是最优解

用示例 1（`prices = [1, 2, 3, 0, 2]`）跑一遍：

| 天 | 价格 | hold | sold | rest |
|---|---|---|---|---|
| 0 | 1 | -1 | 0 | 0 |
| 1 | 2 | -1 | 1 | 0 |
| 2 | 3 | -1 | 2 | 1 |
| 3 | 0 | 1 | -1 | 2 |
| 4 | 2 | 1 | 3 | 2 |

其中 `hold`、`sold`、`rest` 列中，每一个单元格表示这一天结束后保持在这个状态下的最大收益。

第 4 天结束：`max(sold, rest) = max(3, 2) = 3`。

最优方案：第 0 天以 1 买入，第 1 天以 2 卖出（利润 1）；第 2 天冷冻；第 3 天以 0 买入，第 4 天以 2 卖出（利润 2）。总利润 3。
