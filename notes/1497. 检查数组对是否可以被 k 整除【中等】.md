## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/check-if-array-pairs-are-divisible-by-k/)

给你一个整数数组 `arr` 和一个整数 `k`，其中数组长度是偶数，值为 `n`。

现在需要把数组恰好分成 `n / 2` 对，以使每对数字的和都能够被 `k` 整除。

如果存在这样的分法，请返回 `true` ；否则，返回 `false`。

---

示例 1：

```txt
输入：arr = [1,2,3,4,5,10,6,7,8,9], k = 5
输出：true
解释：划分后的数字对为 (1,9),(2,8),(3,7),(4,6) 以及 (5,10)。
```

示例 2：

```txt
输入：arr = [1,2,3,4,5,6], k = 7
输出：true
解释：划分后的数字对为 (1,6),(2,5) 以及 (3,4)。
```

示例 3：

```txt
输入：arr = [1,2,3,4,5,6], k = 10
输出：false
解释：无法在将数组中的数字分为三对的同时满足每对数字和能够被 10 整除的条件。
```

---

提示：

- `arr.length == n`
- `1 <= n <= 10^5`
- `n` 为偶数
- `-10^9 <= arr[i] <= 10^9`
- `1 <= k <= 10^5`

## 2. 🎯 s.1 - 余数计数

::: code-group

```js [js]
/**
 * @param {number[]} arr
 * @param {number} k
 * @return {boolean}
 */
var canArrange = function (arr, k) {
  const cnt = new Array(k).fill(0)
  for (const x of arr) cnt[((x % k) + k) % k]++
  if (cnt[0] % 2 !== 0) return false
  for (let i = 1; i <= k >> 1; i++) {
    if (cnt[i] !== cnt[k - i]) return false
  }
  return true
}
```

```c [c]
bool canArrange(int* arr, int arrSize, int k) {
    int* cnt = (int*)calloc(k, sizeof(int));
    for (int i = 0; i < arrSize; i++)
        cnt[((arr[i] % k) + k) % k]++;
    if (cnt[0] % 2 != 0) { free(cnt); return false; }
    for (int i = 1; i <= k / 2; i++) {
        if (cnt[i] != cnt[k - i]) { free(cnt); return false; }
    }
    free(cnt);
    return true;
}
```

```py [py]
class Solution:
    def canArrange(self, arr: list[int], k: int) -> bool:
        cnt = [0] * k
        for x in arr:
            cnt[x % k] += 1
        if cnt[0] % 2 != 0:
            return False
        for i in range(1, k // 2 + 1):
            if cnt[i] != cnt[k - i]:
                return False
        return True
```

:::

- 时间复杂度：$O(n + k)$，其中 n 是数组长度
- 空间复杂度：$O(k)$，存储余数计数数组

算法思路：

- 统计每个元素对 k 取余的结果的出现次数（负数取余需转正）
- 余数为 0 的元素必须为偶数个
- 余数 i 和 k-i 的元素数量必须相等
