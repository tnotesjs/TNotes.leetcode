## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/the-kth-factor-of-n/)

给你两个正整数 `n` 和 `k`。

如果正整数 `i` 满足 `n % i == 0`，那么我们就说正整数 `i` 是整数 `n` 的因子。

考虑整数 `n` 的所有因子，将它们 升序排列。请你返回第 `k` 个因子。如果 `n` 的因子数少于 `k`，请你返回 `-1`。

---

示例 1：

```txt
输入：n = 12, k = 3
输出：3
解释：因子列表包括 [1, 2, 3, 4, 6, 12]，第 3 个因子是 3。
```

示例 2：

```txt
输入：n = 7, k = 2
输出：7
解释：因子列表包括 [1, 7]，第 2 个因子是 7。
```

示例 3：

```txt
输入：n = 4, k = 4
输出：-1
解释：因子列表包括 [1, 2, 4]，只有 3 个因子，所以我们应该返回 -1。
```

---

提示：

- `1 <= k <= n <= 1000`

进阶：

你可以设计时间复杂度小于 O(n) 的算法来解决此问题吗？

## 2. 🎯 s.1 - 枚举

::: code-group

```js [js]
/**
 * @param {number} n
 * @param {number} k
 * @return {number}
 */
var kthFactor = function (n, k) {
  for (let i = 1; i <= n; i++) {
    if (n % i === 0) {
      if (--k === 0) return i
    }
  }
  return -1
}
```

```c [c]
int kthFactor(int n, int k) {
    for (int i = 1; i <= n; i++) {
        if (n % i == 0) {
            if (--k == 0) return i;
        }
    }
    return -1;
}
```

```py [py]
class Solution:
    def kthFactor(self, n: int, k: int) -> int:
        for i in range(1, n + 1):
            if n % i == 0:
                k -= 1
                if k == 0:
                    return i
        return -1
```

:::

- 时间复杂度：$O(n)$，遍历 1 到 n
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 从 1 到 n 遍历，每找到一个因子就将 k 减 1
- 当 k 减为 0 时返回当前因子
- 遍历结束仍未找到则返回 -1
