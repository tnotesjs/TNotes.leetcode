## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/three-consecutive-odds/)

给你一个整数数组 `arr`，请你判断数组中是否存在连续三个元素都是奇数的情况：如果存在，请返回 `true` ；否则，返回 `false`。

---

示例 1：

```txt
输入：arr = [2,6,4,1]
输出：false
解释：不存在连续三个元素都是奇数的情况。
```

示例 2：

```txt
输入：arr = [1,2,34,3,4,5,7,23,12]
输出：true
解释：存在连续三个元素都是奇数的情况，即 [5,7,23]。
```

---

提示：

- `1 <= arr.length <= 1000`
- `1 <= arr[i] <= 1000`

## 2. 🎯 s.1 - 连续奇数计数

::: code-group

```js [js]
/**
 * @param {number[]} arr
 * @return {boolean}
 */
var threeConsecutiveOdds = function (arr) {
  let cnt = 0

  for (const num of arr) {
    cnt = num % 2 === 1 ? cnt + 1 : 0
    if (cnt === 3) return true
  }

  return false
}
```

:::

- 时间复杂度：$O(N)$，单次遍历统计连续奇数
- 空间复杂度：$O(1)$，只使用常数计数器

算法思路：

- 线性扫描数组，维护当前连续奇数的计数
- 遇偶数清零，否则递增
- 一旦检测到计数达到 3 立刻返回 `true`，否则最终返回 `false`
