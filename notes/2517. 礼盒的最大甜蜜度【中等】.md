## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/maximum-tastiness-of-candy-basket/)

给你一个正整数数组 `price`，其中 `price[i]` 表示第 `i` 类糖果的价格，另给你一个正整数 `k`。

商店组合 `k` 类 不同 糖果打包成礼盒出售。礼盒的 甜蜜度 是礼盒中任意两种糖果 价格 绝对差的最小值。

返回礼盒的 最大 甜蜜度*。*

---

示例 1：

```txt
输入：price = [13,5,1,8,21,2], k = 3
输出：8
解释：选出价格分别为 [13,5,21] 的三类糖果。
礼盒的甜蜜度为 min(|13 - 5|, |13 - 21|, |5 - 21|) = min(8, 8, 16) = 8。
可以证明能够取得的最大甜蜜度就是 8。
```

---

示例 2：

```txt
输入：price = [1,3,1], k = 2
输出：2
解释：选出价格分别为 [1,3] 的两类糖果。
礼盒的甜蜜度为 min(|1 - 3|) = min(2) = 2。
可以证明能够取得的最大甜蜜度就是 2。
```

---

示例 3：

```txt
输入：price = [7,7,7,7], k = 2
输出：0
解释：从现有的糖果中任选两类糖果，甜蜜度都会是 0。
```

---

提示：

- `2 <= k <= price.length <= 10^5`
- `1 <= price[i] <= 10^9`

## 2. 🎯 s.1 - 二分查找

::: code-group

```js [js]
/**
 * @param {number[]} price
 * @param {number} k
 * @return {number}
 */
var maximumTastiness = function (price, k) {
  price.sort((a, b) => a - b)
  let lo = 0,
    hi = price[price.length - 1] - price[0]
  while (lo < hi) {
    const mid = Math.floor((lo + hi + 1) / 2)
    let count = 1,
      prev = price[0]
    for (let i = 1; i < price.length; i++) {
      if (price[i] - prev >= mid) {
        count++
        prev = price[i]
      }
    }
    if (count >= k) lo = mid
    else hi = mid - 1
  }
  return lo
}
```

```c [c]
int cmp(const void *a, const void *b) {
    return *(int *)a - *(int *)b;
}

int maximumTastiness(int* price, int priceSize, int k) {
    qsort(price, priceSize, sizeof(int), cmp);
    int lo = 0, hi = price[priceSize - 1] - price[0];
    while (lo < hi) {
        int mid = lo + (hi - lo + 1) / 2;
        int count = 1, prev = price[0];
        for (int i = 1; i < priceSize; i++) {
            if (price[i] - prev >= mid) {
                count++;
                prev = price[i];
            }
        }
        if (count >= k) lo = mid;
        else hi = mid - 1;
    }
    return lo;
}
```

```py [py]
class Solution:
    def maximumTastiness(self, price: list[int], k: int) -> int:
        price.sort()
        lo, hi = 0, price[-1] - price[0]
        while lo < hi:
            mid = (lo + hi + 1) // 2
            count, prev = 1, price[0]
            for p in price[1:]:
                if p - prev >= mid:
                    count += 1
                    prev = p
            if count >= k:
                lo = mid
            else:
                hi = mid - 1
        return lo
```

:::

- 时间复杂度：$O(n \log n + n \log C)$，其中 $n$ 是数组长度，$C$ 是价格的最大差值
- 空间复杂度：$O(\log n)$，排序的栈空间

算法思路：

- 先将价格数组排序
- 二分答案（最小绝对差 $mid$），贪心检查能否选出 $k$ 个相邻差值 $\geq mid$ 的糖果
- 从左到右扫描，每次距离上一个被选元素 $\geq mid$ 时选中当前元素
