## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/airplane-seat-assignment-probability/)

有 `n` 位乘客即将登机，飞机正好有 `n` 个座位。第一位乘客的票丢了，他随便选了一个座位坐下。

剩下的乘客将会：

- 如果他们自己的座位还空着，就坐到自己的座位上，
- 当他们自己的座位被占用时，随机选择其他座位

第 `n` 位乘客坐在自己的座位上的概率是多少？

---

示例 1：

```txt
输入：n = 1
输出：1.00000
解释：第一个人只会坐在自己的位置上。
```

示例 2：

```txt
输入: n = 2
输出: 0.50000
解释：在第一个人选好座位坐下后，第二个人坐在自己的座位上的概率是 0.5。
```

---

提示：

- `1 <= n <= 10^5`

## 2. 🎯 s.1 - 数学

::: code-group

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var nthPersonGetsNthSeat = function (n) {
  return n === 1 ? 1 : 0.5
}
```

```c [c]
double nthPersonGetsNthSeat(int n) {
    return n == 1 ? 1.0 : 0.5;
}
```

```py [py]
class Solution:
    def nthPersonGetsNthSeat(self, n: int) -> float:
        return 1.0 if n == 1 else 0.5
```

:::

- 时间复杂度：$O(1)$
- 空间复杂度：$O(1)$

算法思路：

- 通过数学归纳可得：当 $n = 1$ 时概率为 1，当 $n \geq 2$ 时概率恒为 0.5
- 证明：第一个人随机坐到自己座位的概率和坐到第 $n$ 个人座位的概率相等，均为 $1/n$，中间情况会产生等价的子问题，最终结果为 0.5
