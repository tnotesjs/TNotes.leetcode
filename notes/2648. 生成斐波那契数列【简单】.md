## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/generate-fibonacci-sequence/)

请你编写一个生成器函数，并返回一个可以生成 斐波那契数列 的生成器对象。

斐波那契数列 的递推公式为 `Xn = Xn-1 + Xn-2`。

这个数列的前几个数字是 `0, 1, 1, 2, 3, 5, 8, 13`。

---

示例 1：

```txt
输入：callCount = 5
输出：[0,1,1,2,3]
解释：
const gen = fibGenerator();
gen.next().value; // 0
gen.next().value; // 1
gen.next().value; // 1
gen.next().value; // 2
gen.next().value; // 3
```

示例 2：

```txt
输入：callCount = 0
输出：[]
解释：gen.next() 永远不会被调用，所以什么也不会输出
```

---

提示：

- `0 <= callCount <= 50`

## 2. 🎯 s.1 - 解法 1

::: code-group

```js [js]
/**
 * @return {Generator<number>}
 */
var fibGenerator = function* () {
  let a = 0,
    b = 1
  while (true) {
    yield a
    ;[a, b] = [b, a + b]
  }
}

/**
 * const gen = fibGenerator();
 * gen.next().value; // 0
 * gen.next().value; // 1
 */
```

:::

- 时间复杂度：$O(1)$
- 空间复杂度：$O(1)$
