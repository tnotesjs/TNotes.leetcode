## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/extra-characters-in-a-string/)

给你一个下标从 0 开始的字符串 `s` 和一个单词字典 `dictionary`。你需要将 `s` 分割成若干个 互不重叠 的子字符串，每个子字符串都在 `dictionary` 中出现过。`s` 中可能会有一些 额外的字符 不在任何子字符串中。

请你采取最优策略分割 `s`，使剩下的字符 最少。

---

示例 1：

```txt
输入：s = "leetscode", dictionary = ["leet","code","leetcode"]
输出：1
解释：将 s 分成两个子字符串：下标从 0 到 3 的 "leet" 和下标从 5 到 8 的 "code"。只有 1 个字符没有使用（下标为 4），所以我们返回 1。
```

示例 2：

```txt
输入：s = "sayhelloworld", dictionary = ["hello","world"]
输出：3
解释：将 s 分成两个子字符串：下标从 3 到 7 的 "hello" 和下标从 8 到 12 的 "world"。下标为 0，1 和 2 的字符没有使用，所以我们返回 3。
```

---

提示：

- `1 <= s.length <= 50`
- `1 <= dictionary.length <= 50`
- `1 <= dictionary[i].length <= 50`
- `dictionary[i]` 和 `s` 只包含小写英文字母。
- `dictionary` 中的单词互不相同。

## 2. 🎯 s.1 - 动态规划

::: code-group

```js [js]
var minExtraChar = function (s, dictionary) {
  const n = s.length
  const set = new Set(dictionary)
  const dp = new Array(n + 1).fill(0)
  for (let i = 1; i <= n; i++) {
    dp[i] = dp[i - 1] + 1
    for (let j = 0; j < i; j++) {
      if (set.has(s.substring(j, i))) {
        dp[i] = Math.min(dp[i], dp[j])
      }
    }
  }
  return dp[n]
}
```

```c [c]
int minExtraChar(char* s, char** dictionary, int dictionarySize) {
    int n = strlen(s);
    int* dp = (int*)calloc(n + 1, sizeof(int));
    for (int i = 1; i <= n; i++) {
        dp[i] = dp[i - 1] + 1;
        for (int k = 0; k < dictionarySize; k++) {
            int len = strlen(dictionary[k]);
            if (i >= len && strncmp(s + i - len, dictionary[k], len) == 0) {
                if (dp[i - len] < dp[i]) dp[i] = dp[i - len];
            }
        }
    }
    int res = dp[n];
    free(dp);
    return res;
}
```

```py [py]
class Solution:
    def minExtraChar(self, s: str, dictionary: list[str]) -> int:
        n = len(s)
        words = set(dictionary)
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            dp[i] = dp[i - 1] + 1
            for j in range(i):
                if s[j:i] in words:
                    dp[i] = min(dp[i], dp[j])
        return dp[n]
```

:::

- 时间复杂度：$O(N^2)$，其中 N 是字符串 s 的长度（N ≤ 50）
- 空间复杂度：$O(N + D \cdot L)$，D 为字典大小，L 为字典单词平均长度

算法思路：

- 定义 `dp[i]` 为前 i 个字符中最少的额外字符数
- 对每个位置 i，默认跳过当前字符：`dp[i] = dp[i-1] + 1`
- 枚举所有可能的子串 `s[j..i]`，若该子串在字典中，则 `dp[i] = min(dp[i], dp[j])`
- 最终返回 `dp[n]`
