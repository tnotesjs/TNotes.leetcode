## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/target-sum/)

给你一个非负整数数组 `nums` 和一个整数 `target`。

向数组中的每个整数前添加 `'+'` 或 `'-'`，然后串联起所有整数，可以构造一个 **表达式** ：

例如，`nums = [2, 1]`，可以在 `2` 之前添加 `'+'`，在 `1` 之前添加 `'-'`，然后串联起来得到表达式 `"+2-1"`。

返回可以通过上述方法构造的、运算结果等于 `target` 的不同 **表达式** 的数目。

---

示例 1：

```txt
输入：nums = [1, 1, 1, 1, 1], target = 3
输出：5
解释：一共有 5 种方法让最终目标和为 3。
-1 + 1 + 1 + 1 + 1 = 3
+1 - 1 + 1 + 1 + 1 = 3
+1 + 1 - 1 + 1 + 1 = 3
+1 + 1 + 1 - 1 + 1 = 3
+1 + 1 + 1 + 1 - 1 = 3
```

---

示例 2：

```txt
输入：nums = [1], target = 1
输出：1
```

---

提示：

- `1 <= nums.length <= 20`
- `0 <= nums[i] <= 1000`
- `0 <= sum(nums[i]) <= 1000`
- `-1000 <= target <= 1000`

## 2. s.1 - 0-1 背包 DP

::: code-group

```c [c]
int findTargetSumWays(int* nums, int numsSize, int target) {
    int total = 0;
    for (int i = 0; i < numsSize; i++) total += nums[i];
    if (total < target || total < -target || (total + target) % 2 != 0) return 0;
    int p = (total + target) / 2;
    int* dp = (int*)calloc(p + 1, sizeof(int));
    dp[0] = 1;
    for (int i = 0; i < numsSize; i++) {
        for (int j = p; j >= nums[i]; j--) {
            dp[j] += dp[j - nums[i]];
        }
    }
    int res = dp[p];
    free(dp);
    return res;
}
```

```js [js]
/**
 * @param {number[]} nums
 * @param {number} target
 * @return {number}
 */
var findTargetSumWays = function (nums, target) {
  const total = nums.reduce((a, b) => a + b, 0)
  if (total < target || total < -target || (total + target) % 2 !== 0) return 0
  const p = (total + target) / 2
  const dp = new Array(p + 1).fill(0)
  dp[0] = 1
  for (const num of nums) {
    for (let j = p; j >= num; j--) {
      dp[j] += dp[j - num]
    }
  }
  return dp[p]
}
```

```py [py]
class Solution:
    def findTargetSumWays(self, nums: List[int], target: int) -> int:
        total = sum(nums)
        if total < target or total < -target or (total + target) % 2 != 0:
            return 0
        p = (total + target) // 2
        dp = [0] * (p + 1)
        dp[0] = 1
        for num in nums:
            for j in range(p, num - 1, -1):
                dp[j] += dp[j - num]
        return dp[p]
```

:::

- 时间复杂度：$O(n \times P)$，每个数都要对容量 $0..P$ 更新一次，其中 $P = (S + target) / 2$，$S$ 为数组元素和
- 空间复杂度：$O(P)$，一维数组记录凑出各容量的方案数

算法思路：

- 设正号数之和为 $P$，负号数之和为 $N$，则 $P + N = S$、$P - N = target$，可得 $P = (S + target) / 2$
- 问题转化为：选出一个和为 $P$ 的子集的方案数
- 若 $S < |target|$，或 $S + target$ 为奇数，则无解
- 0-1 背包计数，$dp[j]$ 表示凑出和 $j$ 的方案数，转移为 $dp[j] = dp[j] + dp[j - nums[i]]$
- 倒序更新，保证每个数只用一次

---

给每个数加正号或负号，相当于把数组分成两部分：正号集合和为 $P$，负号集合和为 $N$。两式联立后，只要子集和恰好为 $P$ 的方案数，就是表达式等于 $target$ 的方案数。

$S < |target|$ 时，即使全部取同一符号也到不了 $target$。$S + target$ 为奇数时，$P$ 不是整数，同样无解。这两条可以先判掉。

用示例 1 走一遍：`nums = [1, 1, 1, 1, 1]`，$target = 3$，$S = 5$，于是 $P = 4$。也就是要从 5 个 $1$ 里选出和为 $4$ 的子集，只有「留下一个 $1$ 不选」这一种形态，共 $5$ 种选法，和题目给出的 5 个表达式一一对应（被放到负号一侧的就是那个没选进子集的 $1$）。

一维 DP 的更新过程是：

- 初始：`[1, 0, 0, 0, 0]`
- 放入第 1 个 `1`：`[1, 1, 0, 0, 0]`
- 放入第 2 个 `1`：`[1, 2, 1, 0, 0]`
- 放入第 3 个 `1`：`[1, 3, 3, 1, 0]`
- 放入第 4 个 `1`：`[1, 4, 6, 4, 1]`
- 放入第 5 个 `1`：`[1, 5, 10, 10, 5]`

最后 $dp[4] = 5$，即答案。倒序更新是为了让当前这个数在一轮里只被用一次，避免完全背包那样重复选取。
