## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/fizz-buzz/)

给你一个整数 `n`，返回一个字符串数组 `answer`（下标从 1 开始），其中：

- `answer[i] == "FizzBuzz"` 如果 `i` 同时是 `3` 和 `5` 的倍数。
- `answer[i] == "Fizz"` 如果 `i` 是 `3` 的倍数。
- `answer[i] == "Buzz"` 如果 `i` 是 `5` 的倍数。
- `answer[i] == i` （以字符串形式）如果上述条件全不满足。

---

示例 1：

```txt
输入：n = 3
输出：["1", "2", "Fizz"]
```

---

示例 2：

```txt
输入：n = 5
输出：["1", "2", "Fizz", "4", "Buzz"]
```

---

示例 3：

```txt
输入：n = 15
输出：[
  "1", "2", "Fizz", "4", "Buzz",
  "Fizz", "7", "8", "Fizz", "Buzz",
  "11", "Fizz", "13", "14", "FizzBuzz"
]
```

---

提示：

- `1 <= n <= 10^4`

## 2. s.1 - 模拟

::: code-group

```c [c]
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
char** fizzBuzz(int n, int* returnSize) {
    *returnSize = n;
    char** ans = malloc(sizeof(char*) * n);

    for (int i = 1; i <= n; ++i) {
        if (i % 3 == 0 && i % 5 == 0) {
            ans[i - 1] = strdup("FizzBuzz");
        } else if (i % 3 == 0) {
            ans[i - 1] = strdup("Fizz");
        } else if (i % 5 == 0) {
            ans[i - 1] = strdup("Buzz");
        } else {
            ans[i - 1] = malloc(12);
            sprintf(ans[i - 1], "%d", i);
        }
    }

    return ans;
}
```

```js [js]
/**
 * @param {number} n
 * @return {string[]}
 */
var fizzBuzz = function (n) {
  const result = []

  for (let i = 1; i <= n; i++) {
    let str = ''
    if (i % 3 === 0) str += 'Fizz'
    if (i % 5 === 0) str += 'Buzz'
    result.push(str || String(i))
  }

  return result
}
```

```py [py]
class Solution:
    def fizzBuzz(self, n: int) -> list[str]:
        ans: list[str] = []
        for i in range(1, n + 1):
            s = ""
            if i % 3 == 0:
                s += "Fizz"
            if i % 5 == 0:
                s += "Buzz"
            ans.append(s or str(i))
        return ans
```

:::

- 时间复杂度：$O(n)$，从 1 扫到 n，每个数常数次判断
- 空间复杂度：$O(1)$，不计返回数组，只用常数额外空间

算法思路：

- 依次处理 $1 \sim n$，按能否被 3、5 整除决定写入内容
- JS / PY：分别拼 `"Fizz"` / `"Buzz"`，两者都整除时自然变成 `"FizzBuzz"`；都不整除则写数字
- C：用 `% 3`、`% 5` 分支（含同时整除）分配对应字符串
