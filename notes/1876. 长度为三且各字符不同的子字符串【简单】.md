## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/substrings-of-size-three-with-distinct-characters/)

如果一个字符串不含有任何重复字符，我们称这个字符串为好字符串。

给你一个字符串 `s`，请你返回 `s` 中长度为 3 的好子字符串的数量。

注意，如果相同的好子字符串出现多次，每一次都应该被记入答案之中。

子字符串是一个字符串中连续的字符序列。

---

示例 1：

```txt
输入：s = "xyzzaz"
输出：1

解释：
总共有 4 个长度为 3 的子字符串："xyz"，"yzz"，"zza" 和 "zaz"。
唯一的长度为 3 的好子字符串是 "xyz"。
```

---

示例 2：

```txt
输入：s = "aababcabc"
输出：4

解释：
总共有 7 个长度为 3 的子字符串："aab"，"aba"，"bab"，"abc"，"bca"，"cab" 和 "abc"。
好子字符串包括 "abc"，"bca"，"cab" 和 "abc"。
```

---

提示：

- `1 <= s.length <= 100`
- `s`​​​​​​ 只包含小写英文字母。

## 2. 🎯 s.1 - 滑动窗口

::: code-group

```js [js]
/**
 * @param {string} s
 * @return {number}
 */
var countGoodSubstrings = function (s) {
  let ans = 0
  for (let i = 0; i + 2 < s.length; i += 1) {
    const a = s[i]
    const b = s[i + 1]
    const c = s[i + 2]
    if (a !== b && a !== c && b !== c) ans += 1
  }
  return ans
}
```

:::

- 时间复杂度：$O(N)$，其中 N 是字符串 s 的长度，需要遍历所有长度为 3 的子串
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 遍历字符串，枚举所有长度为 3 的连续子串
- 对于每个子串，取出三个字符 a、b、c
- 检查三个字符是否两两不同：a ≠ b 且 a ≠ c 且 b ≠ c
- 如果满足条件，计数加 1
