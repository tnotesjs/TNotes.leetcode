## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/verify-preorder-serialization-of-a-binary-tree/)

序列化二叉树的一种方法是使用前序遍历。当我们遇到一个非空节点时，我们可以记录下这个节点的值。如果它是一个空节点，我们可以使用一个标记值记录，例如 `#`。

![](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-09-11-12-05-34.png) {w=244px}

例如，上面的二叉树可以被序列化为字符串 `"9,3,4,#,#,1,#,#,2,#,6,#,#"`，其中 `#` 代表一个空节点。

给定一串以逗号分隔的序列，验证它是否是正确的二叉树的前序序列化。编写一个在不重构树的条件下的可行算法。

保证每个以逗号分隔的字符或为一个整数或为一个表示 `null` 指针的 `'#'`。

你可以认为输入格式总是有效的

- 例如它永远不会包含两个连续的逗号，比如 `"1,,3"`。

---

注意：不允许重建树。

---

示例 1：

```txt
输入: preorder = "9,3,4,#,#,1,#,#,2,#,6,#,#"
输出: true
```

---

示例 2：

```txt
输入: preorder = "1,#"
输出: false
```

---

示例 3：

```txt
输入: preorder = "9,#,#,1"
输出: false
```

---

提示：

- `1 <= preorder.length <= 10^4`
- `preorder` 由以逗号 `“，”` 分隔的 `[0,100]` 范围内的整数和 `“#”` 组成

## 2. s.1 - 槽位计数

::: code-group

```c [c]
bool isValidSerialization(char* preorder) {
    int slots = 1;
    char* token = strtok(preorder, ",");
    while (token) {
        slots--;
        if (slots < 0) return false;
        if (token[0] != '#') slots += 2;
        token = strtok(NULL, ",");
    }
    return slots == 0;
}
```

```js [js]
/**
 * @param {string} preorder
 * @return {boolean}
 */
var isValidSerialization = function (preorder) {
  let slots = 1
  const nodes = preorder.split(',')
  for (const node of nodes) {
    slots--
    if (slots < 0) return false
    if (node !== '#') slots += 2
  }
  return slots === 0
}
```

```py [py]
class Solution:
    def isValidSerialization(self, preorder: str) -> bool:
        slots = 1
        for node in preorder.split(','):
            slots -= 1
            if slots < 0:
                return False
            if node != '#':
                slots += 2
        return slots == 0
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是节点数
- 空间复杂度：$O(1)$

算法思路：

- 初始化槽位为 1（表示遍历开始时的第一个根节点），每个节点消耗 1 个槽位
- 非空节点产生 2 个新槽位，过程中槽位不能为负，最终槽位必须为 0

## 3. 【AI】s.1 - 正确性证明

### 3.1. 必要性：合法序列 ⇒ 算法返回 true

假设 `preorder` 是某棵二叉树 `T` 的前序序列化。我们按前序遍历 `T`，同时维护空位数。

- 初始时，`T` 的根需要一个位置，`slots = 1`。
- 遍历到一个节点：
  - 它占据一个空位，`slots` 减 1。
  - 如果它是内部节点（非 `'#'`），它有两个孩子，因此产生两个新的空位，`slots` 加 2。净效果：`slots` 增加 1。
  - 如果它是叶子节点（`'#'`），它没有孩子，不产生新空位。净效果：`slots` 减少 1。
- 因为 `T` 是一棵合法的二叉树，每个内部节点恰好有两个孩子，每个空位最终都会被某个节点填充。在整个前序遍历过程中，空位数始终等于“尚未被填充的子树位置数”，所以永远不会为负。
- 当遍历完所有节点后，所有空位都被恰好填满，因此 `slots` 最终为 0。

所以算法会顺利遍历完所有节点，不会提前返回 `false`，最后返回 `true`。

### 3.2. 充分性：算法返回 true ⇒ 序列合法

假设算法返回 `true`，即遍历过程中 `slots` 始终 >= 0，且最终 `slots === 0`。我们要证明该序列可以构造出一棵二叉树。

把序列看作前序遍历的顺序。我们用归纳法或构造法说明：

- 初始 `slots = 1`，表示根的位置。
- 每遇到一个非 `'#'` 节点，我们就创建一个内部节点，它需要两个子节点，因此空位数净增加 1（消耗 1 个位置，产生 2 个新位置）。
- 每遇到一个 `'#'`，我们就创建一个空节点，它不产生新位置，空位数净减少 1。
- 由于 `slots` 从未为负，说明每当我们想要创建一个节点时，总有一个空位可供使用，不会出现“无中生有”的节点。
- 最终 `slots === 0`，说明所有产生的空位都被恰好填满，没有多余的空位，也没有未填充的位置。

因此，这个序列恰好对应于一棵完整的二叉树的前序遍历：每个非 `'#'` 节点都有两个子节点（可能是空节点），每个 `'#'` 都是叶子。我们可以按照前序顺序递归地构造这棵树：遇到非 `'#'` 就创建节点，然后递归构造左子树和右子树；遇到 `'#'` 就创建空节点。由于空位平衡，这个过程一定能成功完成，且不会有多余或缺失的节点。

所以序列是合法的二叉树前序序列化。

### 3.3. 边界情况

- 空树：序列为 `"#"`。初始 `slots=1`，遍历 `#`：`slots--` 变为 0，不是非 `'#'` 所以不加，最后 `slots === 0`，返回 `true`。正确。
- 单个非 `'#'` 节点：如 `"1"`。初始 `slots=1`，遍历 `1`：`slots--` 变为 0，然后 `slots += 2` 变为 2，最后 `slots !== 0`，返回 `false`。正确，因为一个内部节点必须有两个孩子。
- 多余节点：如 `"1,#"`。遍历 `1`：`slots` 从 1 变 0 再变 2；遍历 `#`：`slots` 从 2 变 1，最后 `slots=1 ≠ 0`，返回 `false`。正确。

### 3.4. 结论

算法通过维护“空位数量”模拟了二叉树前序遍历中节点的产生与消耗。

- 合法序列必然使空位始终非负且最终归零；  
- 空位始终非负且最终归零也必然对应一棵合法的二叉树。  

因此，该算法正确判断了给定的前序序列化字符串是否为合法的二叉树序列化。
