## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/shuffle-the-array/)

给你一个数组 `nums`，数组中有 `2n` 个元素，按 `[x1,x2,...,xn,y1,y2,...,yn]` 的格式排列。

请你将数组按 `[x1,y1,x2,y2,...,xn,yn]` 格式重新排列，返回重排后的数组。

---

示例 1：

```txt
输入：nums = [2,5,1,3,4,7], n = 3
输出：[2,3,5,4,1,7]

解释：
由于 x1=2, x2=5, x3=1, y1=3, y2=4, y3=7，所以答案为 [2,3,5,4,1,7]
```

---

示例 2：

```txt
输入：nums = [1,2,3,4,4,3,2,1], n = 4
输出：[1,4,2,3,3,2,4,1]
```

---

示例 3：

```txt
输入：nums = [1,1,2,2], n = 2
输出：[1,2,1,2]
```

---

提示：

- `1 <= n <= 500`
- `nums.length == 2n`
- `1 <= nums[i] <= 10^3`

## 2. 🎯 s.1 - 交替重排

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @param {number} n
 * @return {number[]}
 */
var shuffle = function (nums, n) {
  const res = new Array(nums.length)
  let idx = 0
  for (let i = 0; i < n; i++) {
    res[idx++] = nums[i]
    res[idx++] = nums[i + n]
  }
  return res
}
```

:::

- 时间复杂度：$O(n)$，单次遍历前半部分
- 空间复杂度：$O(n)$，结果数组

算法思路：

- 结果长度为 `2n`，依次放入 `x1,y1,x2,y2,...`
- 用一个写指针交替写入 `nums[i]` 与 `nums[i+n]`
