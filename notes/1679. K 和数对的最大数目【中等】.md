## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/max-number-of-k-sum-pairs/)

给你一个整数数组 `nums` 和一个整数 `k`。

每一步操作中，你需要从数组中选出和为 `k` 的两个整数，并将它们移出数组。

返回你可以对数组执行的最大操作数。

---

示例 1：

```txt
输入：nums = [1,2,3,4], k = 5
输出：2
解释：开始时 nums = [1,2,3,4]：
- 移出 1 和 4，之后 nums = [2,3]
- 移出 2 和 3，之后 nums = []
不再有和为 5 的数对，因此最多执行 2 次操作。
```

示例 2：

```txt
输入：nums = [3,1,3,4,3], k = 6
输出：1
解释：开始时 nums = [3,1,3,4,3]：
- 移出前两个 3，之后nums = [1,4,3]
不再有和为 6 的数对，因此最多执行 1 次操作。
```

---

提示：

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 2. 🎯 s.1 - 哈希表

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var maxOperations = function (nums, k) {
  const map = new Map()
  let res = 0
  for (const x of nums) {
    const need = k - x
    if (map.get(need) > 0) {
      res++
      map.set(need, map.get(need) - 1)
    } else {
      map.set(x, (map.get(x) || 0) + 1)
    }
  }
  return res
}
```

```c [c]
#include <stdlib.h>

int cmp1679(const void* a, const void* b) { return *(int*)a - *(int*)b; }

int maxOperations(int* nums, int numsSize, int k) {
    qsort(nums, numsSize, sizeof(int), cmp1679);
    int l = 0, r = numsSize - 1, res = 0;
    while (l < r) {
        int s = nums[l] + nums[r];
        if (s == k) { res++; l++; r--; }
        else if (s < k) l++;
        else r--;
    }
    return res;
}
```

```py [py]
class Solution:
    def maxOperations(self, nums: list[int], k: int) -> int:
        from collections import Counter
        count = Counter(nums)
        res = 0
        for x in list(count.keys()):
            need = k - x
            if need == x:
                res += count[x] // 2
                count[x] = count[x] % 2
            elif need in count:
                pairs = min(count[x], count[need])
                res += pairs
                count[x] -= pairs
                count[need] -= pairs
        return res
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是数组长度
- 空间复杂度：$O(n)$，哈希表

算法思路：

- 遍历数组，对每个元素 x 检查哈希表中 k - x 的计数
- 若 k - x 存在，则配对成功，计数加 1，并将 k - x 的计数减 1
- 否则将 x 的计数加 1 存入哈希表
