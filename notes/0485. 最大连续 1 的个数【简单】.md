## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/max-consecutive-ones/)

给定一个二进制数组 `nums`， 计算其中最大连续 `1` 的个数。

---

示例 1：

```
输入：nums = [1, 1, 0, 1, 1, 1]
输出：3
解释：开头的两位和最后的三位都是连续 1，所以最大连续 1 的个数是 3。
```

---

示例 2：

```txt
输入：nums = [1, 0, 1, 1, 0, 1]
输出：2
```

---

提示：

- `1 <= nums.length <= 10^5`
- `nums[i]` 不是 `0` 就是 `1`

## 2. s.1 - 一次遍历

::: code-group

```c [c]
int findMaxConsecutiveOnes(int* nums, int numsSize) {
    int maxCount = 0;
    int count = 0;

    for (int i = 0; i < numsSize; ++i) {
        if (nums[i] == 1) {
            ++count;
            if (count > maxCount) {
                maxCount = count;
            }
        } else {
            count = 0;
        }
    }

    return maxCount;
}
```

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var findMaxConsecutiveOnes = function (nums) {
  let maxCount = 0
  let count = 0

  for (const num of nums) {
    if (num === 1) {
      count++
      if (count > maxCount) maxCount = count
    } else {
      count = 0
    }
  }

  return maxCount
}
```

```py [py]
class Solution:
    def findMaxConsecutiveOnes(self, nums: list[int]) -> int:
        max_count = 0
        count = 0

        for num in nums:
            if num == 1:
                count += 1
                if count > max_count:
                    max_count = count
            else:
                count = 0

        return max_count
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 为数组长度，需要遍历一遍数组
- 空间复杂度：$O(1)$，只用常数额外空间

算法思路：

- 设数组长度为 $n$。用一个计数器记录当前这段连续 $1$ 的长度，再用一个变量记录出现过的最大值
- 遇到 $1$ 就将计数器加 $1$，并尝试更新最大值；遇到 $0$ 则将计数器置 $0$
- 遍历结束后，记录的最大值即为最大连续 $1$ 的个数
