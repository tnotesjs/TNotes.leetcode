## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/longest-subarray-of-1s-after-deleting-one-element/)

给你一个二进制数组 `nums`，你需要从中删掉一个元素。

请你在删掉元素的结果数组中，返回最长的且只包含 1 的非空子数组的长度。

如果不存在这样的子数组，请返回 0。

- 提示 1：

```txt
输入：nums = [1,1,0,1]
输出：3
解释：删掉位置 2 的数后，[1,1,1] 包含 3 个 1。
```

示例 2：

```txt
输入：nums = [0,1,1,1,0,1,1,0,1]
输出：5
解释：删掉位置 4 的数字后，[0,1,1,1,1,1,0,1] 的最长全 1 子数组为 [1,1,1,1,1]。
```

示例 3：

```txt
输入：nums = [1,1,1]
输出：2
解释：你必须要删除一个元素。
```

---

提示：

- `1 <= nums.length <= 10^5`
- `nums[i]` 要么是 `0` 要么是 `1`。

## 2. 🎯 s.1 - 滑动窗口

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var longestSubarray = function (nums) {
  let left = 0,
    zeros = 0,
    res = 0
  for (let right = 0; right < nums.length; right++) {
    if (nums[right] === 0) zeros++
    while (zeros > 1) {
      if (nums[left] === 0) zeros--
      left++
    }
    // 窗口内最多 1 个 0，删除那个 0 后长度为 right - left
    res = Math.max(res, right - left)
  }
  return res
}
```

```c [c]
int longestSubarray(int* nums, int numsSize) {
    int left = 0, zeros = 0, res = 0;
    for (int right = 0; right < numsSize; right++) {
        if (nums[right] == 0) zeros++;
        while (zeros > 1) {
            if (nums[left] == 0) zeros--;
            left++;
        }
        int len = right - left;
        if (len > res) res = len;
    }
    return res;
}
```

```py [py]
class Solution:
    def longestSubarray(self, nums: list[int]) -> int:
        left = zeros = res = 0
        for right in range(len(nums)):
            if nums[right] == 0:
                zeros += 1
            while zeros > 1:
                if nums[left] == 0:
                    zeros -= 1
                left += 1
            res = max(res, right - left)
        return res
```

:::

- 时间复杂度：$O(n)$，其中 n 是数组长度
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 维护一个最多包含 1 个 0 的滑动窗口
- 当窗口内 0 超过 1 个时，缩小左边界
- 窗口长度 - 1 即为删除那个 0 后的全 1 子数组长度
