## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/n-ary-tree-preorder-traversal/)

给定一个 n 叉树的根节点 `root`，返回 其节点值的 前序遍历。

n 叉树 在输入中按层序遍历进行序列化表示，每组子节点由空值 `null` 分隔（请参见示例）。

---

示例 1：

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-09-21-22-27-30.png)

```txt
输入：root = [1,null,3,2,4,null,5,6]
输出：[1,3,5,6,2,4]
```

示例 2：

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-09-21-22-27-36.png)

```txt
输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出：[1,2,3,6,7,11,14,4,8,12,5,9,13,10]
```

---

提示：

- 节点总数在范围 `[0, 10^4]`内
- `0 <= Node.val <= 10^4`
- n 叉树的高度小于或等于 `1000`

进阶：递归法很简单，你可以使用迭代法完成此题吗?

## 2. 🎯 s.1 - 递归法

::: code-group

```js [js]
/**
 * // Definition for a _Node.
 * function _Node(val, children) {
 *    this.val = val;
 *    this.children = children;
 * };
 */

/**
 * @param {_Node|null} root
 * @return {number[]}
 */
var preorder = function (root) {
  const result = []

  function traverse(node) {
    if (!node) return

    // 访问当前节点
    result.push(node.val)

    // 递归访问每个子节点
    if (node.children) {
      for (let child of node.children) {
        traverse(child)
      }
    }
  }

  traverse(root)
  return result
}
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是 N 叉树的节点数，需要访问每个节点一次
- 空间复杂度：$O(h)$，其中 $h$ 是 N 叉树的高度，主要是递归调用栈的空间消耗，最坏情况下为 $O(n)$

## 3. 🎯 s.2 - 迭代法

::: code-group

```js [js]
/**
 * // Definition for a _Node.
 * function _Node(val, children) {
 *    this.val = val;
 *    this.children = children;
 * };
 */

/**
 * @param {_Node|null} root
 * @return {number[]}
 */
var preorder = function (root) {
  if (!root) return []

  const result = []
  const stack = [root]

  while (stack.length > 0) {
    const node = stack.pop()
    result.push(node.val)

    // 将子节点从右到左入栈，以保证从左到右的访问顺序
    if (node.children) {
      for (let i = node.children.length - 1; i >= 0; i--) {
        stack.push(node.children[i])
      }
    }
  }

  return result
}
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是 N 叉树的节点数，需要访问每个节点一次
- 空间复杂度：$O(n)$，最坏情况下栈中需要存储所有节点，例如当树退化为链表时
