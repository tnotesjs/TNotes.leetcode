## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/maximum-containers-on-a-ship/)

给你一个正整数 `n`，表示船上的一个 `n x n` 的货物甲板。甲板上的每个单元格可以装载一个重量 恰好 为 `w` 的集装箱。

然而，如果将所有集装箱装载到甲板上，其总重量不能超过船的最大承载重量 `maxWeight`。

请返回可以装载到船上的 最大 集装箱数量。

---

示例 1：

```txt
输入：n = 2, w = 3, maxWeight = 15
输出：4
```

解释：

甲板有 4 个单元格，每个集装箱的重量为 3。将所有集装箱装载后，总重量为 12，未超过 `maxWeight`。

---

示例 2：

```txt
输入：n = 3, w = 5, maxWeight = 20
输出：4
```

解释：

甲板有 9 个单元格，每个集装箱的重量为 5。可以装载的最大集装箱数量为 4，此时总重量不超过 `maxWeight`。

---

提示：

- `1 <= n <= 1000`
- `1 <= w <= 1000`
- `1 <= maxWeight <= 10^9`

## 2. 🎯 s.1 - 数学

::: code-group

```js [js]
/**
 * @param {number} n
 * @param {number} w
 * @param {number} maxWeight
 * @return {number}
 */
var maxContainers = function (n, w, maxWeight) {
  // 甲板最多放 n * n 个集装箱
  const capacity = n * n
  // 按重量限制最多能放 maxWeight / w 个
  const byWeight = Math.floor(maxWeight / w)
  // 取两者的最小值
  return Math.min(capacity, byWeight)
}
```

:::

- 时间复杂度：$O(1)$，只需常数次运算
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：

- 集装箱数量受两个因素限制：甲板容量和重量限制
- 甲板容量：最多放 `n × n` 个集装箱
- 重量限制：最多放 `⌊maxWeight / w⌋` 个集装箱
- 答案是两者的最小值
