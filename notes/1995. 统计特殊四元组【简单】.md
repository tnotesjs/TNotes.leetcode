## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/count-special-quadruplets/)

给你一个 下标从 0 开始 的整数数组 `nums`，返回满足下述条件的 不同 四元组 `(a, b, c, d)` 的 数目 ：

- `nums[a] + nums[b] + nums[c] == nums[d]`，且
- `a < b < c < d`

---

示例 1：

```txt
输入：nums = [1,2,3,6]
输出：1

解释：
满足要求的唯一一个四元组是 (0, 1, 2, 3) 因为 1 + 2 + 3 == 6。
```

---

示例 2：

```txt
输入：nums = [3,3,6,4,5]
输出：0

解释：
[3,3,6,4,5] 中不存在满足要求的四元组。
```

---

示例 3：

```txt
输入：nums = [1,1,1,3,5]
输出：4

解释：
满足要求的 4 个四元组如下：
- (0, 1, 2, 3): 1 + 1 + 1 == 3
- (0, 1, 3, 4): 1 + 1 + 3 == 5
- (0, 2, 3, 4): 1 + 1 + 3 == 5
- (1, 2, 3, 4): 1 + 1 + 3 == 5
```

---

提示：

- `4 <= nums.length <= 50`
- `1 <= nums[i] <= 100`

## 2. 🎯 s.1 - 后缀计数三重循环

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var countQuadruplets = function (nums) {
  const n = nums.length
  let ans = 0

  // 用于存储数字 d 及其出现次数的哈希表
  const freq = new Map()

  // 从后往前遍历 c 的位置
  // c 至少为 2，因为 a,b 需要在其前面插入
  for (let c = n - 2; c >= 2; c -= 1) {
    // 将当前 d 值（即 c 位置后一位）加入频率映射
    const dVal = nums[c + 1]
    freq.set(dVal, (freq.get(dVal) || 0) + 1)

    // 枚举所有可能的 3 元组 (a, b, c)
    for (let a = 0; a < c; a += 1) {
      for (let b = a + 1; b < c; b += 1) {
        // 检查是否存在一个 d 值（nums[c+1] 之后的位置）使得 sum = d
        const sum = nums[a] + nums[b] + nums[c]
        ans += freq.get(sum) || 0
      }
    }
  }

  return ans
}
```

:::

- 时间复杂度：$O(N^3)$，其中 N 是数组长度，外层枚举 c 需要 $O(N)$，内层双重循环枚举 a 和 b 需要 $O(N^2)$
- 空间复杂度：$O(N)$，哈希表最多存储 N 个不同的元素值

算法思路：

题目要求统计满足 `nums[a] + nums[b] + nums[c] == nums[d]` 且 `a < b < c < d` 的四元组数量。

- 倒序枚举 c 的位置（从 n-2 到 2），确保 c 后面有空间存放 d
  - d 只需要扫描 `[3, n-1]` 区域即可，d 可能的最小值是 3，因为需要保证 a < b < c < d，最小的四元组只可能是 `(0, 1, 2, 3)`
- 对于每个 c，先将 `nums[c+1]` 加入哈希表 freq 中，记录 c 右侧所有可用的 d 值及其出现次数
- 枚举 c 之前的所有 (a, b) 组合，其中 a < b < c，并计算 `sum = nums[a] + nums[b] + nums[c]`
- 查询哈希表中是否存在等于 sum 的 d 值，将哈希表中 sum 对应的出现次数累加到答案中

该解法通过倒序遍历 c 并动态维护哈希表，避免了四重循环，将时间复杂度从 $O(N^4)$ 优化到 $O(N^3)$。
