## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/n-th-tribonacci-number/)

泰波那契序列 Tn 定义如下：

T0 = 0, T1 = 1, T2 = 1, 且在 n >= 0 的条件下 Tn+3 = Tn + Tn+1 + Tn+2

给你整数 `n`，请返回第 n 个泰波那契数 Tn 的值。

---

示例 1：

```txt
输入：n = 4
输出：4

解释：
T_3 = 0 + 1 + 1 = 2
T_4 = 1 + 1 + 2 = 4
```

---

示例 2：

```txt
输入：n = 25
输出：1389537
```

---

提示：

- `0 <= n <= 37`
- 答案保证是一个 32 位整数，即 `answer <= 2^31 - 1`。

## 2. 🎯 s.1 - 动态规划

::: code-group

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var tribonacci = function (n) {
  // 处理基础情况
  if (n === 0) return 0
  if (n === 1 || n === 2) return 1

  // 使用滚动数组优化空间复杂度
  let t_0 = 0 // T(0) -> Tn
  let t_1 = 1 // T(1) -> Tn+1
  let t_2 = 1 // T(2) -> Tn+2

  // 滚动计算 - 从第 3 项开始计算到第 n 项
  for (let i = 3; i <= n; i++) {
    const next = t_0 + t_1 + t_2
    t_0 = t_1
    t_1 = t_2
    t_2 = next
  }

  return t_2
}

// 另一种写法：
/* 
var tribonacci = function (n) {
  if (n === 0) return 0
  if (n === 1 || n === 2) return 1

  const dp = new Array(n + 1)
  dp[0] = 0
  dp[1] = 1
  dp[2] = 1

  for (let i = 3; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2] + dp[i - 3]
  }

  return dp[n]
}
 */
```

:::

- 时间复杂度：$O(n)$，需要计算从第 3 项到第 n 项
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：使用动态规划的思想，但通过滚动数组优化空间

- 基础情况：直接返回 T(0) = 0, T(1) = T(2) = 1
- 滚动计算：使用三个变量保存前三项的值
- 迭代更新：每次计算新值后，更新三个变量的值

## 3. 🎯 s.2 - 递归解法

::: code-group

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var tribonacci = function (n) {
  const memo = {}

  function helper(n) {
    if (n === 0) return 0
    if (n === 1 || n === 2) return 1
    if (memo[n] !== undefined) return memo[n]

    memo[n] = helper(n - 1) + helper(n - 2) + helper(n - 3)
    return memo[n]
  }

  return helper(n)
}

// 暴力递归：
// 注意：解法正确，但效率较低，提交后无法通过，会提示超时。
/*

  if (n === 0) return 0
  if (n === 1 || n === 2) return 1
  return tribonacci(n - 1) + tribonacci(n - 2) + tribonacci(n - 3)
}
*/
```

:::

- 时间复杂度：$O(n)$，每个项仅计算一次
- 空间复杂度：$O(n)$，备忘录与递归栈占用的空间

算法思路：

- 使用递归结合备忘录来避免重复计算
- 设置 base case 为 $n=0, 1, 2$ 时的情况
- 递归计算前三项之和并存入备忘录，实现自顶向下的求解过程
