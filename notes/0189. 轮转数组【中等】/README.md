## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/rotate-array/)

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

---

示例 1：

```
输入：nums = [1, 2, 3, 4, 5, 6, 7], k = 3
输出：[5, 6, 7, 1, 2, 3, 4]
```

解释:

- 向右轮转 1 步：`[7, 1, 2, 3, 4, 5, 6]`
- 向右轮转 2 步：`[6, 7, 1, 2, 3, 4, 5]`
- 向右轮转 3 步：`[5, 6, 7, 1, 2, 3, 4]`

---

示例 2：

```
输入：nums = [-1, -100, 3, 99], k = 2
输出：[3, 99, -1, -100]
```

解释:

- 向右轮转 1 步：`[99, -1, -100, 3]`
- 向右轮转 2 步：`[3, 99, -1, -100]`

---

提示：

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

---

进阶：

- 尽可能想出更多的解决方案，至少有三种不同的方法可以解决这个问题。
- 你可以使用空间复杂度为 `O(1)` 的原地算法解决这个问题吗？

- 示例：$[1, 2, 3, 4, 5, 6, 7]$，$k=3$

  - 【2】前 3 反转得 $[5, 6, 7, 4, 3, 2, 1]$
  - 【3】后半反转得 $[5, 6, 7, 1, 2, 3, 4]$

::: code-group

<<< ./solutions/2/1.js [js]

<<< ./solutions/2/1.py [py]

:::

- 时间复杂度：$O(n)$，其中 $n$ 是数组长度，每个元素恰好被移动一次
- 空间复杂度：$O(1)$，只用常数变量跟踪环上的交换

算法思路：

- 下标 $i$ 的元素最终应落到 $(i + k) \bmod n$
- 从某个起点出发，沿「当前位置 → 目标位置」形成环，用临时变量把环上元素依次放到正确位置，直到回到起点
  - 内层循环跑一次：将当前位置的成员放置到目标位置
  - 外层循环跑一次：处理下一个环
- 共有 $\gcd(k, n)$ 个互不相交的环；处理完所有环后，整个数组即完成轮转

## 5. 【AI】以示例 1 为例，解释一下 s.2 的详细流程

以示例 1 为准：`nums = [1, 2, 3, 4, 5, 6, 7]`，`k = 3`，`n = 7`。

目标位置规则：下标 `i` → `(i + 3) % 7`。

$\gcd(3, 7) = 1$，所以**只有 1 个环**，会串起全部 7 个元素。

---

### 5.1. 环长什么样

```text
0 → 3 → 6 → 2 → 5 → 1 → 4 → 0
```

对应值的迁移动线：

```text
1 → 4 的位置
4 → 7 的位置
7 → 3 的位置
3 → 6 的位置
6 → 2 的位置
2 → 5 的位置
5 → 1 的位置（回到起点，环结束）
```


### 5.2. 逐步模拟（`start = 0`）

初始：`[1, 2, 3, 4, 5, 6, 7]`  
`prev = 1`（手里拎着起点的值），`current = 0`

| 步 | current → next | 动作 | 数组状态 | prev 变成 |
|----|-----------------|------|----------|-----------|
| 1 | 0 → 3 | 把 1 放进下标 3，原 4 被顶出 | `[1, 2, 3, **1**, 5, 6, 7]` | 4 |
| 2 | 3 → 6 | 把 4 放进下标 6，原 7 被顶出 | `[1, 2, 3, 1, 5, 6, **4**]` | 7 |
| 3 | 6 → 2 | 把 7 放进下标 2，原 3 被顶出 | `[1, 2, **7**, 1, 5, 6, 4]` | 3 |
| 4 | 2 → 5 | 把 3 放进下标 5，原 6 被顶出 | `[1, 2, 7, 1, 5, **3**, 4]` | 6 |
| 5 | 5 → 1 | 把 6 放进下标 1，原 2 被顶出 | `[1, **6**, 7, 1, 5, 3, 4]` | 2 |
| 6 | 1 → 4 | 把 2 放进下标 4，原 5 被顶出 | `[1, 6, 7, 1, **2**, 3, 4]` | 5 |
| 7 | 4 → 0 | 把 5 放进下标 0，原 1 被顶出 | `[**5**, 6, 7, 1, 2, 3, 4]` | 1 |

此时 `current === start === 0`，环闭合。`count = 7 === n`，外层结束。

结果：`[5, 6, 7, 1, 2, 3, 4]`，与示例一致。


### 5.3. 和代码的对应关系

```js
do {
  const next = (current + k) % n
  const temp = nums[next]
  nums[next] = prev
  prev = temp
  current = next
  count++
} while (current !== start)
```

- `prev`：手里正要放进 `next` 的值  
- `temp`：目标格里原来的值，下一轮继续往后传  
- `count`：已放好的元素个数；达到 `n` 就说明所有环都处理完  

本题只有一个环，所以 `start` 只会从 `0` 走一轮。若 `k` 与 `n` 不互质（例如 `n=6, k=2`），会有多个环，外层 `start = 0, 1, …` 各开一条新环。

## 6. 【AI】gcd 是什么？

**gcd** = Greatest Common Divisor，**最大公约数**：能同时整除两个数的最大正整数。

例如：

- $\gcd(3, 7) = 1$（3 和 7 互质）  
- $\gcd(2, 6) = 2$  
- $\gcd(4, 6) = 2$  


### 6.1. 和轮转有什么关系？

右移 $k$ 位时，下标走的是：

$$
i \;\to\; (i+k) \bmod n \;\to\; (i+2k) \bmod n \;\to\; \cdots
$$

这条路什么时候绕回 `i`？当某个倍数 $m\cdot k$ 是 $n$ 的倍数，即 $n$ 整除 $m\cdot k$。最小的这种 $m$ 就是环的长度：

$$
\text{每个环的长度} = \dfrac{n}{\gcd(k, n)}
$$

环的个数则是：

$$
\text{环的个数} = \gcd(k, n)
$$

（因为总共 $n$ 个元素，每个环长 $\dfrac{n}{\gcd}$，所以环数 = $\gcd$。）


### 6.2. 用例子感受

**示例 1：** $n=7$，$k=3$，$\gcd(3,7)=1$

- 只有 **1** 个环  
- 环长 $7/1 = 7$，一次走完所有下标：  
  `0→3→6→2→5→1→4→0`

**若** $n=6$，$k=2$，$\gcd(2,6)=2$

- 有 **2** 个环，每个长 $6/2=3$  
  - 环 0：`0→2→4→0`  
  - 环 1：`1→3→5→1`  

所以外层要从 `start = 0` 再开 `start = 1`，两个环都处理完才行。


### 6.3. 代码里为什么还要提 gcd？

实现里**不必先算 gcd**：用 `count` 数「已经放好的元素」，达到 `n` 就停；每处理完一个环，`start++` 开下一环。

笔记里写 $\gcd(k,n)$，只是在说明：**理论上会有多少条互不相交的环**，帮助理解「为什么有时一个环走完全部，有时要开好几条」。不理解 gcd 公式，只要记住「沿 `(i+k)%n` 走，走回起点再换下一个还没动过的起点」也能写对。
