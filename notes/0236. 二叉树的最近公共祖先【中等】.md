## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

[百度百科][1] 中最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。”

---

```txt
输入：root = [3, 5, 1, 6, 2, 0, 8, null, null, 7, 4], p = 5, q = 1
输出：3
```

解释：节点 5 和节点 1 的最近公共祖先是节点 3。

```txt
输出：5
```

解释：节点 5 和节点 4 的最近公共祖先是节点 5。因为根据定义最近公共祖先节点可以为节点本身。

```txt

```

提示：

- 树中节点数目在范围 `[2, 10^5]` 内。
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` `互不相同`。
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中。

## 2. s.1 - 递归

::: code-group

```c [c]
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     struct TreeNode *left;
 *     struct TreeNode *right;
 * };
 */
struct TreeNode* lowestCommonAncestor(struct TreeNode* root, struct TreeNode* p, struct TreeNode* q) {
    if (!root || root == p || root == q) return root;
    struct TreeNode* left = lowestCommonAncestor(root->left, p, q);
    struct TreeNode* right = lowestCommonAncestor(root->right, p, q);
    if (left && right) return root;
    return left ? left : right;
}
```

```js [js]
/**
 * Definition for a binary tree node.
 * function TreeNode(val) {
 *     this.val = val;
 *     this.left = this.right = null;
 * }
 */
/**
 * @param {TreeNode} root
 * @param {TreeNode} p
 * @param {TreeNode} q
 * @return {TreeNode}
 */
var lowestCommonAncestor = function (root, p, q) {
  if (!root || root === p || root === q) return root
  const left = lowestCommonAncestor(root.left, p, q)
  const right = lowestCommonAncestor(root.right, p, q)
  if (left && right) return root
  return left || right
}
```

```py [py]
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        if not root or root == p or root == q:
            return root
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        if left and right:
            return root
        return left or right
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是节点数
- 空间复杂度：$O(n)$，最坏递归栈深度

算法思路：

- 后序遍历：若当前节点为 null 或等于 p/q，直接返回
- 递归左右子树，若左右都找到则当前节点为 LCA
- 否则返回非空的一侧

## 3. 【AI】s.1 解释

这段代码是 **LeetCode 236. 二叉树的最近公共祖先（LCA）** 的经典递归解法。它适用于**普通二叉树**（不要求是 BST），通过后序遍历自底向上寻找答案。

### 3.1. 核心思想

从根节点开始递归搜索 `p` 和 `q`：

- 如果当前节点是 `null`，返回 `null`；
- 如果当前节点就是 `p` 或 `q`，直接返回当前节点；
- 否则分别去左子树和右子树找，得到 `left` 和 `right`；
- 如果 `left` 和 `right` 都不为空，说明 `p`、`q` 分别在左右两侧，当前节点就是 LCA；
- 如果只有一个不为空，说明两个目标都在同一侧，或者只找到了其中一个，就把找到的那个向上返回。

### 3.2. 逐行解释

```js
var lowestCommonAncestor = function (root, p, q) {
  // 递归终止条件：
  // 1. 走到空节点，返回 null
  // 2. 当前节点就是 p 或 q，返回当前节点
  if (!root || root === p || root === q) return root

  // 后序遍历：先去左右子树找
  const left = lowestCommonAncestor(root.left, p, q)
  const right = lowestCommonAncestor(root.right, p, q)

  // 左右都找到了，说明 p 和 q 分布在当前节点的两侧
  // 当前节点就是最近公共祖先
  if (left && right) return root

  // 否则返回非空的那一边：
  // - 左边找到就返回左边
  // - 右边找到就返回右边
  // - 都没找到就返回 null
  return left || right
}
```

### 3.3. 为什么 `root === p || root === q` 可以直接返回？

因为题目保证 `p` 和 `q` 都存在于树中。

- 如果当前节点是 `p`，而 `q` 在它的子树里，那么 `p` 就是 LCA；
- 如果 `q` 不在它的子树里，那么当前节点只是“找到了其中一个”，需要把这个结果向上传递，让更高层的祖先去和另一边的 `q` 汇合。

所以遇到 `p` 或 `q` 时不需要继续往下搜，直接返回即可。

### 3.4. 执行过程举例

假设树：

```
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4
```

#### 例子 1：`p = 5, q = 1`

- 根节点 `3`：
  - 左子树返回 `5`
  - 右子树返回 `1`
  - `left && right` 成立 → 返回 `3`

LCA = `3` ✅

#### 例子 2：`p = 5, q = 4`

- 根节点 `3`：
  - 左子树递归到 `5`，因为 `root === p`，直接返回 `5`
  - 右子树返回 `null`
  - `left = 5`，`right = null`
  - 返回 `left || right` → 返回 `5`

LCA = `5` ✅  
因为 `4` 在 `5` 的子树里，`5` 本身就是 `4` 的祖先。

#### 例子 3：`p = 6, q = 4`

- 节点 `5`：
  - 左子树找到 `6`
  - 右子树找到 `4`
  - 左右都不为空 → 返回 `5`

LCA = `5` ✅

### 3.5. 复杂度分析

- **时间复杂度：O(n)**  
  最坏情况下每个节点访问一次，`n` 是节点总数。

- **空间复杂度：O(h)**  
  `h` 是树的高度。递归调用栈的深度取决于树高。  
  最坏情况树退化成链表，`h = n`，空间 O(n)；平衡树 `h = log n`，空间 O(log n)。

### 3.6. 与 BST 版本的对比

| | BST 版本 | 普通二叉树版本 |
|---|---|---|
| 适用树 | 二叉搜索树 | 任意二叉树 |
| 方法 | 利用大小关系，一路向下 | 递归后序遍历，自底向上 |
| 时间 | O(h) | O(n) |
| 空间 | O(1) | O(h) |
| 关键判断 | `p.val`、`q.val` 与当前值比较 | 左右子树是否都找到目标 |

### 3.7. 注意点

1. **比较的是节点引用，不是值**：`root === p`，不是 `root.val === p.val`。
2. **题目默认 `p`、`q` 一定在树中**。如果可能不存在，这个写法需要额外判断。
3. **`return left || right`** 只在 `left` 和 `right` 不同时非空时执行；如果两个都为空，返回 `null`。
