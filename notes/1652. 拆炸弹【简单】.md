## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/defuse-the-bomb/)

你有一个炸弹需要拆除，时间紧迫！你的情报员会给你一个长度为 `n` 的循环数组 `code` 以及一个密钥 `k`。

为了获得正确的密码，你需要替换掉每一个数字。所有数字会同时被替换。

- 如果 `k > 0`，将第 `i` 个数字用接下来 `k` 个数字之和替换。
- 如果 `k < 0`，将第 `i` 个数字用之前 `k` 个数字之和替换。
- 如果 `k == 0`，将第 `i` 个数字用 `0` 替换。

由于 `code` 是循环的，`code[n-1]` 下一个元素是 `code[0]`，且 `code[0]` 前一个元素是 `code[n-1]`。

给你循环数组 `code` 和整数密钥 `k`，请你返回解密后的结果来拆除炸弹！

---

示例 1：

```txt
输入：code = [5,7,1,4], k = 3
输出：[12,10,16,13]
```

解释：

- 每个数字都被接下来 3 个数字之和替换。
- 解密后的密码为 `[7+1+4, 1+4+5, 4+5+7, 5+7+1]`。
- 注意到数组是循环连接的。

---

示例 2：

```txt
输入：code = [1,2,3,4], k = 0
输出：[0,0,0,0]
```

解释：当 k 为 0 时，所有数字都被 0 替换。

---

示例 3：

```txt
输入：code = [2,4,9,3], k = -2
输出：[12,5,6,13]
```

解释：

- 解密后的密码为 `[3+9, 2+3, 4+2, 9+4]`。
- 注意到数组是循环连接的。如果 k 是负数，那么和为之前的数字。

---

提示：

- `n == code.length`
- `1 <= n <= 100`
- `1 <= code[i] <= 100`
- `-(n - 1) <= k <= n - 1`

## 2. 🎯 s.1 - 滑动窗口

::: code-group

```c [c]
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int* decrypt(int* code, int codeSize, int k, int* returnSize) {
    int n = codeSize;
    *returnSize = n;
    int* res = (int*)calloc(n, sizeof(int));
    if (k == 0) return res;

    // arr = code + code (模拟循环数组)
    int arr[200];
    for (int i = 0; i < n; i++) arr[i] = arr[i + n] = code[i];

    if (k > 0) {
        int sum = 0;
        for (int i = 1; i <= k; i++) sum += arr[i];
        res[0] = sum;
        for (int i = 1; i < n; i++) {
            sum += arr[i + k] - arr[i];
            res[i] = sum;
        }
    } else {
        int w = -k;
        int sum = 0;
        int cur = n;
        for (int i = cur - w; i < cur; i++) sum += arr[i];
        res[0] = sum;
        for (int i = 1; i < n; i++) {
            sum += arr[cur] - arr[cur - w];
            cur++;
            res[i] = sum;
        }
    }

    return res;
}
```

```js [js]
/**
 * @param {number[]} code
 * @param {number} k
 * @return {number[]}
 */
var decrypt = function (code, k) {
  const n = code.length
  if (k === 0) return new Array(n).fill(0)

  const res = new Array(n).fill(0)
  const arr = code.concat(code)

  if (k > 0) {
    let sum = 0
    for (let i = 1; i <= k; i++) sum += arr[i]
    res[0] = sum
    for (let i = 1; i < n; i++) {
      sum += arr[i + k] - arr[i]
      res[i] = sum
    }
  } else {
    const w = -k
    let sum = 0
    let cur = n // 对应原数组下标 0 的位置
    for (let i = cur - w; i < cur; i++) sum += arr[i]
    res[0] = sum
    for (let i = 1; i < n; i++) {
      sum += arr[cur] - arr[cur - w]
      cur++
      res[i] = sum
    }
  }

  return res
}
```

```py [py]
class Solution:
    def decrypt(self, code: List[int], k: int) -> List[int]:
        n = len(code)
        if k == 0:
            return [0] * n

        res = [0] * n
        arr = code + code

        if k > 0:
            total = sum(arr[1:k + 1])
            res[0] = total
            for i in range(1, n):
                total += arr[i + k] - arr[i]
                res[i] = total
        else:
            w = -k
            cur = n
            total = sum(arr[cur - w:cur])
            res[0] = total
            for i in range(1, n):
                total += arr[cur] - arr[cur - w]
                cur += 1
                res[i] = total

        return res
```

:::

- 时间复杂度：$O(N)$，其中 N 是数组 code 的长度，拼接数组和滑动窗口遍历都是线性时间
- 空间复杂度：$O(N)$，需要创建长度为 2N 的拼接数组和长度为 N 的结果数组

算法思路：

- 特殊情况：如果 `k = 0`，直接返回全 0 数组
- 创建结果数组 `res` 和双倍数组 `arr`（将 `code` 拼接自身，模拟循环数组）
- 如果 `k > 0`（向右求和）：
  - 初始化第一个窗口：计算 `arr[1]` 到 `arr[k]` 的和，作为 `res[0]`
  - 滑动窗口：对于 `i` 从 1 到 n-1，窗口右移一位，加上新进入的 `arr[i+k]`，减去移出的 `arr[i]`
- 如果 `k < 0`（向左求和）：
  - 初始化第一个窗口：计算 `arr[n-|k|]` 到 `arr[n-1]` 的和，作为 `res[0]`
  - 滑动窗口：对于 `i` 从 1 到 n-1，窗口右移一位，加上移出左边界的值，减去新移出的值
- 返回结果数组 `res`
