## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/palindrome-partitioning-iv/)

给你一个字符串 `s`，如果可以将它分割成三个 非空 回文子字符串，那么返回 `true`，否则返回 `false`。

当一个字符串正着读和反着读是一模一样的，就称其为 回文字符串。

---

示例 1：

```txt
输入：s = "abcbdd"
输出：true
解释："abcbdd" = "a" + "bcb" + "dd"，三个子字符串都是回文的。
```

示例 2：

```txt
输入：s = "bcbddxy"
输出：false
解释：s 没办法被分割成 3 个回文子字符串。
```

---

提示：

- `3 <= s.length <= 2000`
- `s`​​​​​​ 只包含小写英文字母。
