## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/k-concatenation-maximum-sum/)

给定一个整数数组 `arr` 和一个整数 `k`，通过重复 `k` 次来修改数组。

例如，如果 `arr = [1, 2]`， `k = 3`，那么修改后的数组将是 `[1, 2, 1, 2, 1, 2]`。

返回修改后的数组中的最大的子数组之和。注意，子数组长度可以是 `0`，在这种情况下它的总和也是 `0`。

由于 结果可能会很大，需要返回的 `10^9 + 7` 的 模。

---

示例 1：

```txt
输入：arr = [1,2], k = 3
输出：9
```

示例 2：

```txt
输入：arr = [1,-2,1], k = 5
输出：2
```

示例 3：

```txt
输入：arr = [-1,-2], k = 7
输出：0
```

---

提示：

- `1 <= arr.length <= 10^5`
- `1 <= k <= 10^5`
- `-10^4 <= arr[i] <= 10^4`

## 2. 🎯 s.1 - Kadane 算法

::: code-group

```js [js]
/**
 * @param {number[]} arr
 * @param {number} k
 * @return {number}
 */
var kConcatenationMaxSum = function (arr, k) {
  const MOD = 1e9 + 7
  const n = arr.length
  const totalSum = arr.reduce((a, b) => a + b, 0)
  let maxSum = 0,
    cur = 0
  const times = Math.min(k, 2)
  for (let t = 0; t < times; t++) {
    for (let i = 0; i < n; i++) {
      cur = Math.max(0, cur) + arr[i]
      maxSum = Math.max(maxSum, cur)
    }
  }
  if (k >= 3 && totalSum > 0) {
    maxSum += (k - 2) * totalSum
  }
  return maxSum % MOD
}
```

```c [c]
int kConcatenationMaxSum(int* arr, int arrSize, int k) {
    long long MOD = 1000000007;
    long long totalSum = 0;
    for (int i = 0; i < arrSize; i++) totalSum += arr[i];
    long long maxSum = 0, cur = 0;
    int times = k < 2 ? k : 2;
    for (int t = 0; t < times; t++) {
        for (int i = 0; i < arrSize; i++) {
            cur = (cur > 0 ? cur : 0) + arr[i];
            if (cur > maxSum) maxSum = cur;
        }
    }
    if (k >= 3 && totalSum > 0) {
        maxSum += (long long)(k - 2) * totalSum;
    }
    return (int)(maxSum % MOD);
}
```

```py [py]
class Solution:
    def kConcatenationMaxSum(self, arr: list[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        total_sum = sum(arr)
        max_sum = cur = 0
        for _ in range(min(k, 2)):
            for x in arr:
                cur = max(0, cur) + x
                max_sum = max(max_sum, cur)
        if k >= 3 and total_sum > 0:
            max_sum += (k - 2) * total_sum
        return max_sum % MOD
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是数组的长度
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 对数组重复 `min(k, 2)` 次运行 Kadane 算法，得到跨越最多 2 个副本的最大子数组和
- 如果数组总和 > 0 且 k ≥ 3，则可在中间插入 `k - 2` 个完整副本，增加 $(k - 2) \times totalSum$
- 结果对 $10^9 + 7$ 取模，且最小为 0（可选择空子数组）
