## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/magical-string/)

神奇字符串 `s` 仅由 `'1'` 和 `'2'` 组成，并需要遵守下面的规则：

神奇字符串 s 的神奇之处在于，串联字符串中 `'1'` 和 `'2'` 的连续出现次数可以生成该字符串。

`s` 的前几个元素是 `s = "1221121221221121122……"`。如果将 `s` 中连续的若干 `1` 和 `2` 进行分组，可以得到 `"1 22 11 2 1 22 1 22 11 2 11 22 ......"`。每组中 `1` 或者 `2` 的出现次数分别是 `"1 2 2 1 1 2 1 2 2 1 2 2 ......"`。上面的出现次数正是 `s` 自身。

给你一个整数 `n`，返回在神奇字符串 `s` 的前 `n` 个数字中 `1` 的数目。

---

示例 1：

```txt
输入：n = 6
输出：3
解释：神奇字符串 s 的前 6 个元素是 “122112”，它包含三个 1，因此返回 3。
```

---

示例 2：

```txt
输入：n = 1
输出：1
```

---

提示：

- `1 <= n <= 10^5`

## 2. s.1 - 模拟生成

::: code-group

```c [c]
int magicalString(int n) {
    if (n == 0) return 0;
    if (n <= 3) return 1;
    int* s = (int*)malloc(sizeof(int) * (n + 2));
    s[0] = 1; s[1] = 2; s[2] = 2;
    int len = 3, i = 2;
    while (len < n) {
        int next = s[len - 1] == 1 ? 2 : 1;
        int count = s[i];
        for (int j = 0; j < count && len < n; j++) s[len++] = next;
        i++;
    }
    int res = 0;
    for (int k = 0; k < n; k++) if (s[k] == 1) res++;
    free(s);
    return res;
}
```

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var magicalString = function (n) {
  if (n === 0) return 0
  if (n <= 3) return 1
  const s = [1, 2, 2]
  let i = 2 // 指向当前组的长度
  while (s.length < n) {
    const next = s[s.length - 1] === 1 ? 2 : 1
    const count = s[i]
    for (let j = 0; j < count && s.length < n; j++) s.push(next)
    i++
  }
  let res = 0
  for (let k = 0; k < n; k++) if (s[k] === 1) res++
  return res
}
```

```py [py]
class Solution:
    def magicalString(self, n: int) -> int:
        if n == 0:
            return 0
        if n <= 3:
            return 1
        s = [1, 2, 2]
        i = 2
        while len(s) < n:
            nxt = 2 if s[-1] == 1 else 1
            s.extend([nxt] * s[i])
            i += 1
        return s[:n].count(1)
```

:::

- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$

算法思路：

- 根据神奇字符串的自描述性质，用指针 $i$ 指向当前组的长度
- 交替生成 1 和 2，每次追加 $s[i]$ 个相同字符
- 统计前 $n$ 位中 1 的个数

---

「长度为 n 的 s」是如何建起来的？

先固定开头 `122`，这是已知的。后面每一位都由更早的数字来决定「下一组写几个、写哪个」。

指针 `i` 从下标 `2` 开始看：`s[2] = 2`，表示下一组要写 2 个数字；**数字必须和末尾不同**，末尾是 `2`，所以追加两个 `1`，得到 `12211`。

然后 `i` 移到下标 `3`：`s[3] = 1`，下一组只写 1 个，末尾是 `1`，所以追加一个 `2`，得到 `122112`。

再然后 `s[4] = 1`，追加一个 `1`，得到 `1221121`；`s[5] = 2`，追加两个 `2`，得到 `122112122`。就这样一直补，直到长度到 `n` 为止。也就是说，`s` 一边生成，一边用已经写下的值当说明书，告诉后面该怎么写。

---

「下一组数字必须和末尾不同」的规则是如何推出来的？

这是从「分组」本身推出来的，题目没有单独写成一条规则。

一组指的是连续相同的数字，比如 `1`、`22`、`11`。新的一组要开始，就必须换一种数字，否则会和上一组合并成同一组。字符串又只由 `1` 和 `2` 组成，所以下一组只能是末尾那个数的反面。

规律推导：

- 开始时 `s = [1, 2, 2]`，`i` 指向 `2` -> `s[i] = 2` 接下来需要插入长度为 `2` 的组，这个组要么是：`1`、`1` 要么是 `2`、`2`，由于 `s` 的结尾组已经是 `2` 了，因此只能接 `1`、`1`。
- 随后`s = [1, 2, 2, 1, 1]`，下一轮 `i` 指向 `3` -> `s[i] = 1`，此时 `s` 的结尾是 `1`，因此只能接 `2`，否则会跟结尾的 `1` 成组，导致长度不是 `1`。
- `s = [1, 2, 2, 1, 1, 2]`，`s[i] = 1`，此时结尾是 `2`，要接一个长度为 `1` 的组，只能接 `1`。
- `s = [1, 2, 2, 1, 1, 2, 1]`，`s[i] = 2` ...
- ... 最终推导出规律：「下一组数字必须和末尾不同」
