## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/find-triangular-sum-of-an-array/)

给你一个下标从 0 开始的整数数组 `nums`，其中 `nums[i]` 是 `0` 到 `9` 之间（两者都包含）的一个数字。

`nums` 的 三角和 是执行以下操作以后最后剩下元素的值：

1. `nums` 初始包含 `n` 个元素。如果 `n == 1`，终止 操作。否则，创建 一个新的下标从 0 开始的长度为 `n - 1` 的整数数组 `newNums`。
2. 对于满足 `0 <= i < n - 1` 的下标 `i`，`newNums[i]` 赋值 为 `(nums[i] + nums[i+1]) % 10`，`%` 表示取余运算。
3. 将 `newNums` 替换 数组 `nums`。
4. 从步骤 1 开始 重复 整个过程。

请你返回 `nums` 的三角和。

## 2. 🎯 s.1 - 模拟

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var triangularSum = function (nums) {
  while (nums.length > 1) {
    const next = []
    for (let i = 0; i < nums.length - 1; i++) {
      next.push((nums[i] + nums[i + 1]) % 10)
    }
    nums = next
  }
  return nums[0]
}
```

```c [c]
int triangularSum(int* nums, int numsSize) {
    while (numsSize > 1) {
        for (int i = 0; i < numsSize - 1; i++) {
            nums[i] = (nums[i] + nums[i + 1]) % 10;
        }
        numsSize--;
    }
    return nums[0];
}
```

```py [py]
class Solution:
    def triangularSum(self, nums: list[int]) -> int:
        while len(nums) > 1:
            nums = [(nums[i] + nums[i + 1]) % 10 for i in range(len(nums) - 1)]
        return nums[0]
```

:::

- 时间复杂度：$O(n^2)$，其中 n 是数组长度，共需迭代 n-1 轮
- 空间复杂度：$O(n)$，每轮需要一个新数组

算法思路：

- 每轮将相邻两个元素求和并对 10 取模，生成长度减 1 的新数组
- 重复此过程直到数组只剩一个元素
- 返回最后剩余的唯一元素
