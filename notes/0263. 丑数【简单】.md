## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/ugly-number/)

丑数就是只包含质因数 `2`、`3` 和 `5` 的正整数。

给你一个整数 `n`，请你判断 `n` 是否为丑数。如果是，返回 `true`；否则，返回 `false`。

---

示例 1：

```txt
输入：n = 6
输出：true
```

解释：6 = 2 × 3

---

示例 2：

```txt
输入：n = 1
输出：true
```

解释：1 没有质因数。

---

示例 3：

```txt
输入：n = 14
输出：false
```

解释：14 不是丑数，因为它包含了另外一个质因数 7。

---

提示：

- `-2^31 <= n <= 2^31 - 1`

## 2. 题目解读

丑数是指只包含质因数 2、3 和 5 的正整数。换句话说，丑数可以写成 2^a × 3^b × 5^c 的形式，其中 a、b、c 都是非负整数。

判断一个数是否为丑数的方法是：

1. 如果数字小于等于 0，则不是丑数
2. 不断地将数字除以 2、3、5，直到不能整除为止
3. 如果最终结果是 1，则原数是丑数；否则不是

## 3. s.1 - 迭代法

::: code-group

```c [c]
bool isUgly(int n) {
    // 丑数必须是正整数
    if (n <= 0) return false;

    // 分别除以 2、3、5 直到不能整除
    int factors[] = {2, 3, 5};
    for (int i = 0; i < 3; i++) {
        while (n % factors[i] == 0) {
            n /= factors[i];
        }
    }

    // 如果最终结果是 1，则是丑数
    return n == 1;
}
```

```js [js]
/**
 * @param {number} n
 * @return {boolean}
 */
var isUgly = function (n) {
  // 丑数必须是正整数
  if (n <= 0) return false

  // 分别除以 2、3、5 直到不能整除
  for (const factor of [2, 3, 5]) {
    while (n % factor === 0) {
      n /= factor
    }
  }

  // 如果最终结果是 1，则是丑数
  return n === 1
}
```

```py [py]
class Solution:
    def isUgly(self, n: int) -> bool:
        # 丑数必须是正整数
        if n <= 0:
            return False

        # 分别除以 2、3、5 直到不能整除
        for factor in (2, 3, 5):
            while n % factor == 0:
                n //= factor

        # 如果最终结果是 1，则是丑数
        return n == 1
```

:::

- 时间复杂度：$O(\log n)$，最坏情况下需要除法操作 $\log n$ 次
- 空间复杂度：$O(1)$

算法思路：

- 小于等于 0 的数不是丑数
- 反复整除 2、3、5，把这三种质因数全部去掉
- 若最后剩下 1，原数只含质因数 2、3、5，是丑数；否则还含有其他质因数

## 4. s.2 - 递归法

::: code-group

```c [c]
bool isUgly(int n) {
    // 丑数必须是正整数
    if (n <= 0) return false;

    // 1 是丑数
    if (n == 1) return true;

    // 递归处理
    if (n % 2 == 0) return isUgly(n / 2);
    if (n % 3 == 0) return isUgly(n / 3);
    if (n % 5 == 0) return isUgly(n / 5);

    // 不能被 2、3、5 整除，则不是丑数
    return false;
}
```

```js [js]
/**
 * @param {number} n
 * @return {boolean}
 */
var isUgly = function (n) {
  // 丑数必须是正整数
  if (n <= 0) return false

  // 1 是丑数
  if (n === 1) return true

  // 递归处理
  if (n % 2 === 0) return isUgly(n / 2)
  if (n % 3 === 0) return isUgly(n / 3)
  if (n % 5 === 0) return isUgly(n / 5)

  // 不能被 2、3、5 整除，则不是丑数
  return false
}
```

```py [py]
class Solution:
    def isUgly(self, n: int) -> bool:
        # 丑数必须是正整数
        if n <= 0:
            return False

        # 1 是丑数
        if n == 1:
            return True

        # 递归处理
        if n % 2 == 0:
            return self.isUgly(n // 2)
        if n % 3 == 0:
            return self.isUgly(n // 3)
        if n % 5 == 0:
            return self.isUgly(n // 5)

        # 不能被 2、3、5 整除，则不是丑数
        return False
```

:::

- 时间复杂度：$O(\log n)$
- 空间复杂度：$O(\log n)$，递归调用栈

算法思路：

- 小于等于 0 不是丑数；1 没有质因数，是丑数，作为递归终止
- 若能被 2、3 或 5 整除，去掉该因子后对商做同样的判断
- 三者都不能整除时，说明含有其他质因数，不是丑数
