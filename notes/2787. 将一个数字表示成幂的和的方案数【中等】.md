## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/ways-to-express-an-integer-as-sum-of-powers/)

给你两个 正 整数 `n` 和 `x`。

请你返回将 `n` 表示成一些 互不相同 正整数的 `x` 次幂之和的方案数。换句话说，你需要返回互不相同整数 `[n1, n2, ..., nk]` 的集合数目，满足 `n = n1^x + n2^x + ... + nk^x`。

由于答案可能非常大，请你将它对 `10^9 + 7` 取余后返回。

比方说，`n = 160` 且 `x = 3`，一个表示 `n` 的方法是 `n = 2^3 + 3^3 + 5^3`。

---

示例 1：

```txt
输入：n = 10, x = 2
输出：1
解释：我们可以将 n 表示为：n = 32 + 12 = 10。
这是唯一将 10 表达成不同整数 2 次方之和的方案。
```

示例 2：

```txt
输入：n = 4, x = 1
输出：2
解释：我们可以将 n 按以下方案表示：
- n = 41 = 4。
- n = 31 + 11 = 4。
```

---

提示：

- `1 <= n <= 300`
- `1 <= x <= 5`

## 2. 🎯 s.1 - 动态规划（0-1 背包）

::: code-group

```js [js]
/**
 * @param {number} n
 * @param {number} x
 * @return {number}
 */
var numberOfWays = function (n, x) {
  const MOD = 1e9 + 7
  const dp = new Array(n + 1).fill(0)
  dp[0] = 1
  for (let i = 1; Math.pow(i, x) <= n; i++) {
    const v = Math.pow(i, x)
    for (let j = n; j >= v; j--) {
      dp[j] = (dp[j] + dp[j - v]) % MOD
    }
  }
  return dp[n]
}
```

```c [c]
int numberOfWays(int n, int x) {
  const int MOD = 1000000007;
  int dp[301] = {0};
  dp[0] = 1;
  for (int i = 1; ; i++) {
    long long v = 1;
    for (int j = 0; j < x; j++) v *= i;
    if (v > n) break;
    for (int j = n; j >= (int)v; j--) {
      dp[j] = (dp[j] + dp[j - (int)v]) % MOD;
    }
  }
  return dp[n];
}
```

```py [py]
class Solution:
    def numberOfWays(self, n: int, x: int) -> int:
        MOD = 10 ** 9 + 7
        dp = [0] * (n + 1)
        dp[0] = 1
        i = 1
        while i ** x <= n:
            v = i ** x
            for j in range(n, v - 1, -1):
                dp[j] = (dp[j] + dp[j - v]) % MOD
            i += 1
        return dp[n]
```

:::

- 时间复杂度：$O(n \cdot n^{1/x})$，外层枚举底数，内层背包遍历
- 空间复杂度：$O(n)$，一维 dp 数组

算法思路：

- 将问题转化为 0-1 背包：每个底数 $i$（$i^x \leq n$）对应一个物品，体积为 $i^x$
- $dp[j]$ 表示凑出和为 $j$ 的方案数
- 从大到小遍历 $j$（保证每个底数只选一次），累加 $dp[j - i^x]$
