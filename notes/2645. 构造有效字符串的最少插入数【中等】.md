## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/minimum-additions-to-make-valid-string/)

给你一个字符串 `word`，你可以向其中任何位置插入 "a"、"b" 或 "c" 任意次，返回使 `word` 有效 需要插入的最少字母数。

如果字符串可以由 "abc" 串联多次得到，则认为该字符串 有效。

---

示例 1：

```txt
输入：word = "b"
输出：2
解释：在 "b" 之前插入 "a"，在 "b" 之后插入 "c" 可以得到有效字符串 "abc"。
```

示例 2：

```txt
输入：word = "aaa"
输出：6
解释：在每个 "a" 之后依次插入 "b" 和 "c" 可以得到有效字符串 "abcabcabc"。
```

示例 3：

```txt
输入：word = "abc"
输出：0
解释：word 已经是有效字符串，不需要进行修改。
```

---

提示：

- `1 <= word.length <= 50`
- `word` 仅由字母 "a"、"b" 和 "c" 组成。

## 2. 🎯 s.1 - 贪心分组

::: code-group

```js [js]
/**
 * @param {string} word
 * @return {number}
 */
var addMinimum = function (word) {
  let groups = 1
  for (let i = 1; i < word.length; i++) {
    if (word[i] <= word[i - 1]) groups++
  }
  return groups * 3 - word.length
}
```

```c [c]
int addMinimum(char* word) {
    int n = strlen(word);
    int groups = 1;
    for (int i = 1; i < n; i++) {
        if (word[i] <= word[i - 1]) groups++;
    }
    return groups * 3 - n;
}
```

```py [py]
class Solution:
    def addMinimum(self, word: str) -> int:
        groups = 1
        for i in range(1, len(word)):
            if word[i] <= word[i - 1]:
                groups += 1
        return groups * 3 - len(word)
```

:::

- 时间复杂度：$O(n)$，遍历一次字符串
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 统计需要多少组 "abc"：当 `word[i] <= word[i-1]` 时，说明开始了新的一组
- 每组需要 3 个字符，总共需要 `groups * 3` 个字符
- 答案为 `groups * 3 - word.length`（需要插入的字符数）
