## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/count-lattice-points-inside-a-circle/)

给你一个二维整数数组 `circles`，其中 `circles[i] = [xi, yi, ri]` 表示网格上圆心为 `(xi, yi)` 且半径为 `ri` 的第 `i` 个圆，返回出现在 至少一个 圆内的 格点数目。

注意：

- 格点 是指整数坐标对应的点。
- 圆周上的点 也被视为出现在圆内的点。

---

示例 1：

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-09-27-11-38-07.png)

```txt
输入：circles = [[2,2,1]]
输出：5
解释：
给定的圆如上图所示。
出现在圆内的格点为 (1, 2)、(2, 1)、(2, 2)、(2, 3) 和 (3, 2)，在图中用绿色标识。
像 (1, 1) 和 (1, 3) 这样用红色标识的点，并未出现在圆内。
因此，出现在至少一个圆内的格点数目是 5。
```

示例 2：

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-09-27-11-38-21.png)

```txt
输入：circles = [[2,2,2],[3,4,1]]
输出：16
解释：
给定的圆如上图所示。
共有 16 个格点出现在至少一个圆内。
其中部分点的坐标是 (0, 2)、(2, 0)、(2, 4)、(3, 2) 和 (4, 4)。
```

---

提示：

- `1 <= circles.length <= 200`
- `circles[i].length == 3`
- `1 <= xi, yi <= 100`
- `1 <= ri <= min(xi, yi)`

## 2. 🎯 s.1 - 枚举

::: code-group

```js [js]
/**
 * @param {number[][]} circles
 * @return {number}
 */
var countLatticePoints = function (circles) {
  const set = new Set()
  for (const [cx, cy, r] of circles) {
    for (let x = cx - r; x <= cx + r; x++) {
      for (let y = cy - r; y <= cy + r; y++) {
        if ((x - cx) * (x - cx) + (y - cy) * (y - cy) <= r * r) {
          set.add(x * 1000 + y)
        }
      }
    }
  }
  return set.size
}
```

```c [c]
int countLatticePoints(int** circles, int circlesSize, int* circlesColSize) {
    // 坐标范围 [0, 200]
    bool seen[201][201];
    memset(seen, false, sizeof(seen));
    int count = 0;
    for (int k = 0; k < circlesSize; k++) {
        int cx = circles[k][0], cy = circles[k][1], r = circles[k][2];
        for (int x = cx - r; x <= cx + r; x++) {
            for (int y = cy - r; y <= cy + r; y++) {
                if (x >= 0 && y >= 0 && x <= 200 && y <= 200) {
                    if ((x - cx) * (x - cx) + (y - cy) * (y - cy) <= r * r && !seen[x][y]) {
                        seen[x][y] = true;
                        count++;
                    }
                }
            }
        }
    }
    return count;
}
```

```py [py]
class Solution:
    def countLatticePoints(self, circles: list[list[int]]) -> int:
        points = set()
        for cx, cy, r in circles:
            for x in range(cx - r, cx + r + 1):
                for y in range(cy - r, cy + r + 1):
                    if (x - cx) ** 2 + (y - cy) ** 2 <= r * r:
                        points.add((x, y))
        return len(points)
```

:::

- 时间复杂度：$O(k \times R^2)$，其中 k 是圆的个数，R 是最大半径
- 空间复杂度：$O(k \times R^2)$，哈希集合存储所有格点

算法思路：

- 对每个圆，枚举其外接正方形内的所有整数点
- 判断每个点到圆心的距离是否不超过半径（用平方避免开方）
- 用 Set 去重，最终返回集合大小
