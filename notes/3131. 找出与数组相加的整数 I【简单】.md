## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/find-the-integer-added-to-array-i/)

给你两个长度相等的数组 `nums1` 和 `nums2`。

数组 `nums1` 中的每个元素都与变量 `x` 所表示的整数相加。如果 `x` 为负数，则表现为元素值的减少。

在与 `x` 相加后，`nums1` 和 `nums2` 相等。当两个数组中包含相同的整数，并且这些整数出现的频次相同时，两个数组 相等。

返回整数 `x`。

---

示例 1：

输入：nums1 = [2,6,4], nums2 = [9,7,5]

输出：3

解释：

与 3 相加后，`nums1` 和 `nums2` 相等。

---

示例 2：

输入：nums1 = [10], nums2 = [5]

输出：-5

解释：

与 `-5` 相加后，`nums1` 和 `nums2` 相等。

---

示例 3：

输入：nums1 = [1,1,1,1], nums2 = [1,1,1,1]

输出：0

解释：

与 0 相加后，`nums1` 和 `nums2` 相等。

---

提示：

- `1 <= nums1.length == nums2.length <= 100`
- `0 <= nums1[i], nums2[i] <= 1000`
- 测试用例以这样的方式生成：存在一个整数 `x`，使得 `nums1` 中的每个元素都与 `x` 相加后，`nums1` 与 `nums2` 相等。

## 2. 🎯 s.1 - 最小值差

::: code-group

```js [js]
/**
 * @param {number[]} nums1
 * @param {number[]} nums2
 * @return {number}
 */
var addedInteger = function (nums1, nums2) {
  // x = min(nums2) - min(nums1)
  return Math.min(...nums2) - Math.min(...nums1)
}
```

:::

- 时间复杂度：$O(n)$，其中 n 是数组长度
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：

- nums1 每个元素加 x 后与 nums2 相等（元素相同、频次相同）
- 因此 nums1 的最小值加 x 等于 nums2 的最小值
- 答案为 `min(nums2) - min(nums1)`
