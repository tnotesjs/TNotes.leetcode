## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/number-of-unequal-triplets-in-array/)

给你一个下标从 0 开始的正整数数组 `nums`。请你找出并统计满足下述条件的三元组 `(i, j, k)` 的数目：

- `0 <= i < j < k < nums.length`
- `nums[i]`、`nums[j]` 和 `nums[k]` 两两不同。
  - 换句话说：`nums[i] != nums[j]`、`nums[i] != nums[k]` 且 `nums[j] != nums[k]`。

返回满足上述条件三元组的数目。

---

示例 1：

```txt
输入：nums = [4,4,2,4,3]
输出：3

解释：
下面列出的三元组均满足题目条件：
- (0, 2, 4) 因为 4 != 2 != 3
- (1, 2, 4) 因为 4 != 2 != 3
- (2, 3, 4) 因为 2 != 4 != 3
共计 3 个三元组，返回 3。
注意 (2, 0, 4) 不是有效的三元组，因为 2 > 0。
```

---

示例 2：

```txt
输入：nums = [1,1,1,1,1]
输出：0

解释：
不存在满足条件的三元组，所以返回 0。
```

---

提示：

- `3 <= nums.length <= 100`
- `1 <= nums[i] <= 1000`

## 2. 🎯 s.1 - 三重循环枚举

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var unequalTriplets = function (nums) {
  let count = 0
  const n = nums.length

  for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {
      for (let k = j + 1; k < n; k++) {
        if (nums[i] !== nums[j] && nums[i] !== nums[k] && nums[j] !== nums[k]) {
          count++
        }
      }
    }
  }

  return count
}
```

:::

- 时间复杂度：$O(N^3)$，其中 N 是数组 nums 的长度，需要三重循环枚举所有三元组
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 使用三重循环枚举所有可能的三元组 (i, j, k)，满足 i < j < k
- 对于每个三元组，检查三个元素是否两两不同
- 统计满足条件的三元组数量
