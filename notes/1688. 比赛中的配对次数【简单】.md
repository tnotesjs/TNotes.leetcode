## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/count-of-matches-in-tournament/)

给你一个整数 `n`，表示比赛中的队伍数。比赛遵循一种独特的赛制：

- 如果当前队伍数是偶数，那么每支队伍都会与另一支队伍配对。总共进行 `n / 2` 场比赛，且产生 `n / 2` 支队伍进入下一轮。
- 如果当前队伍数为奇数，那么将会随机轮空并晋级一支队伍，其余的队伍配对。总共进行 `(n - 1) / 2` 场比赛，且产生 `(n - 1) / 2 + 1` 支队伍进入下一轮。

返回在比赛中进行的配对次数，直到决出获胜队伍为止。

---

示例 1：

```txt
输入：n = 7
输出：6
```

解释：

比赛详情：

- 第 1 轮：队伍数 = 7，配对次数 = 3，4 支队伍晋级。
- 第 2 轮：队伍数 = 4，配对次数 = 2，2 支队伍晋级。
- 第 3 轮：队伍数 = 2，配对次数 = 1，决出 1 支获胜队伍。

总配对次数 = 3 + 2 + 1 = 6

---

示例 2：

```txt
输入：n = 14
输出：13
```

解释：

比赛详情：

- 第 1 轮：队伍数 = 14，配对次数 = 7，7 支队伍晋级。
- 第 2 轮：队伍数 = 7，配对次数 = 3，4 支队伍晋级。
- 第 3 轮：队伍数 = 4，配对次数 = 2，2 支队伍晋级。
- 第 4 轮：队伍数 = 2，配对次数 = 1，决出 1 支获胜队伍。

总配对次数 = 7 + 3 + 2 + 1 = 13

---

提示：

- `1 <= n <= 200`

## 2. 🎯 s.1 - 数学归纳

::: code-group

```c [c]
int numberOfMatches(int n) {
    return n - 1;
}
```

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var numberOfMatches = function (n) {
  return n - 1
}
```

```py [py]
class Solution:
    def numberOfMatches(self, n: int) -> int:
        return n - 1
```

:::

- 时间复杂度：$O(1)$，直接返回计算结果
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 淘汰赛制的核心规律：每场比赛淘汰一支队伍
- 从 n 支队伍决出 1 支冠军，需要淘汰 n-1 支队伍
- 因此总配对次数（比赛场次）恰好等于淘汰的队伍数量：n-1
- 无论过程中如何分组（奇数偶数），最终结果都是 n-1 场比赛
- 直接返回 `n - 1`
