## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/beautiful-arrangement/)

假设有从 1 到 n 的 n 个整数。用这些整数构造一个数组 `perm`（下标从 1 开始），只要满足下述条件 **之一**，该数组就是一个 **优美的排列**：

- `perm[i]` 能够被 `i` 整除
- `i` 能够被 `perm[i]` 整除

给你一个整数 `n`，返回可以构造的 **优美排列** 的 **数量**。

---

示例 1：

```txt
输入：n = 2
输出：2
解释：
第 1 个优美的排列是 [1, 2]：
    - perm[1] = 1 能被 i = 1 整除
    - perm[2] = 2 能被 i = 2 整除
第 2 个优美的排列是 [2, 1]:
    - perm[1] = 2 能被 i = 1 整除
    - i = 2 能被 perm[2] = 1 整除
```

---

示例 2：

```txt
输入：n = 1
输出：1
```

---

提示：

- `1 <= n <= 15`

## 2. s.1 - 回溯

::: code-group

```c [c]
int count;
bool visited[16];

void dfs(int n, int pos) {
    if (pos > n) { count++; return; }
    for (int i = 1; i <= n; i++) {
        if (!visited[i] && (i % pos == 0 || pos % i == 0)) {
            visited[i] = true;
            dfs(n, pos + 1);
            visited[i] = false;
        }
    }
}

int countArrangement(int n) {
    count = 0;
    memset(visited, false, sizeof(visited));
    dfs(n, 1);
    return count;
}
```

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var countArrangement = function (n) {
  let count = 0
  const visited = new Array(n + 1).fill(false)
  const dfs = (pos) => {
    if (pos > n) {
      count++
      return
    }
    for (let i = 1; i <= n; i++) {
      if (!visited[i] && (i % pos === 0 || pos % i === 0)) {
        visited[i] = true
        dfs(pos + 1)
        visited[i] = false
      }
    }
  }
  dfs(1)
  return count
}
```

```py [py]
class Solution:
    def countArrangement(self, n: int) -> int:
        self.count = 0
        visited = [False] * (n + 1)
        def dfs(pos):
            if pos > n:
                self.count += 1
                return
            for i in range(1, n + 1):
                if not visited[i] and (i % pos == 0 or pos % i == 0):
                    visited[i] = True
                    dfs(pos + 1)
                    visited[i] = False
        dfs(1)
        return self.count
```

:::

- 时间复杂度：$O(k)$，$k$ 为满足条件的排列数
- 空间复杂度：$O(n)$

算法思路：

- 从位置 1 开始回溯，尝试将每个未使用的数放在当前位置
- 只有当 `i % pos == 0` 或 `pos % i == 0` 时才放置
- 统计所有合法排列数

## 3. s.2 - 状态压缩 DP【pending】

::: code-group

```c [c]
int countArrangement(int n) {
    int total = 1 << n;
    int* dp = (int*)calloc(total, sizeof(int));
    dp[0] = 1;
    for (int mask = 0; mask < total; mask++) {
        if (dp[mask] == 0) continue;
        int pos = __builtin_popcount(mask) + 1;  // 下一个待填的位置
        for (int bit = 0; bit < n; bit++) {
            if (mask & (1 << bit)) continue;
            int num = bit + 1;
            if (num % pos == 0 || pos % num == 0) dp[mask | (1 << bit)] += dp[mask];
        }
    }
    int res = dp[total - 1];
    free(dp);
    return res;
}
```

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var countArrangement = function (n) {
  const total = 1 << n
  const dp = new Int32Array(total)
  dp[0] = 1
  const ones = new Uint8Array(total)
  for (let mask = 1; mask < total; mask++) ones[mask] = ones[mask >> 1] + (mask & 1)
  for (let mask = 0; mask < total; mask++) {
    if (dp[mask] === 0) continue
    const pos = ones[mask] + 1
    for (let bit = 0; bit < n; bit++) {
      if (mask & (1 << bit)) continue
      const num = bit + 1
      if (num % pos === 0 || pos % num === 0) dp[mask | (1 << bit)] += dp[mask]
    }
  }
  return dp[total - 1]
}
```

```py [py]
class Solution:
    def countArrangement(self, n: int) -> int:
        total = 1 << n
        dp = [0] * total
        dp[0] = 1
        for mask in range(total):
            if dp[mask] == 0:
                continue
            pos = bin(mask).count('1') + 1  # 下一个待填的位置
            for bit in range(n):
                if mask >> bit & 1:
                    continue
                num = bit + 1
                if num % pos == 0 or pos % num == 0:
                    dp[mask | (1 << bit)] += dp[mask]
        return dp[total - 1]
```

:::

- 时间复杂度：$O(n \times 2^n)$，共 $2^n$ 个状态，每个状态枚举 $n$ 个数尝试放置
- 空间复杂度：$O(2^n)$，需要长度 $2^n$ 的 dp 数组记录每个子集的方案数

算法思路：

- 用二进制 `mask` 表示已经使用过的数字集合，`dp[mask]` 表示用 `mask` 中的数字填满前 `popcount(mask)` 个位置的方案数
- 已填位置数为 `popcount(mask)`，下一个位置即 `pos = popcount(mask) + 1`，因此状态本身蕴含了当前填到第几位
- 枚举 `mask` 中未使用的数字 `num = bit + 1`，若满足 `num % pos == 0` 或 `pos % num == 0`，就把 `dp[mask]` 累加到 `dp[mask | (1 << bit)]`
- 最终答案即所有数字都用上的状态 `dp[(1 << n) - 1]`
