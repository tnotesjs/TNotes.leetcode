## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/add-strings/)

给定两个字符串形式的非负整数 `num1` 和`num2`，计算它们的和并同样以字符串形式返回。

你不能使用任何內建的用于处理大整数的库（比如 `BigInteger`）， 也不能直接将输入的字符串转换为整数形式。

---

示例 1：

```txt
输入：num1 = "11", num2 = "123"
输出："134"
```

---

示例 2：

```txt
输入：num1 = "456", num2 = "77"
输出："533"
```

---

示例 3：

```txt
输入：num1 = "0", num2 = "0"
输出："0"
```

---

提示：

- `1 <= num1.length, num2.length <= 10^4`
- `num1` 和`num2` 都只包含数字 `0-9`
- `num1` 和`num2` 都不包含任何前导零

## 2. s.1 - 模拟十进制逐位相加

::: code-group

```c [c]
char* addStrings(char* num1, char* num2) {
    int n1 = strlen(num1), n2 = strlen(num2);
    int cap = (n1 > n2 ? n1 : n2) + 2;
    char* buf = malloc(cap);
    int i = n1 - 1, j = n2 - 1, k = 0, carry = 0;

    while (i >= 0 || j >= 0 || carry) {
        int sum = carry;
        if (i >= 0) sum += num1[i--] - '0';
        if (j >= 0) sum += num2[j--] - '0';
        buf[k++] = sum % 10 + '0';
        carry = sum / 10;
    }
    buf[k] = '\0';

    for (int l = 0, r = k - 1; l < r; ++l, --r) {
        char t = buf[l];
        buf[l] = buf[r];
        buf[r] = t;
    }

    return buf;
}
```

```js [js]
/**
 * @param {string} num1
 * @param {string} num2
 * @return {string}
 */
var addStrings = function (num1, num2) {
  const digits = []
  let i = num1.length - 1
  let j = num2.length - 1
  let carry = 0

  while (i >= 0 || j >= 0 || carry) {
    const d1 = i >= 0 ? num1.charCodeAt(i) - 48 : 0
    const d2 = j >= 0 ? num2.charCodeAt(j) - 48 : 0
    const sum = d1 + d2 + carry
    digits.push(sum % 10)
    carry = (sum / 10) | 0
    i--
    j--
  }

  return digits.reverse().join('')
}
```

```py [py]
class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        i, j, carry = len(num1) - 1, len(num2) - 1, 0
        digits: list[str] = []

        while i >= 0 or j >= 0 or carry:
            d1 = ord(num1[i]) - 48 if i >= 0 else 0
            d2 = ord(num2[j]) - 48 if j >= 0 else 0
            s = d1 + d2 + carry
            digits.append(str(s % 10))
            carry = s // 10
            i -= 1
            j -= 1

        return "".join(reversed(digits))
```

:::

- 时间复杂度：$O(\max(m, n))$，从低位扫到高位，每位只处理一次
- 空间复杂度：$O(\max(m, n))$，结果长度不超过较长串再加一位进位

算法思路：

- 模拟竖式加法：从个位起逐位相加，并带上进位
- 某一位已用完则按 0 处理，直到两个数和进位都处理完
- 各位先按从低到高收集，最后再反转得到结果字符串
