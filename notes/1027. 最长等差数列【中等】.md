## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/longest-arithmetic-subsequence/)

给你一个整数数组 `nums`，返回 `nums` 中最长等差子序列的长度。

回想一下，`nums` 的子序列是一个列表 `nums[i1], nums[i2], ..., nums[ik]`，且 `0 <= i1 < i2 < ... < ik <= nums.length - 1`。并且如果 `seq[i+1] - seq[i]`( `0 <= i < seq.length - 1`) 的值都相同，那么序列 `seq` 是等差的。

---

示例 1：

```txt
输入：nums = [3,6,9,12]
输出：4
解释：
整个数组是公差为 3 的等差数列。
```

示例 2：

```txt
输入：nums = [9,4,7,2,10]
输出：3
解释：
最长的等差子序列是 [4,7,10]。
```

示例 3：

```txt
输入：nums = [20,1,15,3,10,5,8]
输出：4
解释：
最长的等差子序列是 [20,15,10,5]。
```

---

提示：

- `2 <= nums.length <= 1000`
- `0 <= nums[i] <= 500`

## 2. 🎯 s.1 - 动态规划

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @return {number}
 */
var longestArithSeqLength = function (nums) {
  const n = nums.length
  const dp = Array.from({ length: n }, () => new Map())
  let res = 2
  for (let i = 1; i < n; i++) {
    for (let j = 0; j < i; j++) {
      const diff = nums[i] - nums[j]
      const prev = dp[j].get(diff) || 1
      dp[i].set(diff, prev + 1)
      res = Math.max(res, prev + 1)
    }
  }
  return res
}
```

```c [c]
#define OFFSET 500
#define RANGE 1001

int longestArithSeqLength(int* nums, int numsSize) {
    // dp[i][d+OFFSET] = length of arithmetic seq ending at i with diff d
    int** dp = malloc(numsSize * sizeof(int*));
    for (int i = 0; i < numsSize; i++) {
        dp[i] = calloc(RANGE, sizeof(int));
    }
    int res = 2;
    for (int i = 1; i < numsSize; i++) {
        for (int j = 0; j < i; j++) {
            int diff = nums[i] - nums[j] + OFFSET;
            int prev = dp[j][diff] > 0 ? dp[j][diff] : 1;
            dp[i][diff] = prev + 1;
            if (dp[i][diff] > res) res = dp[i][diff];
        }
    }
    for (int i = 0; i < numsSize; i++) free(dp[i]);
    free(dp);
    return res;
}
```

```py [py]
class Solution:
    def longestArithSeqLength(self, nums: list[int]) -> int:
        n = len(nums)
        dp = [dict() for _ in range(n)]
        res = 2
        for i in range(1, n):
            for j in range(i):
                diff = nums[i] - nums[j]
                dp[i][diff] = dp[j].get(diff, 1) + 1
                res = max(res, dp[i][diff])
        return res
```

:::

- 时间复杂度：$O(n^2)$，其中 $n$ 是数组的长度
- 空间复杂度：$O(n \cdot d)$，其中 $d$ 是不同公差的数量

算法思路：

- `dp[i][diff]` 表示以 `nums[i]` 结尾、公差为 `diff` 的等差数列的最大长度
- 对于每对 `(j, i)`，计算 `diff = nums[i] - nums[j]`，更新 `dp[i][diff] = dp[j][diff] + 1`
- 过程中维护全局最大值
