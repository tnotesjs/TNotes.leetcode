## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/add-two-integers/)

给你两个整数 `num1` 和 `num2`，返回这两个整数的和。

---

示例 1：

```txt
输入：num1 = 12, num2 = 5
输出：17

解释：
num1 是 12，num2 是 5，它们的和是 12 + 5 = 17，因此返回 17。
```

---

示例 2：

```txt
输入：num1 = -10, num2 = 4
输出：-6

解释：
num1 + num2 = -6，因此返回 -6。
```

---

提示：

- `-100 <= num1, num2 <= 100`

## 2. 🎯 s.1 - 直接相加

::: code-group

```js [js]
/**
 * @param {number} num1
 * @param {number} num2
 * @return {number}
 */
var sum = function (num1, num2) {
  return num1 + num2
}
```

:::

- 时间复杂度：$O(1)$，常数次运算
- 空间复杂度：$O(1)$，只用常数变量

算法思路：

- 直接返回 `num1 + num2` 即可。
