## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/add-digits/)

给定一个非负整数 `num`，反复将各个位上的数字相加，直到结果为一位数。返回这个结果。

---

示例 1：

```txt
输入: num = 38
输出: 2
```


解释: 各位相加的过程为：

- `38 --> 3 + 8 --> 11`
- `11 --> 1 + 1 --> 2`
- 由于 2 是一位数，所以返回 2。

---

示例 2：

```txt
输入: num = 0
输出: 0
```

---

提示：

- `0 <= num <= 2^31 - 1`

---

进阶：你可以不使用循环或者递归，在 `O(1)` 时间复杂度内解决这个问题吗？

## 2. 题目分析

这道题要求将一个非负整数的各位数字不断相加，直到结果为一位数，返回这个一位数。

例如：38 → 3 + 8 = 11 → 1 + 1 = 2，返回 2。

我们可以使用多种方法来解决这个问题：

1. 模拟法：循环计算各位数字之和直到结果为一位数，模拟真实各位数字求和的过程，易于理解
2. 数学法：利用数字根的数学性质直接计算结果，这种解法需要知道数字根的求解公式

## 3. s.1 - 模拟法（循环）

::: code-group

```c [c]
int addDigits(int num) {
    while (num >= 10) {
        int sum = 0;
        // 计算各位数字之和
        while (num > 0) {
            sum += num % 10;
            num /= 10;
        }
        num = sum;
    }
    return num;
}
```

```js [js]
/**
 * @param {number} num
 * @return {number}
 */
var addDigits = function (num) {
  while (num >= 10) {
    let sum = 0
    // 计算各位数字之和
    while (num > 0) {
      sum += num % 10
      num = Math.floor(num / 10)
    }
    num = sum
  }
  return num
}
```

```py [py]
class Solution:
    def addDigits(self, num: int) -> int:
        while num >= 10:
            total = 0
            # 计算各位数字之和
            while num > 0:
                total += num % 10
                num //= 10
            num = total
        return num
```

:::

- 时间复杂度：$O(\log n)$，每次循环数字位数减少
- 空间复杂度：$O(1)$

算法思路：

- 只要结果还不是一位数，就把当前数拆成各位再求和，用这个和替换原数
- 末位用对 10 取余得到，去掉末位用整除 10
- 每轮之后位数严格减少，直到小于 10

## 4. s.2 - 模拟法（递归）

::: code-group

```c [c]
int addDigits(int num) {
    // 如果是一位数，直接返回
    if (num < 10) return num;

    int sum = 0;
    // 计算各位数字之和
    while (num > 0) {
        sum += num % 10;
        num /= 10;
    }

    // 递归处理和
    return addDigits(sum);
}
```

```js [js]
/**
 * @param {number} num
 * @return {number}
 */
var addDigits = function (num) {
  // 如果是一位数，直接返回
  if (num < 10) return num

  let sum = 0
  // 计算各位数字之和
  while (num > 0) {
    sum += num % 10
    num = Math.floor(num / 10)
  }

  // 递归处理和
  return addDigits(sum)
}
```

```py [py]
class Solution:
    def addDigits(self, num: int) -> int:
        # 如果是一位数，直接返回
        if num < 10:
            return num

        total = 0
        # 计算各位数字之和
        while num > 0:
            total += num % 10
            num //= 10

        # 递归处理和
        return self.addDigits(total)
```

:::

- 时间复杂度：$O(\log n)$
- 空间复杂度：$O(\log n)$，递归调用栈

算法思路：

- 小于 10 时直接返回，这是递归的终止条件
- 否则先求各位之和，再对这个和做同样的处理
- 每次处理的数都比上一次更小，直到结果为一位数

## 5. s.3 - 数根（Digital Root）公式

::: code-group

```c [c]
int addDigits(int num) {
    return (num - 1) % 9 + 1;
}
```
```js [js]
/**
 * @param {number} num
 * @return {number}
 */
var addDigits = function (num) {
  // 数字根公式：
  // 如果 num 为 0，结果为 0
  // 如果 num 能被 9 整除且不为 0，结果为 9
  // 否则结果为 num % 9
  // if (num === 0) return 0
  // return num % 9 === 0 ? 9 : num % 9
  
  // 数字根的另一种表达方式
  return 1 + ((num - 1) % 9)
}
```
```py
class Solution:
    def addDigits(self, num: int) -> int:
        return 0 if num == 0 else (num - 1) % 9 + 1
        # 或者直接用统一公式：return (num - 1) % 9 + 1
```


:::

- 时间复杂度：$O(1)$
- 空间复杂度：$O(1)$

算法思路：

- 利用数根的数学规律求解：**除了 0 以外，任何数的数根都等于它对 9 取模的结果，但余数为 0 时数根为 9**

### 5.1. 数字根

[数字根][1] 的定义：数根（又称数字根）是正整数的一种属性，指通过重复计算各位数字之和直至结果为个位数的值。

![](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-09-13-23-46-55.png) {w=380px}

### 5.2. 数根公式

反复将各位数字相加直到一位数，得到的结果就是**数根**。数根有一个重要规律：**除了 0 以外，任何数的数根都等于它对 9 取模的结果，但余数为 0 时数根为 9**。

因此，对于非负整数 $num$，其数根可以用一个统一的公式表示：

$$
\text{digitalRoot} = \begin{cases} 0, & num = 0 \\ 1 + (num - 1) \bmod 9, & num > 0 \end{cases}
$$

或者合并为：

$$
\text{digitalRoot} = (num - 1) \bmod 9 + 1
$$

> **注意**：当 $num = 0$ 时，$(0-1) \bmod 9 + 1 = (-1) \bmod 9 + 1$。在大多数编程语言中，$-1 \bmod 9$ 的结果是 $-1$（取余），所以最终结果为 $0$，公式依然成立。

## 6. 【AI】「数根公式」推导

**数根公式推导**

我们要推导：对于非负整数 $num$，反复将其各位数字相加直到得到一位数，这个一位数（数根）等于：

$$
\text{dr}(num) = (num - 1) \bmod 9 + 1
$$

当 $num > 0$ 时成立；若 $num = 0$，数根为 $0$。

---

### 6.1. 数根的定义

设函数 $\text{dr}(n)$ 表示对 $n$ 反复求各位数字之和，直到结果为一位数。例如：

$$
\text{dr}(38) = 3 + 8 = 11 \rightarrow 1 + 1 = 2
$$

所以 $\text{dr}(38) = 2$。

---

### 6.2. 关键同余性质：$10 \equiv 1 \pmod 9$

任何十进制整数都可以写成：

$$
n = a_k 10^k + a_{k-1} 10^{k-1} + \cdots + a_1 10 + a_0
$$

其中 $a_i$ 是各位数字，$0 \le a_i \le 9$。

因为：

$$
10 \equiv 1 \pmod 9
$$

所以对任意非负整数 $i$：

$$
10^i \equiv 1 \pmod 9
$$

因此：

$$
n \equiv a_k + a_{k-1} + \cdots + a_1 + a_0 \pmod 9
$$

也就是说：一个整数与它的各位数字之和模 $9$ 同余。

---

### 6.3. 反复求和保持模 $9$ 余数不变

设第一次求和得到：

$$
s_1 = a_k + a_{k-1} + \cdots + a_0
$$

根据上面的结论：

$$
n \equiv s_1 \pmod 9
$$

再对 $s_1$ 求各位数字之和得到 $s_2$，同理：

$$
s_1 \equiv s_2 \pmod 9
$$

继续下去，直到得到一位数 $\text{dr}(n)$，始终有：

$$
n \equiv \text{dr}(n) \pmod 9
$$

所以数根与原来的数模 $9$ 同余。

---

### 6.4. 确定数根的范围

对于非零整数，反复求和最终得到的一位数不可能是 $0$。  
因为如果过程中某一步得到 $0$，说明之前所有数字都是 $0$，但原数非零，矛盾。

因此，当 $num > 0$ 时：

$$
\text{dr}(num) \in \{1, 2, 3, 4, 5, 6, 7, 8, 9\}
$$

并且满足：

$$
\text{dr}(num) \equiv num \pmod 9
$$

---

### 6.5. 构造公式

我们希望找到一个表达式，使得：

- 当 $num \bmod 9 = 1,2,\dots,8$ 时，结果就是对应的余数；
- 当 $num \bmod 9 = 0$ 时，结果应为 $9$，而不是 $0$。

考虑表达式：

$$
(num - 1) \bmod 9 + 1
$$

分析：

- 若 $num \equiv 1 \pmod 9$，则 $num - 1 \equiv 0 \pmod 9$，所以：

  $$
  (num - 1) \bmod 9 + 1 = 0 + 1 = 1
  $$
  正确。

- 若 $num \equiv 2 \pmod 9$，则 $num - 1 \equiv 1 \pmod 9$，结果为 $2$。
- ……
- 若 $num \equiv 0 \pmod 9$，则 $num - 1 \equiv -1 \equiv 8 \pmod 9$，所以：

  $$
  (num - 1) \bmod 9 + 1 = 8 + 1 = 9
  $$
正好得到 $9$。

因此，对于 $num > 0$：

$$
\text{dr}(num) = (num - 1) \bmod 9 + 1
$$

---

### 6.6. 验证例子

- $num = 38$：

  $$
  (38 - 1) \bmod 9 + 1 = 37 \bmod 9 + 1 = 1 + 1 = 2
  $$
正确。

- $num = 9$：

  $$
  (9 - 1) \bmod 9 + 1 = 8 \bmod 9 + 1 = 8 + 1 = 9
  $$
正确。

- $num = 18$：

  $$
  (18 - 1) \bmod 9 + 1 = 17 \bmod 9 + 1 = 8 + 1 = 9
  $$

而 $1 + 8 = 9$，正确。

---

### 6.7. 关于 $num = 0$ 与编程语言差异

当 $num = 0$ 时，数根定义为 $0$。

公式：

$$
(0 - 1) \bmod 9 + 1
$$

在不同语言中结果可能不同：

- 在 C、C++、Java、JavaScript 中，`%` 是取余，`-1 % 9 = -1`，所以：

  $$
  -1 + 1 = 0
  $$
结果正确。

- 在 Python 中，`%` 是取模，`-1 % 9 = 8`，所以：

  $$
  8 + 1 = 9
  $$
这就不对了。因此 Python 中需要特判：

  ```python
  return 0 if num == 0 else (num - 1) % 9 + 1
  ```

---

### 6.8. 总结

数根公式的推导核心是：

$$
10 \equiv 1 \pmod 9 \quad \Rightarrow \quad n \equiv \text{各位数字之和} \pmod 9
$$

反复求和直到一位数，结果与 $n$ 模 $9$ 同余，且非零时取值范围是 $1 \sim 9$。  
为了把余数 $0$ 映射到 $9$，采用：

$$
\text{dr}(n) = (n - 1) \bmod 9 + 1
$$

这就是 LeetCode 258 题 $O(1)$ 解法的数学依据。
