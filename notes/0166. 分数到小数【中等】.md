## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/fraction-to-recurring-decimal/)

给定两个整数，分别表示分数的分子 `numerator` 和分母 `denominator`，以字符串形式返回小数。

如果小数部分为循环小数，则将循环的部分括在括号内。

如果存在多个答案，只需返回任意一个。

对于所有给定的输入，保证答案字符串的长度小于 `10^4`。

---

示例 1：

```txt
输入：numerator = 1, denominator = 2
输出："0.5"
```

---

示例 2：

```txt
输入：numerator = 2, denominator = 1
输出："2"
```

---

示例 3：

```txt
输入：numerator = 4, denominator = 333
输出："0.(012)"
```

---

提示：

- `-2^31 <= numerator, denominator <= 2^31 - 1`
- `denominator != 0`

## 2. s.1 - 长除法 + 哈希表

::: code-group

```c [c]
char* fractionToDecimal(int numerator, int denominator) {
    char* res = (char*)calloc(10001, sizeof(char));
    int pos = 0;
    if (numerator == 0) { res[0] = '0'; return res; }
    // 处理符号
    if ((numerator < 0) ^ (denominator < 0)) res[pos++] = '-';
    long long num = llabs((long long)numerator);
    long long den = llabs((long long)denominator);
    // 整数部分
    pos += sprintf(res + pos, "%lld", num / den);
    long long remainder = num % den;
    if (remainder == 0) return res;
    res[pos++] = '.';
    // 用数组记录余数对应的位置
    long long* rems = (long long*)calloc(10001, sizeof(long long));
    int* remPos = (int*)calloc(10001, sizeof(int));
    int remCount = 0;
    while (remainder != 0) {
        // 检查余数是否出现过
        for (int i = 0; i < remCount; i++) {
            if (rems[i] == remainder) {
                // 插入括号
                int insertPos = remPos[i];
                memmove(res + insertPos + 1, res + insertPos, pos - insertPos);
                res[insertPos] = '(';
                pos++;
                res[pos++] = ')';
                res[pos] = '\0';
                free(rems); free(remPos);
                return res;
            }
        }
        rems[remCount] = remainder;
        remPos[remCount] = pos;
        remCount++;
        remainder *= 10;
        res[pos++] = '0' + (int)(remainder / den);
        remainder %= den;
    }
    res[pos] = '\0';
    free(rems); free(remPos);
    return res;
}
```

```js [js]
/**
 * @param {number} numerator
 * @param {number} denominator
 * @return {string}
 */
var fractionToDecimal = function (numerator, denominator) {
  if (numerator === 0) return '0'
  let res = ''
  // 处理符号
  if (numerator < 0 !== denominator < 0) res += '-'
  let num = Math.abs(numerator)
  let den = Math.abs(denominator)
  // 整数部分
  res += Math.floor(num / den).toString()
  // 计算余数
  let remainder = num % den
  if (remainder === 0) return res
  res += '.'
  // 记录每个余数在结果字符串里首次出现的下标
  const map = new Map()

  // 余数不为 0，还没除尽，继续除
  while (remainder !== 0) {
    // 检查该余数是否已出现过
    if (map.has(remainder)) {
      // 获取余数首次出现时，下一位小数在 res 中的下标
      const idx = map.get(remainder)
      // // 非循环前缀 + (循环节)
      return res.slice(0, idx) + '(' + res.slice(idx) + ')'
    }
    // 记录当前余数首次出现时，下一位小数在 res 中的下标
    map.set(remainder, res.length)
     // 计算余数：余数补 0 → 写出一位商 → 更新余数
    remainder *= 10
    res += Math.floor(remainder / den).toString()
    remainder %= den
  }
  return res
}
```

```py [py]
class Solution:
    def fractionToDecimal(self, numerator: int, denominator: int) -> str:
        if numerator == 0:
            return '0'
        res = []
        if (numerator < 0) != (denominator < 0):
            res.append('-')
        num, den = abs(numerator), abs(denominator)
        res.append(str(num // den))
        remainder = num % den
        if remainder == 0:
            return ''.join(res)
        res.append('.')
        rem_map = {}
        while remainder != 0:
            if remainder in rem_map:
                idx = rem_map[remainder]
                res.insert(idx, '(')
                res.append(')')
                return ''.join(res)
            rem_map[remainder] = len(res)
            remainder *= 10
            res.append(str(remainder // den))
            remainder %= den
        return ''.join(res)
```

:::

- 时间复杂度：$O(d)$，其中 $d$ 是小数部分的长度
- 空间复杂度：$O(d)$，哈希表存储余数位置

算法思路：

- 先处理符号和整数部分
- 对小数部分模拟长除法，用哈希表记录每个余数首次出现的位置
- 当余数重复出现时，说明开始循环，在对应位置插入括号

## 3. 【AI】s.1 中的解法是如何识别循环小数的？

核心就一句：**同一个余数再次出现，小数部分就会从头重复**——因为长除法下一步只取决于「当前余数」。

哈希表存的是：`余数 → 这个余数第一次出现时，结果字符串的下标`。再次碰到同一余数，就把那一段包进 `()`。

---

### 3.1. 识别循环的原理

长除法每一步：

1. 余数 × 10  
2. 除以分母，得到一位小数  
3. 得到新余数  

余数的取值只有 `0, 1, …, den-1` 共 `den` 种。所以：

- 余数变成 `0` → 整除，有限小数  
- 某个余数第二次出现 → 之后的商位序列必然和第一次出现后完全一样 → **循环开始**

---

### 3.2. 以 `1 / 6` 为例（结果 `"0.1(6)"`）

```js
numerator = 1, denominator = 6
```

#### 前置

| 步骤 | 结果 |
|------|------|
| 符号 | 同号，不加 `-` |
| 整数部分 | `1 / 6 = 0` → `res = "0"` |
| 余数 | `1 % 6 = 1` ≠ 0 → `res = "0."` |
| `map` | 空 |

#### 小数循环

**第 1 轮**（`remainder = 1`）

- `map` 没有 `1`  
- `map.set(1, res.length)` → `map = {1 → 2}`（`"0."` 长度是 2，下一位小数将写在下标 2）  
- `remainder = 1 * 10 = 10`  
- 商：`Math.floor(10 / 6) = 1` → `res = "0.1"`  
- 新余数：`10 % 6 = 4`

**第 2 轮**（`remainder = 4`）

- `map` 没有 `4`  
- `map.set(4, 3)` → `{1→2, 4→3}`  
- `remainder = 40`  
- 商：`40 / 6 = 6` → `res = "0.16"`  
- 新余数：`40 % 6 = 4`

**第 3 轮**（`remainder = 4` 再次出现）

- `map.has(4)` 为真，`idx = 3`  
- 循环节就是 `res` 从下标 3 到末尾：`"6"`  
- 返回：`"0.1" + "(" + "6" + ")"` → **`"0.1(6)"`**

对应手工竖式：

```text
  0.1666...
6 ) 1.0000
    0
    10      ← 余数 1，第一次
     6
     40     ← 余数 4，第一次
     36
      40    ← 余数 4，又来了 → 开始循环
```

---

### 3.3. 再看题目示例 `4 / 333` → `"0.(012)"`

| 轮次 | 余数 | map 动作 | 写入的商位 | `res` |
|------|------|----------|------------|-------|
| 开始 | 4 | — | 整数 `0.` | `"0."` |
| 1 | 4 | `4→2` | 0 | `"0.0"` |
| 2 | 40 | `40→3` | 1 | `"0.01"` |
| 3 | 67 | `67→4` | 2 | `"0.012"` |
| 4 | **4** | 发现重复，`idx=2` | — | `"0." + "(012)"` |

余数又变回 `4`，和小数第一位产生前的余数相同，所以从下标 2 起整段 `"012"` 都是循环节。

---

### 3.4. 对照代码关键几行

```js
// notes/0166. 分数到小数【中等】/solutions/1/1.js
while (remainder !== 0) {
  if (map.has(remainder)) {
    const idx = map.get(remainder)
    return res.slice(0, idx) + '(' + res.slice(idx) + ')'
  }
  map.set(remainder, res.length)
  remainder *= 10
  res += Math.floor(remainder / den).toString()
  remainder %= den
}
```

- `map.set(remainder, res.length)`：在**写入这一位小数之前**记下位置，这样括号正好夹住循环节  
- `map.has(remainder)`：同一余数再现 → 立刻截断并加括号  
- `remainder === 0` 退出循环：有限小数，如 `1/2 → "0.5"`，不加括号

---

### 3.5. 小结

| 情况 | 判定 |
|------|------|
| 余数变 0 | 有限小数 |
| 余数在 `map` 中再现 | 从该余数首次对应的下标起进入循环 |
| `map` 的 key | 余数（不是商位本身） |

所以识别循环靠的不是「看数字长得像不像在重复」，而是：**余数状态机一旦回到旧状态，商的序列必然周期重复**。
