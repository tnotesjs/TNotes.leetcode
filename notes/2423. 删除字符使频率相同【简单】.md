## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/remove-letter-to-equalize-frequency/)

给你一个下标从 0 开始的字符串 `word`，字符串只包含小写英文字母。你需要选择一个下标并删除下标处的字符，使得 `word` 中剩余每个字母出现频率相同。

如果删除一个字母后，`word` 中剩余所有字母的出现频率都相同，那么返回 `true`，否则返回 `false`。

注意：

- 字母 `x` 的频率是这个字母在字符串中出现的次数。
- 你必须恰好删除一个字母，不能一个字母都不删除。

---

示例 1：

```txt
输入：word = "abcc"
输出：true

解释：
选择下标 3 并删除该字母：word 变成 "abc" 且每个字母出现频率都为 1。
```

---

示例 2：

```txt
输入：word = "aazz"
输出：false

解释：
我们必须删除一个字母，所以要么 "a" 的频率变为 1 且 "z" 的频率为 2，要么两个字母频率反过来。
所以不可能让剩余所有字母出现频率相同。
```

---

提示：

- `2 <= word.length <= 100`
- `word` 只包含小写英文字母。

## 2. 🎯 s.1 - 枚举删除

::: code-group

```js [js]
/**
 * @param {string} word
 * @return {boolean}
 */
var equalFrequency = function (word) {
  // 枚举删除每个位置的字符
  for (let i = 0; i < word.length; i++) {
    // 删除第 i 个字符后的字符串
    const newWord = word.slice(0, i) + word.slice(i + 1)

    // 统计删除后每个字符的频率
    const freq = new Map()
    for (const char of newWord) {
      freq.set(char, (freq.get(char) || 0) + 1)
    }

    // 检查所有频率是否相同
    const frequencies = Array.from(freq.values())
    if (
      frequencies.length === 0 ||
      frequencies.every((f) => f === frequencies[0])
    ) {
      return true
    }
  }

  return false
}
```

:::

- 时间复杂度：$O(N^2)$，其中 N 是字符串 word 的长度，枚举 N 个位置，每次统计频率需要 $O(N)$
- 空间复杂度：$O(1)$，哈希表最多存储 26 个字母的频率

算法思路：

- 枚举删除字符串中每个位置的字符
- 对于每次删除后的字符串，统计剩余字符的出现频率
- 检查所有字符的频率是否相同，如果相同则返回 true
- 如果枚举所有位置都不满足条件，返回 false
