## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/maximum-height-of-a-triangle/)

给你两个整数 `red` 和 `blue`，分别表示红色球和蓝色球的数量。你需要使用这些球来组成一个三角形，满足第 1 行有 1 个球，第 2 行有 2 个球，第 3 行有 3 个球，依此类推。

每一行的球必须是相同颜色，且相邻行的颜色必须不同。

返回可以实现的三角形的最大高度。

## 2. 🎯 s.1 - 模拟

::: code-group

```js [js]
/**
 * @param {number} red
 * @param {number} blue
 * @return {number}
 */
var maxHeightOfTriangle = function (red, blue) {
  // 模拟构建三角形，返回最大高度
  const build = (odd, even) => {
    // odd 用于奇数行，even 用于偶数行
    let height = 0
    let row = 1
    while (true) {
      if (row % 2 === 1) {
        // 奇数行
        if (odd >= row) {
          odd -= row
          height = row
        } else {
          break
        }
      } else {
        // 偶数行
        if (even >= row) {
          even -= row
          height = row
        } else {
          break
        }
      }
      row++
    }
    return height
  }
  // 两种情况：红色在奇数行/蓝色在偶数行，或者相反
  return Math.max(build(red, blue), build(blue, red))
}
```

:::

- 时间复杂度：$O(\sqrt{n})$，其中 n 为球的总数，三角形高度与 $\sqrt{n}$ 成正比
- 空间复杂度：$O(1)$，只使用了常数级别的额外空间

算法思路：

- 第 i 行需要 i 个球，且相邻行颜色必须不同
- 有两种排列方式：奇数行红色/偶数行蓝色，或者奇数行蓝色/偶数行红色
- 对两种情况分别模拟，逐行构建三角形，直到某一行球数不够为止
- 返回两种情况中能达到的最大高度
