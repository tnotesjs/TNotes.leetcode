## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/separate-black-and-white-balls/)

桌子上有 `n` 个球，每个球的颜色不是黑色，就是白色。

给你一个长度为 `n` 、下标从 0 开始的二进制字符串 `s`，其中 `1` 和 `0` 分别代表黑色和白色的球。

在每一步中，你可以选择两个相邻的球并交换它们。

返回「将所有黑色球都移到右侧，所有白色球都移到左侧所需的 最小步数」。

---

示例 1：

```txt
输入：s = "101"
输出：1
解释：我们可以按以下方式将所有黑色球移到右侧：
- 交换 s[0] 和 s[1]，s = "011"。
最开始，1 没有都在右侧，需要至少 1 步将其移到右侧。
```

示例 2：

```txt
输入：s = "100"
输出：2
解释：我们可以按以下方式将所有黑色球移到右侧：
- 交换 s[0] 和 s[1]，s = "010"。
- 交换 s[1] 和 s[2]，s = "001"。
可以证明所需的最小步数为 2。
```

示例 3：

```txt
输入：s = "0111"
输出：0
解释：所有黑色球都已经在右侧。
```

---

提示：

- `1 <= n == s.length <= 10^5`
- `s[i]` 不是 `'0'`，就是 `'1'`。

## 2. 🎯 s.1 - 贪心

::: code-group

```js [js]
/**
 * @param {string} s
 * @return {number}
 */
var minimumSteps = function(s) {
  let ans = 0, blacks = 0
  for (let i = 0; i < s.length; i++) {
    if (s[i] === '1') blacks++
    else ans += blacks
  }
  return ans
}
```

```c [c]
long long minimumSteps(char* s) {
    long long ans = 0;
    int blacks = 0;
    for (int i = 0; s[i]; i++) {
        if (s[i] == '1') blacks++;
        else ans += blacks;
    }
    return ans;
}
```

```py [py]
class Solution:
    def minimumSteps(self, s: str) -> int:
        ans = 0
        blacks = 0
        for c in s:
            if c == '1':
                blacks += 1
            else:
                ans += blacks
        return ans
```

:::

- 时间复杂度：$O(n)$，遍历字符串一次
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 从左到右遍历字符串，维护已遇到的黑球（'1'）数量
- 每遇到白球（'0'），需要将其移过所有已遇到的黑球，步数即为当前黑球计数
- 累加所有白球的移动步数即为答案
