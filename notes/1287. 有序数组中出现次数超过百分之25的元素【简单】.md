## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/element-appearing-more-than-25-in-sorted-array/)

给你一个非递减的有序整数数组，已知这个数组中恰好有一个整数，它的出现次数超过数组元素总数的 25%。

请你找到并返回这个整数

---

示例：

```txt
输入：arr = [1,2,2,6,6,6,6,7,10]
输出：6
```

---

提示：

- `1 <= arr.length <= 10^4`
- `0 <= arr[i] <= 10^5`

## 2. 🎯 s.1 - 线性计数

::: code-group

```c [c]
int findSpecialInteger(int* arr, int arrSize) {
    int limit = arrSize / 4;
    int count = 1;

    for (int i = 1; i < arrSize; i++) {
        count = (arr[i] == arr[i - 1]) ? count + 1 : 1;
        if (count > limit) {
            return arr[i];
        }
    }

    return arr[0];
}
```

```js [js]
/**
 * @param {number[]} arr
 * @return {number}
 */
var findSpecialInteger = function (arr) {
  const limit = Math.floor(arr.length / 4)
  let count = 1

  for (let i = 1; i < arr.length; i += 1) {
    count = arr[i] === arr[i - 1] ? count + 1 : 1
    if (count > limit) return arr[i]
  }

  return arr[0]
}
```

```py [py]
class Solution:
    def findSpecialInteger(self, arr: List[int]) -> int:
        limit = len(arr) // 4
        count = 1

        for i in range(1, len(arr)):
            count = count + 1 if arr[i] == arr[i - 1] else 1
            if count > limit:
                return arr[i]

        return arr[0]
```

:::

- 时间复杂度：$O(N)$，单次遍历统计连续段
- 空间复杂度：$O(1)$，常数变量

算法思路：

- 数组有序，目标值连续出现且长度超过 $N/4$
- 线性扫描累计当前值的频次，一旦超过 $N/4$ 立即返回该值
