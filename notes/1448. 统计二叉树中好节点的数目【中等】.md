## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/count-good-nodes-in-binary-tree/)

给你一棵根为 `root` 的二叉树，请你返回二叉树中好节点的数目。

「好节点」X 定义为：从根到该节点 X 所经过的节点中，没有任何节点的值大于 X 的值。

---

示例 1：

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-09-21-23-58-56.png)

```txt
输入：root = [3,1,4,3,null,1,5]
输出：4
解释：图中蓝色节点为好节点。
根节点 (3) 永远是个好节点。
节点 4 -> (3,4) 是路径中的最大值。
节点 5 -> (3,4,5) 是路径中的最大值。
节点 3 -> (3,1,3) 是路径中的最大值。
```

示例 2：

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs@main/2025-09-21-23-59-01.png)

```txt
输入：root = [3,3,null,4,2]
输出：3
解释：节点 2 -> (3, 3, 2) 不是好节点，因为 "3" 比它大。
```

示例 3：

```txt
输入：root = [1]
输出：1
解释：根节点是好节点。
```

---

提示：

- 二叉树中节点数目范围是 `[1, 10^5]`。
- 每个节点权值的范围是 `[-10^4, 10^4]`。

## 2. 🎯 s.1 - DFS

::: code-group

```js [js]
/**
 * @param {TreeNode} root
 * @return {number}
 */
var goodNodes = function (root) {
  let count = 0
  const dfs = (node, maxVal) => {
    if (!node) return
    if (node.val >= maxVal) count++
    const newMax = Math.max(maxVal, node.val)
    dfs(node.left, newMax)
    dfs(node.right, newMax)
  }
  dfs(root, -Infinity)
  return count
}
```

```c [c]
int count;
void dfs(struct TreeNode* node, int maxVal) {
    if (!node) return;
    if (node->val >= maxVal) count++;
    int newMax = node->val > maxVal ? node->val : maxVal;
    dfs(node->left, newMax);
    dfs(node->right, newMax);
}

int goodNodes(struct TreeNode* root) {
    count = 0;
    dfs(root, -100000);
    return count;
}
```

```py [py]
class Solution:
    def goodNodes(self, root: TreeNode) -> int:
        def dfs(node: TreeNode | None, max_val: int) -> int:
            if not node:
                return 0
            count = 1 if node.val >= max_val else 0
            new_max = max(max_val, node.val)
            return count + dfs(node.left, new_max) + dfs(node.right, new_max)

        return dfs(root, float('-inf'))
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是二叉树的节点数
- 空间复杂度：$O(h)$，其中 $h$ 是二叉树的高度，递归栈的空间

算法思路：

- DFS 遍历，传递路径上的最大值
- 若当前节点值 ≥ 路径最大值，则为好节点
