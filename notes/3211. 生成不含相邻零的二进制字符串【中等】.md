## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/generate-binary-strings-without-adjacent-zeros/)

给你一个正整数 `n`。

如果一个二进制字符串 `x` 的所有长度为 2 的子字符串中包含 至少 一个 `"1"`，则称 `x` 是一个 有效 字符串。

> 子字符串 是字符串中连续的 非空 字符序列。

返回所有长度为 `n` 的 有效 字符串，可以以任意顺序排列。

---

示例 1：

输入：n = 3

输出：["010","011","101","110","111"]

解释：

长度为 3 的有效字符串有：`"010"`、`"011"`、`"101"`、`"110"` 和 `"111"`。

---

示例 2：

输入：n = 1

输出：["0","1"]

解释：

长度为 1 的有效字符串有：`"0"` 和 `"1"`。

---

提示：

- `1 <= n <= 18`

## 2. 🎯 s.1 - 回溯

::: code-group

```js [js]
/**
 * @param {number} n
 * @return {string[]}
 */
var validStrings = function(n) {
  const res = []
  const backtrack = (path) => {
    if (path.length === n) {
      res.push(path)
      return
    }
    // 可以加 '1'
    backtrack(path + '1')
    // 加 '0' 的条件：上一位不是 '0'
    if (path.length === 0 || path[path.length - 1] !== '0') {
      backtrack(path + '0')
    }
  }
  backtrack('')
  return res
}
```

:::

- 时间复杂度：$O(2^n)$，生成所有合法字符串
- 空间复杂度：$O(n)$，递归深度

算法思路：

- 回溯生成二进制字符串，每次可以添加 '1'
- 仅当上一位不是 '0' 时才能添加 '0'
