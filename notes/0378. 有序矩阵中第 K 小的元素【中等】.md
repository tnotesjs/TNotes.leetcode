## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/kth-smallest-element-in-a-sorted-matrix/)

给你一个 `n x n` 矩阵 `matrix`，其中每行和每列元素均按升序排序，找到矩阵中第 `k` 小的元素。

请注意，它是排序后的第 `k` 小元素，而不是第 `k` 个不同的元素。

你必须找到一个内存复杂度优于 `O(n^2)` 的解决方案。

---

示例 1：

```txt
输入：matrix = [
  [1, 5, 9],
  [10, 11, 13],
  [12, 13, 15]
], k = 8
输出：13
解释：矩阵中的元素为 [1, 5, 9, 10, 11, 12, 13, 13, 15]，第 8 小元素是 13
```


---

示例 2：

```txt
输入：matrix = [[-5]], k = 1
输出：-5
```

---

提示：

- `n == matrix.length`
- `n == matrix[i].length`
- `1 <= n <= 300`
- `-10^9 <= matrix[i][j] <= 10^9`
- 题目数据保证 `matrix` 中的所有行和列都按非递减顺序排列
- `1 <= k <= n^2`

---

进阶：

- 你能否用一个恒定的内存(即 `O(1)` 内存复杂度)来解决这个问题?
- 你能在 `O(n)` 的时间复杂度下解决这个问题吗？这个方法对于面试来说可能太超前了，但是你会发现阅读这篇文章（ [this paper][1] ）很有趣。

## 2. s.1 - 二分查找

::: code-group

```c [c]
int kthSmallest(int** matrix, int matrixSize, int* matrixColSize, int k) {
    int n = matrixSize;
    int lo = matrix[0][0], hi = matrix[n - 1][n - 1];
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        int count = 0, j = n - 1;
        for (int i = 0; i < n; i++) {
            while (j >= 0 && matrix[i][j] > mid) j--;
            count += j + 1;
        }
        if (count < k) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}
```

```py [py]
class Solution:
    def kthSmallest(self, matrix: List[List[int]], k: int) -> int:
        n = len(matrix)
        lo, hi = matrix[0][0], matrix[n - 1][n - 1]
        while lo < hi:
            mid = (lo + hi) // 2
            count, j = 0, n - 1
            for i in range(n):
                while j >= 0 and matrix[i][j] > mid:
                    j -= 1
                count += j + 1
            if count < k:
                lo = mid + 1
            else:
                hi = mid
        return lo
```

:::

- 时间复杂度：$O(n \log(max - min))$，其中 $n$ 是矩阵边长
- 空间复杂度：$O(1)$

算法思路：

- 对值域二分，每次统计矩阵中 $\leq mid$ 的元素个数
- 统计从矩阵右上角开始：`j = n - 1`，`i` 从第 $0$ 行走到最后一行
- 每一行里，`j` 向左移过所有 `matrix[i][j] > mid` 的位置；停下后该行有 $j + 1$ 个元素 $\le mid$
- 行、列都非递减，下一行的分界只可能在当前 `j` 或更左边，`j` 只减不增，一轮统计是 $O(n)$

## 3. 【AI】题目描述中引用的文章讲解

---

http://www.cse.yorku.ca/~andy/pubs/X+Y.pdf 笔记中引用的这篇文章，讲了啥？

---

这篇是 **Mirzaian & Arjomandi, 1985**（《Information Processing Letters》），题目就叫 *Selection in X + Y and Matrices with Sorted Rows and Columns*。

**它在讲什么**

给定 `n×n` 矩阵，每行、每列都非降序，求第 `k` 小。特殊情形是笛卡尔和 `A[i][j] = X[i] + Y[j]`（只存两个向量就行）。他们给出一个 **`O(n)`** 的选择算法，比早期 `O(n log n)` 更好，也声称比 Frederickson–Johnson 1982 的线性算法更简单、常数更小。

**核心套路**

1. **`rank(A, a)`**：数矩阵里 `< a` 的个数，利用行列单调，沿分界线扫一遍，`O(n)`——就是你笔记里「阶梯统计」那一层。
2. **真正选第 k 小**不用值域二分，而是 **分治**：取大约一半大小的子矩阵 $\bar{A}$（奇数行/列等），证明原矩阵里某个值的 rank 和子矩阵 rank 差最多常数倍（≤4），再递归 `biselect` 同时钉住两个秩位置，把候选缩到线性个再挑出来。总时间 `O(n)`；若 `k` 很小还可做到 $O(min{n, k, n²−k})$。

**跟 0378 笔记的关系**

LeetCode 进阶里那句「`O(n)`、读 this paper 很有趣」指的就是这篇（或同一问题的线性选择结果）。笔记中的 **s.1 是值域二分**：每次 `count ≤ mid` 用 `O(n)` 阶梯，外层再 `log(max−min)`，总复杂度 `O(n log(值域))`，好写、面试够用。这篇是把「选第 k 小」本身做到严格 **`O(n)`**，面试一般不要求实现。

一句话：论文在解决「有序矩阵第 k 小」的线性时间版；你现在的代码是实用折中版，共用了它的 `O(n)` 计数积木，但没做它的分治选择。

## 4. s.2 - 线性时间选择（Mirzaian–Arjomandi）

::: code-group

```c [c]
static int qceil(int x) { return (x + 3) / 4; }

/** 1-based 第 k 小；期望线性。最坏严格线性需 BFPRT。mutates a. */
static int pick(int *a, int len, int k) {
    int lo = 0, hi = len - 1, t = k - 1;
    while (1) {
        int pivot = a[(lo + hi) / 2];
        int i = lo, j = hi;
        while (i <= j) {
            while (a[i] < pivot) i++;
            while (a[j] > pivot) j--;
            if (i <= j) {
                int tmp = a[i];
                a[i] = a[j];
                a[j] = tmp;
                i++;
                j--;
            }
        }
        if (t <= j)
            hi = j;
        else if (t >= i)
            lo = i;
        else
            return a[t];
    }
}

static int cmp_int(const void *p, const void *q) {
    int x = *(const int *)p, y = *(const int *)q;
    return (x > y) - (x < y);
}

typedef struct {
    int a, b;
} Pair;

static int choose_val(int kk, int a, int b, int ra_less, int rb_more, int nn,
                      const int *L, int Llen) {
    if (ra_less <= kk - 1) return a;
    int r = kk + rb_more - nn;  // = kk - |{x <= b}|
    if (r <= 0) return b;
    int tmp[Llen > 0 ? Llen : 1];
    memcpy(tmp, L, (size_t)Llen * sizeof(int));
    return pick(tmp, Llen, r);
}

/* Lwork: 共享缓冲区，容量 >= 12*n+10（论文 |L|~12n）；子问题返回后再复用 */
static Pair biselect(int **M, int *rows, int *cols, int n, int k1, int k2,
                     int *Lwork) {
    if (n <= 2) {
        int flat[4], m = 0;
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                flat[m++] = M[rows[i]][cols[j]];
        qsort(flat, (size_t)m, sizeof(int), cmp_int);
        Pair p = {flat[k1 - 1], flat[k2 - 1]};
        return p;
    }

    // 子矩阵 A-bar：奇数行/列（1-based → 下标 0,2,4,...）；n 为偶数时再并上最后一行/列
    int n2 = (n % 2 == 0) ? (n / 2 + 1) : ((n + 1) / 2);
    int rows2[n2], cols2[n2];
    int idx = 0;
    for (int i = 0; i < n; i += 2) {
        rows2[idx] = rows[i];
        cols2[idx] = cols[i];
        idx++;
    }
    if (n % 2 == 0) {
        rows2[idx] = rows[n - 1];
        cols2[idx] = cols[n - 1];
        idx++;
    }

    // k1-bar / k2-bar：使 A-bar 上选出的 (a,b) 夹住 A 上的第 k1、k2 小
    int kb1 = (n % 2 == 0) ? (n + 1 + qceil(k1)) : qceil(k1 + 2 * n + 1);
    int kb2 = qceil(k2);
    Pair ab = biselect(M, rows2, cols2, n2, kb1, kb2, Lwork);
    int a = ab.a, b = ab.b;

    // 一次阶梯扫描：ra- = |{x < a}|，rb+ = |{x > b}|，L = {b < x < a}
    int ra_less = 0, rb_more = 0, Llen = 0;
    int ja = n, jb = n;
    for (int i = 0; i < n; i++) {
        while (ja > 0 && M[rows[i]][cols[ja - 1]] >= a) ja--;
        ra_less += ja;
        while (jb > 0 && M[rows[i]][cols[jb - 1]] > b) jb--;
        rb_more += n - jb;
        for (int jj = jb; jj < ja; jj++)
            Lwork[Llen++] = M[rows[i]][cols[jj]];
    }

    int nn = n * n;
    Pair out = {
        choose_val(k1, a, b, ra_less, rb_more, nn, Lwork, Llen),
        choose_val(k2, a, b, ra_less, rb_more, nn, Lwork, Llen),
    };
    return out;
}

int kthSmallest(int** matrix, int matrixSize, int* matrixColSize, int k) {
    (void)matrixColSize;
    int n = matrixSize;
    int rows[n], cols[n];
    // n <= 300；论文 |L| 约 12n
    int Lwork[300 * 12 + 10];
    for (int i = 0; i < n; i++) {
        rows[i] = i;
        cols[i] = i;
    }
    return biselect(matrix, rows, cols, n, k, k, Lwork).a;
}
```

```js [js]
function qceil(x) {
  return Math.floor((x + 3) / 4)
}

/** 1-based 第 k 小；期望线性。最坏严格线性需 BFPRT。 */
function pick(L, k) {
  const a = L.slice()
  let lo = 0,
    hi = a.length - 1,
    t = k - 1
  while (true) {
    const pivot = a[Math.floor((lo + hi) / 2)]
    let i = lo,
      j = hi
    while (i <= j) {
      while (a[i] < pivot) i++
      while (a[j] > pivot) j--
      if (i <= j) {
        ;[a[i], a[j]] = [a[j], a[i]]
        i++
        j--
      }
    }
    if (t <= j) hi = j
    else if (t >= i) lo = i
    else return a[t]
  }
}

/**
 * @param {number[][]} matrix
 * @param {number} k
 * @return {number}
 */
var kthSmallest = function (matrix, k) {
  const n = matrix.length
  const rows = Array.from({ length: n }, (_, i) => i)
  const cols = Array.from({ length: n }, (_, i) => i)
  return biselect(matrix, rows, cols, k, k)[0]
}

function biselect(M, rows, cols, k1, k2) {
  const n = rows.length
  const at = (i, j) => M[rows[i]][cols[j]]

  if (n <= 2) {
    const flat = []
    for (let i = 0; i < n; i++)
      for (let j = 0; j < n; j++) flat.push(at(i, j))
    flat.sort((x, y) => x - y)
    return [flat[k1 - 1], flat[k2 - 1]]
  }

  // 子矩阵 A-bar：奇数行/列（1-based → 下标 0,2,4,...）；n 为偶数时再并上最后一行/列
  const idxs = []
  for (let i = 0; i < n; i += 2) idxs.push(i)
  if (n % 2 === 0) idxs.push(n - 1)
  const rows2 = idxs.map((i) => rows[i])
  const cols2 = idxs.map((j) => cols[j])

  // k1-bar / k2-bar：使 A-bar 上选出的 (a,b) 夹住 A 上的第 k1、k2 小
  const kb1 = n % 2 === 0 ? n + 1 + qceil(k1) : qceil(k1 + 2 * n + 1)
  const kb2 = qceil(k2)
  const [a, b] = biselect(M, rows2, cols2, kb1, kb2)

  // 一次阶梯扫描：ra- = |{x < a}|，rb+ = |{x > b}|，L = {b < x < a}
  let raLess = 0,
    rbMore = 0
  const L = []
  let ja = n,
    jb = n
  for (let i = 0; i < n; i++) {
    while (ja > 0 && at(i, ja - 1) >= a) ja--
    raLess += ja
    while (jb > 0 && at(i, jb - 1) > b) jb--
    rbMore += n - jb
    for (let jj = jb; jj < ja; jj++) L.push(at(i, jj))
  }

  const nn = n * n
  const choose = (kk) => {
    if (raLess <= kk - 1) return a
    const r = kk + rbMore - nn // = kk - |{x <= b}|
    if (r <= 0) return b
    return pick(L, r)
  }
  return [choose(k1), choose(k2)]
}
```

```py [py]
def qceil(x: int) -> int:
    return (x + 3) // 4


def pick(L: List[int], k: int) -> int:
    """1-based 第 k 小；期望线性。最坏严格线性需 BFPRT。"""
    a = L[:]
    lo, hi, t = 0, len(a) - 1, k - 1
    while True:
        pivot = a[(lo + hi) // 2]
        i, j = lo, hi
        while i <= j:
            while a[i] < pivot:
                i += 1
            while a[j] > pivot:
                j -= 1
            if i <= j:
                a[i], a[j] = a[j], a[i]
                i += 1
                j -= 1
        if t <= j:
            hi = j
        elif t >= i:
            lo = i
        else:
            return a[t]


class Solution:
    def kthSmallest(self, matrix: List[List[int]], k: int) -> int:
        n = len(matrix)
        rows = list(range(n))
        cols = list(range(n))
        x, _ = self._biselect(matrix, rows, cols, k, k)
        return x

    def _biselect(
        self,
        M: List[List[int]],
        rows: List[int],
        cols: List[int],
        k1: int,
        k2: int,
    ) -> Tuple[int, int]:
        n = len(rows)

        def at(i: int, j: int) -> int:
            return M[rows[i]][cols[j]]

        if n <= 2:
            flat = sorted(at(i, j) for i in range(n) for j in range(n))
            return flat[k1 - 1], flat[k2 - 1]

        # 子矩阵 A-bar：奇数行/列（1-based → 下标 0,2,4,...）；n 为偶数时再并上最后一行/列
        idxs = list(range(0, n, 2))
        if n % 2 == 0:
            idxs.append(n - 1)
        rows2 = [rows[i] for i in idxs]
        cols2 = [cols[j] for j in idxs]

        # k1-bar / k2-bar：使 A-bar 上选出的 (a,b) 夹住 A 上的第 k1、k2 小
        if n % 2 == 0:
            kb1 = n + 1 + qceil(k1)
        else:
            kb1 = qceil(k1 + 2 * n + 1)
        kb2 = qceil(k2)

        a, b = self._biselect(M, rows2, cols2, kb1, kb2)

        # 一次阶梯扫描：ra- = |{x < a}|，rb+ = |{x > b}|，L = {b < x < a}
        ra_less = 0
        rb_more = 0
        L: List[int] = []
        ja = n
        jb = n
        for i in range(n):
            while ja > 0 and at(i, ja - 1) >= a:
                ja -= 1
            ra_less += ja
            while jb > 0 and at(i, jb - 1) > b:
                jb -= 1
            rb_more += n - jb
            for jj in range(jb, ja):
                L.append(at(i, jj))

        nn = n * n

        def choose(kk: int) -> int:
            if ra_less <= kk - 1:
                return a
            r = kk + rb_more - nn  # = kk - |{x <= b}|
            if r <= 0:
                return b
            return pick(L, r)

        return choose(k1), choose(k2)
```

:::

- 时间复杂度：$O(n)$（递推 $T(n)=T(\lceil(n+1)/2\rceil)+O(n)$；`pick` 用 quickselect 时期望线性，最坏严格 $O(n)$ 需 BFPRT）
- 空间复杂度：$O(n)$（候选列表 $L$、行列下标与递归栈）

算法思路：

- 对应进阶「$O(n)$」；面试不要求实现，但和 s.1 共用同一块 $O(n)$ 阶梯 rank，外层是分治而非值域二分
- 有序矩阵：行、列均非递减。子矩阵 $\bar{A}$ 取奇数下标行/列（1-based），若 $n$ 为偶数再并上最后一行与最后一列，边长 $\bar{n}=\lceil(n+1)/2\rceil$
- 核心不等式：$\mathrm{rank}^-(A,a)\le 4\cdot\mathrm{rank}^-(\bar{A},a)$（$\mathrm{rank}^+$ 同理），故在 $\bar{A}$ 上钉住两个秩位置，就能把原矩阵答案夹在两个值之间
- `select(A,k)=biselect(n,A,k,k)`；`biselect` 返回第 $k_1$、$k_2$ 小。递归参数：$\bar{k}_2=\lfloor(k_2+3)/4\rfloor$；$\bar{k}_1$ 在 $n$ 偶数时为 $n+1+\lceil k_1/4\rceil$，奇数时为 $\lceil(k_1+2n+1)/4\rceil$
- 递归得到 $(a,b)$ 后，用阶梯一次扫出 $\mathrm{ra}^-=|\{x<a\}|$、$\mathrm{rb}^+=|\{x>b\}|$，并收集 $L=\{x\mid b<x<a\}$；$|L|=O(n)$（论文界约 $12n$）
- 对目标秩 $k$：若 $\mathrm{ra}^-\le k-1$ 则答案为 $a$；若 $k+\mathrm{rb}^+-n^2\le 0$（即 $k\le|\{x\le b\}|$）则答案为 $b$；否则在 $L$ 里 `pick` 第 $k+\mathrm{rb}^+-n^2$ 小
- `pick` 笔记里用 quickselect / `nth_element` 即可；要证明最坏 $O(n)$ 需换成 BFPRT（中位数的中位数）

## 5. 【AI】评价解法 s.1、s.2

---

评价一下笔记里的 s.1（值域二分）和 s.2（Mirzaian–Arjomandi 线性选择）：各自适合什么场景？有没有必要两套都记？

---

### 5.1. 一句话对比

| | s.1 值域二分 | s.2 线性选择 |
| --- | --- | --- |
| 时间 | $O(n \log(max-min))$ | $O(n)$（`pick` 用 quickselect 时期望线性） |
| 空间 | $O(1)$ | $O(n)$（$L$、下标、递归） |
| 写法 | 短、稳、边界少 | 长、公式多、易写错 |
| 面试 / 刷题 | **主解** | 进阶 curiosum，一般不要求写 |
| 和论文关系 | 只用了论文里的 $O(n)$ 阶梯 `rank` | 论文正文那套 `biselect` |

两者共用同一块积木：行列单调下的阶梯扫描。差别只在「外层怎么缩小答案」——s.1 猜值，s.2 分治缩候选。

### 5.2. s.1：该当默认答案

- 代码量小，对偶点（右上 / 左下）想清楚就能写对；LeetCode $n\le 300$、值域到 $10^9$，外层大约 60 次二分，完全够用。
- 空间真 $O(1)$，对上题面「内存优于 $O(n^2)$」和进阶里的恒定内存。
- 缺点是理论上依赖值域宽度，不是严格关于 $n$ 的线性；但这题约束下几乎无感。

**结论：交题、面试、默写，都用 s.1。**

### 5.3. s.2：理论闭环，实战慎用

- 真正回应进阶「能否 $O(n)$」：在 $\bar{A}$ 上同时钉两个秩，用 rank 不等式把答案夹进 $O(n)$ 长的 $L$，再 `pick`。
- 收益主要在渐近意义；常数、实现复杂度和调试成本都明显高于 s.1。`pick` 若不用 BFPRT，最坏还谈不上严格 $O(n)$。
- 适合：读完引用论文后，把「阶梯 rank → 子矩阵 → `biselect` → $L$」这条链落成可跑代码，方便以后回顾；不适合当作第一遍解法。

**结论：作为 s.2 存档值得；现场手写优先还是 s.1。**

### 5.4. 要不要两套都留？

要。分工已经清楚：

1. **s.1** = 这题的标准解（会写、会讲阶梯计数即可）。
2. **s.2** = 进阶引用的线性算法落地，和 §3 文章讲解、§6 引用形成闭环。
3. 不必再堆第三种（纯堆 / 逐行二分）除非以后单独想练模板；和「有序矩阵 + 阶梯」主线关系更弱。

记忆钩子：先会 s.1 的右上角阶梯；再知道同一阶梯在 s.2 里被用来算 $\mathrm{ra}^-$ / $\mathrm{rb}^+$ 和收集 $L$——两套解法就串起来了。
