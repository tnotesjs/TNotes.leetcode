## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/course-schedule-ii/)

现在你总共有 `numCourses` 门课需要选，记为 `0` 到 `numCourses - 1`。给你一个数组 `prerequisites`，其中 `prerequisites[i] = [ai, bi]`，表示在选修课程 `ai` 前必须先选修 `bi`。

- 例如，想要学习课程 `0`，你需要先完成课程 `1`，我们用一个匹配来表示：`[0, 1]`。

返回你为了学完所有课程所安排的学习顺序。可能会有多个正确的顺序，你只要返回任意一种就可以了。如果不可能完成所有课程，返回一个空数组。

---

示例 1：

```txt
输入：numCourses = 2, prerequisites = [[1, 0]]
输出：[0, 1]
```

解释：总共有 2 门课程。要学习课程 1，你需要先完成课程 0。因此，正确的课程顺序为 `[0, 1]`。

---

示例 2：

```txt
输入：numCourses = 4, prerequisites = [[1, 0], [2, 0], [3, 1], [3, 2]]
输出：[0, 2, 1, 3]
```

解释：总共有 4 门课程。要学习课程 3，你应该先完成课程 1 和课程 2。并且课程 1 和课程 2 都应该排在课程 0 之后。因此，一个正确的课程顺序是 `[0, 1, 2, 3]`。另一个正确的排序是 `[0, 2, 1, 3]`。

---

示例 3：

```txt
输入：numCourses = 1, prerequisites = []
输出：[0]
```

---

提示：

- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= numCourses * (numCourses - 1)`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < numCourses`
- `ai != bi`
- 所有 `[ai, bi]` 互不相同

## 3. 对比：`0207. 课程表【中等】`

这道题和 `0207. 课程表【中等】` 几乎完全一样，只是多一个数组来记录顺序罢了。

使用的是同一套 BFS 拓扑排序（Kahn），差别主要在返回值：

| -      | 0207               | 0210               |
| ------ | ------------------ | ------------------ |
| 问什么 | 能不能修完（判环） | 给出一种修课顺序   |
| 遍历时 | 只记 `count++`     | 把节点推进 `order` |
| 有解   | `true`             | `order`            |
| 有环   | `false`            | `[]`               |

建图、入度、入队出队逻辑完全一样；`order` 的入队顺序本身就是拓扑序。
