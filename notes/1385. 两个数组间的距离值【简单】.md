## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/find-the-distance-value-between-two-arrays/)

给你两个整数数组 `arr1`， `arr2` 和一个整数 `d`，请你返回两个数组之间的距离值。

「距离值」定义为符合此距离要求的元素数目：对于元素 `arr1[i]`，不存在任何元素 `arr2[j]` 满足 `|arr1[i]-arr2[j]| <= d`。

---

示例 1：

```txt
输入：arr1 = [4,5,8], arr2 = [10,9,1,8], d = 2
输出：2

解释：
对于 arr1[0]=4 我们有：
|4-10|=6 > d=2
|4-9|=5 > d=2
|4-1|=3 > d=2
|4-8|=4 > d=2
所以 arr1[0]=4 符合距离要求

对于 arr1[1]=5 我们有：
|5-10|=5 > d=2
|5-9|=4 > d=2
|5-1|=4 > d=2
|5-8|=3 > d=2
所以 arr1[1]=5 也符合距离要求

对于 arr1[2]=8 我们有：
|8-10|=2 <= d=2
|8-9|=1 <= d=2
|8-1|=7 > d=2
|8-8|=0 <= d=2
存在距离小于等于 2 的情况，不符合距离要求

故而只有 arr1[0]=4 和 arr1[1]=5 两个符合距离要求，距离值为 2
```

示例 2：

```txt
输入：arr1 = [1,4,2,3], arr2 = [-4,-3,6,10,20,30], d = 3
输出：2
```

示例 3：

```txt
输入：arr1 = [2,1,100,3], arr2 = [-5,-2,10,-3,7], d = 6
输出：1
```

---

提示：

- `1 <= arr1.length, arr2.length <= 500`
- `-10^3 <= arr1[i], arr2[j] <= 10^3`
- `0 <= d <= 100`

## 2. 🎯 s.1 - 暴力解法

::: code-group

```js [js]
/**
 * @param {number[]} arr1
 * @param {number[]} arr2
 * @param {number} d
 * @return {number}
 */
var findTheDistanceValue = function (arr1, arr2, d) {
  let count = 0

  // 遍历 arr1 中的每个元素
  for (const num1 of arr1) {
    let isValid = true

    // 检查当前元素是否与 arr2 中所有元素的距离都大于 d
    for (const num2 of arr2) {
      if (Math.abs(num1 - num2) <= d) {
        isValid = false
        break // 找到一个不符合条件的就跳出
      }
    }

    if (isValid) {
      count++
    }
  }

  return count
}

// 使用 every 方法的简化版本：
/* 
var findTheDistanceValue = function(arr1, arr2, d) {

        if (arr2.every(num2 => Math.abs(num1 - num2) > d)) {
            count++;
        }
    }

};
*/
```

:::

- 时间复杂度：$O(m \times n)$，其中 $m$、$n$ 分别为两个数组长度，双重循环暴力匹配
- 空间复杂度：$O(1)$，仅使用了常数空间

算法思路：

- 遍历 `arr1` 中的每个元素 `num1`
- 内部遍历 `arr2` 检查是否存在元素 `num2` 满足 `|num1 - num2| <= d`
- 若不存在满足条件的 `num2`，则计数加 1

## 3. 🎯 s.2 - 排序 + 二分

::: code-group

```js [js]
/**
 * @param {number[]} arr1
 * @param {number[]} arr2
 * @param {number} d
 * @return {number}
 */
var findTheDistanceValue = function (arr1, arr2, d) {
  arr2.sort((a, b) => a - b)

  let count = 0

  for (const x of arr1) {
    const pos = lowerBound(arr2, x)
    const leftOk = pos - 1 >= 0 ? Math.abs(x - arr2[pos - 1]) > d : true
    const rightOk = pos < arr2.length ? Math.abs(x - arr2[pos]) > d : true
    if (leftOk && rightOk) count++
  }

  return count
}

// 返回第一个 >= target 的下标
function lowerBound(nums, target) {
  let l = 0
  let r = nums.length
  while (l < r) {
    const m = (l + r) >> 1
    if (nums[m] < target) l = m + 1
    else r = m
  }
  return l
}
```

:::

- 时间复杂度：$O((m + n) \log n)$，排序 `arr2` 并对每个 `arr1` 元素二分
- 空间复杂度：$O(1)$，原地排序外仅常数空间

算法思路：

- 使用排序 + 二分查找优化方案，将暴力法的 $O(m \times n)$ 优化到了 $O((m + n) \log n)$
- 先将 `arr2` 升序排序
- 对每个 `arr1[i]` 用二分找到 `arr2` 中第一个大于等于它的元素位置 `pos`
- 检查 `pos` 的左右相邻元素与 `arr1[i]` 的差值是否都大于 `d`
  - `pos` 相邻元素的特殊性：`arr2` 排序后，与 `x` 距离最近的一定是 `x` 在 `arr2` 中插入位置附近的元素
  - 如果这两个邻居都满足 `|x - neighbor| > d`，那么其他元素必然也满足（因为距离更远）
- 若左右都安全，则该元素计入距离值

示例验证：

```txt
示例 1：
arr1 = [4,5,8], arr2 = [10,9,1,8], d = 2
排序 arr2 = [1,8,9,10]

x=4: lowerBound=1 (元素8)
  |4-1|=3>2 ✓, |4-8|=4>2 ✓ → 计数+1

x=5: lowerBound=1 (元素8)
  |5-1|=4>2 ✓, |5-8|=3>2 ✓ → 计数+1

x=8: lowerBound=2 (元素9)
  |8-8|=0>2 ✗ → 不计数

结果：2
```
