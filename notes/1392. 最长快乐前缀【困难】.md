## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/longest-happy-prefix/)

「快乐前缀」 是在原字符串中既是非空前缀也是后缀（不包括原字符串自身）的字符串。

给你一个字符串 `s`，请你返回它的最长快乐前缀。如果不存在满足题意的前缀，则返回一个空字符串 `""`。

---

示例 1：

```txt
输入：s = "level"
输出："l"
```

解释：不包括 s 自己，一共有 4 个前缀（"l", "le", "lev", "leve"）和 4 个后缀（"l", "el", "vel", "evel"）。最长的既是前缀也是后缀的字符串是 "l"。

---

示例 2：

```txt
输入：s = "ababab"
输出："abab"
```

解释："abab" 是最长的既是前缀也是后缀的字符串。题目允许前后缀在原字符串中重叠。

---

提示：

- `1 <= s.length <= 10^5`
- `s` 只含有小写英文字母

## 2. 🎯 s.1 - 前缀函数 + KMP

::: code-group

```c [c]
char* longestPrefix(char* s) {
    int n = strlen(s);
    int* lps = (int*)calloc(n, sizeof(int));

    for (int i = 1; i < n; i++) {
        int j = lps[i - 1];
        while (j > 0 && s[i] != s[j])
            j = lps[j - 1];
        if (s[i] == s[j])
            j++;
        lps[i] = j;
    }

    int prefixLen = lps[n - 1];
    char* result = (char*)malloc((prefixLen + 1) * sizeof(char));
    if (prefixLen > 0)
        memcpy(result, s, prefixLen);
    result[prefixLen] = '\0';

    free(lps);
    return result;
}
```

```js [js]
/**
 * @param {string} s
 * @return {string}
 */
var longestPrefix = function (s) {
  const n = s.length
  const lps = new Array(n).fill(0)

  for (let i = 1; i < n; i++) {
    let j = lps[i - 1]

    while (j > 0 && s[i] !== s[j]) j = lps[j - 1]
    if (s[i] === s[j]) j++

    lps[i] = j
  }

  return s.slice(0, lps[n - 1])
}
```

```py [py]
class Solution:
    def longestPrefix(self, s: str) -> str:
        n = len(s)
        lps = [0] * n

        for i in range(1, n):
            j = lps[i - 1]
            while j > 0 and s[i] != s[j]:
                j = lps[j - 1]
            if s[i] == s[j]:
                j += 1
            lps[i] = j

        return s[: lps[-1]]
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是字符串 `s` 的长度，构建前缀函数只需线性扫描一次字符串
- 空间复杂度：$O(n)$，需要额外的前缀函数数组

算法思路：

- 令 `lps[i]` 表示子串 `s[0...i]` 的最长相等真前后缀长度，也就是既是前缀又是后缀，但不能等于整个子串本身
- 从左到右构建 `lps` 数组：如果当前字符和已有前后缀的下一个字符相等，就扩展匹配长度；如果不等，就利用之前算出的 `lps` 值回退到更短的候选前后缀继续尝试
- 当扫描完整个字符串后，`lps[n - 1]` 就是整个字符串 `s` 的最长快乐前缀长度，答案即为 `s[0...lps[n - 1) ]`
