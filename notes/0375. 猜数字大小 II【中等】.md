## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/guess-number-higher-or-lower-ii/)

我们正在玩一个猜数游戏，游戏规则如下：

1. 我从 `1` 到 `n` 之间选择一个数字。
2. 你来猜我选了哪个数字。
3. 如果你猜到正确的数字，就会 赢得游戏。
4. 如果你猜错了，那么我会告诉你，我选的数字比你的 更大或者更小，并且你需要继续猜数。
5. 每当你猜了数字 `x` 并且猜错了的时候，你需要支付金额为 `x` 的现金。如果你花光了钱，就会 输掉游戏。

给你一个特定的数字 `n`，返回能够 确保你获胜 的最小现金数，不管我选择那个数字。

## 2. 🎯 s.1 - 区间 DP

::: code-group

```c [c]
int getMoneyAmount(int n) {
    int dp[n + 2][n + 2];
    memset(dp, 0, sizeof(dp));
    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            dp[i][j] = INT_MAX;
            for (int k = i; k <= j; k++) {
                int left = dp[i][k - 1], right = dp[k + 1][j];
                int cost = k + (left > right ? left : right);
                if (cost < dp[i][j]) dp[i][j] = cost;
            }
        }
    }
    return dp[1][n];
}
```

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var getMoneyAmount = function (n) {
  const dp = Array.from({ length: n + 2 }, () => new Array(n + 2).fill(0))
  for (let len = 2; len <= n; len++) {
    for (let i = 1; i + len - 1 <= n; i++) {
      const j = i + len - 1
      dp[i][j] = Infinity
      for (let k = i; k <= j; k++) {
        const cost = k + Math.max(dp[i][k - 1], dp[k + 1][j])
        dp[i][j] = Math.min(dp[i][j], cost)
      }
    }
  }
  return dp[1][n]
}
```

```py [py]
class Solution:
    def getMoneyAmount(self, n: int) -> int:
        dp = [[0] * (n + 2) for _ in range(n + 2)]
        for length in range(2, n + 1):
            for i in range(1, n - length + 2):
                j = i + length - 1
                dp[i][j] = float('inf')
                for k in range(i, j + 1):
                    cost = k + max(dp[i][k - 1], dp[k + 1][j])
                    dp[i][j] = min(dp[i][j], cost)
        return dp[1][n]
```

:::

- 时间复杂度：$O(n^3)$
- 空间复杂度：$O(n^2)$

算法思路：

- $dp[i][j]$ 表示在 $[i, j]$ 范围内确保胜利的最小开销
- 枚举猜 $k$，代价为 $k + \max(dp[i][k-1],\ dp[k+1][j])$
- 取所有 $k$ 的最小值
