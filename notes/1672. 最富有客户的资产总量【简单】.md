## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/richest-customer-wealth/)

给你一个 `m x n` 的整数网格 `accounts`，其中 `accounts[i][j]` 是第 `i​​​​​` 位客户在第 `j` 家银行托管的资产数量。返回最富有客户所拥有的资产总量。

客户的资产总量就是他们在各家银行托管的资产数量之和。最富有客户就是资产总量最大的客户。

---

示例 1：

```txt
输入：accounts = [[1,2,3],[3,2,1]]
输出：6
```

解释：

- 第 1 位客户的资产总量 = 1 + 2 + 3 = 6
- 第 2 位客户的资产总量 = 3 + 2 + 1 = 6
- 两位客户都是最富有的，资产总量都是 6，所以返回 6。

---

示例 2：

```txt
输入：accounts = [[1,5],[7,3],[3,5]]
输出：10
```

解释：

- 第 1 位客户的资产总量 = 6
- 第 2 位客户的资产总量 = 10
- 第 3 位客户的资产总量 = 8
- 第 2 位客户是最富有的，资产总量是 10

---

示例 3：

```txt
输入：accounts = [[2,8,7],[7,1,3],[1,9,5]]
输出：17
```

---

提示：

- `m == accounts.length`
- `n == accounts[i].length`
- `1 <= m, n <= 50`
- `1 <= accounts[i][j] <= 100`

## 2. 🎯 s.1 - 行求和取最大

::: code-group

```c [c]
int maximumWealth(int** accounts, int accountsSize, int* accountsColSize) {
    int ans = 0;
    for (int i = 0; i < accountsSize; i++) {
        int sum = 0;
        for (int j = 0; j < accountsColSize[i]; j++) {
            sum += accounts[i][j];
        }
        if (sum > ans) ans = sum;
    }
    return ans;
}
```

```js [js]
/**
 * @param {number[][]} accounts
 * @return {number}
 */
var maximumWealth = function (accounts) {
  let ans = 0

  for (const row of accounts) {
    let sum = 0
    for (const v of row) sum += v
    if (sum > ans) ans = sum
  }

  return ans
}
```

```py [py]
class Solution:
    def maximumWealth(self, accounts: List[List[int]]) -> int:
        return max(sum(row) for row in accounts)
```

:::

- 时间复杂度：$O(M \times N)$，其中 M 是客户数量，N 是银行数量，需要遍历所有元素
- 空间复杂度：$O(1)$，只使用常数额外空间

算法思路：

- 初始化最大资产总量 `ans` 为 0
- 遍历每个客户（每一行）：
  - 初始化当前客户的资产总和 `sum` 为 0
  - 遍历该客户在各银行的资产，累加到 `sum`
  - 如果 `sum` 大于 `ans`，更新 `ans`
- 返回 `ans`，即为最富有客户的资产总量
