## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/maximum-number-of-operations-to-move-ones-to-the-end/)

给你一个 二进制字符串 `s`。

你可以对这个字符串执行 任意次 下述操作：

- 选择字符串中的任一下标 `i`（ `i + 1 < s.length` ），该下标满足 `s[i] == '1'` 且 `s[i + 1] == '0'`。
- 将字符 `s[i]` 向 右移 直到它到达字符串的末端或另一个 `'1'`。例如，对于 `s = "010010"`，如果我们选择 `i = 1`，结果字符串将会是 `s = "000110"`。

返回你能执行的 最大 操作次数。

---

示例 1：

输入：s = "1001101"

输出：4

解释：

可以执行以下操作：

- 选择下标 `i = 0`。结果字符串为 `s = "0011101"`。
- 选择下标 `i = 4`。结果字符串为 `s = "0011011"`。
- 选择下标 `i = 3`。结果字符串为 `s = "0010111"`。
- 选择下标 `i = 2`。结果字符串为 `s = "0001111"`。

---

示例 2：

输入：s = "00111"

输出：0

---

提示：

- `1 <= s.length <= 10^5`
- `s[i]` 为 `'0'` 或 `'1'`。

## 2. 🎯 s.1 - 一次遍历

::: code-group

```js [js]
/**
 * @param {string} s
 * @return {number}
 */
var maxOperations = function(s) {
  let ones = 0, ops = 0
  for (let i = 0; i < s.length; i++) {
    if (s[i] === '1') {
      ones++
    } else if (i > 0 && s[i - 1] === '1') {
      ops += ones
    }
  }
  return ops
}
```

:::

- 时间复杂度：$O(n)$，遍历字符串
- 空间复杂度：$O(1)$，只用常数额外空间

算法思路：

- 维护当前已遇到的 1 的个数 ones
- 当遇到 '10' 模式（从 1 到 0 的边界）时，所有已有的 1 都会操作一次
- 累加 ones 到结果
