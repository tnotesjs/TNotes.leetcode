## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/count-number-of-pairs-with-absolute-difference-k/)

给你一个整数数组 `nums` 和一个整数 `k`，请你返回数对 `(i, j)` 的数目，满足 `i < j` 且 `|nums[i] - nums[j]| == k`。

`|x|` 的值定义为：

- 如果 `x >= 0`，那么值为 `x`。
- 如果 `x < 0`，那么值为 `-x`。

---

示例 1：

```txt
输入：nums = [1,2,2,1], k = 1
输出：4
解释：差的绝对值为 1 的数对为：
- [1,2,2,1]
- [1,2,2,1]
- [1,2,2,1]
- [1,2,2,1]
```

示例 2：

```txt
输入：nums = [1,3], k = 3
输出：0
解释：没有任何数对差的绝对值为 3。
```

示例 3：

```txt
输入：nums = [3,2,1,5,4], k = 2
输出：3
解释：差的绝对值为 2 的数对为：
- [3,2,1,5,4]
- [3,2,1,5,4]
- [3,2,1,5,4]
```

---

提示：

- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`
- `1 <= k <= 99`

## 2. 🎯 s.1 - 哈希计数差值

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var countKDifference = function (nums, k) {
  const cnt = new Array(101).fill(0)
  let ans = 0

  for (const x of nums) {
    const low = x - k
    const high = x + k
    if (low >= 1) ans += cnt[low]
    if (high <= 100) ans += cnt[high]
    cnt[x] += 1
  }

  return ans
}
```

:::

- 时间复杂度：$O(N)$
- 空间复杂度：$O(1)$

算法思路：

- 用计数表记录已遍历值，对每个当前值累加 `cnt[x - k] + cnt[x + k]`，再更新计数，即可线性统计绝对差为 k 的数对。
