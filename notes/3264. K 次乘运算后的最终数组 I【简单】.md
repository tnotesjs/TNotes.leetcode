## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/final-array-state-after-k-multiplication-operations-i/)

给你一个整数数组 `nums`，一个整数 `k` 和一个整数 `multiplier`。

你需要对 `nums` 执行 `k` 次操作，每次操作中：

- 找到 `nums` 中的 最小 值 `x`，如果存在多个最小值，选择最 前面 的一个。
- 将 `x` 替换为 `x * multiplier`。

请你返回执行完 `k` 次乘运算之后，最终的 `nums` 数组。

---

示例 1：

输入：nums = [2,1,3,5,6], k = 5, multiplier = 2

输出：[8,4,6,5,6]

解释：

| 操作       | 结果              |
| ---------- | ----------------- |
| 1 次操作后 | `[2, 2, 3, 5, 6]` |
| 2 次操作后 | `[4, 2, 3, 5, 6]` |
| 3 次操作后 | `[4, 4, 3, 5, 6]` |
| 4 次操作后 | `[4, 4, 6, 5, 6]` |
| 5 次操作后 | `[8, 4, 6, 5, 6]` |

---

示例 2：

输入：nums = [1,2], k = 3, multiplier = 4

输出：[16,8]

解释：

| 操作       | 结果      |
| ---------- | --------- |
| 1 次操作后 | `[4, 2]`  |
| 2 次操作后 | `[4, 8]`  |
| 3 次操作后 | `[16, 8]` |

---

提示：

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `1 <= k <= 10`
- `1 <= multiplier <= 5`

## 2. 🎯 s.1 - 模拟

::: code-group

```js [js]
/**
 * @param {number[]} nums
 * @param {number} k
 * @param {number} multiplier
 * @return {number[]}
 */
var getFinalState = function (nums, k, multiplier) {
  for (let i = 0; i < k; i++) {
    // 找到最小值的下标（最前面的）
    let minIdx = 0
    for (let j = 1; j < nums.length; j++) {
      if (nums[j] < nums[minIdx]) {
        minIdx = j
      }
    }
    // 乘以 multiplier
    nums[minIdx] *= multiplier
  }

  return nums
}
```

:::

- 时间复杂度：$O(k \times n)$，其中 n 是数组长度，执行 k 次操作，每次找最小值需要 $O(n)$
- 空间复杂度：$O(1)$，原地修改数组

算法思路：

- 模拟 k 次操作过程
- 每次操作：遍历数组找到最小值的下标（相同最小值取最前面的）
- 将该位置的值乘以 multiplier
