## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/elimination-game/)

列表 `arr` 由在范围 `[1, n]` 中的所有整数组成，并按严格递增排序。请你对 `arr` 应用下述算法：

- 从左到右，删除第一个数字，然后每隔一个数字删除一个，直到到达列表末尾。
- 重复上面的步骤，但这次是从右到左。也就是，删除最右侧的数字，然后剩下的数字每隔一个删除一个。
- 不断重复这两步，从左到右和从右到左交替进行，直到只剩下一个数字。

给你整数 `n`，返回 `arr` 最后剩下的数字。

---

示例 1：

```txt
输入：n = 9
输出：6
解释：
arr = [1, 2, 3, 4, 5, 6, 7, 8, 9]
arr = [2, 4, 6, 8]
arr = [2, 6]
arr = [6]
```

---

示例 2：

```txt
输入：n = 1
输出：1
```

---

提示：

- `1 <= n <= 10^9`

## 2. s.1 - 数学递推

::: code-group

```c [c]
int lastRemaining(int n) {
    int head = 1, step = 1, remaining = n;
    bool left = true;
    while (remaining > 1) {
        if (left || remaining % 2 == 1) head += step;
        step *= 2;
        remaining /= 2;
        left = !left;
    }
    return head;
}
```

```js [js]
/**
 * @param {number} n
 * @return {number}
 */
var lastRemaining = function (n) {
  let head = 1,
    step = 1,
    left = true,
    remaining = n
  while (remaining > 1) {
    if (left || remaining % 2 === 1) head += step
    step *= 2
    remaining = Math.floor(remaining / 2)
    left = !left
  }
  return head
}
```

```py [py]
class Solution:
    def lastRemaining(self, n: int) -> int:
        head, step, remaining, left = 1, 1, n, True
        while remaining > 1:
            if left or remaining % 2 == 1:
                head += step
            step *= 2
            remaining //= 2
            left = not left
        return head
```

:::

- 时间复杂度：$O(\log n)$
- 空间复杂度：$O(1)$

算法思路：

- 跟踪剩余序列的首元素 `head`，步长 `step`，方向 `left`
- 从左开始或剩余为奇数时，`head` 移动一步
- 每轮后步长翻倍、数量减半、方向反转

### 2.1. 递推流程

核心就一句：**只盯着当前剩余序列的第一个数 `head`，判断这一轮会不会把它删掉；会就把它换成下一个幸存者。**

以 `n = 9` 为例，初始是 `[1,2,3,4,5,6,7,8,9]`，`head=1`，`step=1`（相邻差 1）。

1. **从左往右**：第一个一定删掉，所以 `head` 必须变成 `1+1=2`。删完后剩 `[2,4,6,8]`，人数减半，步长变 2。
2. **从右往左**：现在 `remaining=4` 是偶数。从右删时，删的是末尾那一侧，**不会动到左边的 `head=2`**，所以 `head` 不动。剩 `[2,6]`，步长变 4。
3. **再从左往右**：又会删掉当前第一个，`head` 变成 `2+4=6`。只剩一个，结束。

规律概括成代码里的那句：

- **从左删**：`head` 一定被删，所以 `head += step`
- **从右删**：只有剩余个数是奇数时，最左边那个也会轮到被删，才 `head += step`；偶数时左边安全，不动

每轮之后 `step *= 2`（幸存者之间的间隔翻倍）、`remaining /= 2`、方向反转。**循环到只剩 1 个数，`head` 就是答案**。
