## 1. 📝 题目描述

- [leetcode](https://leetcode.cn/problems/check-if-a-string-contains-all-binary-codes-of-size-k/)

给你一个二进制字符串 `s` 和一个整数 `k`。如果所有长度为 `k` 的二进制字符串都是 `s` 的子串，请返回 `true`，否则请返回 `false`。

---

示例 1：

```txt
输入：s = "00110110", k = 2
输出：true

解释：
长度为 2 的二进制串包括 "00"，"01"，"10" 和 "11"。
它们分别是 s 中下标为 0，1，3，2 开始的长度为 2 的子串。
```

示例 2：

```txt
输入：s = "0110", k = 1
输出：true

解释：
长度为 1 的二进制串包括 "0" 和 "1"，显然它们都是 s 的子串。
```

示例 3：

```txt
输入：s = "0110", k = 2
输出：false

解释：
长度为 2 的二进制串 "00" 没有出现在 s 中。
```

---

提示：

- `1 <= s.length <= 5 * 10^5`
- `s[i]` 不是`'0'` 就是 `'1'`
- `1 <= k <= 20`

## 2. 🎯 s.1 - 哈希集合

::: code-group

```js [js]
/**
 * @param {string} s
 * @param {number} k
 * @return {boolean}
 */
var hasAllCodes = function (s, k) {
  if (s.length < k) return false
  const seen = new Set()
  for (let i = 0; i <= s.length - k; i++) {
    seen.add(s.substring(i, i + k))
  }
  return seen.size === 1 << k
}
```

```c [c]
bool hasAllCodes(char* s, int k) {
    int n = strlen(s);
    if (n < k) return false;
    int total = 1 << k;
    int mask = total - 1;
    int* seen = (int*)calloc(total, sizeof(int));
    int hash = 0, count = 0;
    for (int i = 0; i < n; i++) {
        hash = ((hash << 1) | (s[i] - '0')) & mask;
        if (i >= k - 1 && !seen[hash]) {
            seen[hash] = 1;
            count++;
            if (count == total) { free(seen); return true; }
        }
    }
    free(seen);
    return false;
}
```

```py [py]
class Solution:
    def hasAllCodes(self, s: str, k: int) -> bool:
        if len(s) < k:
            return False
        seen: set[str] = set()
        for i in range(len(s) - k + 1):
            seen.add(s[i:i + k])
        return len(seen) == (1 << k)
```

:::

- 时间复杂度：$O(n \times k)$，其中 n 是字符串长度
- 空间复杂度：$O(2^k)$，哈希集合最多存储 $2^k$ 个不同子串

算法思路：

- 遍历字符串，提取所有长度为 k 的子串加入集合
- 最终检查集合大小是否等于 $2^k$，即是否包含了所有可能的 k 位二进制串
