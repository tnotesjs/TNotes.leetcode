## 1. 题目描述

- [leetcode](https://leetcode.cn/problems/plus-one/)

给定一个由整数组成的非空数组所表示的非负整数，在该数的基础上加一。

最高位数字存放在数组的首位，数组中每个元素只存储单个数字。

你可以假设除了整数 0 之外，这个整数不会以零开头。

---

示例 1：

```
输入：digits = [1, 2, 3]
输出：[1, 2, 4]
```

解释：输入数组表示数字 123。

---

示例 2：

```
输入：digits = [4, 3, 2, 1]
输出：[4, 3, 2, 2]
```

解释：输入数组表示数字 4321。

---

示例 3：

```
输入：digits = [9]
输出：[1, 0]
```

解释：

- 输入数组表示数字 9。
- 加 1 得到了 9 + 1 = 10。
- 因此，结果应该是 [1, 0]。

---

提示：

- `1 <= digits.length <= 100`
- `0 <= digits[i] <= 9`

## 2. s.1 - 从末尾逐位进位

::: code-group

```c [c]
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int* plusOne(int* digits, int digitsSize, int* returnSize) {
    for (int i = digitsSize - 1; i >= 0; i--) {
        if (digits[i] < 9) {
            digits[i]++;
            *returnSize = digitsSize;
            return digits;
        }
        digits[i] = 0;
    }

    // 所有位都是 9，需要新建长度为 n+1 的数组
    int* result = (int*)malloc(sizeof(int) * (digitsSize + 1));
    result[0] = 1;
    for (int i = 1; i <= digitsSize; i++) {
        result[i] = 0;
    }
    *returnSize = digitsSize + 1;
    return result;
}
```

```js [js]
/**
 * @param {number[]} digits
 * @return {number[]}
 */
var plusOne = function (digits) {
  for (let i = digits.length - 1; i >= 0; i--) {
    if (digits[i] < 9) {
      digits[i]++
      return digits
    }
    digits[i] = 0
  }

  // 所有位都是 9，在数组开头插入 1
  digits.unshift(1)
  return digits
}
```

```py [py]
class Solution:
    def plusOne(self, digits: list[int]) -> list[int]:
        for i in range(len(digits) - 1, -1, -1):
            if digits[i] < 9:
                digits[i] += 1
                return digits
            digits[i] = 0

        # 所有位都是 9，在数组开头插入 1
        return [1] + digits
```

:::

- 时间复杂度：$O(n)$，其中 $n$ 是数组长度，最坏情况所有位都是 9 需要遍历整个数组
- 空间复杂度：$O(1)$，除了返回结果外只使用常数额外空间；若所有位均为 9 则返回长度为 $n+1$ 的新数组

算法思路：

- 从数组末尾开始逐位加一，模拟手动加法中的进位过程
- 若当前位加一后小于 10，说明没有进位，直接修改该位并返回原数组
- 若当前位加一后等于 10，将该位置为 0，继续向前进位
- 若遍历完所有位仍有进位（例如 `[9, 9, 9]`），则在数组开头插入 `1`，得到 `[1, 0, 0, 0]`
