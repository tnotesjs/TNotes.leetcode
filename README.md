## 算法图解说明

### 工具

在刷题过程中，会陆续将所有涉及到含有图解说明的内容统一采用 [Excalidraw][2] 来绘制。

### 图解资源

统一放在各例题的 assets 目录下。

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs-2026@main/2026-08-05-21-59-53.png)

其中 `*.excalidraw` 是 Excalidraw 格式的绘图文件，`*.svg` 是通过导出结果，用于在笔记内引用。

### 二次编辑

通过 [VSCode 中的 Excalidraw 插件（作者 pomdtr）][3] 可以直接打开 `assets/*.excalidraw` 文件进行二次编辑，然后重新导出新的 svg，替换旧图。

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs-2026@main/2026-08-05-22-01-33.png)
